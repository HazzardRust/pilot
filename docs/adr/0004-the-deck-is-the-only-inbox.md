# The deck is the only inbox, and every item is a thread

Questions to the user used to go through `AskUserQuestion` in chat, which blocks the pilot until answered and buries the to-do list in scrollback. Every question, walkthrough and sign-off is now posted to the deck and answered there; the pilot never blocks in chat. To keep grilling's push-back, an item is a thread: the pilot posts, the user replies, the pilot may argue, and only the pilot resolves it. A read-only dashboard was rejected because it fixes neither the blocking nor the scrolling.
