# The author's machine installs the package like a friend does

Once the plugin installs cleanly, `~/environment` deletes its own copies of the agents, skills, rules, hooks and cost report and keeps only personal configuration, installing the plugin by the same pasted prompt. Two copies drift the first time one is edited, and a shipped package nobody runs is untested. The deletion happens only after the plugin is verified working on this machine, because `~/environment` is live configuration.
