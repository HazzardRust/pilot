```
pilot-co-pilot.md
  ## Steps 4 to 8        + bullet: right after each Agent(...) spawn, SendMessage the child's agentId the hello
                         + bullet: a seam change inside the rails is yours; edit the owning slice file on feat/<slug>
  ## What goes to main   (replaces "## Questions go to main"): the four items of spec 4, nothing else
```

## Tests

1. `the co-pilot greets each child so the child can address it`: `pilot-co-pilot.md` names the hello, `SendMessage`, the child's agentId and "right after".
2. `the co-pilot sends main only four things`: the "What goes to main" section names a question for the user, a seam change that moves a spec line or a locked decision, a crew hand-off it cannot resolve, and the hand-back table. "Your crew sends its own questions to `main`" is gone.
3. `a seam change inside the rails is the co-pilot's`: the sentence names the owning slice file and `feat/<slug>`.
4. `an implementer addresses its spawner`: the addressee sentence is in `pilot-implementer.md`, and no bare "to `main`" survives outside it.
5. `an implementer waits for the hello, never falls back to main`.
