# S4 `pilot integrate` refuses a PR title off the format

Feature `co-pilot-reports` · delivers spec 9 · source: `../architecture.md` §2, L9, L10, A1 · after: – (beside S1)

## Files owned

- `scripts/integrate.mjs`: the title check, after `assertPushable` and before the base merge; the header comment gains one sentence.
- `scripts/test/integrate.test.mjs`: the tests below.
- `docs/adr/0100-pr-titles-have-one-format-and-integrate-enforces-it.md` (new). Re-check the number first (A5).

## Interface

```
titleProblem(title: string, slug: string): string | null
  // null when the title fits L9 for this slug; otherwise the format it should match
integrate(branch, options): { ok, line, failing }   // signature unchanged
  refused: { ok: false, failing: [],
    line: 'NOT integrated <branch>: PR #<n> title "<title>" does not match <format>;
           retitle with gh pr edit and rerun; nothing merged or pushed' }
```

The slug is read from the checked-out `feat/<slug>`. A title starting `fix(` is held to the fix format; any other title is held to the slice format.

## Tests

1. `a slice PR titled off the format is refused before any merge`: `findPr` returns `S1 The first slice`, and HEAD is unmoved with no merge commit.
2. `the refusal names the title, the format and gh pr edit`.
3. `a lower-case slice title integrates as today`: the fixture's `feat(x): S1 the first slice`.
4. `a fix-round title integrates`: `fix(x): drop the dead helper`.
5. `no PR integrates as today` (A1): `findPr` returns null.
6. `a title with another feature's slug is refused`: `feat(y): S1 …` onto `feat/x`.

## Done

- **Expected**: the pilot or co-pilot runs `pilot integrate` on a slice whose PR is titled `S6 The tab's…`. It gets one line naming the title and the format, and nothing is merged. After `gh pr edit` the same call integrates.
- **Verification**: `node --test scripts/test/integrate.test.mjs scripts/test/integrate-base.test.mjs`; `npm test`; once, by hand, the command in a scratch clone whose `gh` (a stub first on `PATH`) returns an off-format title, reading the line it prints.
- **Evidence**: tests 1, 2 and 6 failing before and passing after; the printed refusal line.
- **Prohibited**: a second `gh` call when `findPr` already answers; a check after the merge; refusing when there is no PR (A1).
- **Done when**: the six tests and `npm test` are green and the refusal line has been read from a real run of the command.
