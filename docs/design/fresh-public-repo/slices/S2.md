# S2 Scratch and env files are ignored and the tree scans clean

Feature `fresh-public-repo` · delivers spec 1 · source: `../architecture.md` §2, §3, §5 L4 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer` (secrets: the scan is the slice's evidence)
Model: opus — it hits the security trigger, and a scan finding needs a judgement, not a rule.

## Files owned

- `.gitignore`: adds `.env`, `.env.*`, `*.local`, and root scratch (`/pb.txt`, `/*.scratch.*`); keeps `node_modules/`.
- `scripts/test/gitignore.test.mjs` (new): the pins.
- `deck/test/skeleton.test.mjs`: a trailing `// gitleaks:allow` on the five `CREDENTIALS` fixture lines the scan flags (175, 176, 177, 182, 184), made-up strings of the A6 credential-refusal test; the co-pilot's yes, assumed A7.

## Interface

```
.gitignore patterns, as `git check-ignore <path>` answers them:
  ignored: .env, .env.prod, deck/.env.local, pb.txt, notes.scratch.md
  not ignored: .env.example (stays committable), every currently tracked file
```

## Tests

1. `env and scratch files are ignored`: `.gitignore patterns` → `git check-ignore` exits 0 for each ignored path.
2. `nothing tracked is newly ignored`: `.gitignore patterns` → `git ls-files -ci --exclude-standard` prints nothing.
3. `an example env file stays committable`: `.gitignore patterns` → `git check-ignore .env.example` exits 1.

Rewrite check: reordering or merging the patterns keeps tests 1-3.

## Done

- **Expected**: a `.env` or a scratch note dropped in the checkout never shows in `git status`, and the published tree has no secret in it.
- **Verification**: `node --test scripts/test/gitignore.test.mjs`; `npm test`; the scan: `git archive HEAD | tar -x -C <scratch>/tree`, then `docker run --rm -v <scratch>:/s zricethezav/gitleaks:latest dir /s/tree -r /s/gitleaks.json` (or `gitleaks dir` from winget).
- **Evidence**: tests red before, green after; the scan's exit 0 and `gitleaks.json` (`[]`) attached to the slice PR. A finding goes to `main` with its path and rule, never its value; a false positive is listed with why, a real one stops the slice.
- **Prohibited**: ignoring a tracked file to hide it; a `.gitleaksignore` or allowlist without `main`'s yes; pasting a finding's secret anywhere; scanning the working dir with `node_modules` in it.
- **Done when**: the tests are green and the scan of the exported tree reports zero findings.
