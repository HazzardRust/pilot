## Interface

```
// deck/store-recovery.mjs
keepBackup(file: string): void
  // links file onto `${file}.bak` only if its size and mtime match the last parse noted by noteParsed; else does nothing
noteParsed(file: string, stat: fs.Stats): void
recoverStore(file: string, why: string): string | null
  // .bak parses as a deck -> file set aside as `${file}.corrupt-<YYYY-MM-DD>[-n]`, .bak's bytes written
  // through atomicWriteFileSync, one console.error line naming both, returns the restored raw; else null
```

## Tests

1. `the backup is the store a write replaced`: `keepBackup` → after two posts `deck.json.bak` equals the store after the first.
2. `a store changed behind the deck's back is not backed up`: `keepBackup` → a deck.json rewritten externally after the parse leaves `.bak` untouched.
3. `a corrupt store is set aside and the backup served`: `recoverStore` → the next `listItems` returns the backup's items, `deck.json.corrupt-<date>` holds the bad bytes byte-identical, the log line names both.
4. `a second corruption the same day does not overwrite the first`: `recoverStore` → `-2` suffix, both kept.
5. `no readable backup keeps today's refusal`: `recoverStore` → null, and `readDeck` throws the existing `unreadableStore` message.
6. `a newer version is not recovered`: `recoverStore` → never called for a version mismatch; the refusal stands and `.bak` is untouched.

Rewrite check: replacing the hard link with a copy keeps every result above.
