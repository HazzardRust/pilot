## Tests

1. Main lane: `held while a ticket is live`, `queued with none live and a next`, `empty with neither`, `switching while switches.main is pending`.
2. Co-pilot lane: `held with a live co-pilot`, `queued with yellow tickets but no co-pilot`, `empty with no yellow ticket`, `switching while switches.coPilot is pending`.
3. `a live co-pilot changes no main word, and a main switch changes no co-pilot word`.
4. `a malformed switches entry reads as none`, and so does `a record whose from or to is no longer an open red or green ticket` (L21).
5. `invariant: one in-hand row whenever an open red or green ticket exists`: over decks of only queued tickets (red, green, asked, mixed), exactly one row is `in-hand`. Only yellow tickets gives `empty` and none. A switching deck has one `in-hand` row (`from`) and no `in-hand` on `to`.
6. `the Tickets panel carries both words`: a render test.
7. `S1's co-pilot mark is unchanged through deckLanes`: co-pilot-mark.test passes.
8. `with no co-pilot, the yellow head carries the blue next chip and no row is co-pilot-held`; with a co-pilot live, no chip.
