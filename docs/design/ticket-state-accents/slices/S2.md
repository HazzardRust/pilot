# S2 Cards and thread pages wear their ticket's accent, live

Feature `ticket-state-accents` · delivers spec 3, 4, 8 · source: `../architecture.md` §2, L4-L6, L11, A3 · after: S1

Diff limit: 300 lines. Past it, stop and ask `main`.

## Files owned

- `deck/items.mjs`: `accentOf` and `standingOf`, beside `isBehind`.
- `deck/ui/render.mjs`: `renderCard` puts `data-accent` on its `<article>`. `renderThreadPage`'s KIND leads with `<span class="accent" data-accent>` and adds the ticket line with its standing.

- `deck/test/accents.test.mjs` (new): the pins.

## Interface

```
type Accent = 'green' | 'yellow' | 'red' | 'plain' | 'blue'
accentOf(item, items): Accent      // closed thread or ticket → plain; no ticket → blue; merged → host's state
type Standing = 'in hand' | 'co-pilot' | 'parked' | 'closed'
standingOf(ticket, items, coPilotTicket: string | null): Standing
// card:   <article data-accent="yellow"> / <article class="settled" data-accent="plain">
// thread: <span class="kind" data-live="kind"><span class="accent" data-accent="red"></span>… · <a class="ticket">T</a> <span class="standing">parked</span>
S1's Tab.coPilot: the co-pilot's ticket, for `co-pilot`
```

## Tests

1. `five threads draw five accents`: a green, a yellow, a red, a closed and an unticketed thread give green, yellow, red, plain and blue.
2. `a closed thread of an open ticket is plain`, and `an open thread of a closed ticket is plain`.
3. `a merged ticket's open question takes its host's accent`.
4. `a ticket's own card wears its own state`.
5. `the accent is read per draw`: the same walkthrough renders yellow, then red after `needTicket`, and the stored item has no accent field.
6. `the thread page's accent sits inside the kind region`: `data-accent` appears between `data-live="kind"` and the region's close.
7. `a walkthrough under a parked ticket names the ticket and parked`; the main slot's ticket reads `in hand`, and a co-pilot's reads `co-pilot`.

## Done

- **Expected**: the user sees each card's stripe in its ticket's colour and the same mark on the thread page. A ticket changing state recolours both without a reload.
- **Verification**: `node --test deck/test/accents.test.mjs deck/test/overview-one-ticket.test.mjs deck/test/press-refused.test.mjs`, then `npm test`.
- **Evidence**: tests 1, 5 and 6 fail before the change and pass after. On a scratch deck (L2), `deck_ticket need` on a yellow ticket turns its walkthrough's card stripe and its open thread page mark from yellow to red, read from the DOM after the event. Screenshot both.
- **Prohibited**: no accent stored on any item; no new SSE event or change to `live.mjs`; no accent attribute on a `[data-live]` element itself, because innerHTML swaps would never update it.
- **Done when**: the seven tests and `npm test` are green, and the live recolour has been seen in the browser.
