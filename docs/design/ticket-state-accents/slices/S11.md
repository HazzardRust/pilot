# S11 `deck_ticket co-pilot <to>` completes a co-pilot switch; Cancel clears it

## Files owned

- `deck/store.mjs`: `setCoPilot(to, true)` with a pending co-pilot switch to `to` writes `to` live in place of `from` and clears `switches[repoKey].coPilot`, in one write. A `release` of `from` is still allowed first. `cancelSwitch(repo, lane)` clears the given lane's record and adds a user reply on `to` reading `switch cancelled`.
- `deck/server.mjs`: `/switch-cancel` takes `lane`.
- `deck/ui/render.mjs`: Cancel on the lit yellow button.
- `deck/test/co-pilot-switch-complete.test.mjs` (new): the pins.
