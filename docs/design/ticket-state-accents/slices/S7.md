# S7 The pilot hears a switch and completes it

Feature `ticket-state-accents` · delivers spec 12 (the wake and the no-session path), 13, 15 (completion) · source: `../architecture.md` L8, L13-L15, L20 · after: S6

Diff limit: 300 lines. Past it, stop and ask `main`.

## Files owned

- `deck/store.mjs`: while a switch is pending, `takeTicket(to)` parks `from`, takes `to` and clears the record in one write, and passes S4's refusal. `cancelSwitch(repo)` clears the record and adds a user reply on `to` reading `switch cancelled`. `requestSwitch(repo, to, { complete })` completes in its own write when `complete` is true.
- `deck/server.mjs`: `POST /switch-cancel` (behind `fromOwnPage`). `/switch` passes `complete: true` when the repository's tab has no live run.
- `deck/wait.mjs`: `printed()` adds `SWITCH <from|none> -> <to>: stash, then deck_ticket take <to>`, and `SWITCH cancelled`, after the fallback note.
- `deck/ui/render.mjs`: the lit button's Cancel.
- `deck/test/switch-complete.test.mjs` (new): the pins.

## Interface

```
takeTicket(id): Ticket                       // with a pending switch to `id`: park from, take id, clear, one write
cancelSwitch(repo: string): void         // DeckRefusal when none is pending
requestSwitch(repo, to, { complete = false } = {}): Switch | null   // null once completed
POST /switch-cancel  form { repo, back } -> 303 back
S6's Reply.switch: read by printed()
```

## Tests

1. `take of the pending to parks from, takes to and clears the record`: in one write.

5. `with no live run, Confirm completes at once`: the record is never left standing.
6. `after completion, the in-hand mark is on to and no button is lit`: a render test.
