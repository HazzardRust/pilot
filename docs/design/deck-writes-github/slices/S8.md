# S8 Every `gh` call goes through `deck/host.mjs`

Feature `deck-writes-github` · delivers spec 8 · source: `../architecture.md` §2, §3 Seams · after: S1 (`hostIn`), S4 (`scripts/integrate.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a process start moves in four files, the security trigger.

## Files owned

- `deck/tickets.mjs`: its private `ghIn` copy goes; `openRuns` and `tickets` default to `hostIn(cwd)`.
- `scripts/branches.mjs`: the inline `execFileSync('gh', …)` goes; `main` defaults `inject.gh` to `hostIn(cwd)`.
- `scripts/integrate.mjs`: the exported `ghIn` goes; `main` defaults `gh` to `hostIn(cwd)`.
- `scripts/land.mjs`: imports `hostIn` from `deck/host.mjs` in place of `ghIn`.
- `scripts/test/host-bar.test.mjs` (new): the grep bar and the moved defaults.

## Interface

```
S1's hostIn, HOST_VERBS: the one gh runner every default below names
openRuns(records, { gh })                  // deck/tickets.mjs, unchanged; tickets({ gh = hostIn(cwd) })
main(argv, inject?: { gh })                // scripts/branches.mjs, scripts/integrate.mjs: gh defaults to hostIn(cwd)
readyAlone({ git, gh })                    // scripts/land.mjs, unchanged; its main defaults gh to hostIn(cwd)
```

## Tests

1. `no gh process starts outside the host`: `hostIn` → a scan of `deck/` and `scripts/` (tests excluded) finds `execFileSync('gh'`, `spawn('gh'` or `spawnSync('gh'` only in `deck/host.mjs`; 3 hits on the base, 0 after.
2. `no module exports ghIn`: `hostIn` → `ghIn` is absent from every export in `deck/` and `scripts/`.
3. `the old callers keep their reads`: `openRuns` → over a fake `gh`, the same `pr list` argv and the same runs as before the move.

Rewrite check: replacing `gh` behind `hostIn` with the REST API keeps the bar at 0 and every caller's argv and result.

## Done

- **Expected**: `deck/host.mjs` is the only place a `gh` process starts; `pilot tickets`, `pilot branches`,
  `pilot integrate` and `pilot land` read and write their PRs as before.
- **Verification**: `node --test scripts/test/host-bar.test.mjs`; `npm run test:changed -- --since=<base>`;
  `npm test` in the background once.
- **Evidence**: test 1 red with 3 hits on the base, green after; the existing integrate, land, branches and tickets
  suites green unchanged.
- **Prohibited**: a verb added to `HOST_VERBS` to pass a test without a caller; an allow-list exception in the bar;
  editing an existing test's expected argv; a shell.
- **Done when**: the three tests, the existing suites and the gate are green, and the bar's scan hits only `deck/host.mjs`.
