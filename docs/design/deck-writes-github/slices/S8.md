# S8 Every `gh` call goes through `deck/host.mjs`

Feature `deck-writes-github` · delivers spec 8 · source: `../architecture.md` §2, §3 Seams · after: S1 (`hostIn`), S4 (`scripts/integrate.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a process start moves in four files, the security trigger.

## Files owned

- `deck/tickets.mjs`: its private `ghIn` copy (:24) goes; `tickets` (:127) defaults `gh` to `hostIn(cwd)`.
- `scripts/branches.mjs`: the inline `execFileSync('gh', …)` (:149) goes; `main` defaults `inject.gh` to `hostIn(cwd)`.
- `scripts/integrate.mjs`: the exported `ghIn` (:59) goes; its default (:329) becomes `hostIn(cwd)`.
- `scripts/land.mjs`: imports `hostIn` from `deck/host.mjs` in place of `ghIn` (:27, :54).
- `deck/host.mjs` (seam, co-pilot 2026-11-16): `label create` joins the allowlist with its `assertHostVerb` case and one host test; its caller is `scripts/release.mjs:98` via `land.mjs:240`, which would otherwise open the main PR unlabelled.
- `scripts/test/host-bar.test.mjs` (new): the grep bar and the moved defaults.

## Interface

```
S1's hostIn and its assertHostVerb allowlist: the one gh runner every default below names
tickets({ gh = hostIn(cwd) })              // deck/tickets.mjs; openRuns(records, { gh }) unchanged
main(argv, inject?: { gh })                // scripts/branches.mjs: gh defaults to hostIn(cwd)
land({ gh = hostIn(cwd) }), retarget({ gh, head })   // scripts/land.mjs, unchanged otherwise
```

## Tests

1. `no gh process starts outside the host`: `hostIn` → a scan of `deck/` and `scripts/` (tests excluded) finds `execFileSync('gh'`, `spawn('gh'` or `spawnSync('gh'` only in `deck/host.mjs`; 3 hits on the base, 0 after.
2. `no module exports ghIn`: `hostIn` → `ghIn` is absent from every export in `deck/` and `scripts/`.
3. `the old callers keep their reads`: `tickets` → over a fake `gh`, the same `api user` and `pr list` argv and the same runs as before the move.

Rewrite check: replacing `gh` behind `hostIn` with the REST API keeps the bar at 0 and every caller's argv and result.
Misses: a verb a caller sends that `assertHostVerb` refuses only on a path no existing test reaches; the full gate is the net.

## Done

- **Expected**: `deck/host.mjs` is the only place a `gh` process starts; `pilot tickets`, `pilot branches`,
  `pilot integrate` and `pilot land` read and write their PRs as before (`retarget`'s `pr edit --base` included).
- **Verification**: `node --test scripts/test/host-bar.test.mjs`; `npm run test:changed -- --since=<base>`; `npm test` once.
- **Evidence**: test 1 red with 3 hits on the base, green after; the existing integrate, land, branches and tickets
  suites green unchanged.
- **Prohibited**: a verb added to `assertHostVerb` without a caller; an allow-list exception in the bar;
  editing an existing test's expected argv; a shell.
- **Done when**: the three tests, the existing suites and the gate are green, and the bar's scan hits only `deck/host.mjs`.
