## Tests

1. `two missing rules are named`: `allowRow` → fail, detail names `Bash(pilot sync *)` and `Bash(pilot integrate *)` and no other.
2. `all present passes`: `allowRow` → pass.
3. `a covered rule is not missing`: `allowRow` → pass when `ask` covers the absent rule.
4. `an unreadable settings file cannot tell`: `allowRow` → `cannot tell`, exit unaffected.

Rewrite check: reading the settings another way keeps the four verdicts.
Misses: project-level `.claude/settings*.json` rules, which doctor does not read; a rule spelled another way that still matches.
