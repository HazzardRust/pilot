## Tests

1. `a prompt naming gh pr edit --base fails`: `checkReferences` → 1 failure naming the file and line.
2. `a prompt naming pilot integrate --default fails`: `checkReferences` → 1 failure.

4. `the slice PR's create passes`: `checkReferences` → 0 failures for `gh pr create --draft --base feat/<slug> --head slice/x`.
5. `the shipped tree is clean`: `checkReferences` → 0 failures over `SURFACE`.

Rewrite check: moving the patterns to their own script keeps all five results.
