# S4 The stalled-wait line names the agent that started it

Feature `wait-deadlines` · delivers spec 5 · source: `../architecture.md` §2, §5 L7, §6 A6 · after: S3 (`deck/stalled-waits.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — reads transcripts (another agent's context, ADR 0042 L5) on assumed A6.

## Files owned

- `deck/transcripts.mjs`: `holderOfCommand`, a needle search over one repository's subagent transcripts.
- `deck/stalled-waits.mjs`: `reapStalled`'s default `holder` wired to `holderOfCommand`.
- `deck/test/wait-holder.test.mjs` (new): a fixture projects dir with two subagent transcripts.

## Interface

```
holderOfCommand(repo: string, needle: string, { projectsRoot?, since? }) -> { agentType: string, agentId: string } | null
  // the one subagent transcript under projectDir(repo) whose Bash tool_use command contains needle; null for none or several;
  // returns no tool text (ADR 0042 L5); a line that does not parse is skipped;
  // a transcript whose mtime is before `since` (ms epoch) is not read: reapStalled passes now minus the row's ageS
S3's reapStalled: holder(row) -> `<agentType> <agentId>` | 'unknown', needle = row.script (the whole unwrapped wait script); takes { holder?, stallAgeS } and the default holder passes since
```

## Behaviours

1. `the holder is named` (test): `holderOfCommand` → `{ agentType: 'pilot:rust-reviewer', agentId }` for wait B's needle over a fixture of its transcript lines.
2. `ambiguity is unknown` (test): `holderOfCommand` → null when two transcripts hold the needle, and when none does.
3. `the line carries it` (test): `reapStalled` → note `… held by pilot:rust-reviewer a74c7de1fde395ad7 for 3 h` with the fixture root.

Rewrite check: replacing the transcript scan with a ledger keeps 1-3: the same holder for the same command.
Misses: a transcript format change; the next real stalled wait reads it.

## Done

- **Expected**: the pilot's line says which agent started the stalled wait, or `unknown`.
- **Verification**: `node --test deck/test/wait-holder.test.mjs deck/test/stalled-waits.test.mjs deck/test/transcripts*.test.mjs`; `npm test`.
- **Evidence**: behaviours red before, green after.
- **Prohibited**: no tool text or prompt text in the return or the line; no read outside `projectDir(repo)`.
- **Done when**: the three tests and `npm test` are green.
