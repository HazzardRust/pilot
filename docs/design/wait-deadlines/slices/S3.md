# S3 The deck stops a stalled wait and tells the pilot

Feature `wait-deadlines` · delivers spec 5, 6, 8, 9 · source: `../architecture.md` §2, §3, §5 L5-L7, §6 A1, A2, A4 · after: S2 (`unboundedWaits`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the daemon stops processes on its own proof (a process stop, the security trigger), on assumed A1, A2, A4.

## Files owned

- `deck/stalled-waits.mjs` (new): recognition of a stalled wait row, the proof, and the scan that stops through `gc`.
- `deck/daemon.mjs`: a 5-min unref'd interval calling `reapStalled` with the real adapters.
- `deck/test/stalled-waits.test.mjs` (new): the pins over fake tables, including the two live rows of waits A and B.

## Interface

```
STALL_AGE_S = 50 * 60   // A4, the same 50 min as wait-for's cap
shellScript(command: string) -> string | null      // the -c script of a bash/sh command line, unwrapped from Claude Code's eval '…'; null if none
stalledWaits(table, { runs, stallAgeS = STALL_AGE_S }) -> Array<gc row>
  // row: { pid, kind: 'shell', owner: <claude pid>, worktree: <run repo>, orphan: 'stalled <n> min', marker, repo, script, ageS }
  // only when: name bash/sh(.exe); unboundedWaits(shellScript(command)) non-empty; nearest claude ancestor is the ppid
  // of a runs[i].pid; ageS >= STALL_AGE_S; the parent of a matched pair only (the child bash is in its tree)
reapStalled({ read, runs, kill, note, holder?, stallAgeS = STALL_AGE_S }) -> string[]
  // one table read, stalledWaits, gc(rows, { kill }) stopping each with its tree, then note(repo, line) per stop:
  // `stopped stalled wait <pid> "<marker>" held by <holder|unknown> for <age>`; a read failure stops nothing
stallAgeOf(env, leashed) -> seconds   // daemon.mjs: PILOT_DECK_STALL_AGE_S (integer 1-2999) only on a leashed deck with PILOT_DECK_DIR set, else STALL_AGE_S
S2's unboundedWaits; gc.mjs's gc and stopper; store-runs' listLiveRuns; store-items' noteDeck
```

## Behaviours

1. `the recorded rows are seen` (test): `stalledWaits` → the two rows for waits A and B, built from their captured win32 command lines, ages 14 h and 3 h.
2. `only a stalled loop under a pilot run` (test): `stalledWaits` → none for a 49-min loop, a loop under a `claude` with no live run, a `node`, `claude`, `git` or bounded-wait row of any age.
3. `the stop is the shell only` (test): `reapStalled` → `kill` called once per stalled pid with its tree, never for the `claude` or run pid; one `note` per stop naming pid, marker, `unknown` and age.
4. `an unreadable table stops nothing` (test): `reapStalled` → one line, 0 kills, when `read` throws.
5. `a planted loop goes` (run): a scratch deck with `STALL_AGE_S` injected at 5 s, a real `until` loop under a registered session: gone after one tick, the line on the ticket, the session alive.

Rewrite check: replacing gc with a direct kill keeps 1-4: the same rows stopped and the same lines.
Misses: a loop the tokeniser cannot see into; the agent named (S4); QA's scratch walk reads both.
