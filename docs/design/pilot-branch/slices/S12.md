# S12 The pilot runs as main deck or sub-deck

Feature `pilot-branch` · delivers spec 7, 12, 14, 15 · source: `../architecture.md` §2, §4, L8, L17, L18, L24, L27 · after: S5, S15

## Files owned

- `agents/pilot.md`: "Modes" becomes "Sub-deck".
  - `/api/record`'s `role` says which you are, and its `budget` is how many agents you hold, yourself included. No number is written in the prompt.
  - As sub-deck: take the yellow head from step 4, never post or sign a gate, and `need` at the posted walkthrough. A refused call is never retried or routed around its refusal: record it in the run record as a blocked step with its command, do the work that does not need it, and carry on; the gate2 body lists the blocked steps for the user to resolve. On a pause notice, finish the slice in flight, park the ticket, and finish `paused`.
  - As main deck: never take yellow, and conclude red from the record.
- `scripts/test/ticket-states.test.mjs`, `scripts/test/pilot-need.test.mjs`: their autonomous pins become sub-deck pins.
- Added by the pilot, 2026-10-05, so the Done grep can come back empty and no test names a mode that is gone:
  - `agents/pilot-qa.md`: "In an autonomous run, report once it is posted and stop" (pinned at `scripts/test/ticket-states.test.mjs:128`) is reworded for a sub-deck's run, and any other `autonomous` in `agents/`. The rule itself does not change.
  - `deck/test/audit-offer.test.mjs:155-160`: the comment and the negative pin on step 1 are reworded or dropped with the modes they name.
  - `hooks/test/away.test.js:52`, `hooks/test/join.test.js:156`: comments only.
  - The pause, as S13 built it: the notice is given once, on the sub-deck's next wait, which returns at once; the daemon then answers `exit` when the run finishes `paused`.
  - The prompt budget: S5 left 4.5 tokens under the pin in `scripts/test/measure-prompt.test.mjs` (the test near line 108). Removing "Modes" must pay for "Sub-deck"; lower the pin to what you measure, never raise it.
- `CONTEXT.md`: entries for Main deck, Sub-deck and Holder; the Implementation mode entry is removed.
- `docs/adr/0085-the-sub-deck-replaces-implementation-mode.md` (new): supersedes the mode half of ADR 0060's consequences and the "autonomous" wording.
