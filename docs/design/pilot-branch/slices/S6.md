# S6 `pilot run --sub` opens the sub-deck worktree, with its tab beside its parent's

Feature `pilot-branch` · delivers spec 7, 8, 9 · source: `../architecture.md` §2, L6, L10, L24, L25, L26 · after: S1

## Files owned

- `deck/subdeck.mjs` (new): the sub-deck's directory for a main deck, and creating or refreshing its detached worktree at `origin/pilot`; `SUBDECK_ALLOW`, the one allowlist constant (L25), and `subdeckArgs()`.
- `deck/run.mjs`: `--sub` starts `claude` with its cwd in the sub-deck's worktree and `PILOT_SUB_OF` set to the main directory, adding `subdeckArgs()` to its `claude` arguments. A plain `pilot run` gets no new flag.
- `deck/client.mjs`: registration carries `parent` from `PILOT_SUB_OF`.
- `deck/store.mjs`: `registerRun` stores `parent` and refuses a second live sub-deck run for the same parent, naming the live one.
- `deck/tabs.mjs`: a tab with a parent is ordered immediately after its parent's and carries `parent`.
- `deck/ui/render.mjs` (`renderStrip`): a child tab is drawn as its parent's child, with `data-parent` and an indent marker.
- `deck/ui/deck.css`: the child marker.
- `deck/test/subdeck.test.mjs` (new), `deck/test/tabs.test.mjs`: the pins.
- `docs/adr/0086-the-sub-deck-refuses-instead-of-asking.md` (new): L24 to L26, in the repository's ADR format; it amends ADR 0039's "no permission flag" for this one session.

## Interface

```
subdeckDir(mainDir: string): string                         // <dirname(mainDir)>/<basename(mainDir)>-subdeck
openSubdeck(mainDir, { git }): { dir: string, sha: string } // worktree add --detach origin/pilot, or checkout --detach when clean; refuses a dirty one by name
POST /api/runs { repo, pid, parent? } -> 409 "<mainDir> already has a sub-deck: <dir>" while one is live
type Tab = { ...today, parent?: string }                      // repoKey of the main deck
pilot run --sub     // run from the main checkout
SUBDECK_ALLOW: string[]   // Edit, Write, Agent, mcp__plugin_pilot_deck__*, Bash(git *), Bash(gh pr *), Bash(npm *), Bash(npx *), Bash(node *), Bash(pilot *)
subdeckArgs(): string[]   // ["--permission-mode", "dontAsk", "--settings", JSON.stringify({ permissions: { allow: SUBDECK_ALLOW } })]
S1's PILOT_BRANCH
```

## Tests

1. `openSubdeck creates a detached worktree at origin/pilot`: `git worktree list` shows it.
2. `a second openSubdeck refreshes it to the new tip`, and a dirty one is refused by name.
3. `a second live sub-deck run for one parent is refused with 409 naming the first`.
4. `tabsOf puts a child tab right after its parent's`, whatever the registration order.
5. `renderStrip marks the child tab with data-parent`.
6. `subdeckArgs carries dontAsk and the allowlist under permissions.allow`, and `a plain pilot run adds neither`.
7. `a --sub start writes nothing to the config directory`: a scratch `CLAUDE_CONFIG_DIR`'s `settings.json` is byte-identical after.

## Done

- **Expected**: running `pilot run --sub` in the main checkout opens a session in `<repo>-subdeck`, and the deck strip shows its tab right of the main deck's, marked as its child.
- **Verification**: `node --test deck/test/subdeck.test.mjs deck/test/tabs.test.mjs`; `npm test`; `pilot run --sub` against a scratch deck (own `PILOT_DECK_DIR` and `PILOT_DECK_PORT`) and the strip looked at in the browser.
- **Evidence**: test 3 failing before and passing after; a screenshot of the strip.
- **Check first**: against code.claude.com/docs/en/permissions, the `Edit` and `Write` rule form that covers slice worktrees, which are siblings of the cwd created mid-run. If a bare `Edit` rule does not reach them, send the finding to `main` before choosing a path pattern.
- **Prohibited**: no headless start; no `auto` or bypass mode; no permission flag on a plain `pilot run`; no write to any `settings.json`; no allow rule beyond L25's families; never the live deck on 4321.
- **Done when**: tests are green and the screenshot shows the child tab beside its parent.
