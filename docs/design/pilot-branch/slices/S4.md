# S4 `pilot land` lands a feature on the pilot branch and names the PRs to merge first

Feature `pilot-branch` · delivers spec 2, 6, 4 · source: `../architecture.md` §2, L14, L15, L20 · after: S3

## Files owned

- `scripts/land.mjs` (new): sync, take the pilot tip into `feat/<slug>`, test, fast-forward `pilot`, retry once. Then name the open feature PRs already on `pilot` and not on the default branch, oldest first.
- `scripts/test/land.test.mjs` (new): scratch clone with a bare origin, `gh` injected.
- `bin/pilot.mjs`: the `land` subcommand and its usage line.

## Interface

```
land({ cwd, git, gh, test }): { sha: string, retried: boolean, mergeFirst: number[] }
pilot land [--test "<cmd>"] -> "landed feat/<slug> on pilot at <sha>"
                              + "merge first: #a, #b" | "merge first: none"
exit 1: not on a feat/ branch, red, or still non-fast-forward after one retake
exit 3: a conflict taking the tip
S3's sync first; S2's integrate() with no branch takes the tip
push: feat/<slug>:pilot, never forced, passing S1's assertPushable('pilot'); no PR is opened against pilot
mergeFirst: open PRs based on the default branch with a feat/ head that is an ancestor of origin/pilot and not of origin/<default>, this one excluded, ordered by when their head reached pilot; gh as argv only
```

## Tests

1. `land fast-forwards pilot to the feature tip`: `origin/pilot` equals the feat tip, and no PR is created.
2. `a pilot that moved after the take is retaken once and lands`: two features from one tip both land.
3. `still moving after one retake exits 1 and pushes nothing to pilot`.
4. `land refuses outside a feat/ branch`, naming the branch.
5. `land runs sync first`: a new main commit is on pilot after the land.
6. `land names the earlier landed feature PRs, oldest first`: with A and then B landed and unmerged, landing C prints `merge first: #A, #B`. After A merges to main it prints `#B` alone.

## Done

- **Evidence**: tests 2 and 6 failing before and passing after; the scratch clone's `git log --graph --oneline origin/pilot`.
- **Prohibited**: no `gh pr merge`; no `--force` or `--force-with-lease`; no squash; no PR opened against `pilot`.
- **Done when**: tests are green and the scratch features are on `origin/pilot` with the order printed.
