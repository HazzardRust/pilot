# S13 Pause and Resume on the sub-deck's tab

Feature `pilot-branch` · delivers spec 14 · source: `../architecture.md` §2, L17, L9 · after: S11

## Files owned

- `deck/server.mjs`:
  - `POST /subdeck/pause` and `POST /subdeck/resume`, each taking the deck's own page only (Origin equal to Host).
  - The pause notice is added to the sub-deck's next wait reply.
- `deck/store.mjs`: the sub-deck run's `pausing` and `paused` flags. A finish of `paused` clears `pausing`.
- `deck/chain.mjs`: a sub-deck that finished `paused`, or is `pausing` with its ticket parked, answers `{ exit: true }`.
- `deck/ui/render.mjs`: Pause on a live child tab, Resume on a paused one. Every rendered value goes through the existing escape.
- `deck/ui/deck.css`: the two buttons.
- `deck/client.mjs`: the notice text.
- `deck/test/subdeck-pause.test.mjs` (new): the pins.

## Interface

```
POST /subdeck/pause  { repo: <main dir> } -> 303 | 404 no sub-deck | 409 already pausing or paused
POST /subdeck/resume { repo: <main dir> } -> 303 | 409 live | refusal from S10's startSession
wait notice: "pause: finish the slice in flight, park the ticket as planned, finish paused"
S9's chainNext { exit: true }; S10's startSession(repo, { sub: true })
```

## Tests

1. `pause marks the live sub-deck pausing, and its next wait carries the notice`.
2. `a paused finish with the ticket parked yellow makes the chain answer exit`.
3. `resume on a paused sub-deck starts run --sub through S10's start`, with `spawn` injected.
4. `pause and resume refuse a foreign Origin`.
5. `the child tab draws Pause when live and Resume when paused`, with the directory name escaped (a `<` in the name renders as text).

## Done

- **Expected**: the user presses Pause mid-ticket. The slice in flight integrates, the ticket reads planned, and the window closes. Resume reopens it, and it carries on from the next slice.

- **Evidence**: test 2 failing before and passing after; the window seen closing and reopening; the record's `next` before and after.
