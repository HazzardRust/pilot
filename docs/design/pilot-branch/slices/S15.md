# S15 The agent split is the user's setting

Feature `pilot-branch` · delivers spec 15 · source: `../architecture.md` §2, L18, L27 · after: S4, S13

## Files owned

- `deck/budget.mjs` (new): the defaults (main 3, sub 5), the validation, and the ceiling warning.
- `deck/store.mjs`: the `budgets` map keyed by `repoKey`, `setBudget` and `budgetFor`.
- `deck/server.mjs`: `POST /api/budget`, and `budget` in `GET /api/record` for the caller's role.
- `bin/pilot.mjs`: the `budget` subcommand and its usage line.
- `deck/test/budget.test.mjs` (new): the pins.

## Interface

```
DEFAULT_BUDGET = { main: 3, sub: 5 }; CEILING = 8
checkBudget({ main, sub }): { budget, warning?: string }    // throws naming the field: integers; main >= 1, sub >= 2
POST /api/budget { repo, main?, sub? } -> { budget, warning? }
GET /api/record?repo=&ticket= -> { record, role, budget: number }    // this session's own number
pilot budget [--main N] [--sub N] -> "budget main <m> sub <s>" [+ "warning: <m+s> is over the ceiling of 8"]; no flags prints it
S7's role
```

## Tests

1. `a deck with no setting reports 3 to the main deck and 5 to the sub-deck`.
2. `pilot budget --main 2 --sub 6 changes what each role's record reports`.
3. `main 0, sub 1 or a non-integer is refused, naming the field and its floor`.
4. `a sum over eight is stored, with a warning naming the ceiling`.
5. `a setting on one main deck does not change another's`.

## Done

- **Expected**: the user sets the split once per deck from the terminal, and each session reads its own number at start.
- **Verification**: `node --test deck/test/budget.test.mjs`; `npm test`; `pilot budget` against a scratch deck, then `curl` its `/api/record`.
- **Evidence**: test 2 failing before and passing after; the curl output.
- **Prohibited**: no number written into a prompt file; no field in `~/.claude/settings.json`; no page control.
- **Done when**: tests are green and the scratch curl shows the stored split.
