## Interface

```
PILOT_BRANCH = 'pilot'
type Git = (args: string[]) => string            // argv only, run in cwd
assertPushable(ref: string, { git }): void       // throws naming the ref when it is the default branch (origin/HEAD)
ensurePilotBranch({ git }): { sha: string, created: boolean }   // fetch; origin/pilot's tip, or push the default tip to refs/heads/pilot first
pilot base -> "base pilot <sha>" | "base pilot <sha> (created from <default>)"
exit 1 + reason: origin unreachable or default branch unknown
exit 1 + "a run needs a git repository: run `git init` and add a remote" outside a work tree (L13)
```

## Tests

1. `base prints the pilot branch even with open feat/ branches`: a scratch clone with two `feat/` branches pushed prints `base pilot <sha>`.
2. `base creates pilot from the default tip when the remote has none`: the bare origin then has `refs/heads/pilot` at main's SHA, and the line says created.
3. `base never creates pilot over an existing one`: an existing `pilot` ahead of main is kept and printed.
4. `assertPushable refuses the default branch by name`: `main` throws naming `main`; `pilot`, `feat/x` and `design/x` pass.
5. `base exits 1 and says why when origin is unreachable`: nothing is pushed.
6. `base refuses a directory that is not a repository`: in a plain temp directory it exits 1, names `git init`, and creates nothing there (L13).

## Done

- **Expected**: in any clone, `pilot base` names `pilot` and its tip. There is no stack and no exit 3, and `pilot` exists on the remote afterwards.
- **Verification**: `node --test scripts/test/pilot-branch.test.mjs scripts/test/base.test.mjs`; `npm test`; `pilot base` in a scratch clone.
- **Evidence**: tests 2 and 4 failing before and passing after; the scratch clone's `git ls-remote origin pilot`.
- **Prohibited**: no `gh` call in `base`; no forced push; no network in tests beyond a local bare repository; never against this repository's real origin.
- **Done when**: the tests and `npm test` are green and `pilot base` in a scratch clone prints `base pilot <sha>`.
