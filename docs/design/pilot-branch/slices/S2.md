## Interface

```
baseOf(cwd): { ref: 'origin/pilot' }             // no gh, no PR read
integrate(branch?, options): same report line, "(base pilot@<sha>)"; exit 0 | 1, never 3
S1's assertPushable: checked against HEAD before every push
```

## Tests

1. `integrate merges origin/pilot before the slice`: pilot moved since the cut; the report's base names `pilot@<sha>`.
2. `integrate with no branch takes pilot alone`.
3. `integrate on a default-branch HEAD refuses and pushes nothing`, naming the branch.
4. `a Stands on line in the PR body is ignored`: the base is still pilot.
5. `a missing origin/pilot exits 1 naming pilot base`.
