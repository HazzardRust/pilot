# S14 The install asks before a push or merge to the default branch

Feature `pilot-branch` · delivers spec 13 · source: `../architecture.md` §2, A11, A6 · after: –

## Files owned

- `scripts/install-settings.mjs`: merges the ask rules into `permissions.ask` beside the `WebFetch` allows. It uses the same refusal of an unreadable `permissions` block, and one backup per write.
- `scripts/test/install-ask.test.mjs` (new): the merge, the idempotence and the preservation. It is kept apart from `install.test.mjs`, which #320 S4 edits.
- `docs/INSTALL.md`:
  - The settings row names the ask rules.
  - One paragraph names what they cannot catch (Bash rules match as written) and recommends branch protection.

## Interface

```
DEFAULT_BRANCH_ASK = [
  'Bash(git push origin main)', 'Bash(git push origin main *)', 'Bash(git push origin *:main)',
  'Bash(git push origin master)', 'Bash(git push origin master *)', 'Bash(git push origin *:master)',
  'Bash(gh pr merge *)',
]
merged into settings.permissions.ask; reported as added | already present | covered by a deny rule (left alone)
```

## Tests

1. `the install adds the ask rules to an empty settings file`.
2. `a second install adds nothing and writes nothing`.
3. `the user's own allow, ask and deny rules are kept byte for byte`, in their order.
4. `a rule the user already denies is reported and not added to ask`.
5. `an unreadable permissions block refuses as today`.

## Done

- **Expected**: after the install, any session on the machine asks before `git push origin main` or `gh pr merge`, and the user's own rules are untouched.
- **Verification**: `node --test scripts/test/install-ask.test.mjs`; `npm test`; the install run against a scratch config directory, never the real `~/.claude` (L16).
- **Evidence**: test 1 failing before and passing after; the scratch `settings.json` diff.
- **Prohibited**: no `deny` rules; no `autoMode` keys; no allow rule for any push; never write the real `~/.claude/settings.json`.
- **Done when**: tests are green and the scratch run shows exactly the seven rules added once.
