Feature `spec-first` · delivers spec 1, 4, 5, 6 · source: `../architecture.md` §2, §5 L2, L4, L8 · after: S1 (Behaviours grammar)
Reviewers: `pilot:security-reviewer`

## Files owned

- `agents/pilot-implementer.md`: the loop builds to behaviours, one evidence row each; `tdd-workflow` loaded for `test` behaviours; reviewer brief; absolutes sweep.
- `skills/tdd-workflow/SKILL.md`: description scoped to deterministic logic; body unchanged.
- `vendor/toolbox.md`: the ledger row's `adapted` text for the description.
- `VENDOR.md`: regenerated by `build-vendor-ledger` (seam, added by the co-pilot: the ledger edit makes it stale).
- `scripts/test/pilot-agents.test.mjs`: test 1, `no tdd-workflow preload` (seam, added by the co-pilot: no test file was owned).

## Interface

```
agents/pilot-implementer.md
  frontmatter skills: [verification-loop, test-design]        # tdd-workflow loaded with the Skill tool
  ## The loop        # per behaviour: build, then show it with the kind's evidence; test kind -> tdd-workflow red/green
  ## Report          # evidence rows: "B<k> <kind>: <what was seen>", one per behaviour (S2's Evidence trailer)
  reviewer brief     # judge the diff against the behaviours; missing test only for test kind or mis-marked logic
skills/tdd-workflow/SKILL.md description: "Use for deterministic logic: ..."
S1's Behaviours grammar: what the loop reads
```

## Tests

1. `no tdd-workflow preload`: `frontmatter skills` → lacks `tdd-workflow`; the existing preload-ships test stays green.
2. `the skill still ships`: `skills/tdd-workflow/SKILL.md description` → `toolbox.test.mjs` and `build-vendor-ledger --check` green.
3. `the prompt is no larger`: `## Report` → `measure-prompt` own share and total for pilot-implementer at or under 6513.5 and 10013.
4. `references hold`: `## The loop` → `check-references` green.

Rewrite check: rewording the loop with the same headings keeps all four results.
Misses: whether the loop reads as judgement with reasons; the security reviewer reads the kept-absolutes list (A4) and QA's spec-7 run shows it.

  `node scripts/check-references.mjs`; `git grep -ciwE 'never|always|must' agents/pilot-implementer.md`.
