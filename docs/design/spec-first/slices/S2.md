# S2 Integrate refuses a slice missing evidence

Feature `spec-first` · delivers spec 2, 8 · source: `../architecture.md` §2, §5 L3, L5 · after: S1 (`behavioursOf`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — `--trailer` is a CLI argument boundary (security trigger) and the refusal rests on A2.

## Files owned

- `scripts/integrate.mjs`: `assertEvidence` beside `assertSecurityVerdict`, both reading `sliceFileOf`.
- `scripts/test/integrate-slice-commit.test.mjs`: the pins.

## Interface

```
integrate(branch: string, opts: { cwd, test, install, gh, trailers: string[] }): { ok: boolean, line: string, failing: string[] }
  // refuses, nothing merged or pushed, when the slice file has behaviours and a B<k> has no trailer
Evidence trailer: "Evidence: B<k> <kind>: <one line of what was seen>"
sliceFileOf(cwd, head, slice): string | null   // internal; the lookup assertSecurityVerdict does today
S1's behavioursOf: the behaviours the trailers must cover
```

## Tests

1. `every behaviour evidenced integrates`: `integrate` → ok with one `Evidence: B<k>` trailer per behaviour, the trailers on the merge commit.
2. `a missing behaviour refuses`: `integrate` → `NOT integrated … B2 has no --trailer "Evidence: B2 …"; nothing merged or pushed`.
3. `an old-shape slice needs no evidence`: `integrate` → ok with no `Evidence:` trailer for a `## Tests` slice file.
4. `the security refusal still holds`: `integrate` → the existing security-verdict refusal, unchanged.

Rewrite check: moving the slice-file lookup elsewhere keeps all four results.
Misses: whether an evidence line is true; the reviewer and the fundamentalist read the evidence itself.

## Done

- **Expected**: a co-pilot integrating a slice with an unevidenced behaviour sees a one-line refusal naming it.
- **Verification**: `node --test scripts/test/integrate-slice-commit.test.mjs`.
- **Evidence**: test 2 red before `assertEvidence`, green after; tests 3-4 green throughout.
- **Prohibited**: checking only the count of trailers; a trailer that spans lines; skipping the check when the run record lacks a row the security check would read.
- **Done when**: the four tests pass and the existing integrate tests are green.
