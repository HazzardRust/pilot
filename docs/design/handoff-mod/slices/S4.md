# S4 A pilot session's start releases a dead co-pilot and chains nothing

Feature `handoff-mod` · delivers spec 10 · source: `../architecture.md` §2, §3 (launcher duties), §5 L12, L13 · after: S2 (`deck/run-look.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — replaces a loopback write route (an API boundary) and changes what a session's start does.

## Files owned

- `deck/server-routes.mjs`: `POST /api/chain` (717-723) becomes `POST /api/started { repo }`: `releaseCoPilot(repo)`, `announceChange()`, answers `{ released }`; same loopback and `isTrustedOrigin` guard.
- `deck/chain.mjs`: `chainNext` loses `atStart` (77-89, its `releaseCoPilot` call and `resumableRecordFor` branch); a clean finish chains as today.
- `deck/test/chain.test.mjs`: the `atStart` cases go; the finish cases stay.
- `deck/test/started-route.test.mjs` (new): the route against a scratch store.
- `deck/run-look.mjs`: `start` also POSTs `/api/started` once.
- `deck/test/run-look.test.mjs`: `start`'s release.

## Interface

```
POST /api/started  { repo: string } -> 200 { released: boolean }   // 400 without repo; refused with a foreign Origin
POST /api/chain    -> 404 (gone)
chainNext(repo, { pastMark? }) -> as today without atStart
S2's look('start', { repo }) -> { act: 'none', why: 'reported in' | 'released' }
```

## Tests

1. `started releases this repository's co-pilot and posts no hand-off`: `POST /api/started` → `released: true`, co-pilot not live, 0 `handoff` items.
2. `started leaves another repository's co-pilot live`: `POST /api/started` → that co-pilot still live.
3. `the chain route is gone`: `POST /api/chain` → 404.
4. `a clean finish still chains`: `chainNext` → one chain hand-off naming the head ticket.
5. `the look's start releases once`: `POST /api/started` → one POST per `look('start')`, the reported-in stamp still written.

Rewrite check: any other carrier for the release keeps tests 1, 2 and 5's counts.
Misses: two pilot sessions in one repository (L13's tradeoff); no test can say which is the user's.
