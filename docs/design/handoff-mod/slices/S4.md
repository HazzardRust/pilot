- `deck/run.mjs`: `run` spawns plainly with inherited stdio and `runEnv` plus `PILOT_RUN_PID`, `PILOT_RUN_REPO`; the watch keeps `registered` and the End stream and kills the child on `end`; `watch` no longer calls `clearOnce`.
- `deck/test/run.test.mjs`: the pty-start tests (1037-1230) become plain-start tests; End against a plain child.
- `deck/test/facades.test.mjs`: `loadPty` leaves the export list.

- `deck/README.md`: the `run.mjs` row reads "`pilot run`: starts the pilot; the mod clears at the hand-off".

## Tests

1. `run starts claude with inherited stdio and the run env`: `run` → `plain` got `claudeArgs`, env with `PILOT_RUN_PID`, `PILOT_RUN_REPO`.
2. `an end event kills the plain child once`: `watch` → `end` called once, child killed.
3. `watch types nothing and calls no look`: `watch` → a change event with an open hand-off writes nothing.
4. `package.json names no node-pty`: `run` → `loadPty` is not exported and `package.json` has no `node-pty` (`// lint: no-node-pty`, ADR 0180).

Rewrite check: any other spawn keeps the args, env, inherited stdio and the one kill on `end`.
Misses: the real terminal handing stdio to `claude` on Windows and in WSL; QA's `pilot run` hand-offs cover it.
