# S3 The mod hears every pilot session

Feature `handoff-mod` · delivers spec 2, 3, 4, 6 · source: `../architecture.md` §2, §5 L3, L4, L11, L12, §6 A4, A6 · after: S1 (`hooks/handoff-mod.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — timers and turn state inside the host, agent configuration (`hooks/`).

## Files owned

- `hooks/handoff-mod.mjs`: busy and idle from `turn.start` and `turn.complete`; `start` at `session.start`; the hold timers (the only looker while a hand-off is held, L12); the started check; a refused submit.
- `hooks/test/handoff-mod.test.mjs`: a fake `on`, `$` and clock.

## Interface

```
S1's register(on) and S1's look contract (ops 'start', 'turn', 'cleared', 'unstarted')
mod state: { busy: boolean, turnEndedAt: number, held: { until } | null, submitted: { id, at } | null }
session.start (main session, every pilot session)  -> look 'start'
turn.start  (main)  -> busy = true; a pending submitted.id is started
turn.complete (main) -> busy = false, turnEndedAt = now; look 'turn' --turn-ended
held        -> one timer at until - now and one every HOLD_LOOK_MS = 30_000 while held; a timer look while busy waits for turn.complete
prompt.submit rejects -> look 'unstarted' --why refused
no turn.start within STARTED_MS = 60_000 of the submit -> look 'unstarted' --why 'no turn'
```

## Tests

1. `a held outcome looks again at its bound and every 30 s, idle only`: `register` → looks at `until` and each 30 s tick; none while busy, one at the next `turn.complete`.
2. `a release ends the timers`: `register` → after a `clear` outcome no timer remains.
3. `session.start runs start once`: `register` → one `start` look; none after a clear (the host does not refire it).
4. `a refused submit is said`: `register` → `unstarted --why refused` after `prompt.submit` rejects.
5. `no turn.start within 60 s is said; one inside it is not`: `register` → one `unstarted --why 'no turn'`, or none.
6. `the turn-ended time passed to the look is the last turn.complete`: `register` → argv carries it.

Rewrite check: any other timer source keeps the looks at the same moments and never one mid-turn.
Misses: the real host's event order and clock; the live check below and QA's five hand-offs cover them.
