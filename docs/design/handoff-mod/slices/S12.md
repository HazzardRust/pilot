# S12 `pilot start` opens a pilot window and exits

Feature `handoff-mod` · delivers spec 13 · source: `../architecture.md` §2, §5 L12, L15, §6 A4 · after: S7 (`bin/pilot.mjs`), S9 (`openPilot`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI verb that starts a process (the security trigger), bounded by L15's "holds no child".

## Files owned

- `bin/pilot.mjs`: a `start` verb: `openPilot(process.cwd(), { reach: readReach() })`, then exit 0; off Windows it prints the `claude` argv from `startArgs` and exits 0; any argument is refused with the usage; one help line `pilot start   open a pilot session in a new window (any reach)`.
- `deck/test/pilot-start.test.mjs` (new): the verb against a fake spawn and a scratch home.

## Interface

```
pilot start            -> exit 0 after one detached openPilot; never awaits the child
pilot start <anything> -> exit 2, the usage
S9's openPilot(repo, deps) and S9's startArgs(reach, opts)
```

## Tests

1. `start opens one window and returns`: `pilot start` → 1 detached, unref'd spawn; exit 0 with the fake child still running.
2. `start passes the reach's plugin and rules`: `pilot start` → at reach `nothing` the argv carries `--settings <file>` enabling `pilot@pilot` and `--add-dir <rules root>`.
3. `start takes no argument`: `pilot start` → exit 2 and 0 spawns for `pilot start --now`.
4. `nothing on the hand-off path reads what start wrote`: `pilot start` → `grep -rl start-settings hooks deck/run-look.mjs scripts/handoff.mjs deck/client.mjs` finds 0 files (`// lint: start-is-not-mechanics`, ADR 0180).

Rewrite check: any other way to open the window keeps 1 spawn, exit 0 and no awaited child.
Misses: non-Windows terminals; off Windows the verb only prints the command.

## Done

- **Expected**: in a terminal, `pilot start` opens the pilot in a new window in that directory and gives the prompt back at once; it never takes part in a hand-off.
- **Verification**: `node --test deck/test/pilot-start.test.mjs`; the gate in `../brief.md`; live, in Git Bash in a scratch checkout: `time node bin/pilot.mjs start`.
- **Evidence**: tests 1-4 red before, green after; `time` under 2 s and the window seen.
- **Prohibited**: no wait on the child; no stdio inherited; no prompt on the line; no write the hand-off path reads; no second window builder beside S9's.
- **Done when**: the four tests and the gate are green and the live start returned under 2 s with a window open.
