## Tests

1. `a finish that chains names the hand-off in its answer`: `deck_record` → the line ends `; chained itm_<hex>.`
2. `a finish that does not chain names none`: `deck_record` → no `chained`.
3. `the client stamps a chained id for its session`: `notePosted` → `posted-<CLAUDE_PID>.stamp` holds the id.
4. `an answer without a well-shaped id stamps nothing`: `notePosted` → null for `chained itm_X;rm`, no file.

Rewrite check: any other route from the finish to the stamp keeps tests 3 and 4's files.
Misses: whether the MCP client's session pid equals the look's; the live check below proves it.
