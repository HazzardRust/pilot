## Interface

```
// hooks/handoff-mod.mjs
export function register(on: (event: string, handler: ($, e, next) => Promise<unknown>) => void): void
// deck/run-look.mjs — the whole contract; S1 implements 'turn' and 'cleared', S2 the rest
type Op = 'start' | 'turn' | 'cleared' | 'unstarted'
type Outcome = { act: 'none', why: string } | { act: 'held', id: string, until: number }
  | { act: 'clear', id: string } | { act: 'submit', id: string, prompt: string } | { act: 'said', id: string, why: string }
export async function look(op: Op, args: { repo: string, id?: string, turnEndedAt?: number, why?: string }, deps?: { read?, coPilot?, now?, say? }): Promise<Outcome>
export async function main(argv: string[], io?: { out: (line: string) => void }): Promise<number>
// CLI: node <root>/deck/run-look.mjs <op> --repo <dir> [--id itm_<hex>] [--turn-ended <ms>] [--why <text>]
//      prints one JSON Outcome line, exit 0; a refused argument is exit 2 and no line
// reported in: `start` writes ~/.claude/pilot-inbox/claims/mod-<PILOT_RUN_PID>.stamp
// deck/run-env.mjs: runEnv(reach) also carries PILOT_PLUGIN_ROOT (the plugin root)
```

## Tests

1. `turn with an open hand-off answers clear and takes the claim`: `look` → `{ act: 'clear', id }`, `clear-typed-<id>.claim` exists; a second `turn` → `{ act: 'none' }`.
2. `cleared with the lane's marker answers the prompt`: `look` → `{ act: 'submit', prompt: 'Pick up the hand-off on the deck.' }`.
3. `an id that is not itm_<hex> is refused before any read`: `main` → exit 2, no line, no claim.
4. `turn.complete runs the look, clears, then submits`: `register` → fake `$` saw `process.run` (fixed argv from `PILOT_PLUGIN_ROOT`), `command.run({ command: 'clear' })`, `process.run` `cleared`, `prompt.submit({ text })`, in that order.
5. `a subagent's turn.complete and a session without PILOT_RUN_REPO do nothing`: `register` → no `$` call.
6. `runEnv carries PILOT_PLUGIN_ROOT`: `runEnv` → the plugin root.

Rewrite check: replacing the CLI with any other process boundary keeps the call order of test 4 and the outcomes of 1-3.
