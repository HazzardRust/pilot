## Interface

```
// hooks/handoff-mod.mjs
export function register(on: (event: string, handler: ($, e, next) => Promise<unknown>) => void): void
// deck/run-look.mjs — the whole contract; S1 implements 'turn' and 'cleared', S2 the rest
type Op = 'start' | 'turn' | 'cleared' | 'unstarted'
type Outcome = { act: 'none', why: string } | { act: 'held', id: string, until: number }
  | { act: 'clear', id: string } | { act: 'submit', id: string, prompt: string } | { act: 'said', id: string, why: string }
export async function look(op: Op, args: { repo?: string, id?: string, turnEndedAt?: number, why?: string }, deps?: { read?, coPilot?, now?, say?, env?, ppid? }): Promise<Outcome>
export function sessionPid(env, ppid): number   // CLAUDE_PID, else ppid
export async function main(argv: string[], io?: { out: (line: string) => void }): Promise<number>
// CLI: node <root>/deck/run-look.mjs <op> [--repo <dir>] [--id itm_<hex>] [--turn-ended <ms>] [--why <text>]
//      repo defaults to listeningRepo(cwd); one JSON Outcome line, exit 0; a refused argument is exit 2, no line
// posted:      claims/posted-<session pid>.stamp holds the id `pilot handoff` posted (A6)
// reported in: claims/mod-<session pid>.stamp, written by 'start' (S2), read by `pilot handoff` (S6)
// scripts/handoff.mjs
export async function handoff({ cwd, env, trailers }): Promise<{ ok: boolean, line: string }>
```

## Tests

1. `turn in the session that posted the hand-off answers clear and takes the claim`: `look` → `{ act: 'clear', id }`, `clear-typed-<id>.claim` exists; a second `turn` → `{ act: 'none' }`.
2. `turn in a session that posted nothing clears nothing`: `look` → `{ act: 'none' }` with an open hand-off and no `posted-<pid>.stamp`.
3. `cleared with the lane's marker answers the prompt and drops the posted stamp`: `look` → `{ act: 'submit', prompt: 'Pick up the hand-off on the deck.' }`.
4. `an id that is not itm_<hex> is refused before any read`: `main` → exit 2, no line, no claim.
5. `the session pid is CLAUDE_PID, else the parent`: `sessionPid` → 4242 from env, the ppid without it.
6. `turn.complete runs the look, clears, then submits`: `register` → fake `$` saw `process.run` (fixed argv, the look's path from the module's own URL), `command.run({ command: 'clear' })`, `process.run` `cleared`, `prompt.submit({ text })`, in that order.
7. `a subagent's turn.complete does nothing`: `register` → no `$` call.
8. `a hand-off from a worktree is posted for the checkout and stamped for the session`: `handoff` → item `repo` is the main checkout; `posted-<CLAUDE_PID>.stamp` holds its id.

Rewrite check: replacing the CLI with any other process boundary keeps the call order of test 6 and the outcomes of 1-5 and 8.
Misses: whether the host sets `import.meta.url` and `CLAUDE_PID` for a real mod; the live check below proves both.
