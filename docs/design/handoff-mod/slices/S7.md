# S7 A session where the mod cannot run is told at the hand-off

Feature `handoff-mod` · delivers spec 8 · source: `../architecture.md` §2, §5 L7, L10, L11, §6 A2 · after: S1 (`scripts/handoff.mjs`), S2 (the reported-in stamp)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — spec 8's minimum is assumed (A2), and `pilot handoff` is the CLI that clears a session.

## Files owned

- `scripts/handoff.mjs`: `wrapperAlive` (57) and `PILOT_RUN_PID` (37) give way to the reported-in check; the line (179-181) says the mod clears, or that it has not reported in and the user types `/clear`.
- `scripts/test/handoff.test.mjs`: the line, all three ways; the wrapper-env cases (106, 192) become reported-in cases.
- `deck/doctor.mjs`: a `mods` row (deck-writes-github's S5 adds another row to `checkAll` (326); separate hunks).
- `deck/test/doctor-mods.test.mjs` (new): the row's verdicts.

## Interface

```
S1's handoff({ cwd, env, trailers }) -> { ok, line }, now with
  reportedIn(env, { version }) -> { in: boolean, why?: string }   // S1's claims/mod-<session pid>.stamp; why: 'Claude Code <v> is below 2.1.325' | 'not reported in'
  line, reported in:  `handed off: ...; posted <id>; the hand-off mod clears this session and submits the first prompt; stop here`
  line, otherwise:    `handed off: ...; posted <id>; the hand-off mod has not reported in (<why>): tell the user to type /clear, and stop`
export const MIN_MODS_VERSION = '2.1.325';
modsRow({ version, settings, env }) -> { name: 'mods', verdict: 'pass' | 'fail' | 'cannot tell', detail, steps? }
  // fail: version below minimum, disableAllHooks, CLAUDE_CODE_SAFE_MODE; cannot tell: an unreadable version
```

## Tests

1. `a session with no reported-in stamp is told to type /clear`: `reportedIn` → `{ in: false, why: 'not reported in' }`; `handoff`'s line names it and still posts.
2. `an old claude is named as the cause`: `reportedIn` → `why` names the version and the minimum.
3. `a reported-in session gets the mod's line`: `reportedIn` → `{ in: true }`; the line says the mod clears.
4. `doctor fails an old version and disableAllHooks, passes 2.1.325`: `modsRow` → the three verdicts.

Rewrite check: any other way of reading the version or the stamp keeps the same three outcomes and verdicts.
Misses: a mod that reported in at start and died mid-session; the stamp is not a heartbeat.
