# S7 A session where the mod cannot run is told

Feature `handoff-mod` · delivers spec 8 · source: `../architecture.md` §2, §6 A2 · after: S5 (`deck/run.mjs`), S2 (the reported-in stamp)
Reviewers: `pilot:typescript-reviewer`
Model: opus — spec 8's minimum is assumed (A2).

## Files owned

- `deck/run.mjs`: before the spawn, `claude --version` against `MIN_MODS_VERSION`; 30 s after it, the reported-in stamp; either failing prints one line.
- `deck/test/run-mods.test.mjs` (new): the line, both ways.
- `deck/doctor.mjs`: a `mods` row.
- `deck/test/doctor-mods.test.mjs` (new): the row's verdicts.

## Interface

```
export const MIN_MODS_VERSION = '2.1.325';
run({ ..., version = claudeVersion, reported = modReported, reportMs = 30_000 }) -> Promise<number>
  // one line: `pilot run: the hand-off mod is not running (<why>): type /clear yourself at a hand-off`
modsRow({ version, settings, env }) -> { name: 'mods', verdict: 'pass' | 'fail' | 'cannot tell', detail, steps? }
  // fail: version below minimum, disableAllHooks, CLAUDE_CODE_SAFE_MODE; cannot tell: an unreadable version
S2's reported-in stamp: claims/mod-<PILOT_RUN_PID>.stamp
```

## Tests

1. `an old claude is one line before the start`: `run` → the line names the version and the minimum; claude still starts.
2. `a mod that never reports is one line at 30 s`: `run` → the line once, naming "not reported in".
3. `a mod that reports says nothing`: `run` → no line.
4. `doctor fails an old version and disableAllHooks, passes 2.1.325`: `modsRow` → the three verdicts.

Rewrite check: any other way of reading the version keeps the same line and verdicts.

## Done

- **Expected**: `pilot run` under `--safe-mode`, an old Claude Code or mods off prints one line and the pilot starts plainly; `pilot doctor` shows the same.
- **Verification**: `node --test deck/test/run-mods.test.mjs deck/test/doctor-mods.test.mjs`; `pilot doctor`; the gate in `../brief.md`.
- **Evidence**: tests 1-4 red before, green after; `pilot doctor`'s `mods` row on this machine.
- **Prohibited**: no refusal to start; no second line per run; no read of `~/.claude.json` secrets (the version comes from `claude --version`).
- **Done when**: the four tests and the gate are green and the doctor row reads `pass` here.
