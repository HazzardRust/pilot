## Tests

1. `End is gone`: `POST /end-session` → 404.
2. `the wrapper stream is gone`: `GET /events?wrapper=` → served as the page stream's refusal or 404, never a stream that ends a session.
3. `a live tab renders no End`: `renderStrip` → no `end-session` form.
4. `a tab carries no wrapped`: `tabsOf` → no `wrapped` key.

Rewrite check: any other removal order leaves tests 1-4 and a green suite.
Misses: a page cached before the change posting `/end-session`; it gets the 404.
