## Interface

```
S1's look and Outcome, now for every Op
look('start', { repo }) -> { act: 'none', why: 'reported in' }   // writes S1's reported-in stamp; S4 adds the release
look('turn', { repo, turnEndedAt }) -> { act: 'held', id, until } | { act: 'clear', id } | { act: 'none', why }
look('cleared', { repo, id }) -> { act: 'submit', id, prompt } | { act: 'said', id, why: 'no marker' }
look('unstarted', { repo, id, why: 'refused' | 'no turn' }) -> { act: 'said', id, why }
cooldown: claims/cleared-<repoKey>.stamp, written by 'turn' on a clear; 5 min, CLEAR_COOLDOWN_MS
log lines (wrapper.log): `mod: cleared <id>` (once, in 'cleared'), `mod: submitted <id>`, `mod: not started <id> (<why>)`
```

## Tests

1. `start writes the reported-in stamp and posts nothing`: `look` → `mod-<session pid>.stamp` exists; 0 deck writes.
2. `a live co-pilot holds the clear and posts the hold`: `look` → `{ act: 'held', until }`, one `/api/hold`, claim given back.
3. `a re-arm press clears with the co-pilot live, after a turn end past the press`: `look` → `clear` only when `turnEndedAt` ≥ the press.
4. `the hold clears at 20 minutes`: `look` → `clear` at `until`, `held` a minute before.
5. `a hand-off closed or superseded before the turn ended is not cleared`: `look` → `none`, claim given back.
6. `a forged hand-off inside the cooldown clears nothing`: `look` → `none` for a fresh id 1 minute after a clear; `clear` after 5.
7. `cleared names the oldest due lander`: `look` → prompt ends ` Spawn pilot-lander <id>.`.
8. `no marker, a refused submit and no turn each say it once`: `look` → one `deck_reply` naming the cause, one log line; a second call adds none.

Rewrite check: any other store for the claim and cooldown keeps every outcome above, and 0 clears for test 6.
Misses: the real deck's timing under a live co-pilot; QA's held hand-off (acceptance 5) covers it.
