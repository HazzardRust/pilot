## Tests

1. `a join that failed is tried again by the next call`: `ensureOnTheDeck` → against a deck that refuses the first register and accepts the second, the first call is false, the second true, and `listRuns()` has one run.
2. `a joined session is not joined twice`: `ensureOnTheDeck` → two calls after a success register one run (the memo from :159 still holds).
3. `startup gives up after JOIN_ATTEMPTS`: `JOIN_ATTEMPTS` → against a deck that always refuses to register, startup makes exactly 3 register attempts, logs each, and does not reject.

Rewrite check: replacing the memo with a state machine keeps one run per session, at most `JOIN_ATTEMPTS` tries at startup, and a retry on the next call.
