## Files owned

- `deck/test/run.test.mjs`: `eventually` and `SETTLE_BUDGET_MS`; every `await settle()` that is followed by a positive assertion becomes `eventually`; `settle()` stays only before absence assertions.

## Interface

```
SETTLE_BUDGET_MS: number   // the one wait budget in run.test.mjs
eventually(predicate: () => boolean, what: string): Promise<void>   // polls until true; rejects at SETTLE_BUDGET_MS naming `what` and the budget (A4: the predicate is a boolean, so the assertion after the wait prints the actual value)
settle(): Promise<void>    // unchanged 150 ms; only before "did not happen" assertions
// unchanged, under test: wrapper.watch({ cwd, type, signal, retryMs, ... })
```

## Tests

1. `a chain at start the deck did not answer is asked again`: `eventually` → waits until `keys.typed` equals `HANDED_OFF`, then `chains.length === 2`; after a following `settle()`, still 2 ("then not again").
2. `eventually names what never happened`: `eventually` → a predicate that is never true rejects with a message containing `what`.
3. `eventually resolves as soon as the condition holds`: `eventually` → a predicate true on its third check resolves well inside `SETTLE_BUDGET_MS`.

Rewrite check: replacing `eventually`'s polling with an event the fake deck emits keeps all three results.
