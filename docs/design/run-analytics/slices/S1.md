# S1 Walking skeleton: `pilot analytics <slug>` prints one row per agent, counted once

Feature `run-analytics` · delivers spec 1 (command), 2, 6, 7, 8, 9 · source: `../architecture.md` §3, L2–L5, A4, A6, A7, A9 · after: –

## Files owned

- `deck/transcripts.mjs` (new): the shared reader (spec 9). It finds the run's sessions, reads the main and subagent transcripts, dedupes by `message.id`, and joins agents across sessions.
- `deck/analytics.mjs` (new): `main(argv)` for the subcommand, and the agent table as Markdown.
- `bin/pilot.mjs`: dispatches `analytics` and adds its line to `usage()`.
- `deck/test/transcripts.test.mjs` (new): the reader's pins.
- `deck/test/analytics.test.mjs` (new): the command's output pins.
- `deck/test/fixtures/transcripts/` (new): a synthetic projects root with two sessions, a hand-off and a resumed agent. Shapes only; every value is invented.

## Interface

```
// deck/transcripts.mjs
type TokenCounts = { input: number, cacheWrite5m: number, cacheWrite1h: number, cacheRead: number, output: number }
type AgentUsage = {
  id: string,                  // agentId, or 'pilot' for the main sessions
  role: string,                // meta agentType, 'pilot:' stripped; 'pilot' for main sessions
  description: string | null,  // the spawn description from meta, never prompt text
  parentId: string | null,     // meta parentAgentId
  models: Record<string, TokenCounts>,  // per model, each message counted once (L3)
  toolCalls: number,           // unique tool_use ids (A7)
  durationMs: number,          // sum over files of last minus first timestamp (A6)
  matched: string[],           // the needles found in the agent's earliest brief (L5)
}
type RunUsage = { sessions: string[], agents: AgentUsage[], skippedLines: number,
  claude: { costUSD: number, usage: Record<string, { input, output, cacheRead, cacheWrite }> } | null }
  // claude: one read of cost-state, null unless every session of the run has one with modelUsage
projectDir(repo: string, projectsRoot?: string): string | null   // case-insensitive munged-cwd match
readRun(repo: string, slug: string, opts?: { needles?: string[], projectsRoot?: string }): RunUsage
// projectsRoot defaults to ~/.claude/projects
// deck/analytics.mjs
main(argv: string[], opts?: { cwd?: string, repo?: string, projectsRoot?: string }): number
  // `pilot analytics <slug>`; prints Markdown to stdout, 0 or 1. cwd defaults to process.cwd(),
  // repo to the main checkout of the repository cwd is in (git runs in cwd), or cwd outside one
```

## Tests

1. `a message streamed across several entries is counted once, at its largest output`: three entries with one id give one message's input and cache tokens and the last entry's output.
2. `a resumed agent in the next session is one agent`: the same agentId in two sessions gives one AgentUsage, and its role comes from the meta that has a description.
3. `only sessions whose deck_status names the slug are read`: a third session with another slug contributes nothing.
4. `a half-written last line is skipped and counted`: `skippedLines` is 1 and nothing throws.
5. `no prompt text leaves the reader`: a planted token in a brief is absent from `JSON.stringify(readRun(...))`, and a needle it contains shows up in `matched`.
6. `the projects directory is found whatever the case of the drive path`.
7. `pilot analytics prints one row per agent and a pilot row`: runs `main` against the fixture root and checks the columns and the row count.
