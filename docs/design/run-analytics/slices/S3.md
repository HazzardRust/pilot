# S3 Cost per agent and per slice from an editable price table

Feature `run-analytics` · delivers spec 4, 5 · source: `../architecture.md` §2 lines 4–5, A1, A2 · after: S2

## Files owned

- `deck/prices.json` (new): the default price table, in dollars per million tokens per model. The implementer fills it from Anthropic's current pricing page (through `pilot:docs-lookup`) and names the page and the date in a `source` field.
- `deck/analytics.mjs`: loads the table (A1: `<store>/prices.json` overrides per model), adds a cost column to both tables, and adds the footer (price file per model, unpriced models, Claude Code's `cost-state` total, skipped lines).
- `deck/test/analytics-cost.test.mjs` (new): the pins.

## Interface

```
// deck/prices.json
{ source: string, models: Record<string, { input: number, output: number, cacheWrite5m: number, cacheWrite1h: number, cacheRead: number }> }
// deck/analytics.mjs
loadPrices(storeDir?: string): { models: Record<string, Price>, from: Record<string, string> }  // model -> file it came from
costOf(counts: Record<string, TokenCounts>, prices): number | null  // dollars; null when any model is unpriced
S1's TokenCounts: the cache-write split priced separately
store.mjs's storeDir(): where the override lives
```

## Tests

1. `an override price changes only that model's cells`: a store `prices.json` with one model changed moves that model's cost and nothing else.
2. `an unpriced model shows no price and is named in the footer`: the fixture uses a model missing from both files, and it is never costed at zero.
3. `five-minute and one-hour cache writes are priced separately`.
4. `the footer prints the cost-state total beside the table total` when one exists, and `unknown` when none does.
5. `a malformed override is refused by name`: exit 1, naming the file, with no silent fallback to the defaults.

## Done

- **Expected**: both tables have a cost column. Editing a price in `~/.claude/pilot/prices.json` and
  rerunning moves only that model's cells. The footer says the figures are API-equivalent.
- **Verification**: `node --test deck/test/analytics-cost.test.mjs`, then `npm test`, then
  `node bin/pilot.mjs analytics thread-ownership`.
- **Evidence**: tests 1 and 2 fail before and pass after. The real run's total goes in the PR
  beside the sum of its sessions' `cost-state` totals, with the gap stated as a percentage; a gap
  over 10% is reported to `main`, not tuned away.
- **Prohibited**: no prices invented or copied from `cost-state` arithmetic; no `0` for a missing
  price; no editing the prices to close the gap with `cost-state`.
- **Done when**: the test file and the full suite are green, and the real run's cost and the
  `cost-state` gap are in the PR.
