# S2 Each agent lands in its slice, and the slice rows add up

Feature `run-analytics` · delivers spec 3 · source: `../architecture.md` §3 "Slice attribution", A5, A9 · after: S1

## Files owned

- `deck/analytics.mjs`: reads the `run.json` mirror, builds needles from it, buckets each agent, and prints the slice table under the agent table.
- `deck/test/analytics-buckets.test.mjs` (new): the pins.
- `deck/test/fixtures/transcripts/`: adds a `run.json` fixture, and briefs that name slice worktrees and branches.

## Interface

```
// deck/analytics.mjs
type Bucket = string   // 'S<n>' | 'design' | 'feature' | 'pilot' | 'unattributed'
bucketOf(agent: AgentUsage, byId: Map<string, AgentUsage>, record: RunRecord): Bucket  // A5
  // the best match is the lowest rank (slice, then design, then feature), and within a rank the
  // longest needle, so a brief naming slice/<slug>-s10 lands on S10 though slice/<slug>-s1 also matches
S1's readRun: called with needles from every slice row's branch and worktree, plus design/<slug>, feat/<slug> and the feature worktree
S1's AgentUsage.matched: the only input bucketOf reads from a transcript
```

## Tests

1. `an implementer whose brief names its slice worktree lands on that slice`, even though the brief also names `feat/<slug>`.
2. `a reviewer with no match inherits its parent implementer's slice` through `parentId`.
3. `the architect's design/<slug> brief lands on design, and QA's feat/<slug> brief lands on feature`.
4. `an explorer that matches nothing lands on unattributed, and the row is printed`.
5. `the slice totals equal the agent totals`: the two tables' token and tool-call sums are equal.
6. `paths match whatever their slashes and case`: a Windows back-slashed worktree in a brief matches the forward-slashed one in run.json.

## Done

- **Expected**: `pilot analytics thread-ownership` prints S1–S6, `design`, `feature`, `pilot` and
  `unattributed`. Each implementer and its reviewer sit on their own slice, and the totals row
  matches the agent table.
- **Verification**: `node --test deck/test/analytics-buckets.test.mjs`, then `npm test`, then
  `node bin/pilot.mjs analytics thread-ownership`.
- **Evidence**: tests 1, 2 and 5 fail before and pass after. The real output's slice table goes
  in the PR with a count of the agents in `unattributed` (2 on the prototype).
- **Prohibited**: no matching on the spawn description (it is the pilot's free text, not a key);
  no hiding the `unattributed` row when it is zero or non-zero; no reaching into transcript text
  past S1's `matched`.
- **Done when**: the test file and the full suite are green, and the real run's slice totals equal
  its agent totals.
