# S5 Usage Claude Code counted and no transcript holds gets its own row

Feature `run-analytics` · delivers spec 10 · source: `../architecture.md` §2 line 10, L7 · after: S3

## Why

On thread-ownership the table totals $85.29 and Claude Code's `cost-state` $109.43. Prices are not
the cause and the reader drops nothing: the difference is tokens on the subagents' models that
`cost-state.modelUsage` counts and no transcript file holds. What produced them is not known.

## Files owned

- `deck/transcripts.mjs`: `readRun` also returns Claude Code's own counts per model, summed over the
  run's sessions, from each main transcript's last `cost-state` entry.
- `deck/analytics.mjs`: the `not in transcripts` rows, and the footer sentence.
- `deck/test/analytics-unrecorded.test.mjs` (new): the pins.
- `deck/test/fixtures/transcripts/`: a `cost-state` with `modelUsage` on one fixture session, by hand.
- `deck/test/analytics*.test.mjs`, `deck/test/transcripts.test.mjs`: only the pinned output these rows move.

## Interface

```
// deck/transcripts.mjs, readRun's result (S1's RunUsage)
claude.usage: Record<model, { input, output, cacheRead, cacheWrite }>   // claude is null when any session of the run has no cost-state with modelUsage
// deck/analytics.mjs
unrecorded(claudeUsage, agents): Record<model, { input, output, cacheRead, cacheWrite }>  // Claude Code's count minus the transcripts', per kind, signed
```

## Behaviour

- The agent table gains one row per model whose difference is not zero in every kind: agent
  `not in transcripts`, role and description `–`, the model, the four token differences, tool calls
  and duration `–`, and a cost.
- The slice table gains one `not in transcripts` row, the sum of those, after `unattributed` and
  before `Total`. `Total` includes it in both tables.
- Cost is the difference at the table's prices. `cost-state` does not split cache writes, so the
  cache-write difference is priced at the 5-minute rate, and the footer says so. An unpriced model
  shows `no price`, as everywhere else.
- A difference is shown signed. A negative one is never clamped to zero.
- When any session of the run has no `cost-state` entry, there are no such rows and the footer says
  `Claude Code's own count is unknown for this run`.
- The footer keeps both totals and adds one sentence: the rows are usage Claude Code counted that no
  transcript records, belonging to no agent or slice.

## Tests

1. `usage only cost-state holds gets a row per model`: the fixture's `modelUsage` exceeds its transcripts for one model; the row carries exactly the difference.
2. `a model that matches gets no row`.
3. `the totals include the rows, in both tables`, and the two tables' totals are equal.
4. `a session without cost-state means no rows and a footer that says so`.
5. `a negative difference is shown signed`.
