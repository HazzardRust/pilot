## Interface

```
ghStub({ dir?: string }) -> { dir, gh, env: { PATH, NODE_OPTIONS } }
  // dir: given, else fs.mkdtempSync(os.tmpdir()/pilot-gh-stub-); created if missing
  // gh: <dir>/gh.exe on win32, <dir>/gh elsewhere: a hard link to process.execPath, a copy across volumes
  // <dir>/stub.cjs: preloaded via NODE_OPTIONS=--require; a no-op unless the running exe's base name is gh/gh.exe
  // under it gh <args>: appends JSON.stringify(args) + '\n' to <dir>/calls.jsonl,
  //   writes <dir>/reply.txt to stdout ('' when absent), exits 0; no network
  // env.PATH: dir first, then process.env.PATH
main(argv: string[]) -> exit code
  // pilot gh-stub [--dir <d>] [--powershell]
  // stdout, sh (default): export PATH="<dir as /c/... under MSYSTEM>:$PATH"; export NODE_OPTIONS="--require <stub.cjs>"; # dir <dir>
  // stdout, --powershell: $env:PATH = "<dir>;" + $env:PATH; $env:NODE_OPTIONS = "--require <stub.cjs>"; # dir <dir>
  // exit 2 naming an unknown flag
pilot help  // lists "  pilot gh-stub [--dir <d>] [--powershell]" and one line under it
  // env block: "  PILOT_STOP_HOLD_MS   how long the Stop hook holds for a reply (default 570000 ms; raise it with the hook timeout in hooks/hooks.json)"
```

## Tests

1. `gh under the stub env answers from reply.txt`: `ghStub` → `execFileSync('gh', ['pr','view','12'], { env })` prints reply.txt's bytes, exit 0.
2. `every call is recorded`: `ghStub` → calls.jsonl holds exactly `["pr","view","12"]`, one line, proving the stub, not a real gh, answered.
3. `a node run under the same env is untouched`: `ghStub` → `node -e "console.log(1)"` under `env` prints `1` and writes no calls.jsonl line.
4. `the printed lines are the env`: `main` → `--powershell` and the default each print a PATH line naming the dir first and a NODE_OPTIONS line naming stub.cjs; an unknown flag exits 2.
5. `help lists it`: `pilot help` → a `  pilot gh-stub` line, read through `helpSubcommands`.
6. `help names every PILOT_ variable a hook reads`: `pilot help` → each `process.env.PILOT_*` in `hooks/*.js` appears in the env block (`// lint:`, a code-to-help check, not a phrase pin).

Rewrite check: replacing the hard-linked node with a compiled stub keeps all six results.

## Done

- **Expected**: an agent runs `eval "$(pilot gh-stub)" && gh pr view 12` in one Bash call and sees the canned reply, and the dir's calls.jsonl shows the call; real GitHub sees nothing.
- **Verification**: `node --test scripts/test/gh-stub.test.mjs scripts/test/operating-commands.test.mjs`; `node scripts/check-references.mjs`; `npm test`.
- **Evidence**: tests 1-3 red before `scripts/gh-stub.mjs` exists; a scratch Git Bash and a scratch PowerShell each running the printed lines then `gh pr view 12`, output pasted in the PR.
- **Prohibited**: no `shell: true` or `gh.cmd` (execFileSync never finds it, the trap this helper exists for); no mocking `execFileSync` in the tests; no network call in any test; no change to existing gh fakes.
- **Done when**: the six tests pass, the gate is green, and both scratch shells have shown the stub's reply.
