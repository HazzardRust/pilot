# S2 POSIX install appends the pilot block to the shell's profile

Feature `install-pilot-path` · delivers spec 1b, 2, 4, 5 · source: `../architecture.md` §2, §5, §6 A1 A4 · after: S1 (`persistPath`, `scripts/install-path.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer` (writes shell code into a profile)

## Files owned

- `scripts/install-path.mjs`: the POSIX branch of S1's `persistPath`.
- `scripts/test/install-path.test.mjs`: the POSIX pins, against a temp home.

## Interface

```
profileFor(shell: string | undefined, home: string): string | null   // zsh ~/.zshrc, bash ~/.bashrc, fish ~/.config/fish/conf.d/pilot.fish, else null
pilotBlock(dir: string, shell: 'zsh' | 'bash' | 'fish'): string        // '# >>> pilot >>>' … '# <<< pilot <<<', dir single-quoted; throws on ' $ a backslash or any control character
S1's persistPath: platform 'linux' | 'darwin' picks this branch; PathResult.where is the profile path
```

## Tests

1. `zsh and bash profiles get one block that exports the directory`: `persistPath` → `added`, the file ends with `pilotBlock`, earlier content byte-identical.
2. `fish gets its own conf.d file using a guarded set -gx`: `persistPath` → `added`, `~/.config/fish/conf.d/pilot.fish` created.
3. `a second run, or a directory on the process PATH, writes nothing`: `persistPath` → `present`, profile bytes identical.
4. `an unknown or unset SHELL, or an unwritable profile, is failed with the directory`: `persistPath` → `failed`, nothing written.
5. `a directory containing a quote, a newline or $ is refused, not written`: `pilotBlock` → throws, and `persistPath` → `failed` with the hand-add note, the profile untouched (A4).
6. `a dry run writes nothing`: `persistPath` → `would-add`, the profile absent.

Rewrite check: switching from appending to a marked rewrite of the block keeps every result above.

## Done

- **Expected**: on macOS or Linux, the install appends one pilot block to the profile of the user's shell, says which file, and a second run leaves it alone.
- **Verification**: `node --test scripts/test/install-path.test.mjs`; `npm test`.
- **Evidence**: test 1 failing before (no POSIX branch: `failed`) and passing after; the fixture profile printed in the test output for zsh.
- **Prohibited**: no write to the real `~`; no double-quoted directory; no escaping in place of the A4 refusal; no rewriting of lines outside the block; no new shell beyond zsh, bash, fish.
- **Done when**: the POSIX tests and `npm test` are green on this machine, the shell-sourcing test skipped only on Windows.
