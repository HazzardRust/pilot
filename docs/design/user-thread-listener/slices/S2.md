# S2 A pilot in a worktree is held on a user's thread it cannot disown

Feature `user-thread-listener` · delivers spec 2, 6 · source: `../architecture.md` §2, L3, L6 · after: – (beside S1)

## Files owned

- `hooks/lib/deck.js`: `projectDir(input, env)` and `isUserOpened(item)`, both exported.
- `hooks/stop-gate.js`: every `input.cwd` join goes through `projectDir` (lines 280, 293, 304). `reasonFor` drops the escape when every quoted thread is user-opened or on this run's live ticket (L6), and names the ones that are. `namedTickets` also asks for the ticket of an answered thread this session did not post, so the live-ticket join works after a hand-off.
- `hooks/inbox-alert.js`: `arrive` and `deliver` key on `projectDir`. The join only; the notice text stays the same.
- `hooks/test/listener-join.test.js` (new): the pins.
- `docs/adr/0071-the-hooks-key-on-the-project-and-a-user-opened-thread-is-the-pilots.md` (new).

## Interface

```
projectDir(input: { cwd?: string }, env: NodeJS.ProcessEnv): string  // env.CLAUDE_PROJECT_DIR || input.cwd
isUserOpened(item): boolean                                          // kind 'user' or 'chat'
isOnLiveTicket(item, tickets): boolean                                   // item.ticket names a ticket in `tickets` with live === true, not closed
reasonFor(items, tickets): string  // no "another session" sentence for a user-opened thread or one on the live ticket; says "the user opened <id> in this repository: it is yours" / "<id> is on this run's ticket: it is yours"
```

## Tests

1. `a Stop with cwd in a worktree and CLAUDE_PROJECT_DIR the repo blocks on the user's answered thread`: fails on main, because `isForThisRepo` uses the worktree path.
2. `the reason for a user-opened thread never offers another session`: there is no `/another session/`, and the thread is named as this repository's.
3. `a question stamped with another repository still stands aside`: unchanged behaviour.
4. `a mixed hold of a user thread and a question on no live ticket keeps the escape for the question only`.
7. `a question on this repository's live ticket that this session never posted never offers another session`: an empty posted list, as after a hand-off; fails on main.
8. `a question on a ticket that is not live keeps the escape`.
5. `a PostToolUse with cwd in a worktree delivers the repo's reply instead of reading past it`: the cursor is not advanced past an undelivered reply.
6. `with CLAUDE_PROJECT_DIR empty the hooks key on cwd as before`: the existing `inbox.test.js` drift test still passes untouched.

## Done

- **Expected**: the pilot integrating from a `feat/` worktree ends a turn while the user's Create thread holds an answer. The Stop gate holds it, quotes the answer, and gives no "belongs to another session" exit. The inbox lane hands the reply over at the next tool call.
- **Verification**: `node --test hooks/test/listener-join.test.js hooks/test/inbox.test.js hooks/test/owner-hooks.test.js hooks/test/join.test.js`, then `npm test`.
- **Evidence**: tests 1 and 5 failing on main and passing after. `hooks/stop-gate.js` run by hand against a scratch deck (port 4399) with a worktree `cwd`, with its JSON output pasted.
- **Prohibited**: no git spawn in a hook; no change to `isOnDeck`'s run join beyond the key it is given; no removing the escape for threads that are neither user-opened nor on this run's live ticket (L6); no new read beyond `deck.record` per distinct named ticket; no editing the notice text (S3's).
- **Done when**: the eight tests and `npm test` are green, and the hand run blocked with a reason that has no "another session".
