# S3 An answered thread is repeated until the pilot answers it

Feature `user-thread-listener` · delivers spec 4 · source: `../architecture.md` §2, L4, L5, A1 · after: S2

## Files owned

- `hooks/lib/deck.js`: `unanswered(items, posted, baseline, repo)`, moved here from the Stop gate's `answered` filter and its `awaitsPilot`/`lastMessage`/`isForThisRepo`.
- `hooks/stop-gate.js`: calls `deck.unanswered`. Behaviour unchanged.
- `hooks/inbox-alert.js`: after `deliver`, reads `deck_read {open:true, limit:20}` (no `repo`, L5) and adds the short repeat for every unanswered thread not delivered in this same call. The "delivered once" sentence goes.
- `hooks/test/inbox.test.js`: the pins.
- `docs/adr/0072-an-unanswered-thread-is-said-until-it-is-answered.md` (new).

## Interface

```
unanswered(items: Item[], posted: string[], baseline: number, repo: string): Item[]
  // open, owned by pilot (or no owner), user spoke last after baseline; posted ids skip the baseline
repeat line: SYSTEM NOTICE: still unanswered on the deck: <id> "<title>"[, …]. Act on each, then deck_resolve it or answer with deck_reply.
S2's projectDir: the repo both callers pass
```

## Tests

1. `two tool uses after an unanswered reply both carry still unanswered: <id>`: the first gives the full notice; the second gives the short line only.
2. `a tool use after deck_reply on that thread says nothing`.
3. `a tool use after deck_resolve on that thread says nothing`.
4. `a reply on a QA-owned thread is never repeated to the pilot`.
5. `the Stop gate holds on exactly the threads the repeat names`: same fixture, both callers, same ids.
6. `a deck that fails the read says nothing more than it does today`: no notice, no throw.

## Done

- **Expected**: the pilot cannot work through tool calls with a user's answer sitting unanswered. Every tool call carries one line naming the thread, until it replies or resolves.
- **Verification**: `node --test hooks/test/inbox.test.js hooks/test/owner-hooks.test.js hooks/test/standing.test.js`, then `npm test`.
- **Evidence**: test 1 failing on main (the second call is silent) and passing after. The PostToolUse hook run by hand three times against a scratch deck (port 4399), with the three outputs pasted.
- **Prohibited**: no `deck_read` with `repo` (it marks delivered); no re-quoting the full reply text on repeats (A1); no second copy of the unanswered rule; no claim file per repeat.
- **Done when**: the six tests and `npm test` are green, and the hand run showed notice, notice, silence.
