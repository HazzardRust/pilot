# S11 A landing that ends short wakes the pilot

Feature `three-lanes` · delivers spec 15 · source: `../architecture.md` §2, §3 Landing, L7 · after: S7 (`deck/store-items.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `deck/store-items.mjs`: `settleLanding` stores a short landing as `{ from: 'deck', seq, text }`, where short means refused, `pr ready failed` or merge-first `unknown`; a clean `landed` stays as today.
- `deck/store-runs.mjs`: `repliesSince` takes a `from: 'deck'` line; `ownerFilter` hands it to the pilot kind whoever owns the gate2.
- `hooks/lib/deck.js`: `awaitsPilot` holds the Stop hook on a `deck` line until a later message or the close.
- `deck/test/landing-wake.test.mjs` (new): the pins.

## Interface

```
deck/store-items.mjs
  export function settleLanding(id, outcome: { ok: boolean, line: string, sha?: string }): Item
  export function isShortLanding(outcome): boolean
deck/store-runs.mjs
  repliesSince(items, since, heard): Reply[]   // `from: 'deck'` heard by the pilot kind only
hooks/lib/deck.js
  awaitsPilot(item, baseline): boolean         // true on a trailing `deck` line with a seq
`pilot wait` prints: REPLY <gate2 id> "<title>"\n<landing line>
```

## Tests

1. `a refused landing returns the parked pilot wait with the line`: `settleLanding` → the pilot's `deck_wait` returns it; QA's does not.
2. `a clean landing wakes nobody`: `isShortLanding` → false for `landed … ready: #n`.
3. `the Stop hook holds while a landing line is unanswered`: `awaitsPilot` → true, then false after a later message.

Rewrite check: carrying the wake on a separate landing event channel keeps every result above.

## Done

- **Expected**: with a gate2 signed and the landing refused, the parked `pilot wait` returns at once with the line.
- **Verification**: `node --test deck/test/landing-wake.test.mjs deck/test/landing*.test.mjs hooks/test/stop-gate*.test.js`; `npm test`; a scratch deck press with landing stubbed to refuse.
- **Evidence**: tests failing before and passing after; the `pilot wait` output.
- **Prohibited**: writing the line as `from: 'user'`; waking QA's wait; changing a clean landing.
- **Done when**: the tests and the suite are green and the wake was seen.
