# S13 Merge-first and the push survive an unreachable GitHub

Feature `three-lanes` · delivers spec 17 · source: `../architecture.md` §2, §3 Landing, A7 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `scripts/pilot-branch.mjs`: `remoteDefaultBranch` falls back to the local `refs/remotes/origin/HEAD` when origin cannot be asked, and says so.
- `scripts/land.mjs`: `mergeFirst` falls back to the open gate2s' `pr` read from the deck when `gh` fails, and says which it used; the push is retried once when origin could not be asked; a tip already on origin reads `landed <head> on pilot at <sha7>`.
- `scripts/test/land-offline.test.mjs` (new): the pins, with origin and `gh` stubbed.

## Seam note (co-pilot, A-f8)

`remoteDefaultBranch(git, { fallback = false } = {})` takes the git runner every caller already holds and returns `{ branch, from: 'origin' | 'origin/HEAD' }`, so its callers in `scripts/branches.mjs`, `scripts/sync.mjs` and `scripts/worktrees.mjs` read `.branch` (one line each). The push guard keeps calling it with no fallback: fail-closed unchanged. `mergeFirst` stays module-private and returns `{ mergeFirst, from: 'gh' | 'deck', unknown? }`; `land()` takes an optional `deckPrs(source)` that `main()` supplies from the deck store, so existing `land()` pins keep `unknown`. Amended by the principles fix round: `remoteDefaultBranch(git)` keeps its string return and no `fallback` option, and land's own `landBase(git)` catches it and falls back to the local origin/HEAD, saying so, so no other caller changes.

## Tests

1. `an unreachable origin falls back to origin/HEAD and says so`: `remoteDefaultBranch` → `from: 'origin/HEAD'`.
2. `a failing gh falls back to the deck's gate2 PRs`: `mergeFirst` → `from: 'deck'`, with the line naming it.
3. `a tip already on origin reads landed`: `remoteDefaultBranch` → the land output is `landed … at <sha7>`, not `NOT landed`.

Rewrite check: reading the fallback PRs from a cache file instead of the deck keeps every result above.

## Done

- **Expected**: with GitHub unreachable, a landing whose tip is already pushed reads `landed`, and merge-first names its fallback source.
- **Verification**: `node --test scripts/test/land-offline.test.mjs scripts/test/land*.test.mjs`; `npm test`.
- **Evidence**: tests failing before and passing after; the land output.
- **Prohibited**: retrying more than once; a push with `--force`; a fallback that hides which source was used.
