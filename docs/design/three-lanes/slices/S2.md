## Tests

1. `a planning switch leaves the concluding ticket live`: `requestSwitch` → after the completing take, the concluding ticket is still live.
2. `a pending planning switch does not lock the concluding lane`: `refuseLaneSwitch` → no throw for `concluding`.
3. `a stored main record reads as its target's lane`: `refuseLaneSwitch` → throws for the lane of `main.to`, and not for the other.

Rewrite check: storing both lanes' switches in one array keeps every result above.
