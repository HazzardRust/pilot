## Tests

1. `three held lanes show a three-entry selector, implementing chosen`: `renderStatusSelector` → three links, the yellow one `aria-current`.
2. `choosing the concluding ticket draws its record`: `renderStrips` → that record's table and graph.
3. `one held lane shows no selector`: `renderStatusSelector` → ''.
4. `a ticket id that is no held lane's is ignored and never echoed`: `GET /` → the default selection; the id is absent from the page.
5. `a planning ticket with no record says so`: `renderStrips` → `no slice table yet`.

Rewrite check: a `<select>` form posting the same `ticket` parameter keeps every result above.
