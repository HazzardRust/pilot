## Tests

1. `a question line in the body is refused naming it`: `reportAskGaps` → `the body asks: Should I keep the worktree?`.
2. `say so, tell me and let me know are asks in any case`: `reportAskGaps` → one gap each, the step numbered.
3. `a ? inside a code span, a URL or quotes asks nothing`: `reportAskGaps` → `[]` for each fixture `?` line.
4. `today's sanctioned lines pass and today's asks do not`: `reportAskGaps` → `[]` for the nine "I reply here" lines; a gap for itm_ffb2bd6090ea's and itm_351eeb1012f6's lines.
5. `a report that asks is refused at post and stores nothing`: `postItem` → DeckRefusal naming ADR 0148 and the line; the ticket stays open.
6. `the worktrees reply cannot ask`: `addPilotMessage` → refused for "Tell me which to keep"; "Kept: `pilot-feat-x` (dirty)" stored.

Rewrite check: replacing the regexes with a tokenizer keeps every result above over the same fixture.
