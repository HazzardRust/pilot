## Interface

```
deck/items.mjs
  export const RECORD_KINDS: string[]            // [KIND_REPORT]: kinds that take no user reply
  export function isRecord(item): boolean
deck/store-items.mjs
  export function addReply(id: string, said: string): Item   // throws DeckRefusal on a record, before any reopen
deck/ui/render-pages.mjs
  renderThreadPage(item, items, …): string       // a record's page carries no reply form
POST /reply  id=<report id>  -> the DeckRefusal (303 ?refused= on a page press; error status otherwise)
Refusal: "a closing report is a record and takes no reply (ADR 0148); say it on the chat: /thread/<chat id>"
```

## Tests

1. `a user's reply on an open report is refused naming the chat`: `addReply` → throws with `ADR 0148` and `/thread/<chat id>`; the report's replies stay empty.
2. `a reply on a closed report reopens nothing`: `addReply` → throws; the report stays closed.
3. `POST /reply on a report stores nothing`: `POST /reply` → the refusal; the stored item unchanged.
4. `a report's page has no reply box, a question's keeps one`: `renderThreadPage` → no `reply-text` and no `action="/reply"` for the report; both for a question.
5. `only reports are records`: `isRecord` → true for `report`, false for every other kind in `KINDS`, chat and user.
6. `ADR 0148 is indexed`: `RECORD_KINDS` → its doc comment names ADR 0148, and `docs/adr/README.md` lists 0148.

Rewrite check: replacing the kind list with a per-item flag keeps every result above.
