# S3 The closing report counts blocked steps by agent and reason

Feature `crew-refusals` · delivers spec 5 · source: `../architecture.md` §2, §3 Closing report · after: S4 (`classifier-log`'s `readRefusals`)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — one pure function on S4's seam and its tests, no assumed line, no security trigger, under 100 lines.

## Files owned

- `deck/closing-report.mjs`: `blockedStepLines`; `postFilled` reads `readRefusals({ repo, ticket })`; `closingReportOf`'s body gains the lines after `Closed by the pilot:`.
- `deck/test/closing-report.test.mjs`: the pins.

## Interface

```
blockedStepLines(refusals: Refusal[]): string[]
  // -> ['Blocked steps: <n>', '- <agent> <reason>: <count>', ...] by count desc, then agent, reason
  // -> ['Blocked steps: none'] when empty
closingReportOf(record, gate, left, closes, blocked?: string[]): { title, body }
S4's readRefusals, S4's Refusal
```

## Behaviours

1. `two blocked steps from two agents are two rows` (test): `blockedStepLines` → `Blocked steps: 2`, `- pilot:pilot-implementer [Destructive or Unwanted Actions]: 1`, `- pilot:pilot-evidence-runner [Undermining Oversight]: 1`.
2. `no refusals reads none` (test): `blockedStepLines` → `Blocked steps: none`.
3. `the report carries the lines` (test): `closingReportOf` → body contains `Blocked steps:` after the `Closed by the pilot:` section.

Rewrite check: any grouping of S4's entries by agent and reason keeps 1-3.
Misses: whether a user notices a new habit in the report; QA reads the scratch deck's report (§9 item 7).
