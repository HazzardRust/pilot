# S3 The closing report counts blocked steps by agent and reason

Feature `crew-refusals` · delivers spec 5 · source: `../architecture.md` §2, §3 Closing report · after: –
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — one pure function and its tests, no assumed line, no security trigger, under 100 lines.

## Files owned

- `deck/closing-report.mjs`: `blockedStepLines`, and `closingReportOf`'s body gains its lines after `Closed by the pilot:`.
- `deck/test/closing-report.test.mjs`: the pins.

## Interface

```
blockedStepLines(items: Item[], ticketId: string, repo: string): string[]
  // items with title starting 'Blocked:', item.ticket === ticketId, same repo
  // -> ['Blocked steps: <n>', '- <agent> <reason>: <count>', ...] by count desc, then agent, reason
  // -> ['Blocked steps: none'] when there are none; '?' for a missing Agent: or Reason: line
closingReportOf(record, gate, left, closes, blocked?: string[]): { title, body }
```

## Behaviours

1. `two blocked steps from two agents are two rows` (test): `blockedStepLines` → `Blocked steps: 2`, `- pilot:pilot-implementer [Destructive or Unwanted Actions]: 1`, `- pilot:pilot-evidence-runner [Undermining Oversight]: 1`.
2. `another ticket's or repo's blocked step is not counted` (test): `blockedStepLines` → `Blocked steps: none`.
3. `the report carries the lines` (test): `closingReportOf` → body contains `Blocked steps:` after the `Closed by the pilot:` section.

Rewrite check: any parse of the `Agent:` / `Reason:` lines `hooks/lib/blocked.js:112-113` writes keeps 1-3.
Misses: whether a user notices a new habit in the report; QA reads the scratch deck's report (§9 item 6).
