## Behaviours

1. `a test run cannot resolve the real store` (test): `deckDir` → throws naming the path when `HOME`, `USERPROFILE` are set to `os.userInfo().homedir` and `PILOT_DECK_DIR` is unset, inside `node --test`.
2. `a test's own store still resolves` (test): `deckDir` → returns a temp `PILOT_DECK_DIR`, and the suite home under `testUtils`, unchanged.
3. `the table redirects no home` (read): `grep -cE 'HOME=|USERPROFILE=|PILOT_DECK_DIR=' agents/pilot-evidence-runner.md` → 0.
4. `the suite stays green under the guard` (run): `npm test` green; each file the guard newly fails is fixed with `tempDeck` and named in the report.

Rewrite check: any guard that refuses the real path under `node --test` and leaves temp stores alone keeps 1 and 2.
Misses: whether auto mode allows the new coverage cell; QA's run in the scratch repo (§9 item 1) reads that.

## Done

  deck throws instead.
- **Verification**: `node --test hooks/test/deck-dir-guard.test.js`; `node scripts/check-references.mjs`; `npm test`.
- **Evidence**: behaviour 1 red before the guard, green after, on this Windows machine; the `grep -c` output; the
  suite's pass/fail counts.
- **Prohibited**: no permission, allowlist or hook change (L1); no env override moved into another spelling (a

- **Done when**: behaviours 1-4 hold and `npm test` is green.
