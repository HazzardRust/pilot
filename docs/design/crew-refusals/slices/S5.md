# S5 The audit reports each recurring refusal habit as a row

Feature `crew-refusals` · delivers spec 7 · source: `../architecture.md` §2, §3 Refusal capture, §5 L9, §6 A5 · after: S4 (`classifier-log`'s `readRefusals`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a skill's area file is agent configuration, the security trigger, and spec 7 is assumed (A5).

## Files owned

- `scripts/audit-refusals.mjs` (new): reads the log for one repo, prints JSON rows; read-only, exit 0.
- `scripts/test/audit-refusals.test.mjs` (new): its pins on a seeded log.
- `skills/audit/areas/refusals.md` (new): `area: refusals`, `owner: auditor`, `## Measure` (the command under `timeout 60`), `## Rows`.

## Interface

```
commandShape(command: string): string
  // each part split on && || ; | -> its program and first word or flag, joined by ' ; '
  // 'export HOME=… ; npx c8' -> 'export HOME ; npx c8'
refusalRows(refusals: Refusal[], opts?: { min?: number }): AuditRow[]
  // verdict 'refused' only; grouped by commandShape; a group of >= min (3) is one row:
  // { finding, agents, reasons, count, example, spec }
node scripts/audit-refusals.mjs <repo> [--log <file>]
  -> { log, total, byAgentReason: [{ agent, reason, count }], rows: AuditRow[] }
S4's readRefusals, S4's Refusal
```

## Behaviours

1. `a shape refused three times is one habit row` (test): `refusalRows` → 1 row for 3 `export HOME` refusals, `count` 3, both agents named.
2. `two of a shape is no row` (test): `refusalRows` → `[]`.
3. `no-verdicts are counted, never a habit` (test): `refusalRows` → `[]` for 5 `Classifier unavailable` entries.
4. `the three habits of this run are three rows` (test): `refusalRows` → 3 rows for §1's commands seeded 3 times each.
5. `the auditor finds the area` (read): `skills/audit/areas/refusals.md` names `node "${CLAUDE_PLUGIN_ROOT}/scripts/audit-refusals.mjs" .` and its rows.

Rewrite check: any grouping that puts §1's three commands in three groups and keeps the bar of 3 keeps 1-4.
Misses: whether the auditor turns a row into a good ticket; QA's run of the script on a seeded log (§9 item 8).

## Done

- **Expected**: the next audit of a repository lists each recurring refusal habit with its count, agents, an example
  command and a spec the user can pick as a ticket.
- **Verification**: `node --test scripts/test/audit-refusals.test.mjs`; `node scripts/check-references.mjs`; `npm test`.
- **Evidence**: behaviour 4 red before, green after; the script's JSON on a seeded log.
- **Prohibited**: the script writes nothing and the auditor changes nothing in the repository (L9); no ticket posted
  from the script; no raw log line copied into a row past S4's withheld command; diff over 300 lines → stop and ask `main` (L8).
- **Done when**: behaviours 1-5 hold and `npm test` is green.
