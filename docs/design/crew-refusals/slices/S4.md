# S4 Every classifier denial lands in the classifier log

Feature `crew-refusals` · delivers spec 6 · source: `../architecture.md` §2, §3 Refusal capture, §5 L9, §6 A4, A5 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a hook input written to disk with a credential check is the security trigger, and spec 6 is assumed (A4, A5).

## Files owned

- `deck/classifier-log.mjs` (new): the log's one writer and one reader.
- `deck/test/classifier-log.test.mjs` (new): its pins, against a temp `dir`.
- `hooks/permission-denied.js`: `onDenied` appends every denial before its lane check; the post path unchanged.
- `hooks/lib/blocked.js`: header `:18-19` names the log and its credential check; `postBlocked` hands back the ticket it resolved for the entry.
- `hooks/test/permission-denied.test.js`: a main-session denial with no run logs once and posts nothing.

## Interface

```
type Refusal = { when: string, repo: string, ticket: string | null, agent: string, reason: string,
                 tool: string, command: string, verdict: 'refused' | 'no-verdict' }
appendRefusal(entry: Omit<Refusal, 'when'>, opts?: { dir?: string, now?: () => Date }): void
  // <dir ?? deckDir()>/classifier.log, one JSON line; command clipped to 300 chars;
  // findCredential hit -> command '<withheld: credential>'; newest 10,000 lines kept; never throws
readRefusals(filter?: { dir?: string, repo?: string, ticket?: string }): Refusal[]
  // oldest first; a torn or foreign line skipped
onDenied(payload, deps) -> null   // unchanged return
```

## Behaviours

1. `a denial outside a pilot run is logged` (test): `onDenied` → one entry `readRefusals` returns with the agent and reason, and 0 posts.
2. `a credential never reaches the log` (test): `appendRefusal` → a command holding a token reads back `<withheld: credential>`.
3. `the log stays bounded` (test): `appendRefusal` → after 10,001 appends `readRefusals` returns 10,000, the oldest gone.
4. `a no-verdict is tagged, a refusal is not` (test): `readRefusals` → `verdict` `no-verdict` for `Classifier unavailable`, `refused` otherwise.
5. `a log that cannot be written changes nothing else` (test): `onDenied` → with an unwritable dir it still posts a lane's refusal and returns null.

Rewrite check: any store keyed by repo and ticket that withholds credentials and keeps the newest 10,000 keeps 1-5.
Misses: whether real auto-mode payloads carry every field; QA's refused call in the scratch session (§9 item 6).

## Done

- **Expected**: every auto-mode denial on this machine leaves one line in the classifier log; a credential never does.
- **Verification**: `node --test deck/test/classifier-log.test.mjs hooks/test/permission-denied.test.js`; `npm test`.
- **Evidence**: behaviours 1 and 2 red before, green after; the suite's counts.
- **Prohibited**: nothing reads the log to approve, retry, skip or pre-clear a call (L9); no change to the hook's
  return or the post (L3); no raw command written when the credential check cannot load; no `os.homedir()` path,
  only `deckDir()`; diff over 300 lines → stop and ask `main` (L8).
- **Done when**: behaviours 1-5 hold and `npm test` is green.
