# S1 `prune --run` names every tree of the run

Feature `prune-run-trees` · delivers spec 1, 2, 3, 5 · source: `../architecture.md` §2, §3 F1-F4, §5 L1-L3, §6 A1 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it widens which trees a landed prune force-removes (A1 assumed), and a CLI argument picks them.

## Files owned

- `scripts/worktrees.mjs`: `runTrees` (new), with name inference and the known-run guard; `runWorktrees` as its paths; `prune`'s selection through `runTrees` on both paths.
- `scripts/test/worktrees-run-trees.test.mjs` (new): the fixture of each tree kind, the slug collision, the line-per-tree pins.
- `docs/adr/NNNN-prune-run-trees.md` (new): L1-L3, A1, A2.

## Interface

```
runTrees(repo: string, slug: string, view?: Git) -> { path: string, by: 'tag' | 'branch' | 'land' | 'name' }[]  // never main
runWorktrees(repo: string, slug: string, view?: Git) -> string[]   // runTrees' paths, signature unchanged
// by 'name': fix/<slug>-<any> not isRunBranch, design/<slug>-recut, or detached untagged <home>-fund-<slug>,
//            and no longer known run (feat/ or design/ ref, local or remote, or a tag) claims it
prune(repo, base, opts) -> { removed, kept, failed }   // selection: runTrees, less by 'land' unless landed
```

## Behaviours

1. `each kind of run tree is reached` (test): `runTrees` → for a fixture with a slice, a `fix/<slug>-drift`, a `design/<slug>-recut` and a detached `<home>-fund-<slug>` tree, 4 entries with `by` `branch`, `name`, `name`, `name`.
2. `a landed prune removes them all` (test): `prune` → with `landed`, 4 of 4 paths in `removed`; `git worktree list` names 0 of them.
3. `every run tree gets one line on both paths` (test): `prune` → the paths across `removed`, `kept` and `failed` equal `runTrees`' paths, with `landed` and without (the land dir out on the latter).
4. `the longest known slug wins` (test): `runTrees` → with slugs `x` and `x-y` and a tree on `fix/x-y-drift`, 0 entries for `x` and 1 for `x-y`.
5. `no real tree has two runs` (run): over the shared checkout, read-only, `runTrees` for every known slug: 0 paths in two sets.

Rewrite check: any membership rule keeps another run's longer-slug tree out and gives each run tree exactly one prune line.
Misses: a run with no ref and no tag whose tree a guess claims; S2's strict rule bounds what that costs, and the fundamentalist reads the guard.
