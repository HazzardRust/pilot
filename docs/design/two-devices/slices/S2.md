# S2 Bare doctor and start show clashes on the slugs this deck holds

Feature `two-devices` · delivers spec 2b, 4 · source: `../architecture.md` §2, §3, §5 L5, §6 A2, A4 · after: S1 (`deck/doctor.mjs`, `slugClashes`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — slugs read from ticket bodies reach git argv, and `start` is a process start: the security trigger.

## Files owned

- `deck/doctor.mjs`: `heldSlugs`, `slugsRow`; `checkAll` gains the row after `host`.
- `bin/pilot.mjs`: `start` prints `slugsRow`'s lines when not `pass`, then opens as today.
- `deck/test/doctor-slugs.test.mjs` (new): the row's pins.
- `scripts/test/start-slugs.test.mjs` (new): start prints and still opens.

## Interface

```
heldSlugs(view: { open: { body: string }[], records: { slug: string }[] }) -> string[]
  // each `docs/design/<slug>/` in an open ticket's body, SLUG-checked, deduped, minus record slugs (L5)
slugsRow({ view, git, hostFor }) -> { name: 'slugs', verdict: 'pass'|'fail'|'cannot tell', detail, steps }
  // view from GET /api/tickets?repo=&open=1, bounded as `pilot base` (5 s); deck unread -> 'cannot tell'
S1's slugClashes: one call per held slug
```

## Behaviours

1. `a held slug that clashes fails the row` (test): `slugsRow` → a view naming `docs/design/x/` and a Host with an open PR from `feat/x` gives `fail`, a step naming `PR #<n>`.
2. `the deck's own run is not a clash` (test): `heldSlugs` → a body naming `docs/design/x/` with a record slug `x` gives `[]`.
3. `nothing held passes` (test): `slugsRow` → a view with no design path gives `pass` and 0 git calls.
4. `a body slug off SLUG is dropped` (test): `heldSlugs` → `docs/design/--x/` gives `[]`.
5. `start warns and opens` (test): `slugsRow` → a clashing view; start, with `openPilot` recorded, prints the row lines, calls it once, and `process.exitCode` stays unset (A4).
6. `bare doctor shows the row` (run): `pilot doctor` on this repo → a `slugs` row.

Rewrite check: any held-slug source that skips this deck's records keeps 1-5.
Misses: how slow `pilot start` feels with a slow remote; QA's run reads that.

## Done

- **Verification**: `node --test deck/test/doctor-slugs.test.mjs scripts/test/start-slugs.test.mjs`; `npm test`; `pilot doctor`.
- **Evidence**: 1-5 red before, green after; the `slugs` row as printed.
- **Prohibited**: start never refuses on a clash (A2); no `deck_read`; no store write; `wc -l deck/doctor.mjs` stays under 800.
- **Done when**: behaviours 1-6 hold and `npm test` is green.
