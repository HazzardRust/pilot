## Interface

```
type Clash = { ref: string } | { pr: number, head: string }   // 'origin/feat/<slug>' | PR #n from feat|design/<slug>
slugClashes(slug: string, { git, host }: { git: (args: string[]) => string, host: Host | null })
  -> { clashes: Clash[], unread?: string }   // unread: the remote or host that could not answer
  // throws on a slug off SLUG before any git or host call (L4)
pilot doctor slug <slug>
  // free: `free <slug>`, exit 0; clash: one `clash <slug>: <ref | PR #n from head>` line each, exit 1;
  // unread: `cannot tell <slug>: <what>`, exit 1; not a slug: usage on stderr, exit 2
```

## Behaviours

1. `a branch on origin is a clash` (test): `slugClashes` → origin (bare repo) holding `feat/x` and `design/x` gives two `{ ref }` clashes.
2. `an open PR is a clash` (test): `slugClashes` → stub Host answering an open review from `design/x` gives `{ pr, head }`; host null gives none.
3. `stale tracking refs are not read` (test): `slugClashes` → local `refs/remotes/origin/feat/x` with origin lacking it gives 0 clashes.
4. `unreachable reads cannot tell` (test): `slugClashes` → origin url to a missing path gives `unread`, never an empty free answer.
5. `a bad slug never reaches git` (test): `slugClashes` → `--upload-pack=x` throws; the git recorder holds 0 calls.
6. `the verb prints and exits` (run): `pilot doctor slug two-devices` in this repo → clash lines, exit 1; a fresh name → `free`, exit 0.
