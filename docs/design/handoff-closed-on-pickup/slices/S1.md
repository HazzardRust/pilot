## Tests

1. `a held open hand-off blocks the stop and names it`: `run` → `decision: 'block'`, reason contains the item id and `deck_resolve`.
2. `a resolved hand-off lets the turn end and drops the marker`: `run` → `null`; `heldHandoff` → `null` afterwards.
3. `the session that posted the hand-off is not held`: `run` → `null` with the item open and no marker.
4. `stop_hook_active and a subagent stand aside`: `run` → `null` for both, the marker held.
5. `a dead deck never blocks`: `run` → no `decision: 'block'`.
6. `delivery writes the held marker, a chain hand-off does not`: `deliver` → `heldHandoff` returns the id; `null` for an `item.next` delivery or a failed write.
7. `a plain pick-up drops the held marker`: `plainPickup` → `heldHandoff` returns `null`.
8. `the notice names reply then resolve in one sentence`: `notice` → sentence 2 as in the Interface block; no "Resolve its thread" left.
9. `the marker round-trips and refuses a non-id`: `holdHandoff` → `heldHandoff` returns it; `holdHandoff(s, '../x')` → `null`.

Rewrite check: replacing the marker file with any other per-session store keeps results 1–9.
