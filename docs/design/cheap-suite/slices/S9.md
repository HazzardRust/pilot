# S9 Deck tests reuse one deck and one fixture per file

Feature `cheap-suite` · delivers spec 2, 3, 6 · source: `../architecture.md` §2 verdict table, §3 F10, §5 L3 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — test-only, but spec 2 (A1) and 3 (A4) are assumed, so keeping each test's protection is judgement.

## Files owned

- `deck/test/daemon.test.mjs`: the read-only API tests on one deck per file, state reset through the store.
- `deck/test/gate2-base.test.mjs`: the planted fixture through `gitFixture` once; the two planted tests on it.
- `deck/test/landing-recut.test.mjs`: `landOn` from a prebuilt fixture key, no checkout per test.
- `deck/test/classifier-log.test.mjs`: one scratch dir for the probe loop (`before`/`after`), inputs unchanged.

## Interface

```
S9 changes no production seam; each file keeps its own helpers, reshaped:
gitFixture(t, key, build)   // scripts/test/lib/git-fixture.mjs, unchanged, now used by gate2-base and landing-recut
```

## Behaviours

1. `daemon keeps 75 tests on fewer decks` (run): `node --test deck/test/daemon.test.mjs` passes, `duration_ms` under 30 s (49 s measured).
2. `gate2-base and landing-recut build once` (run): both pass, git under 60 each in `GIT_TRACE` (130 and 123 measured).
3. `classifier-log keeps its probes` (run): 55 tests pass, under 15 s (30 s measured).
4. `nothing they guarded is lost` (read): assert counts per file equal; coverage of `deck/daemon.mjs`, `deck/landing.mjs` and `deck/classifier-log.mjs` from these files not lower.

Rewrite check: (run and read kinds only) any reshaping that keeps the counts and coverage keeps 1-4.
Misses: state shared across tests on one deck; three runs in a row and the reviewer read it.
