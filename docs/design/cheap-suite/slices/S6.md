# S6 A landing asks git for its remote once

Feature `cheap-suite` · delivers spec 3 · source: `../architecture.md` §2, §3 F4, Seams · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — a production memo on the landing path; a stale answer inside one call is the risk to judge.

## Files owned

- `scripts/remotes.mjs`: `runRemote(git)` answers once per `git` runner.
- `scripts/pilot-branch.mjs`: `remoteDefaultBranch(git)` answers once per `git` runner.
- `scripts/test/remotes.test.mjs`: the memo pins.
- `scripts/test/pilot-branch.test.mjs`: the memo pins.

## Interface

```
runRemote(git) -> string | null            // unchanged contract; memoised in a WeakMap keyed by `git`
remoteDefaultBranch(git) -> string         // unchanged contract; memoised the same way; a throw is not memoised
```

## Behaviours

1. `one runner asks once` (test): `runRemote` → called three times with one counting `git`, `config --get pilot.remote` is asked once and every answer is equal; the same for `remoteDefaultBranch` and `ls-remote`.
2. `a new runner asks again` (test): `remoteDefaultBranch` → after the remote's HEAD is renamed, a second `git` runner reads the new name.
3. `a failure is asked again` (test): `remoteDefaultBranch` → a `git` that throws once then answers: the second call answers.
4. `landing tests start fewer git` (run): `GIT_TRACE` on `scripts/test/land-clear.test.mjs` before and after: `config --get pilot.remote` and `ls-remote --symref` lines fall from 90 and 71 to at most 12 each (one per land call), counts in the slice report.

Rewrite check: caching on the cwd instead of the runner keeps 1 and 3; 2 then needs a fresh process, which the test names.
Misses: a caller that changes `pilot.remote` and expects the same runner to see it; the reviewer greps for `config pilot.remote` writes between reads.

## Done

- **Expected**: one `land` asks git for its run remote and the default branch once each, and lands as before.
- **Verification**: `node --test scripts/test/remotes.test.mjs scripts/test/pilot-branch.test.mjs`; `npm run test:changed -- --since=<base>`; the traced run.
- **Evidence**: 1-3 red before, green after; the two trace counts.
- **Prohibited**: no module-level cache keyed by nothing; no memo of a ref's sha (`rev-parse` of a branch moves); no test asserting call counts loosened.
- **Done when**: 1-3 green, the selected gate green, the trace counts under the bar. Estimate 60 lines.
