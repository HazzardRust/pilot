# S1 One command prints what each test file costs

Feature `cheap-suite` · delivers spec 1 · source: `../architecture.md` §2, §3 F1, F2, Seams, §5 L4 · after: –
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `scripts/test-cost.mjs` (new): the per-file reporter and the cost table.
- `scripts/count-spawns.mjs`: `spawnCount`'s `owners` split by kind.
- `scripts/gate.mjs`: `--cost` adds the reporter and prints the table after the census lines; `spawnLines` reads the new owner shape.
- `package.json`: `"test:cost": "node scripts/gate.mjs --cost"`.
- `scripts/test/test-cost.test.mjs` (new): the table's pins.
- `scripts/test/gate-spawns.test.mjs`: the owner-shape pins.

## Interface

```
spawnCount(file) -> { total, node, git, other, owners: Map<string, { total, node, git, other }> }
costReporter(source) -> AsyncGenerator<string>   // node --test reporter: one JSON line per top-level test
                                                 // { file (repo-relative), ms, pass }
costTable(lines: string[], owners) -> string
  // `file  s  tests  spawns  git  node  other`, slowest first by summed ms, every file a row (QA),
  // then `total <files> files <s> s <spawns> spawns (git <g>)`
gate --cost   // full or selected; the table after `spawns ...`; the run's status unchanged
```

## Behaviours

1. `the table ranks files by time and names their spawns` (test): `costTable` → for three files' lines and owners, rows in descending time, each with its git, node and other counts, and a total row whose sums match.
2. `spawns are split per file by kind` (test): `spawnCount` → a spawn file with git and node lines for two owners answers each owner's kinds; the totals are unchanged.
3. `a file with spawns and no passing test still shows` (test): `costTable` → an owner absent from the reporter lines is a row with 0 s.
4. `the real suite's cost` (run): `npm run test:cost` once on the slice's tip: the table, pasted into the slice report, covers every test file the run started.

Rewrite check: replacing the reporter with a log parse keeps 1-3, which go through `costTable` and `spawnCount`.
Misses: a file's module-load time (outside its tests' durations); the census sees no timing at all, so the reader takes the table's seconds as a lower bound.
