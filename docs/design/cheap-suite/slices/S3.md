# S3 The gate's Rune tests share one build and skip a change that cannot reach them

Feature `cheap-suite` · delivers spec 7, 8 · source: `../architecture.md` §2, §3 F5, F7, §5 L5, §6 A3 · after: S1 (`scripts/gate.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it changes the environment of a process the gate starts (the security trigger) and the bound in A3 is assumed.

## Files owned

- `scripts/gate.mjs`: `cargoStep` takes the selection and returns the env; `runGate` passes both.
- `scripts/select-tests.mjs`: the selection also answers `changed`, the paths its diff named.
- `scripts/rune-target.mjs` (new): the shared target directory and its bound.
- `scripts/test/gate-cargo.test.mjs`: the pins.
- `scripts/test/rune-target.test.mjs` (new): the bound's pins.

## Interface

```
cargoStep(env, which, platform, selection?) -> { command, args, env } | { skip: string }
  // selection undefined or files null: runs; a selection whose `changed` has no path under deck/
  // and no FULL_TRIGGERS file: { skip: 'rune deck: nothing under deck/ changed since <sha7>, skipped' }
selectTests(...) -> { files, total, since, reason?, changed: string[] }   // changed: repo-relative, sorted
runeTargetDir(env, platform) -> string     // <LOCALAPPDATA>/pilot/rune-target on Windows
boundTarget(dir, { max = RUNE_TARGET_MAX }) -> { wiped: boolean, units: number }
  // counts entries in <dir>/debug/.fingerprint; over max, removes dir first (one cold build)
RUNE_TARGET_MAX: number                    // A3: 400 fingerprint units
```

## Behaviours

1. `a selected gate that touches nothing under deck/ runs no cargo` (test): `cargoStep` → given a selection with `changed: ['scripts/land.mjs']`, the skip line naming the sha.
2. `a deck change or a full run still runs cargo` (test): `cargoStep` → given `changed: ['deck/view.mjs']`, or no selection, a command whose env carries `CARGO_TARGET_DIR` = `runeTargetDir`.
3. `the shared build stays bounded` (test): `boundTarget` → a scratch dir with 401 fingerprint entries is removed and reads `wiped: true`; one with 3 is kept.
4. `a second worktree reuses the build` (run): `cargo test` timed in two fresh worktrees of the same commit through the gate's env: the second build under 2 minutes; both numbers in the PR body.

Rewrite check: moving the directory elsewhere keeps 1-3, which read `runeTargetDir`, not a literal path.
Misses: two gates' cargo serialising on the shared directory's lock under load; S8's timed run with gates beside it reads it. The gate dates `deck/rune`'s own sources before its cargo (`staleRoot`), so it rebuilds the root crate from its own worktree, but two gates in different worktrees building at once still race on the root crate's one set of outputs: the second build can overwrite the binary the first is about to run.

## Done

- **Expected**: a slice gate on a scripts-only change prints the skip line; a landing's cargo step reuses the dependencies another worktree built.
- **Verification**: `node --test scripts/test/gate-cargo.test.mjs scripts/test/rune-target.test.mjs`; `npm run test:changed -- --since=<base>`; the two timed builds.
- **Evidence**: 1-3 red before, green after; the second-worktree build time.
- **Prohibited**: no `CARGO_TARGET_DIR` set outside the gate's cargo spawn (`deck/open.mjs` keeps reading `deck/rune/target/release`); no skip of a full run; no target dir under `~/.claude/pilot`, which is the deck's store.
- **Done when**: 1-3 green and the second build is under 2 minutes. Estimate 150 lines.
