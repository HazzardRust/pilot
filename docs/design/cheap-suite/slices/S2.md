# S2 The Rune deck's tests link as one binary

Feature `cheap-suite` · delivers spec 7, 9 · source: `../architecture.md` §2, §3 F6, §5 L6 · after: –
Reviewers: `pilot:rust-reviewer`
Model: sonnet — a file move into one module tree with a guard test; Interface and files leave no choice open.

## Files owned

- `deck/rune/tests/*.rs` (moved): each of the 25 files `git mv`'d to `deck/rune/tests/deck/<name>.rs`, its `mod support;` replaced by `use crate::support;` or `use super::support`.
- `deck/rune/tests/support/mod.rs` (moved): to `deck/rune/tests/deck/support/mod.rs`.
- `deck/rune/tests/deck/main.rs` (new): `mod support;` and one `mod <name>;` per moved file.
- `deck/rune/Cargo.toml`: `[profile.dev] debug = "line-tables-only"` and `[profile.dev.package."*"] debug = false` (L6): backtraces keep file and line, the PDBs shrink.
- `scripts/test/rune-one-binary.test.mjs` (new): the guard.

## Interface

```
deck/rune/tests/deck/main.rs   // the one integration-test target cargo discovers, named `deck`
runeTestTargets(dir) -> string[]   // in the guard test: top-level *.rs and */main.rs under tests/
```

## Behaviours

1. `the Rune deck's tests build one test binary` (test): `runeTestTargets` → `['deck/main.rs']` for the checkout's `deck/rune/tests`; a scratch dir with a top-level `foo.rs` → two targets, and the test names `foo.rs`.
2. `every Rune test still runs` (run): `cargo test --manifest-path deck/rune/Cargo.toml` lists 172 tests (the count before the move, `grep -c '#\[test\]'`), 0 failed, three runs in a row.
3. `a cold build links once and is smaller` (run): `cargo test --no-run` in a fresh `CARGO_TARGET_DIR` timed and sized (`du -sm`) before and after; after is lower on both (before: 13,091 MB per worktree), the numbers in the slice report.

Rewrite check: splitting the module tree differently keeps 1 as long as cargo discovers one target.
Misses: two tests that shared nothing across binaries and now race on a port or an env var in one process; behaviour 2's three runs read it, and the reviewer checks for `std::env::set_var` and fixed ports.

## Done

- **Expected**: `cargo test` builds `deck-<hash>.exe` once instead of 25 test executables; every test still runs.
- **Verification**: `node --test scripts/test/rune-one-binary.test.mjs`; `cargo test --manifest-path deck/rune/Cargo.toml` x3; the timed `--no-run` pair.
- **Evidence**: test 1 red before the move, green after; the 172-test count; the two cold-link timings.
- **Prohibited**: no `autotests = false` (a new top-level file would then never run); no `#[ignore]` added; no test deleted.
- **Done when**: the guard is green, 172 tests pass three times, and the cold build is faster. Estimate 120 lines changed, most of them renames.
