## Behaviours

1. `the recorded run meets the spawn bars` (test): `costBars` → on `cost-after.txt`, spawns ≤ 11,000 and git ≤ 10,000, `ok`.
2. `the full suite fits under load` (run): `npm run test:cost` with two other full suites started beside it in two other worktrees: wall ≤ 15 min, `left running: none`; the three start and end times in the report.
3. `the mutants still die` (run): 20 sampled mutants each on `scripts/land.mjs`, `scripts/sync.mjs`, `scripts/integrate.mjs`, run against those modules' tests on the base and on the tip: killed counts equal or higher.
4. `the ceiling follows the count` (read): `SPAWN_CEILING` is the measured total + 10%, its comment dated.
5. `the version is bumped` (read, spec 10, added, user, itm_52b72e87a2a3): every file that carries the plugin version on feat/cheap-suite reads one version higher than on the base, and they agree with each other. A patch bump (A5); the files are found from the last bump commit, 2530153.

Rewrite check: replacing the cost table's format keeps 1 if `costBars` reads the new one.
Misses: a machine slower than this one; CI's run times on three OSes are read from the PR's checks instead.
