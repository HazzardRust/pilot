## Found

`pilot integrate` of S1 died before its gate ran: `Error: EPERM: operation not permitted, mkdir '...\pilot-gate-slots\slot-0.json.takeover'` at `takeOver` (`scripts/gate-slots.mjs:55`), called from `takeSlot` (`:98`) while it waited for a slot (log `~/.claude/pilot/logs/20261123T065306341Z-slice-cheap-suite-s1.log`). On Windows, `mkdir` of a directory another waiter is removing at that moment answers `EPERM`, not `EEXIST`; `takeOver` rethrows everything but `EEXIST`, so the waiter crashes instead of waiting.

## Files owned

- `scripts/gate-slots.mjs`: `takeOver` treats a lock `mkdir` answering `EPERM` (or `EACCES`) as held by another waiter, as `EEXIST` is: no takeover this round.
- `scripts/test/gate-slots.test.mjs`: the pin.

## Interface

```
takeSlot({ dir, slots, cwd, env, alive, sleep, say, mkdir }) -> { release, slot, waited }   // mkdir injected
```

## Behaviours

1. `a takeover lock being removed reads as held` (test): `takeSlot` → with an injected `mkdir` answering `EPERM` once for the lock, it does not throw and takes the slot on a later round; red before the change (it throws EPERM).
2. `any other mkdir error still throws` (test): `takeSlot` → `ENOSPC` from the lock `mkdir` is rethrown.
3. `a lock that keeps answering EPERM is a fault, not a wait` (test): `takeSlot` → with an injected `mkdir` that always answers `EPERM` for the lock and a dead holder's slot file, it throws `{ code: 'EPERM' }` after `STALE_MS / POLL_MS` (10) consecutive rounds, and not before (10 sleeps); red before the change (it never returns). The count is of rounds, not wall time, and resets for that slot on a round its lock `mkdir` succeeds or answers `EEXIST`.

Behaviour 1's red before the change is its `sleeps` assertion (0, not 1), not a thrown EPERM: the old code already swallowed EPERM, so it took the slot at once without waiting.

Rewrite check: moving `takeOver`'s error handling into another helper keeps 1-3, since each goes through `takeSlot` and its injected `mkdir`.
Misses: a real permission fault on the lock surfaces after about 10 s of rounds rather than at once.
