# S7 Hook and client tests share their daemon and stop waiting on fixed budgets

Feature `cheap-suite` · delivers spec 2, 3, 6 · source: `../architecture.md` §2 verdict table, §3 F10, §5 L3 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — the start budget becomes injectable in `deck/client.mjs`, and keeping each test's protection is judgement.

## Files owned

- `hooks/test/inbox.test.js`: one daemon per file, a fresh `PILOT_DECK_DIR` per test; stop holds 1200/1500 ms to 200 ms.
- `deck/client.mjs`: `ensureDaemon`'s start budget (and `replaceOlder`'s port wait) as an option, default `START_TIMEOUT_MS` (ADR 0121: derived from the contract).
- `deck/test/client-rejoin.test.mjs`: the cap test at a 1 s budget; the two rejoin tests on one daemon.

## Interface

```
ensureDaemon({ resolve, spawnProcess, startTimeoutMs = START_TIMEOUT_MS })   // the start budget, injectable
START_TIMEOUT_MS = 10_000                                     // unchanged default
```

## Behaviours

1. `the client gives up at its injected budget` (test): `ensureDaemon` → with `startTimeoutMs: 1000` and a start hook that never serves, it rejects within 3 s naming the budget.
2. `inbox keeps every check on a shared daemon` (run): `node --test hooks/test/inbox.test.js` → 66 tests pass, its `duration_ms` under 50 s (105 s measured).
3. `client-rejoin is cheaper` (run): its file time under 12 s (36 s measured), 4 tests pass.
4. `nothing it guarded is lost` (read): the coverage of `hooks/inbox*.js`, `hooks/stop-gate*.js` and `deck/client.mjs` from these files, before and after, not lower; the assert count per file not lower.

Rewrite check: any other way of reaching the budget keeps 1, which reads only the rejection and its time.
Misses: a leak from one test's deck state into the next on the shared daemon; a fresh deck dir per test bounds it, and three runs in a row read it.
