# S5 A landing runs only what green CI did not prove

Feature `cheap-suite` · delivers spec 5 · source: `../architecture.md` §2, §3 F8, F9, §5 L7, L8, §6 A2 · after: S3 (`scripts/select-tests.mjs`), S4 (`provenTree`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it changes what the last gate before `pilot` moves runs (the security trigger), and A2 is assumed.

## Files owned

- `scripts/land.mjs`: after `checksGate`, `provenTree` on the same sha; its tree as `since` to `mergeIntoPilot`, its line in land's output.
- `scripts/select-tests.mjs`: `since` may name a tree; a tree is diffed as is against the working tree, no merge-base.
- `scripts/test/land-suite.test.mjs`: the proved and unproved landings.
- `scripts/test/select-tests.test.mjs`: the tree pins.
- `docs/adr/NNNN-cheap-suite.md` (new): the landing trusts a proved tree (amends ADR 0166 L4, L8).

## Interface

```
S4's provenTree({ host, git, sha, base })   // called once per landing, on the caught-up tip
selectTests({ cwd, since })   // since resolving to a tree object: `git diff --name-only <tree> --` plus untracked;
                              // the answer's `since` is the tree; a commit keeps today's merge-base rule
land's output gains one line before the test run: S4's PROOF line
```

## Behaviours

1. `a proved landing runs the selection since the proved tree` (test): `land` → with a fake host proving tree T of the feature, `mergeIntoPilot` is called with `since: T`, the test command is `npm run test:changed -- --since=<T>`, and the output carries `ci proved`.
2. `an unproved landing runs the full suite` (test): `land` → with no proof (a failed job), `npm test` runs and the output carries `no ci proof: <reason>`.
3. `a tree since diffs exactly` (test): `selectTests` → in a scratch repo, `since` = the tree of a commit that is not an ancestor of HEAD selects only the tests reached from the files that differ from that tree, not those since a merge-base.
4. `an unresolvable since still runs full` (test): `selectTests` → a 40-hex that is neither commit nor tree reads `full suite: cannot resolve`.

Rewrite check: replacing the tree diff with `git diff-tree` keeps 3, which checks the selected files only.
Misses: a test the selection misses for a file the delta changed (no import, no basename); the ADR names it, and CI's next run on `pilot` (push) is the backstop.

## Done

- **Expected**: a landing whose tip CI proved on three OSes prints `ci proved <tree7> on 3 jobs` and `selected <n> of <m> test files since <tree7>`; one without prints `no ci proof: <why>` and runs the full suite.
- **Verification**: `node --test scripts/test/land-suite.test.mjs scripts/test/select-tests.test.mjs`; `npm run test:changed -- --since=<base>`.
- **Evidence**: 1-4 red before, green after.
- **Prohibited**: no `since` passed when `provenTree` says none; no skip of the census or the home-store check on a selected landing; no change to `checksGate`'s refusal.
- **Done when**: 1-4 green, ADR written. Estimate 160 lines.
