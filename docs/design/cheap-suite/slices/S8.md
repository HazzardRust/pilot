## Behaviours

1. `merged files keep every assertion` (read): per merged file, `grep -c 'assert\.'` before and after equal; the slice report lists each merge as `old names → new name`.
2. `the landing files land fewer times` (run): `GIT_TRACE` on the five land files: `land` invocations fall by 6 (land-prune 3, land 1, land-adr-branch 1, land-conflict 1; land-clear kept, line 10); file times read from `duration_ms`.
3. `test-quiet still guards the reporter` (run): its tests pass and a deliberately failing fixture still prints `✖ <name>` and `fail 1`, under 10 s (65 s measured).
4. `install still proves a real install` (run): `install-command` passes with exactly one `npm install -g` in a trace, under 20 s (62 s measured).
5. `coverage holds` (read): coverage of `scripts/land.mjs`, `scripts/install*.mjs`, `scripts/quiet-reporter.mjs` and the verbs `cli-wiring` reaches, from these files, not lower.

Rewrite check: (read and run kinds only) a different grouping of the same assertions keeps 1-5.
Misses: an assertion that held only because a test ran on a fresh scenario rather than after another assertion's reads; three runs in a row and the reviewer read it.
