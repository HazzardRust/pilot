## Tests

1. `a moot Blocked item closes and frees its gate2`: `isMoot` → true; `resolveItem` accepted with a notice, then the gate2 post is accepted.
2. `a plain close still waits`: `resolveItem` → `Done` on an unanswered Blocked item is still refused naming Assume the default.
3. `Moot is only for Blocked items, and only the pilot's`: `isMoot` → false on a blocking design question and for a QA writer.
4. `the stop hook holds nothing on a moot item`: `resolveItem` → after the moot close, the stop gate's decision for that session is none.

Rewrite check: inlining the rule in `resolveItem` keeps all four results.
