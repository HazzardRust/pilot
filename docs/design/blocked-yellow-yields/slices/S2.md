# S2 A paused ticket is not concluding and the rail says so

Feature `blocked-yellow-yields` · delivers spec 1, 4 · source: `../architecture.md` §2, A6 · after: S1 (the `paused` mark)
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `deck/items.mjs`: `isPaused`, and its use in `nextTicketOf`, `isBehind`, `standingOf`; `threadState`'s `deck` branch (seam, below).
- `deck/ui/render-parts.mjs`: the standing span reads `paused on <question id>`.

## Interface

```
deck/items.mjs
  isPaused(ticket): boolean          // open, green, with a paused.question string
  nextTicketOf(items, repo, state)   // never a paused ticket
  isBehind(item, items)              // false for a thread naming a paused ticket
  standingOf(ticket, items, coPilotTicket) -> 'closed' | 'co-pilot' | 'in hand' | 'paused' | 'parked'
  threadState(item)                  // a question whose newest message is from: 'deck' reads 'paused'; every other kind keeps 'landing ended short'
deck/ui/render-parts.mjs  renderTicketStanding  // 'paused' reads "paused on <question id>"
```

## Tests

1. `paused is green with a question`: `isPaused` → true for green + `paused.question`; false for green without it and for yellow.
2. `the concluding lane skips a paused ticket`: `nextTicketOf` → with a paused green head and a concluding green second, the second.
3. `a paused ticket's question is never behind`: `isBehind` → false.
4. `the rail says paused on its question`: `standingOf` → `'paused'`; `renderTicketStanding` names the question id.
5. `the yield line is not a short landing`: `threadState` → `'paused'` for a question whose last reply is S1's `from: 'deck'` yield line; `'landing ended short'` still for a gate2 whose last reply is a `deck` line.

Rewrite check: storing `paused` as a ticket state instead of a mark keeps all five results.

Seam (co-pilot, step 6): S1's yield posts a `from: 'deck'` line on the question, which `threadState` (`deck/items.mjs:745`) read as `landing ended short`, seen on S4's live check. Moves no spec line: spec 4's rail says paused.
