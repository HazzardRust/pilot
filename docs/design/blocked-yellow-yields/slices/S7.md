# S7 The crew's prose names the yield, Moot and the shapes auto mode refuses

Feature `blocked-yellow-yields` · delivers spec 8, 9 · source: `../architecture.md` §2, L2, L3, A4, A5 · after: S6 (`hooks/permission-denied.js` beside `blocked.js`), S1 (the deck line), S5 (the `Moot:` rule)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer` (agent configuration: `agents/`, `hooks/`)
Model: opus — prose every crew agent obeys, and a hook that drops a class of denials.

## Files owned

- `agents/pilot.md`: the yield (pause, `deck_ticket co-pilot` the next runnable, resume) and `Moot:`.
- `agents/pilot-co-pilot.md`: hand back `paused` on the yield; the forbidden call shapes.
- `agents/pilot-implementer.md`: the forbidden call shapes; a refused edit goes to `main` as a question with its default.
- `hooks/permission-denied.js`: an `Edit`, `Write` or `NotebookEdit` denial posts nothing.
- `scripts/test/yield-wording.test.mjs` (new), `scripts/test/measure-prompt.test.mjs`, `hooks/test/permission-denied.test.js`: the pins and the pilot's pin line.

## Interface

```
agents/pilot.md              ## Yellow: the "Paused <id>" line -> the pause, then deck_ticket co-pilot the next runnable; resume on its answer
                             a Blocked item done another way, another role's or no longer needed -> deck_resolve "Moot: <why>"
agents/pilot-co-pilot.md     forbidden: a kill bundled with a read; cat of a transcript or task-output file; pilot land
agents/pilot-implementer.md  forbidden as above; a refused edit -> SendMessage main one question with its default
hooks/permission-denied.js   FILE_TOOLS = ['Edit', 'Write', 'NotebookEdit']   // onDenied posts nothing for one
```

## Tests

1. `the pilot names the yield and Moot`: `agents/pilot.md` → the deck line's words, `Moot:` and the resume.
2. `the crew forbids the three shapes`: `agents/pilot-co-pilot.md` → each shape named and forbidden; the same in `agents/pilot-implementer.md`.
3. `a refused edit is a question`: `FILE_TOOLS` → an `Edit` denial posts nothing; a `Bash` denial still posts.
4. `the pin moves by the wording`: `agents/pilot.md` → `measure-prompt` at the measured number, with its history line.

Rewrite check: rewording a sentence while keeping its rule keeps tests 3 and 4 and every pinned term.
