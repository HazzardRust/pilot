# S1 Skeleton: the deck pauses a blocked co-pilot ticket at 20 minutes

Feature `blocked-yellow-yields` · delivers spec 1, 5 · source: `../architecture.md` §2, §3 Seams, L1–L5, A1 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — a daemon timer that writes the store on the clock, the first in the deck besides the landing timeout.

## Files owned

- `deck/lanes.mjs`: `YIELD_MS` and the pure `yieldsDue`.
- `deck/store-tickets.mjs`: `yieldTicket`, beside `needTicket`, reusing its release.
- `deck/store.mjs`: re-exports `yieldTicket`.
- `deck/server-wait.mjs`: `armYields()`, called wherever `armHandoffs()` is.
- `deck/test/yield.test.mjs` (new): the pins.

## Interface

```
deck/lanes.mjs
  YIELD_MS = 20 * 60_000
  yieldsDue(items, repo, coPilotTicket: string | undefined, now: number)
    -> Array<{ ticket: string, question: string, at: number }>   // at = question.postedAt + YIELD_MS
    // only the held ticket; an open blocking question naming it; no message from the user on it
deck/store-tickets.mjs
  yieldTicket(id: string, questionId: string) -> ticket
    // one write: yellow -> green, ticket.paused = { question, at: ISO }, releaseIn, and on the question
    // a { from: 'deck', author: 'deck', seq } line: "Paused <id>: <question> unanswered 20 min; send the
    // co-pilot the pause, then deck_ticket co-pilot the next runnable ticket"; refused unless still due
deck/server-wait.mjs
  armYields(): void   // one unref'd timer per due yield; one already past fires at once; re-armed on change
```

## Tests

1. `a question 20 minutes unanswered is due`: `yieldsDue` → one entry at `postedAt + YIELD_MS`; none with a user reply, none for a ticket the co-pilot does not hold, none for a plain question.
2. `the yield writes green, paused and released in one write`: `yieldTicket` → ticket green with `paused.question`, `coPilotFor` not live, the deck line with a `seq` on the question.
3. `a yield no longer due is refused`: `yieldTicket` → refused once the user replied, the ticket is not yellow, or the co-pilot holds another.
4. `an overdue yield fires on start`: `armYields` → with an injected clock, a store planted 25 minutes old yields at once; a 10-minute one 10 minutes later.

Rewrite check: replacing the timers with a one-minute sweep keeps every result above but the exact firing moment.
