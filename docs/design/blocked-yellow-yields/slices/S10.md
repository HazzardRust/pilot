# S10 A moot close resumes the ticket it paused

Feature `blocked-yellow-yields` · delivers spec 11 (added) · source: `../architecture.md` §2, A3, A4 · after: S4, S5
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer` (who may move a ticket on a close is a trust boundary)
Model: sonnet — two named lines change and three pins say how; nothing is left to choose.

Added by the co-pilot (build-now rule), found by S5's implementer: the yield pauses a ticket on any blocking question,
a `Blocked:` item included, and S5 lets the pilot close that item `Moot: <why>`. S4's `resumeIn`
(`deck/store-tickets.mjs`, `answered`) counts only a message `from: 'user'`, and `resolveItem` never calls it, so a
ticket paused on a Blocked item the pilot then moots stays paused until the user writes on a closed thread. Moves no
locked decision: A3's "answered" gains the Moot close A4 already allows; L1 and L2 stand.

## Files owned

- `deck/store-tickets.mjs`: `resumeIn`'s `answered` predicate only.
- `deck/store-items.mjs`: `resolveItem`, one call to `resumeIn(deck, item)` after a Moot close is written.
- `deck/test/moot-resume.test.mjs` (new): the pins.

## Interface

```
resumeIn(deck, question)   // answered(item): a user message on it, or it is closed with a resolution isMoot accepted
                           //   (closed, item.resolution starts with MOOT from deck/blocked-shape.mjs)
resolveItem(id, resolution, author)
                           // when the close went through isMoot, resumeIn(deck, item) in the same write
```

## Tests

1. `a moot close of the pausing Blocked item resumes the ticket`: a green ticket `paused` on a `Blocked:` question,
   the pilot's `resolveItem(q, 'Moot: done another way', '')` → the ticket is yellow at the yellow head, `paused` gone.
2. `a moot close of the last unanswered blocker resumes it`: paused on question A the user has answered, while Blocked
   item B naming the ticket is open and unanswered; mooting B resumes the ticket.
3. `a plain close resumes nothing`: an agent's non-Moot close of a non-blocking question naming a paused ticket leaves
   it green and `paused`; a Moot on a non-Blocked blocking question is still refused (S5's pin, unchanged).

Rewrite check: calling `resumeIn` on every close instead of only a Moot one keeps all three results.
