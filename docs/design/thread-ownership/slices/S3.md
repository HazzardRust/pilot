# S3 Reads hand over only your own threads, and delivery names its recipient

Feature `thread-ownership` · delivers spec 2 (`deck_read`, `deliveredTo`, the bar) · source: `../architecture.md` §2, A9 · after: S1

## Files owned

- `deck/store.mjs`: `markDelivered` writes `deliveredTo`; `ownerFilter` skips a reply delivered to another kind.
- `deck/server.mjs`: `deck_read` hands off only replies on threads the caller owns; each item returned carries `owner`.
- `deck/client.mjs`: `noteHanded` records only the caller's own threads, under its kind.
- `deck/items.mjs`: `threadState` reads `<owner> has it`; the pilot's wording is unchanged.
- `deck/test/owner-read.test.mjs` (new): the pins.

## Interface

```
markDelivered(handedOver, to: 'pilot' | 'qa'): boolean   // also writes reply.deliveredTo = to, once
reply.deliveredTo?: 'pilot' | 'qa'
deck_read result: items[].owner                            // ownerOf(item), for the reader and the hooks
threadState(item): ... | `${ownerOf(item)} has it`         // 'the pilot has it' for a pilot-owned thread, as today;
                                                           //   an agent's message reads 'qa replied' or 'the pilot replied';
                                                           //   a pass that carries replies is read through to the newest
S1's ownerFilter: now also false for a reply whose deliveredTo is another kind
```

## Tests

1. `a qa deck_read does not mark a pilot thread's reply delivered`: `deliveredAt` stays unset.
2. `a pilot deck_read marks its own thread's reply delivered to pilot`.
3. `a reply delivered to pilot is not handed to a qa wait`: set `deliveredTo: 'pilot'` on a QA-owned reply, and the QA wait skips it.
4. `deliveredTo is written once and never rewritten`.
5. `a qa thread whose reply was handed over reads "qa has it"`.
6. `deck_read items carry their owner`.

## Done

- **Expected**: the bar on a QA walkthrough reads `qa has it` once QA has the reply. A pilot
  polling `deck_read` no longer marks QA's replies as its own. Each reply records who got it.
- **Verification**: `node --test deck/test/owner-read.test.mjs deck/test/handoff.test.mjs`; `npm test`.
- **Evidence**: test 1 fails before and passes after. `handoff.test.mjs` is green unchanged.
  On a scratch deck, the card's bar shows `qa has it` after a QA wait returns the reply.
- **Prohibited**: no filtering of what `deck_read` *shows* (it stays a read); no rewrite of an
  existing `deliveredAt`; no change to `the pilot has it` for pilot threads.
- **Done when**: both test files and the full suite are green, and the bar has been seen live.
