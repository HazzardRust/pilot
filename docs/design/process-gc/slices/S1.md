# S1 A test daemon and a scratch deck die with whoever started them

Feature `process-gc` · delivers spec 1 · source: `../architecture.md` §2, §5 L1-L4 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `deck/leash.mjs` (new): the leash. Parsed from argv, held by polling, and the session pid read from env.
- `deck/daemon.mjs`: `main` holds the leash `leashFrom` returns, closing the server like SIGTERM does.
- `deck/scratch.mjs`: `launch` passes `--leash <CLAUDE_PID> --leash-dir <cwd>` when the session is known.
- `deck/test/leash.test.mjs` (new): the pins.

## Interface

```
type Leash = { pid: number, paths: string[] }
// null for the user's deck: port === DECK_PORT and no --leash. Else pid = --leash ?? ppid,
// paths = [daemonFile, ...(--leash-dir ? [dir] : [])]
export function leashFrom(argv: string[], env: NodeJS.ProcessEnv, opts: { ppid: number, daemonFile: string }): Leash | null
// calls onGone once, within intervalMs (default 2000) of the pid exiting or a path vanishing; returns stop()
export function holdLeash(leash: Leash, onGone: (why: string) => void, opts?: { intervalMs?: number, alive?: (pid: number) => boolean, exists?: (p: string) => boolean }): () => void
// Number(env.CLAUDE_PID) when a positive integer, else null
export function sessionPid(env: NodeJS.ProcessEnv): number | null
daemon.mjs argv: node deck/daemon.mjs [--leash <pid>] [--leash-dir <path>]
```

## Tests

1. `the user's deck has no leash`: `leashFrom` → null on `DECK_PORT` with no `--leash`; `{ pid: ppid }` on any other port.
2. `--leash and --leash-dir are read`: `leashFrom` → `{ pid: 42, paths: [daemonFile, dir] }`.
3. `a gone pid or path calls onGone once`: `holdLeash` → one call naming the reason, with injected `alive`/`exists`.
4. `a daemon leashed to a sleeper exits within 10 s of it`: `leashFrom` → a real `daemon.mjs` on a free port, `/api/health` dead ≤ 10 s after the sleeper is killed.
5. `a removed leash dir ends the daemon`: `holdLeash` → the real daemon gone ≤ 10 s after `rmSync` of its `--leash-dir`.
6. `a scratch deck dies with its session`: `sessionPid` → `startScratch` under a fake `CLAUDE_PID` sleeper; killing it ends the deck, and `stopScratch` afterwards answers "not a scratch deck" without throwing elsewhere.

Rewrite check: replacing the 2 s poll with an OS wait handle keeps all six results.

## Done

- **Expected**: a daemon that a test, a client child or a scratch run started is gone 10 s after its starter is. The user's deck behaves as today.
- **Verification**: `node --test deck/test/leash.test.mjs deck/test/scratch.test.mjs deck/test/daemon.test.mjs`; `npm test`.
- **Evidence**: tests 4-6 red before (the daemon still answers) and green after; `pilot ps`-free proof via `tasklist` in the PR.
- **Prohibited**: leashing the user's deck; reading the leash from env (L4); a timer that kills on age; skipping `server.close` on exit.
- **Done when**: the six tests and `npm test` are green and a hand run shows a killed sleeper's daemon gone.
