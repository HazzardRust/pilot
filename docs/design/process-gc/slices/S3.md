# S3 `pilot ps` lists pilot-owned processes and names orphans

Feature `process-gc` · delivers spec 4 · source: `../architecture.md` §2, §4, §5 L4-L6 · after: S1 (`--leash` argv)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `deck/procs.mjs` (new): the process table (two adapters), the pilot-owned filter and the orphan rules.
- `bin/pilot.mjs`: `pilot ps`, with a usage entry.
- `deck/test/procs.test.mjs` (new): the pins.

## Interface

```
type Proc = { pid: number, ppid: number, name: string, command: string, ageS: number }
type Owned = Proc & { kind: 'daemon' | 'wait' | 'test', owner: number | null, worktree: string | null, orphan: string | null }
// win32: one `powershell -NoProfile -Command` CIM query; else `ps -eo pid=,ppid=,etimes=,comm=,args=`
export function processTable(opts?: { platform?: NodeJS.Platform, run?: (cmd: string, args: string[]) => string }): Proc[]
// orphan = the reason (L5) or null; the user's deck and unmatched processes are never orphans
export function pilotProcesses(table: Proc[], opts: { userDeckPid: number | null, exists?: (p: string) => boolean }): Owned[]
pilot ps: one line per Owned: `<pid> <kind> owner <pid|-> age <h:mm> <worktree|-> <orphan: why|live>`
```

## Tests

1. `the user's deck is listed live, never orphan`: `pilotProcesses` → its row has `orphan: null` even with a dead parent.
2. `a daemon whose --leash pid is gone is an orphan`: `pilotProcesses` → `orphan: 'leash <pid> gone'`; a live leash → null.
3. `a daemon whose worktree is gone is an orphan`: `pilotProcesses` → `orphan: 'worktree gone'` with injected `exists`.
4. `a wait with no claude ancestor is an orphan`: `pilotProcesses` → its reason; one under `claude.exe` → null.
5. `a test root whose parent is gone is an orphan`: `pilotProcesses` → its children are not listed separately.
6. `the Windows and ps readers parse to the same table`: `processTable` → equal `Proc[]` from two recorded outputs.
7. `pilot ps lists a real leashed daemon`: `processTable` → its row with owner = the sleeper's pid.

Rewrite check: replacing PowerShell CIM with `wmic` or a native addon keeps every result above.
