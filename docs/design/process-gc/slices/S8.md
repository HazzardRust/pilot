# S8 The gate goes red on a process left running

Feature `process-gc` · delivers spec 3 · source: `../architecture.md` §2, §5 L9 · after: S7 (`scripts/gate.mjs`), S3 (`pilotProcesses`)
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `scripts/gate.mjs`: a census before and after the suite; red with one line per leftover after a 10 s grace.
- `scripts/test/gate-census.test.mjs` (new): the pins.
- `scripts/test/fixtures/leak/` (new): a scratch checkout whose one test spawns a detached sleeper named `deck/daemon.mjs`.

## Interface

```
// pilot-owned processes under cwd present in `after` and not in `before`
export function leftovers(before: Owned[], after: Owned[], cwd: string): Owned[]
gate output: `left running: none` or `left running: <pid> <kind> <command>` per process, exit 1
S3's processTable, pilotProcesses: what the census reads
```

## Tests

1. `a process present before is not a leftover`: `leftovers` → [] when the same pid is in both.
2. `a process under another checkout is not a leftover`: `leftovers` → [] for a daemon under a sibling worktree.
3. `the leak fixture is red and names it`: `leftovers` → the gate on `fixtures/leak` exits 1 with the sleeper's pid, and the test stops it after.
4. `a leashed daemon that dies in the grace is not a leftover`: `leftovers` → [] for a daemon whose leash ends at suite end.

Rewrite check: replacing the before/after snapshot with a process-creation subscription keeps the four results.

## Done

- **Expected**: a test that starts a process and forgets it turns `npm test` red with the process named, and a green run says `left running: none`.
- **Verification**: `node --test scripts/test/gate-census.test.mjs`; `npm test` ends with `left running: none`.
- **Evidence**: the red fixture run's line, and the full suite's `left running: none`; any real leaker found is fixed in its test, named in the PR.
- **Prohibited**: an allow-list of known leakers; killing leftovers silently instead of going red; a grace over 10 s.
- **Done when**: the four tests are green and `npm test` ends green with `left running: none`.
