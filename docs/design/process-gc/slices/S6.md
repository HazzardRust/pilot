# S6 A third gate waits for a slot

Feature `process-gc` · delivers spec 5 · source: `../architecture.md` §2, §5 L8, A3, A4 · after: –
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `scripts/gate-slots.mjs` (new): two lock files under `os.tmpdir()/pilot-gate-slots`, stale takeover, one waiting line, re-entry by env.
- `scripts/integrate.mjs`: `runTests` takes a slot around its `spawnSync` and passes `PILOT_GATE_SLOT` to the child.
- `scripts/test/gate-slots.test.mjs` (new): the pins.

## Interface

```
// synchronous; re-entrant: env.PILOT_GATE_SLOT set → { release: noop, waited: false } at once
// says once: `gate: waiting for a slot: pid <a> in <dir>, pid <b> in <dir>`
export function takeSlot(opts: { dir?: string, slots?: number, cwd: string, env: NodeJS.ProcessEnv,
  alive?: (pid: number) => boolean, sleep?: (ms: number) => void, say?: (line: string) => void }): { release: () => void, slot: number, waited: boolean }
export const GATE_SLOTS = 2
```

## Tests

1. `two holders, the third waits and says so`: `takeSlot` → `say` called once with both holders; the slot is granted after a `release`.
2. `a dead holder's slot is taken over`: `takeSlot` → granted at once when `alive` says the holder is gone.
3. `a gate inside a gate takes no slot`: `takeSlot` → with `PILOT_GATE_SLOT` set, no file written.
4. `runTests holds a slot while the suite runs`: `takeSlot` → a slot file exists during a fake suite and is gone after, red or green.

Rewrite check: replacing lock files with a named pipe keeps the four results.

## Done

- **Expected**: however many sessions land, sync or integrate at once, two suites run and the rest queue with a line saying whose they wait on.
- **Verification**: `node --test scripts/test/gate-slots.test.mjs scripts/test/integrate.test.mjs`; `npm test`.
- **Evidence**: test 1's waiting line; red before (no slot), green after.
- **Prohibited**: a busy loop without `sleep`; a slot left on a red or thrown run; touching other repos' test commands beyond the slot (A3).
- **Done when**: the four tests and `npm test` are green.
