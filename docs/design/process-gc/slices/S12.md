# S12 The user's deck exits after 10 idle minutes

Feature `process-gc` · delivers spec 9 · source: `../architecture.md` §2, §5 L2, ADR 0136 · after: S1 (`deck/daemon.mjs`), S3 (`processTable`)
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `deck/idle.mjs` (new): the idle rule, a pure decision and a minute tick that reads the process table only when the cheap two conditions already hold.
- `deck/daemon.mjs`: for the user's deck (`leashFrom` null), stamps the last request on `server.on('request')` and holds the idle tick; on idle, closes like SIGTERM.
- `deck/landing.mjs`: `landingsRunning()`, the count of `land` children this daemon has live.
- `deck/test/idle.test.mjs` (new): the pins.

## Interface

```
export const IDLE_MS = 10 * 60_000
// true only when all three hold; `sessions` is read lazily, never when either of the others is live
export function isIdle(state: { now: number, lastRequestAt: number, landings: number, sessions: () => number }): boolean
// ticks every intervalMs (default 60_000); calls onIdle once; returns stop()
export function holdIdle(opts: { lastRequestAt: () => number, landings: () => number,
  table: () => Proc[], onIdle: () => void, now?: () => number, intervalMs?: number }): () => void
export function landingsRunning(): number
S3's processTable, Proc: a session is a row whose name is `claude` or `claude.exe`
```

## Tests

1. `idle when all three hold`: `isIdle` → true at 10 min with no session, no landing and no request.
2. `any one live keeps the deck`: `isIdle` → false with a session, with a landing, or with a request at 9:59.
3. `the table is read only when the other two hold`: `holdIdle` → `table` not called while a landing runs or a request is recent.
4. `a running land counts`: `landingsRunning` → 1 while a fake `land` child runs, 0 after it exits.
5. `a real daemon closes on the fake idle`: `holdIdle` → a daemon on a free port with injected clock, table and landings stops answering `/api/health` once idle, and still answers while a fake session is in the table.

Rewrite check: replacing the minute tick with a timer re-armed on each request keeps all five results.

## Done

- **Expected**: with no Claude session, no landing and nobody reading the page for 10 minutes, the user's deck is gone; the next session starts it as today.
- **Verification**: `node --test deck/test/idle.test.mjs deck/test/daemon.test.mjs deck/test/landing.test.mjs`; `npm test`.
- **Evidence**: tests 1-5 red before and green after; a hand run with `IDLE_MS` injected short showing the deck close.
- **Prohibited**: reading the process table every tick; exiting during a landing; an idle rule on a leashed daemon; a sweep that kills the deck from outside.
- **Done when**: the five tests and `npm test` are green.
