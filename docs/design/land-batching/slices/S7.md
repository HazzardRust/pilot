# S7 The gate holds a git ceiling and the product-only run is measured

Feature `land-batching` · delivers spec 1, 2, 6 · source: `../architecture.md` §2, §6 A1, A4, A5 · after: S3 (suite), S4 (suite), S5 (suite)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — one constant, one parameter and a recorded run; the one choice (which numbers) is a rule below.

## Files owned

- `scripts/gate.mjs`: `GIT_CEILING` (new), `spawnLines` red above either ceiling, a dated comment.
- `scripts/test/gate-spawns.test.mjs`: the bar cases.
- `docs/design/cheap-suite/architecture.md`: spec 3 and A4 name the ceilings this slice sets.
- `docs/design/land-batching/cost-after.txt` (new): the measured full run, product cut only.
- `docs/design/land-batching/spawns-after.txt` (new): the census by `census-probe.mjs`, the same probe as `spawns-before.txt`.

## Interface

```
SPAWN_CEILING: number; GIT_CEILING: number   // scripts/gate.mjs
runGate(args, { ceiling?: number, gitCeiling?: number, ... })   // red when total > ceiling or git > gitCeiling
```

The rule for the numbers: the run meets 11,000 / 10,000, the ceilings are 11,000 / 10,000 (spec 1, 2 done here);
it does not, they are the run's own two numbers, and S6 lowers them to the signed ones.

## Behaviours

1. `a run over either ceiling is red` (test): `runGate` → with ceilings 11,000 / 10,000, a count of 11,001 total is red; 10,001 git under 11,000 total is red, naming `git over 10000`; 11,000 / 10,000 is green.
2. `the product-only run is recorded` (run): `npm run test:cost` on the feature tip, after prune-worktrees is on main (A4), saved as `cost-after.txt`; the ceilings follow the rule above.
3. `the census says where the saving came from` (read): `spawns-after.txt` against `spawns-before.txt`, per entry module.

Rewrite check: any ceiling check that reads both numbers keeps 1.
Misses: headroom for later features (A5); the next feature's gate reads it.

## Done

- **Expected**: the gate is red past either ceiling, and the product cut's full run is on record.
- **Verification**: `node --test scripts/test/gate-spawns.test.mjs`; `npm run test:cost` once, alone.
- **Evidence**: the gate's spawn line quoted from `cost-after.txt`.
- **Prohibited**: no ceiling above the run's own numbers; no test skipped.
- **Done when**: 1-3 hold. Estimate 60 lines plus the two recorded files.
