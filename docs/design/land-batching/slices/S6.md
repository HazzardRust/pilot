# S6 Test fixture helpers spawn fewer git

Feature `land-batching` · delivers spec 5 · source: `../architecture.md` §2, §6 A1 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — A1 is assumed, and which helper folds keep every caller's repository identical is a judgement.

## Files owned

- `scripts/test/lib/land-repos.mjs`: `commitFile` and `clone` fold their add/commit and clone/checkout pairs.
- `scripts/test/lib/git-fixture.mjs`: any per-test git its restore runs.
- `scripts/test/lib/fixture-git.test.mjs` (new): the folded helpers make the same commits with fewer spawns.

## Interface

```
commitFile(repo: string, file: string, text: string, message: string): string   // the new commit's SHA, as today
S1's countGit: the spawn count each helper is held to
```

## Behaviours

1. `a folded helper makes the same commit` (test): `commitFile` → on a fresh repo the commit's tree, parent, subject and author equal those the base helper made, with fewer git (both counts in the test).
2. `no test is lost` (read): the full run's file count (629) and pass count equal the base's; 0 asserts removed in the diff.

Rewrite check: a helper built on `git fast-import` or plumbing keeps 1's tree and subject.
Misses: a test that relied on a helper's intermediate state (an unstaged file between add and commit); the full suite reads it.

## Done

- **Expected**: the shared fixture helpers make the same repositories with fewer git.
- **Verification**: `node --test scripts/test/lib/fixture-git.test.mjs`; `npm test` once on the final state.
- **Evidence**: 1's counts; the full run's file and pass counts against the base's.
- **Prohibited**: no test file deleted, skipped or `todo`; no assert removed; no edit outside `scripts/test/lib/` but helper call sites whose arguments change.
- **Done when**: 1-2 hold and the gate is green. Estimate 150 lines.
