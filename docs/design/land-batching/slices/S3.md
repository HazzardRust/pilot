# S3 `pilot integrate` runs on one view

Feature `land-batching` · delivers spec 3, 4 · source: `../architecture.md` §3, §5 L2, §6 A4 · after: S1 (`gitView`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — `integrate` builds runners in six places and starts processes; prune-worktrees' `pruneSlice` lands beside it (A4).

## Files owned

- `scripts/integrate.mjs`: `integrate`, `trial`, `baseOf`, `pilotBase`, `landedOnPilot` take the command's view instead of `gitIn(cwd)`.
- `scripts/test/integrate-pin.test.mjs` (new): the integrate pin and its git count.

## Interface

```
baseOf(cwd: string, runs?: string | null, git?: Git): { ref: string, chained?: string }   // git defaults to gitView(cwd)
landedOnPilot(cwd: string, head: string, ref?: string, git?: Git): boolean
S1's gitView: built once in integrate() and trial(), passed down
```

## Behaviours

1. `integrate prints what it printed on the base` (test): `integrate` → one slice integrated on a seeded repo prints the pinned line, the merge subject and trailers, and feat's new tip parents, recorded on the base first.
2. `one integrate spawns at most 75% of its base count` (test): `baseOf` → called through `integrate` on the seeded repo, the whole command spawns ≤ 0.75 × the base count, both numbers in the test.

Rewrite check: any memo behind `baseOf` keeps 1's lines and 2's bar.
Misses: a run record base of `feat/<N>` whose branch is gone; `integrate-chain`'s existing tests read it.

## Done

- **Expected**: `pilot integrate` prints the same line and makes the same merge with a quarter fewer git or better.
- **Verification**: `git merge origin/main` first (A4); `node --test scripts/test/integrate*.test.mjs`; `npm run test:changed -- --since=origin/main`.
- **Evidence**: the pin green on the base commit before the change; the count before and after.
- **Prohibited**: no change to `integrate.mjs`'s exported `git`; no edit to existing integrate* tests; no edit to `pruneSlice` beyond passing the view.
- **Done when**: 1-2 pass, every integrate* test unedited and green, gate green. Estimate 120 lines.
