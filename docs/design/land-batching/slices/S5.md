# S5 The landing's tail reuses its fetch and worktree list

Feature `land-batching` · delivers spec 4 · source: `../architecture.md` §6 A3, A4 · after: S2 (`scripts/land.mjs` passes its view; `tipOf`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — `deleteMerged` deletes remote branches and `prune` removes worktrees; A3 is assumed.

## Files owned

- `scripts/branches.mjs`: `deleteMerged` takes the landing's view and skips its own `fetch origin` when given `fetched: true`.
- `scripts/worktrees.mjs`: `prune` takes an optional view for its worktree list and pilot tip, and skips `fetchBase` when given `fetched: true`.
- `scripts/land.mjs`: `deleteRunBranches` and `clear` pass the view and `fetched: true`.
- `scripts/test/land-tail-spawns.test.mjs` (new): the tail's count and its outcome.
- `scripts/test/land-pin.test.mjs`: the landing's bar moves to ≤ 27, spec 4's.

## Interface

```
deleteMerged({ git, host, select, into, fetched?: boolean }): { deleted, kept, deleteFailed? }
prune(repo: string, base: string, { run, merged, keep, holder, git?: Git, fetched?: boolean }): { removed, kept, failed }
S2's tipOf: the landed pilot's tip
```

## Behaviours

1. `the tail deletes and removes what it did before` (test): `deleteMerged` → after a landing on a seeded repo with a merged `design/x` and a slice worktree, the same branches are deleted and the same `removed`/`kept` lines print as on the base.
2. `the tail fetches nothing` (test): `prune` → given `fetched: true` it spawns no `fetch`; without it, one, as today.
3. `one landing spawns at most 27 git` (test): `deleteMerged` → reached through S1's landing pin, the landing spawns ≤ 27 (39 on the base) and prints the pinned lines.

Rewrite check: any source of the refs that names the same branches keeps 1.
Misses: a branch pushed by another session during the landing (A3); the next landing sees it.

## Done

- **Expected**: a landing's tail deletes the same branches and removes the same worktrees with two fewer fetches and one worktree list.
- **Verification**: `git merge origin/main` first (A4, prune-worktrees); `node --test scripts/test/land*.test.mjs scripts/test/worktrees*.test.mjs scripts/test/branches.test.mjs`.
- **Evidence**: 1's lines equal on base and tip; the landing pin's count 32 → ≤ 27.
- **Prohibited**: no skipped fetch outside a landing (`pilot worktrees prune` alone still fetches); no edit to existing worktrees* or branches tests.
- **Done when**: 1-3 pass and the gate is green. Estimate 100 lines.
