# S2 The deck traces grant, release, resolve, the press and its own start

Feature `crew-handoff-trace` · delivers spec 1, 9 · source: `../architecture.md` §2, §3 Seams, §5 L1, L5 · after: S1 (`deck/server-tools.mjs`, `step`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the press is written in a route on the deck's HTTP boundary, which is the security trigger.

## Files owned

- `deck/server-tools.mjs`: in `deck_ticket`, a row `granted` or `released` with its ticket; in `deck_resolve`, a row `resolved` for a `handoff` or `crew-handoff`.
- `deck/server-routes.mjs`: on a stored `Handoff failed` choice, a row `failed` (about 30 lines free under the 800 cap).
- `deck/daemon.mjs`: at start, a row `deck started` with `root` (the deck's code directory) and `version` (`package.json`).
- `deck/test/trace-deck.test.mjs` (new): one test per row.

## Interface

```
S1's step(row)          // row gains two optional fields, for `deck started` only: root, version
S1's trace(argv)        // prints the newest `deck started` row first: `deck: <root> <version> since <at>`
```

## Behaviours

1. `a grant and a release leave rows` (test): `step` → `deck_ticket co-pilot` then `release` on a scratch ticket write `granted`, `released`, each with that ticket.
2. `resolving a crew-handoff leaves a row` (test): `step` → `deck_resolve` on one writes `resolved` with its item; on a question, nothing.
3. `the user's press leaves a row` (test): `step` → a `Handoff failed` reply on a crew-handoff writes `failed` with the item.
4. `the deck says what code it runs` (test): `trace` → after a daemon start, the first line names the root and version.

Rewrite check: moving any row's write into the store keeps 1-4, because they read only the trace file.
Misses: a refused `deck_ticket` writes no row, so a refusal is not traced; the tool's own reply already says it.

## Done

- **Expected**: on a scratch deck, `pilot trace <ticket>` starts with the deck's code root and lists the grant and release.
- **Verification**: `node --test deck/test/trace-deck.test.mjs`; `npm test` once.
- **Evidence**: 1-4 red before, green after; `wc -l deck/server-routes.mjs` under 800.
- **Prohibited**: no line in `store-runs.mjs`, `store-items.mjs` or `items.mjs`; no row on a refused call.
- **Done when**: four behaviours hold and `npm test` is green. Estimate about 80 lines.
