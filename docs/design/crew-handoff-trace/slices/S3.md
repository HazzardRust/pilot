# S3 Hooks trace a co-pilot's stop and its successor's spawn

Feature `crew-handoff-trace` · delivers spec 1 · source: `../architecture.md` §2, §3.2, §5 L1, L4 · after: S1 (`step`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new hook registration under `hooks/` is the security trigger, and SubagentStop's payload is unprobed.

## Files owned

- `hooks/subagent-stop.js` (new): on a `pilot:pilot-co-pilot` stop, a row `stopped` with its agent id and the deck's co-pilot ticket.
- `hooks/hooks.json`: a `SubagentStop` entry for it.
- `hooks/spawn-trace.js` (new): a PostToolUse lane. On a main-session `Agent` call with `subagent_type` `pilot:pilot-co-pilot`, a row `spawned`.
- `hooks/post-tool.js`: `spawn-trace.js` in `MODULES`.
- `hooks/test/spawn-trace.test.js` (new): both rows, and the silent cases.

## Interface

```
spawn-trace run(input): null          // writes S1's step({ step: 'spawned', kind: 'crew-handoff', ticket, session }); says nothing
subagent-stop main(): exit 0          // writes S1's step({ step: 'stopped', kind: 'crew-handoff', ticket, agent }); prints nothing
ticket: GET /api/record?repo=<cwd> co-pilot.ticket (L4), else absent; never read from a prompt
```

## Behaviours

1. `a co-pilot spawn leaves a row` (test): `run` → an Agent payload for `pilot:pilot-co-pilot` writes `spawned` with the deck's ticket.
2. `a spawn's prompt never reaches the row` (test): `run` → a prompt holding a marker writes no row containing it.
3. `any other spawn is silent` (test): `run` → `pilot:pilot-implementer`, or an Agent call from a subagent, writes nothing.
4. `a co-pilot stop leaves a row` (test): `main` → a SubagentStop payload for a co-pilot writes `stopped`; a deck that is down still writes it, with no ticket.
5. `SubagentStop's fields are as assumed` (run): a live probe of one SubagentStop payload, its keys pasted in the PR.

Rewrite check: reading the ticket some other way keeps 1-4, because they read only the trace file.
Misses: a co-pilot killed without a SubagentStop leaves no `stopped`; the timeline's tail names it as waiting.

## Done

- **Expected**: in a scratch pilot session, spawning a co-pilot and letting it stop leaves `spawned` and `stopped` in `pilot trace`.
- **Verification**: `node --test hooks/test/spawn-trace.test.js`; behaviour 5's probe; `npm test` once.
- **Evidence**: 1-4 red before, green after; the probe's payload keys.
- **Prohibited**: no output from either hook; no blocking; no prompt text read beyond `subagent_type`.
- **Done when**: five behaviours hold and `npm test` is green. Past 150 lines, or if `agent_type` is missing from SubagentStop, stop and ask.
