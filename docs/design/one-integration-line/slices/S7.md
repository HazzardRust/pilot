# S7 `adr-index` names a duplicate number and knows the placeholder

Feature `one-integration-line` · delivers spec 7 · source: `../architecture.md` §2, A4, red team · after: –
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — two checks and one helper with fixed shapes; added from a found issue.

## Files owned

- `scripts/adr-index.mjs`: `checkIndex` names a number two files share; `NNNN` in a supersession list is accepted while a `NNNN-*.md` file exists; exports `nextNumber`.
- `scripts/test/adr-index-placeholder.test.mjs` (new): the pins below over fixture directories.

## Interface

```
checkIndex(dir) -> { ok, problems: string[] }   (seam, recorded at integration: the real return shape)
  // + `ADR <n> is used by <a> and <b>`; a placeholder file is never indexed and never a problem
nextNumber(dir) -> string   // one past the highest `^\d{4}-` file, four digits; '0001' in an empty dir
PLACEHOLDER = 'NNNN'
```

## Tests

1. `a duplicate number is named`: `checkIndex` → two `0161-*.md` files: exactly 1 problem naming both.
2. `a placeholder passes on a feature branch`: `checkIndex` → `NNNN-x.md` plus `0140` with `superseded_by: [NNNN]`: 0 problems.
3. `the next number`: `nextNumber` → files `0001`, `0166` give `0167`.

Rewrite check: reading the directory another way keeps all three results.

## Done

- **Expected**: `npm run adr-index` says which two files share a number, and a run's placeholder ADR passes.
- **Verification**: `node --test scripts/test/adr-index*.test.mjs`; `npm run adr-index`; `npm test` in the background.
- **Evidence**: test 1 red before (reads "missing from the index"), green after.
- **Prohibited**: renaming either duplicate in the check; listing the placeholder in the index.
- **Done when**: the three tests and `npm test` are green.
