## Files owned

- `scripts/adr-allocate.mjs` (new): finds the placeholder, renames it, rewrites citations, refreshes the index, amends HEAD.
- `scripts/sync.mjs`: `mergeIntoPilot` calls `allocateAdr` on a merge it will push, after the merge or the reused one, before the suite.
- `scripts/land.mjs`: prints `ADR NNNN-<slug> is <n>` above the main line.
- Added (found, spec 9): `scripts/land.mjs` (the already-on-pilot branch at `if (merge.merged)`, :209): an already-landed feature still closes its open PR against pilot with the landing comment; it posts no new comment on a closed PR or one against main. Pin in `scripts/test/land-main-pr.test.mjs`.
- `scripts/test/adr-allocate.test.mjs` (new): the module's pins.
- `scripts/test/land-adr.test.mjs` (new): two landings in sequence over `scripts/test/lib/land-repos.mjs`.

allocateAdr(dir, { since }) -> { from: string, to: string } | null

## Tests

1. `two features land with consecutive numbers`: `mergeIntoPilot` → feature x then y, each with `NNNN-*.md`: pilot holds `0168-x.md` then `0169-y.md`, 1 commit per landing.
2. `citations follow the rename`: `allocateAdr` → `ADR NNNN` and `NNNN-x` in a changed file read `ADR 0168` and `0168-x`; an unchanged file naming `NNNN` is untouched.
3. `two placeholders refuse the landing`: `allocateAdr` → throws naming both; nothing pushed.
4. `the prepared trial allocates nothing`: `mergeIntoPilot` → `push` false: the placeholder keeps its name.
5. `a re-landing closes the feature PR left open (added, spec 9)`: `comment` → feature already on pilot, its PR open against pilot: 1 `pr close` with the landing comment; the same with the PR closed: 0 `pr close`, 0 `pr comment`.

Rewrite check: allocating in another module keeps all four results.
