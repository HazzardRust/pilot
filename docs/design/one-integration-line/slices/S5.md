# S5 `pilot integrate --trial` replaces `--default`

Feature `one-integration-line` · delivers spec 1 · source: `../architecture.md` §2, L5, A2, A8 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument, and about 180 lines deleted around a kept seam.

Rebases on suite-at-landing S6 (`integrate.mjs`'s `runTests` calls).

## Files owned

- `scripts/integrate.mjs`: `--trial` pushes the feature and runs `trialOnPilot`; `takeDefault`, `keepDefault`, `resumeDefault`, `mergeableOf` and `--default` are deleted.
- `scripts/merge-generated.mjs`: `measurePins`, `resolvePin`, `measuredPilot` deleted with their only caller (A8).
- `scripts/test/integrate-default.test.mjs`: deleted with `takeDefault`.
- `scripts/test/integrate-trial.test.mjs`: re-pointed at `--trial`.
- `scripts/test/merge-generated.test.mjs`: its `integrate --default merges both` case goes.

## Interface

```
integrate(undefined, { trial: true, cwd, gh }) -> { ok, line, failing, code? }
  // line: `on pilot: clean at <sha7>` (pushed) | the lander's conflict line, code 3 | `trial NOT run: <why>`
main(['--trial']) -> 0 | 1 | 3
main(['--default']) -> 1   // usage: pilot integrate [<slice-branch>] | pilot integrate --trial
trialOnPilot({ cwd, git, head }) -> { clean: true } | { paths, dir }   // unchanged
```

## Tests

1. `the trial pushes the tip and merges nothing`: `integrate` → a feat behind origin/main: `on pilot: clean at <sha7>`, feat's tip unchanged, 0 merge commits made.
2. `a conflicted trial prepares the lander's merge`: `integrate` → code 3, the `-land-<slug>` worktree holds the prepared merge.
3. `--default is a usage error`: `main` → exit 1 and the usage line.

Rewrite check: trying the merge another way keeps all three results.

## Done

- **Expected**: before its gate2, QA runs `pilot integrate --trial` and posts the sha it prints.
- **Verification**: `node --test scripts/test/integrate*.test.mjs scripts/test/merge-generated.test.mjs`; `npm test` in the background.
- **Evidence**: test 1 red before (no `--trial`), green after.
- **Prohibited**: keeping `--default` as an alias; merging anything into feat in `--trial`.
- **Done when**: the three tests and `npm test` are green and `git grep -n measurePins scripts` is empty.
