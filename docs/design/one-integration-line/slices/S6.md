## Files owned

## Interface

```
sync({ cwd, git, test, keep }) -> { sha, merged, line }
  // main's merge changes no file (git merge-tree --write-tree pilotTip mainTip equals pilotTip^{tree}):
  // { sha: pilotTip, merged: false, line: `pilot already has main@<sha7>` }, nothing pushed, no suite
```

## Tests

1. `main that merged pilot is a no-op`: `sync` → main = merge of pilot (a merge commit pilot lacks): `pilot already has main@<sha7>`, 0 pushes, 0 test runs.
2. `a squash of pilot is a no-op too`: `sync` → main holds pilot's tree as one squash commit: the same line, 0 pushes.
3. `real work on main still syncs`: `sync` → main with one new file: a `Merge main into pilot` pushed.

Rewrite check: comparing trees another way keeps all three results.
