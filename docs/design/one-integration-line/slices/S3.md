## Interface

```
closingReportOf(record, gate) -> string
  // first human step: `Merge #<n> into main with a merge commit, when you want main to have it.`
  // no main line in the landing: `main gets pilot: not printed by land`
startLanding(gate) -> void   // spawns `pilot land` alone; no `--ready` retry
S2's mainLine: the line shapes parsed here
postFilled(fields) -> fields  // added, spec 8: a bodiless `report` with `ticket` gets closingReportOf's body
```

## Tests

1. `the report's first step is the main PR`: `closingReportOf` → a landing line `main gets pilot: #901` gives `Merge #901 into main with a merge commit`.
2. `no ready retry is spawned`: `startLanding` → a landed gate2 spawns `pilot land` 1 time and nothing with `--ready`.
3. `an unknown main line asks the pilot`: `closingReportOf` → `main gets pilot: unknown (gh failed)` reads as needing the pilot in the store's flag.

4. `a report with no body is filled from the record (added, spec 8)`: `postFilled` → a daemon over a fixture run record: `deck_post` kind `report` with `ticket` and no body is stored, its body the closing report; any other kind with no body is still refused "body must be a non-empty string".

Rewrite check: rendering the report from another template keeps all three results.
