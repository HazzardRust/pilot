## Interface

```
mainGetsPilot({ git, gh }) -> { number: number | null, opened: boolean, why?: string }
  // reuse the one open PR head pilot, base the default branch; else gh pr create --base <default> --head pilot --title "main gets pilot"
  // run remote not origin, or none: number null and why; gh fails: number null and why
mainGetsPilot({ git, gh }) -> { number: number | null, opened: boolean, why?: string, byHand?: string }
  // seam, recorded by the co-pilot: byHand is '<remote>/pilot' under a fork run remote, 'pilot' under none; then number null, 0 gh calls
mainLine({ number, opened, why, byHand }) -> string
  // `main gets pilot: #<n>` | `main gets pilot: #<n> (opened)` | `main gets pilot: open a PR from <byHand> to main by hand` | `main gets pilot: unknown (<why>)`
  // `main gets pilot: #<n>` | `main gets pilot: #<n> (opened)` | `main gets pilot: open a PR from <remote>/pilot to main by hand` | `main gets pilot: unknown (<why>)`
main(['--ready']) -> 1   // usage: pilot land
```

## Tests

1. `the first landing opens the main PR`: `mainGetsPilot` → no open pilot PR: `gh pr create` called 1 time, `#<n> (opened)`.
2. `a later landing reuses it`: `mainGetsPilot` → one open: 0 creates, the same number.
3. `a fork run remote opens none`: `mainGetsPilot` → `pilot.remote` names a fork: number null, 0 gh calls.
4. `an open feature PR is closed with the landing comment`: `mainGetsPilot` → after a landing whose fake gh reads the feature PR OPEN, 1 `gh pr close` carrying `landed on pilot at <sha>`.
5. `the landing's last line is the main line`: `mainLine` → land's output ends `main gets pilot: #<n>`, with no `merge first` or `ready` line.

Rewrite check: asking GitHub through another client keeps all five results.
