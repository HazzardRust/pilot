## Tests

1. `a list line with a numeral passes`: `checkSpec` → `[]` for "1. A ticket pauses after 20 minutes."
2. `a line that only says it works is refused`: `checkSpec` → one `spec-bar` at that line.
3. `a table row whose only digits are its # and ticket cells is refused`: `checkSpec` → one `spec-bar`.
4. `identifier digits are not a bar`: `checkSpec` → `spec-bar` for a line naming only `S2`, `ADR 0142`, `x.mjs:12` and "spec 3".
5. `a number word or bound phrase is a bar`: `checkSpec` → `[]` for "two tickets" and "at most once".
6. `the CLI routes architecture.md to the spec check`: `node scripts/check-slices.mjs <dir>/architecture.md` → exit 1 naming `no-bar.md`'s line; exit 0 on `good.md` copied as `architecture.md`.

Rewrite check: replacing the bar regexes with a tokenizer keeps every result above.
