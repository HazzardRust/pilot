# S3 A rebuild keeps the user's Rune window

Feature `ui-design-workflow` · delivers spec 8 · source: `../architecture.md` §2, §3.1, §3.3, §6 A9 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the cause is a hypothesis (A9) and the slice starts a process, the security trigger.

## Files owned

- `deck/open.mjs`: `openDeck` spawns the copy `launchCopy` returns.
- `deck/test/open-copy.test.mjs` (new): the pins.
- `bin/pilot.mjs`: added in the run (seam, co-pilot): `pilot deck` prints `open <runCopy(rune)>`, the copy it launches, not the release exe.
- `deck/test/launch.test.mjs`, `deck/test/open.test.mjs`: added in the run (seam, co-pilot): the `open` line pins match the copy under `target/run`.

## Interface

```
launchCopy(binary: string, dir: string, fs = node:fs): string   // copies to <dir>/pilot-deck-<mtimeMs>(.exe) once per build; removes older copies not in use
openDeck(spawnOpener, platform, rune): unchanged signature; spawns launchCopy(rune, <target>/run) when rune is set
```

## Behaviours

1. `the cause, probed first` (run): with a window open from `target/release`, `cargo build --release` after a touch of `src/main.rs`; its exit and message are recorded. A 0 exit stops the slice and goes to `main` (A9).
2. `the spawned path is never the release exe` (test): `openDeck` → the injected opener gets `<target>/run/pilot-deck-<mtime>`, not `target/release/pilot-deck`.
3. `one copy per build` (test): `launchCopy` → called twice for one mtime copies once; a new mtime copies again.
4. `a copy in use is kept` (test): `launchCopy` → a removal that throws `EBUSY` or `EPERM` leaves the file and does not throw.
5. `rebuild with the window up` (run): the window open, `cargo build --release` exits 0 and the window stays; `pilot deck` then opens the new build.

Rewrite check: replacing the copy with a hard link keeps 2 and 3.
Misses: disk use of old copies held open for days; QA's doctor read covers it.

## Done

- **Expected**: the user's deck window survives every rebuild, and the next open shows the new build.
- **Verification**: `node --test deck/test/open-copy.test.mjs`; 1 and 5 by hand on Windows; the selection once.
- **Evidence**: behaviour 1's output; 2-4 red before, green after; behaviour 5 seen.
- **Prohibited**: no kill of a running deck; no shell; no path from the environment.
- **Done when**: five behaviours hold, or behaviour 1 refutes A9 and `main` has the re-cut. Estimate about 90 lines.
