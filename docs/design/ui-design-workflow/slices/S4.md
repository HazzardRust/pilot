# S4 `pilot look apply` changes only the touched tokens

Feature `ui-design-workflow` · delivers spec 3 · source: `../architecture.md` §2, §3.3, §5 L6, §6 A3, A7, A10 · after: S1 (`deck/look.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — A3 and A7 are assumed, and the export is user-supplied input written into a tracked file.

## Files owned

- `skills/ui-design/playground/tokens.js` (new): the leaf parser lifted out of the Rune page, plus `applyExport`; a classic script that sets `globalThis.tokens`.
- `deck/rune/playground/index.html`: loads `tokens.js` by `<script src>` and drops its inline parser.
- `deck/look.mjs`: `apply` subcommand, loading `tokens.js` through `vm`.
- `deck/test/look-apply.test.mjs` (new): the pins.

## Interface

```
tokens.leaves(text: string): { root, leaves: { path: string[], start, end, raw, value }[] }   // throws on trailing text
tokens.exportText(doc): string                       // untouched leaves keep their raw bytes
tokens.applyExport(current: string, exported: string): { text: string, changed: string[], refused: string[] }
// pilot look apply <export.json> <surface.json>: writes the token file only when refused is empty; prints changed paths
```

## Behaviours

1. `an untouched export is byte-identical` (test): `applyExport` → the current text in, the same bytes out, `changed` empty.
2. `one changed colour changes one leaf` (test): `applyExport` → `by.qa` moved; the diff is that one value, `changed` is `['by.qa']`.
3. `an unknown key or a wrong shape is refused whole` (test): `applyExport` → a new key, or a hex where a number stood, gives `refused` and `text` equal to current.
4. `the Rune page still exports byte-stably` (look): the page opened from file://, imported `theme.json`, exported untouched: `git diff --exit-code` on the copy.
5. `apply on the real theme` (run): an export changing two leaves, then `pilot look apply`: `git diff --stat` shows `theme.json` only, 2 lines.

Rewrite check: replacing the hand parser with any byte-preserving JSON editor keeps 1-3.
Misses: a token file that is not JSON; the adapter format says JSON only.

## Done

- **Expected**: a user's export lands as one change to the token file, refused whole when it does not fit.
- **Verification**: `node --test deck/test/look-apply.test.mjs`; `cargo test --manifest-path deck/rune/Cargo.toml --test theme playground_mix`; 4, 5 by hand.
- **Evidence**: 1-3 red before, green after; `playground_mix` still green; behaviour 5's diff stat.
- **Prohibited**: no `JSON.stringify` of the whole file; no `eval` of the export; no write on any refusal.
- **Done when**: five behaviours hold and the gate is green. Estimate about 200 lines.
