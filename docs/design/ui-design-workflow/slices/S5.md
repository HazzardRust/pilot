## Interface

```
tokens.contrast(fg: '#rrggbb', bg: '#rrggbb'): number      // WCAG 2.x ratio, 2 decimals
surface.json: + preview: string                            // a page relative to surface.json
onTokens(event: MessageEvent): void                       // each preview's handler; reads only data.tokens and data.dark
postMessage({ tokens: object, dark: boolean }, '*')        // page → preview; the preview reads only these two keys
// pilot look shape <surface.json>: opens index.html?preview=<file url>
```

## Behaviours

1. `contrast at the AA edge` (test): `tokens.contrast` → `#777777` on `#ffffff` is 4.48; `#767676` is 4.54.
2. `the Rune mix still matches theme.rs` (run): `cargo test --test theme playground_mix` is green at the moved path.
3. `one page, two surfaces` (look): `pilot look shape` on each `surface.json` shows its own preview; a moved colour redraws it.
4. `a low pair is flagged` (look): setting `roles.surface` to a mid grey flags the text pair under 4.5:1.
5. `a preview ignores a foreign message` (test): `onTokens` → a message lacking `tokens` changes nothing.

Rewrite check: replacing `postMessage` with any page-to-preview channel keeps 1, 2, 5.
Misses: browsers that block file:// iframes; QA's walkthrough on the user's browser reads it.
