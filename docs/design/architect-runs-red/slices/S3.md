## Interface

```

  // adds: §6 has an A<n> and no record -> refused; verdictsOf(artefact at sha) differs -> refused naming each id
S2's parseVerdictMessage, verdictsOf
```

## Tests

1. `the pilot records its verdicts`: `recordVerdicts` → the ticket holds the parsed record; a yellow ticket is refused.
2. `only the pilot records`: `deck_ticket { id, action: 'verdicts', verdicts: string }` → refused for an architect stamp.
3. `no record, no gate1`: `assertVerdicts` → refused naming the missing record when §6 has A1.
4. `a differing verdict is named`: `assertVerdicts` → refused naming `A2` when the artefact says stands and the record overturned.
5. `an id on one side is named`: `assertVerdicts` → refused naming it; a matching artefact passes.

Rewrite check: storing the record elsewhere keeps tests 3-5's refusals and the matching gate1 accepted.
