# S1 The architect posts a gate1 the pilot owns

Feature `architect-runs-red` · delivers spec 3, 5 · source: `../architecture.md` §2, §5 L4 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — widens who may post a gate, the security trigger.

## Files owned

- `deck/store-items.mjs`: `POSTERS` gives gate1 to the pilot and the architect.
- `deck/items.mjs`: `ownerOf` returns `pilot` for a gate1 whoever posted it.
- `deck/test/posters.test.mjs`: two refusal-message pins read "pilot and architect" (seam change at implementation, accepted by the co-pilot: an existing pin of the behaviour this slice changes).
- `deck/test/architect-gate1.test.mjs` (new): the pins.

## Interface

```
POSTERS[gate1]: ['pilot', 'architect']        // deck/store-items.mjs:79; gate2 unchanged
refusePoster(kind: string, author: string): void   // existing; throws DeckRefusal for any other kind of author
ownerOf(item): OwnerKind                       // gate1 -> 'pilot', as chat, user and ticket already are
```

## Tests

1. `an architect-stamped gate1 passes the poster check`: `refusePoster` → no throw for `('gate1', 'pilot:pilot-architect')`; throws for `'pilot:pilot-implementer'`.
2. `an architect-posted gate1 is stored`: `refusePoster` → `callTool('deck_post', { kind: 'gate1', author: 'pilot:pilot-architect', … })` on a live ticket returns `Posted itm_…`.
3. `an architect-posted gate1 is the pilot's thread`: `ownerOf` → `'pilot'`; a user's reply on it is handed to a pilot wait and not to an architect wait.

Rewrite check: replacing the posters table with any other check keeps the architect and pilot accepted, every other kind refused, and a gate1 owned by the pilot.

## Done

- **Expected**: the architect can post the gate1 on its ticket, and the user's press on it wakes the pilot.
- **Verification**: `node --test deck/test/architect-gate1.test.mjs deck/test/architect-owner.test.mjs deck/test/posters.test.mjs`; `npm test`.
- **Evidence**: test 1 failing before the `POSTERS` change and passing after; test 3 failing before the `ownerOf` change.
- **Prohibited**: no widening of gate2 posters; no stored `owner` override written at post time in place of `ownerOf`; no author read from the agent's own argument (the hook's stamp only).
- **Done when**: the three tests pass, `npm test` is green, and `posters.test.mjs` still refuses an implementer's gate1.
