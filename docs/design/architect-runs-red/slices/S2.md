# S2 `pilot verdicts` writes the lines from a message

Feature `architect-runs-red` · delivers spec 2 · source: `../architecture.md` §2, §5 L3 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new CLI command reading a path argument and stdin, the security trigger.

## Files owned

- `scripts/verdicts.mjs`: the message grammar and the placement, pure.
- `bin/pilot.mjs`: the `verdicts` command and its help line.
- `scripts/test/verdicts-write.test.mjs` (new): the pins.
- `fixtures/verdicts/message.txt` (new): a verdict message, one stands, one stands with why, one overturned.
- `fixtures/verdicts/architecture.md` (new): an artefact with three A‹n› in §6 and an A9 in §7.

## Interface

```
parseVerdictMessage(text: string): Record<string, string>
  // one 'A<n> Verdict: <verdict>' per non-blank line; verdict as VERDICT's grammar; throws naming the bad line
verdictsOf(markdown: string): Record<string, string>   // §6's verdict per A<n>, without the 'Verdict: ' prefix
writeVerdicts(markdown: string, record: Record<string, string>): string
  // each §6 bullet gets '  Verdict: <verdict>', replacing one already there; throws naming ids on one side only
pilot verdicts <artefact>   // stdin: the message; rewrites the file in place; exit 0, or 1 with the reason on stderr
```

## Tests

1. `a message parses to its record`: `parseVerdictMessage` → `{ A1: 'stands', A2: 'stands — why', A3: 'overturned: why' }` from the fixture; a line without `Verdict:` throws naming it.
2. `the fixture writes clean the first time`: `writeVerdicts` → markdown whose `unverdicted` is `[]` and whose `verdictsOf` equals the record; §7's A9 untouched.
3. `writing twice is writing once`: `writeVerdicts` → the same text on a second run.
4. `an id on one side only is refused`: `writeVerdicts` → throws naming `A3` when the message lacks it, and `A7` when §6 lacks it.
5. `the command rewrites the file`: `pilot verdicts <artefact>` → exit 0 and the file equals test 2's output; a short message exits 1, file unchanged.

Rewrite check: replacing the placement code keeps tests 2-5's file contents and exit codes.
