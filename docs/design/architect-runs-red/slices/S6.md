# S6 A failed integrate never leaves the worktree mid-merge in silence

Feature `architect-runs-red` · delivers spec 9 (added) · source: `../architecture.md` §2 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:silent-failure-hunter`
Model: sonnet — one helper's error path and one test, every change specified.

Added by the co-pilot at integration (found issue, build-now rule). In `scripts/integrate.mjs:335`, `reset()` runs
`git reset -q --merge <start>` and ignores its status. When the gate has rewritten a file the merge touched,
`reset --merge` refuses ("Entry ... not uptodate"). S4's red run left the feature worktree mid-merge that way,
with a rebuilt `scripts/shipped-rules.json`, and the line read only "not pushed".

## Files owned

- `scripts/integrate.mjs`: on red, after the test command, restore the paths the merge staged (`git checkout --` on them,
  never run.json the deck wrote) before `reset --merge`; and when `reset()` still fails, say so in the line:
  `; reset failed (<first line>): <cwd> is left mid-merge`.
- the integrate test file under `scripts/test/` that pins red runs: the pin.

## Interface

```
integrate(branch, options) -> { ok, line, failing }   // scripts/integrate.mjs; on red the merge in hand is reset
```

## Tests

1. `a red gate that rewrote a merged file still resets`: `integrate(branch, options)` → on a temp feature repo whose test command rewrites a file the slice
   changes and exits 1, there is no `MERGE_HEAD`, HEAD is at start, and the line names the failing run.
   It fails before the change.
2. `a reset that cannot run is named`: `integrate(branch, options)` → with the reset made to fail, the line carries `left mid-merge`.

Rewrite check: rewording the restore keeps the line's `left mid-merge` suffix and the run.json exclusion.

## Done

- **Verification**: the integrate test file; `npm test`.
- **Prohibited**: no `reset --hard`; never discard the run.json the deck wrote; no change to a green run.
- **Done when**: tests 1-2 fail before and pass after; `npm test` green.
