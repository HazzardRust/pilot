# S2 A yellow ticket is replanned at a merge commit with no press

Feature `recut-decision` · delivers spec 1, 2, 3 · source: `../architecture.md` §2, §5 L4, §6 A1 (overturned) · after: S1 (`deck/server-tools.mjs`, `deck/recut.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — the section rule from A1's overturn is a judgement on parsing a signed artefact.

## Files owned

- `deck/store-tickets.mjs`: `replanTicket` takes an open yellow signed ticket too, keeping `grantedAt`.
- `deck/server-tools.mjs`: `replanned` (`:223-245`) diffs from `recut.from`, else `plan.sha`; the section rule; the ticket line.
- `deck/recut.mjs`: `signedSections`, beside `planChanges`.
- `deck/test/replan.test.mjs`: yellow, reword, refused and headless pins.

## Interface

```
replanTicket(id, sha) -> ticket   // red+recut: as today; open yellow signed: plan.sha := sha, grantedAt kept, state yellow
signedSections(text: string) -> { spec, locked, slices } | null   // bodies under "## 2.", "## 5.", "## 8." of architecture.md; null if any is missing
deck_ticket replan { id, sha } -> "Replanned <id> at <sha7>: signed plan kept[; reworded <files or §n>]."
  // from = recut.from ?? plan.sha; refused when signedSections differs or is null at either sha: "§<n> changed since <from7>; deck_ticket recut, then a gate1 with Changed since <from7>:"
ticket line: "Replanned at <sha7> by <author kind>: <unchanged | reworded <files, §n>>"
```

## Behaviours

1. `a yellow ticket moves to the merge commit` (test): `deck_ticket replan` → state `yellow`, `plan.sha` the new sha, `grantedAt` unchanged, 0 gate1 items.
2. `a wording-only change passes` (test): `deck_ticket replan` → a §3 edit and a `slices/S2.md` edit are replanned, the ticket line names both.
3. `a changed spec line takes a gate1` (test): `deck_ticket replan` → a §2 edit refused naming §2 and `deck_ticket recut`; ticket unchanged; likewise §5 and §8.
4. `a headless artefact is never proven` (test): `signedSections` → null without `## 8.`, and the replan is refused.
5. `a red re-cut ticket replans as before` (test): `replanTicket` → the existing red pins still pass.

Rewrite check: any section reader keeps behaviour 3 refused and behaviour 2 passing.
Misses: a slice-file edit that changes owned files without §8 (L8 says §8 mirrors it); the pilot reads that.

## Done

- **Expected**: the pilot moves a signed plan onto new pilot in one call; only a spec, locked or slice-graph change asks the user.
- **Verification**: `node --test deck/test/replan.test.mjs deck/test/recut.test.mjs`; `npm test`.
- **Evidence**: behaviour 1 failing on today's red-only refusal, passing after.
- **Prohibited**: no replan of a ticket a gate2 names; no passing an unreadable sha (null stays refused, ADR 0187 L5).
- **Done when**: the five behaviours pass and `npm test` is green.
