## Interface

```

deck_ticket replan { id, sha } -> "Replanned <id> at <sha7>: signed plan kept[; reworded <files>]."
```

## Behaviours

1. `a yellow ticket moves to the merge commit` (test): `deck_ticket replan` → state `yellow`, `plan.sha` the new sha, `grantedAt` unchanged, 0 gate1 items.
2. `a slice-file reword passes` (test): `deck_ticket replan` → replanned, the ticket line names `slices/S2.md`.
3. `a changed artefact takes a gate1` (test): `deck_ticket replan` → refused naming `architecture.md` and `deck_ticket recut`; ticket unchanged.
4. `a red re-cut ticket replans as before` (test): `replanTicket` → the existing red pins still pass.

Rewrite check: any diff engine keeps behaviour 3 refused and behaviour 2 passing.
Misses: an `architecture.md` change that is wording only (A1's cost); the pilot judges it at the gate1.
