# S12 Mode control replaces full auto on the tab, reported by the route and the wait

Feature `ticket-states` · run 2 · delivers spec 15 · source: `../architecture.md` §2, L20, B1 (Replace), B3 · after: S11

## Files owned

- `deck/store.mjs`: `setMode(repo, mode)` and `modeFor(repo)` on a per-repository `mode` map. `setAuto`/`clearAuto`/`autoFor` and the `auto` closures in `postItem` (questions, sign-offs, gates, walkthroughs closed as `auto`, and the merge flag) are removed. A legacy `auto` entry is ignored and reads attended.
- `deck/items.mjs`: whatever marks an item `auto` goes with it.
- `deck/server.mjs`: the `/auto` form becomes `/mode` (same Origin rule, independence L4). `GET /api/record` reports `mode` and no longer `auto`. `deck_wait` returns a `mode:` notice once after a change.
- `deck/ui/render.mjs`, `deck/ui/deck.css`: the full-auto toggle under Create, its confirm and merge box become a two-position control, Attended · Autonomous; the `auto` styling goes.
- `deck/ui/js/*`: the control's script, from the existing toggle's file; `confirm.mjs` loses the full-auto confirm.
- `deck/tools.mjs`: `deck_wait`'s description names the notice; nothing mentions full auto.
- `deck/test/mode.test.mjs` (new). `deck/test/auto.test.mjs` is deleted; the `auto` cases in `small-flight`, `audit-offer`, `standing`, `phase`, `gate-kinds`, `confirm`, `chat-scroll` and `away` tests are removed or rewritten.

## Interface

```
MODES = ['attended', 'autonomous']
setMode(repo, mode): { mode, at }        // 'attended' deletes the entry
modeFor(repo): 'attended' | 'autonomous'
POST /mode  form { repo, mode }
GET /api/record?repo= -> { record, mode }
deck_wait -> '... mode: autonomous (takes effect at your next park or close)'   // once per change
```

## Tests

1. `the mode defaults to attended, and a legacy auto entry reads attended`.
2. `no item is closed as auto at post in either mode`.
3. `the route reports the mode and nothing named auto`.
4. `the live pilot's next wait carries one mode notice, and only one`.
5. `/mode refuses a missing or foreign Origin`.
6. `grep: no full auto left in deck/*.mjs, deck/ui or deck/test`.

## Done

- **Expected**: the user switches a tab to Autonomous, the choice survives a reload, the live pilot hears about it on its next wait, and nothing on the deck offers or performs full auto.
- **Verification**: `node --test deck/test/mode.test.mjs`; `npm test`.
- **Evidence**: the tests; the control used in a browser on a scratch deck; curl output from the route; the grep.
- **Prohibited**: no second map beside `mode`; no mode that closes items for the user.
- **Done when**: the tests are green, the grep is empty and the control has been seen working live.
