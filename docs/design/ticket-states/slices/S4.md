## Interface

```
liveTicketOf(items, repo): Item | undefined
phaseOf(items, repo): 'green'|'yellow'|'red'|null      // the live ticket's state
takeTicket(id): Item     // open ticket; refused while another ticket in the repo is live; sets live, takenAt
parkTicket(id): Item     // live ticket in any state; clears live; the state is unchanged
deck_ticket { action: 'take'|'park', id }
```

## Tests

1. `with no live ticket the phase is null and the strip has no data-phase`.
2. `taking a ticket makes the phase its state`; and `signing its gate1 makes the phase yellow`.
3. `take is refused while another ticket in the repo is live`, named.
4. `park keeps the state and clears live`; `take` after `park` sets a new `takenAt`.
5. `a question posted while the live ticket is yellow needs recommended` (the away rule moved).
6. `gate1 and gate2 must name the live ticket` (S1 and S3 refusals tightened).
