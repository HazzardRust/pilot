# S1 Signing a gate1 turns its ticket yellow (walking skeleton)

Feature `ticket-states` · run 1 · delivers spec 1, 2 (green and yellow; gate1's `ticket`) · source: `../architecture.md` §2, L3, L6, L8, L11, L12 · after: –

## Files owned

- `deck/items.mjs`: `TICKET_STATES`, `stateOf(ticket)` (reads a legacy item), and the required `ticket` field on `gate1`.
- `deck/store.mjs`: `postItem` stamps `state: 'green'` on a ticket; `resolveItem` of a signed `gate1` sets its ticket to `yellow` in the same write; gate1 refusals.
- `deck/ui/render.mjs`: the ticket row's state badge (`data-state`).
- `deck/ui/deck.css`: the badge's three colours, reusing the phase palette.
- `deck/test/ticket-state.test.mjs` (new): the pins.

## Interface

```
TICKET_STATES = ['green', 'yellow', 'red', 'closed']
stateOf(ticket): 'green'|'yellow'|'red'|'closed'   // absent: open -> green, resolved -> closed (L12)
gate1 fields: artefact, sha, locked, slices, ticket (required, itm_ id)
ticket item: { ..., state }                          // written only in store transitions (L3)
renderTicketRow(item, ...) -> '<li data-state="green|yellow|red">…'
```

## Tests

1. `a posted ticket is green`: the stored item carries `state: 'green'`.
2. `a legacy ticket with no state reads green open and closed resolved`.
3. `a gate1 with no ticket is refused by name`; and one that names a closed ticket, a non-ticket, or a non-green ticket.
4. `signing a gate1 turns its ticket yellow in the same write`: one `writeDeck` call.
5. `a gate1 resolved without a sign-off leaves the ticket green` (L11).
6. `the ticket row draws data-state`.

## Done

- **Expected**: a ticket posted on a scratch deck shows green on the Tickets tab, and after a `gate1` naming it is signed it shows yellow.
- **Verification**: `node --test deck/test/ticket-state.test.mjs`; `npm test`.
- **Evidence**: the tests above failing before and passing after; the row seen turning yellow on a scratch deck (a second daemon on a free port).
- **Prohibited**: no derivation of the state from gate items at read time; no state write outside `postItem`/`resolveItem`; no `STORE_VERSION` bump.
- **Done when**: the tests and `npm test` are green and the yellow row has been seen live.
