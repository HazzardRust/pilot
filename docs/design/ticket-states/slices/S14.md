# S14 Red-phase grilling: questions on a ticket, gate2 sign refused; the first red ticket opens with its previews

Feature `ticket-states` · run 2 · delivers spec 17, 20 · source: `../architecture.md` §2, L6, L21, L22 · after: S13

## Files owned

- `deck/items.mjs`: `question` gains an optional `ticket`. `awaitsUser` is false for a question whose ticket is not live (L21). Adds `openQuestionsOf(items, ticketId)`.
- `hooks/lib/deck.js`: mirrors the `awaitsUser` rule. Pinned by `join.test.js`.
- `deck/store.mjs`: the ADR 0029 refusal for `gate2` (L22). Posting it is blocked only by open questions that do not name its ticket. Signing it is blocked while any question naming its ticket is open.
- `deck/ui/render.mjs`: the ticket row shows the count of its open questions.
- `deck/test/red-grilling.test.mjs` (new).

## Interface

```
question fields: ..., ticket?   (an itm_ id of an open ticket)
openQuestionsOf(items, ticketId): Item[]
awaitsUser(item, items): false when item.ticket names a ticket that is not live
refusal on gate2 sign: 'gate2 <id> waits on <n> open question(s) on ticket <id>: <ids>'
```

## Tests

1. `a question on a parked ticket does not hold the Stop gate`, in both the deck and the hook mirror.
2. `a question on the live ticket does`.
3. `gate2 can be posted while its ticket has open questions`, and the ticket turns red.
4. `Sign off on that gate2 is refused by name until the questions close`.
5. `an open question not naming the ticket still refuses the post` (ADR 0029 kept).
6. `the row shows the question count`.

## Done

- **Expected**: a red ticket shows its queued questions. Its Gate 2 cannot be signed until they are answered.
- **Verification**: `node --test deck/test/red-grilling.test.mjs hooks/test/join.test.js`; `npm test`.
- **Evidence**: the tests; the refusal seen on a scratch deck.
- **Prohibited**: no hiding the questions from the thread list; no refusal for questions that do not name the ticket.
- **Done when**: the tests are green and the refusal has been seen live.
