# S6 A ticket is posted with its creation estimate

Feature `ticket-states` · run 1 · delivers spec 6 · source: `../architecture.md` §2 · after: S5

## Files owned

- `deck/items.mjs`: the ticket's `estimate` field, required, a count of minutes.
- `deck/store.mjs`: the refusal reaches `postItem` like any required field.
- `deck/tools.mjs`: `deck_post`'s schema names `estimate` for a ticket.
- `deck/ui/render.mjs`: the row shows `~Nh Mm`.
- `deck/test/ticket-state.test.mjs`, `deck/test/make-tickets.test.mjs`: extended; every fixture ticket posting gains `estimate`.

## Interface

```
ticket fields: slice?, repo?, dir?, estimate (required, count, minutes)
row: '<span class="estimate">~2h 30m</span>'
```

## Tests

1. `a ticket without estimate is refused by name`.
2. `a non-count estimate is refused`.
3. `the row draws the estimate in hours and minutes`.
4. `a legacy stored ticket with no estimate still renders`, with no estimate span.

## Done

- **Expected**: posting a ticket needs an estimate, and the tab shows it.
- **Verification**: `npm test`.
- **Evidence**: tests; a row seen with its estimate on a scratch deck.
- **Prohibited**: no estimate parsed from the body; no default estimate filled in.
- **Done when**: tests green and the estimate seen live.
