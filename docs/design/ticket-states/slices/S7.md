# S7 Gate 1 writes the plan and its measured estimate

Feature `ticket-states` · run 1 · delivers spec 7, 8 · source: `../architecture.md` §2, L5, L7, L13, A4 · after: S6

## Files owned

- `deck/items.mjs`: `gate1` gains `branch` (required) and `sliceCount` (required count); `minutesPerSlice(items, repo)`.
- `deck/store.mjs`: S1's gate1 sign-off transition also writes `ticket.plan`.
- `deck/ui/render.mjs`: a yellow row shows both estimates and the artefact link.
- `deck/test/estimate.test.mjs` (new).

## Interface

```
gate1 fields: artefact, sha, locked, slices, sliceCount (count), branch, ticket
ticket.plan: { artefact, branch, sha, slug, sliceCount, estimate, gate1 }  // slug from the artefact path
minutesPerSlice(items, repo): number
  // per closed ticket with plan.sliceCount > 0 and a signed gate2 naming it:
  // (gate2.postedAt - max(gate1.resolvedAt, ticket.takenAt)) / sliceCount, in minutes;
  // the median of the newest 20 at most (L13 as amended); 30 when none
```

## Tests

1. `signing a gate1 writes the plan with slug and Gate 1 estimate`.
2. `minutesPerSlice is 30 with no closed ticket`.
3. `minutesPerSlice is the median of the newest 20 at most, from the later of gate1 resolved and the last take`.
4. `a gate1 without sliceCount or branch is refused by name`.
5. `a yellow row shows the creation and Gate 1 estimates`.
