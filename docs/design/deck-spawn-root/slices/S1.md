# S1 A checkout client spawns the installed deck

Feature `deck-spawn-root` · delivers spec 1, 2, 3, 4, 5 · source: `../architecture.md` §2, §3, L2-L4 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Interface

```
spawnRoot({ ownRoot: string, port: number, env?: NodeJS.ProcessEnv, lookup?: (env) => string })
  -> { root: string, version: string }
isCheckout(root: string) -> boolean   // fs.existsSync(<root>/.git); S3's health reads it
  // port !== DECK_PORT -> ownRoot; ownRoot without .git -> ownRoot; else lookup(env) (default bin/launcher.mjs pluginRoot)
  // throws Error whose message names why and `pilot deck --from <dir>`; never answers ownRoot for a checkout on DECK_PORT
ensureDaemon({ resolve?: () => { root, version }, spawnProcess?: typeof spawn } = {}) -> Promise<boolean>
  // spawns process.execPath [<root>/deck/daemon.mjs]; a throw from resolve: one stderr line, no spawn, and whether a deck answers (false with none; seam, co-pilot 2026-10-20)
  // resolve runs only when no deck answers or isOlder(found.version, PLUGIN_VERSION)
replaceOlder(found, { version?: string /* defaults to PLUGIN_VERSION */, post?, table?, kill? }) -> Promise<'replaced' | 'kept'>
postExit(version: string) -> Promise<{ status, error? }>   // body { version } is the root version
```

## Tests

1. `a checkout on the deck port spawns the installed root`: `spawnRoot` → a temp ownRoot with `.git` and a lookup answering a temp installed dir gives that dir and its package.json version.
2. `an installed copy never asks claude`: `spawnRoot` → ownRoot without `.git` gives ownRoot; the lookup throws if called.
3. `another port keeps its own checkout`: `spawnRoot` → port 4999 gives ownRoot without calling lookup.
4. `no installed root starts no deck`: `ensureDaemon` → with resolve throwing, it answers false, spawns nothing, and stderr has one line naming the reason and `pilot deck --from`.
5. `older is the root's version`: `ensureDaemon` → own 0.9.4, root 0.9.2, found 0.9.2: no exit POST, true.
6. `the exit request carries the root version`: `replaceOlder` → `post` receives `0.9.5` when root is 0.9.5.
7. `a join to a current deck resolves nothing`: `ensureDaemon` → a found deck at own PLUGIN_VERSION answers true with resolve never called.

Rewrite check: replacing the `.git` test or the lookup with another source of the installed root keeps all seven results.
