# S2 `pilot deck --from <dir>` is the one opt-in

Feature `deck-spawn-root` · delivers spec 6 · source: `../architecture.md` §2, L5 · after: S1 (`spawnRoot`, `ensureDaemon`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument names the directory a process is started from (the security trigger).

## Files owned

- `bin/pilot.mjs`: the `deck --from <dir>` branch and its usage line.
- `deck/spawn-root.mjs`: `spawnRoot` takes `from` and validates it.
- `deck/test/deck-from.test.mjs` (new): the pins below.

## Interface

```
S1's spawnRoot, plus: spawnRoot({ from?: string, ... })
  // from given: resolved absolute; throws naming `deck/daemon.mjs` when <from>/deck/daemon.mjs is missing,
  // naming `@modelcontextprotocol/sdk` when it does not resolve from <from>; else { root: from, version }
pilot deck --from <dir>   // exit 0 "The deck is up at <url>"; exit 1 "pilot deck --from: <why>"; exit 2 on a missing <dir> argument (a <dir> that does not exist is exit 1); exit 1 when a deck already answers on the port (seam, co-pilot 2026-10-20)
```

## Tests

1. `from a dir without the daemon refuses`: `spawnRoot` → throws naming `deck/daemon.mjs`.
2. `from a dir without dependencies refuses`: `spawnRoot` → throws naming `@modelcontextprotocol/sdk`.
3. `from a complete checkout answers it`: `spawnRoot` → `{ root: <dir>, version }` with no lookup call.
4. `the CLI refuses and names why`: `pilot deck --from <dir>` → exit 1 and `pilot deck --from: ` with the reason, on `PILOT_DECK_PORT` set to a free port.

Rewrite check: validating the dependency some other way than resolving the sdk keeps all four results.

## Done

- **Expected**: the user can start a deck from a checkout only by naming it, and a checkout that could not land is refused up front.
- **Verification**: `node --test deck/test/deck-from.test.mjs`; `npm test`; `PILOT_DECK_PORT=4399 node bin/pilot.mjs deck --from <a fresh clone without npm ci>`, with its output read.
- **Evidence**: test 2 failing before and passing after; the live refusal text.
- **Prohibited**: `--from` read from the environment; a relative `<dir>` passed on unresolved; shelling out to `npm ls`.
- **Done when**: the four tests and `npm test` are green, and the live refusal names the sdk.
