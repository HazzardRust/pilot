# S3 The deck names its root, and a checkout deck says so on the page

Feature `deck-spawn-root` · delivers spec 8 · source: `../architecture.md` §2, L7 · after: S1 (`spawn-root.mjs`'s `isCheckout`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — a page change with a browser check, and the banner's placement is left to the implementer.

## Files owned

- `deck/health.mjs`: `healthOf` adds `root` and `checkout`.
- `deck/probe.mjs`: `probeDeck` keeps `root` (text) and `checkout` (boolean).
- `deck/status-command.mjs`: `statusLines` prints `root     <dir>`, with `, checkout` appended when it is one.
- `deck/ui/js/deck.mjs`: on load, `GET /api/health`; when `checkout`, a banner naming `root`.
- `deck/ui/deck.css`: the banner's style.
- `deck/test/health-root.test.mjs` (new): the pins below.

## Interface

```
healthOf() -> { ok, pid, url, seq, rss, version, startedAt, root: string, checkout: boolean }
  // root: the directory holding the daemon's package.json; checkout: S1's isCheckout(root)
probeDeck(url, opts) -> { state: 'deck', pid, version?, startedAt?, root?: string, checkout?: boolean } | ...
statusLines({ url, probe, agents, logTail, pluginVersion, now }) -> string[]   // adds the root line
banner text: "This deck serves from a checkout: <root>"   // inserted as text (textContent), never markup (seam, co-pilot 2026-10-20: escape.mjs is the Esc-key handler)
```

## Tests

1. `health names the daemon's root`: `healthOf` → `root` is this checkout and `checkout` is true.
2. `the probe keeps root and checkout`: `probeDeck` → both fields from a stub server; a non-text root is dropped.
3. `status prints the root`: `statusLines` → a `root` line, ending `, checkout` when `checkout` is true.

Rewrite check: S1's `isCheckout` computed some other way keeps all three results for a clone and an installed copy.

## Done

- **Expected**: `pilot status` says where the deck runs from, and a deck from a checkout says so on every page.
- **Verification**: `node --test deck/test/health-root.test.mjs deck/test/status-command.test.mjs`; `npm test`; `pilot deck --scratch` from this worktree, opened in Chrome through the DevTools MCP.
- **Evidence**: test 1 failing before; a screenshot of the banner on the scratch deck's home and thread pages.
- **Prohibited**: inserting `root` into the page as HTML without escaping; a banner shown when `checkout` is false.
- **Done when**: the three tests and `npm test` are green, and the banner has been seen in the browser.
