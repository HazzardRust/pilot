# S2 A gate2 lands once, one at a time, and never hangs

Feature `gate2-lands` · delivers spec 3, 6, 7 · source: `../architecture.md` §2, §5 L4, L6; §6 A1, A3, A4 · after: S1

## Files owned

- `deck/store.mjs`: `addReply` refuses a Sign off on a gate2 whose landing is running or landed, or while another gate2 in its repository is running; a running landing whose `pid` is not this daemon's reads as interrupted.
- `deck/landing.mjs`: the 30-minute timeout, killing the held child tree only.
- `deck/test/landing-guard.test.mjs` (new): the pins below.

## Interface

```
S1's Landing, beginLanding, settleLanding
// refusal texts (DeckRefusal, landed on the thread by ADR 0096):
"gate2 <id> is landed at <sha7>; nothing run"
"gate2 <id> is landing since <hh:mm>; nothing run"
"gate2 <other> in this repository is landing; press again when it settles"
LANDING_TIMEOUT_MS = 30 * 60_000
```

## Tests

1. `Not yet, Dismiss and a typed reply on a gate2 start no landing`.
2. `a Sign off refused over an open question starts no landing`.
3. `a Sign off on a landed gate2 is refused naming the SHA, stores no reply, spawns nothing`.
4. `a Sign off while running is refused`; `a second gate2 in the same repository while one runs is refused`.
5. `a Sign off after NOT landed starts a new landing` (A1).
6. `a running landing with another daemon's pid reads interrupted and may be pressed again`.
7. `a landing past 30 minutes is killed by its handle and settles NOT landed: timed out after 30 min`.

## Done

- **Expected**: whatever the user presses, a feature lands at most once per Sign off, and a stuck or orphaned landing never locks the gate2.
- **Verification**: `node --test deck/test/landing-guard.test.mjs`; `npm test`; acceptance 3 on the scratch deck.
- **Evidence**: tests 3 and 6 red before the guard; the scratch refusal line on the thread, as page text or a screenshot.
- **Prohibited**: an in-memory latch instead of the stored state; killing by a stored pid; a sleep-based timeout test.
- **Done when**: every test above is green and a second real press on a landed scratch gate2 showed the refusal.

- `deck/ui/render.mjs` (3 lines): a gate2 whose landing settled NOT landed or interrupted draws Sign off unlocked, so A1's retry has a button.
- `deck/test/landing.test.mjs` (1 line): S1's pid pin expects the daemon's pid.
- Size: 326 changed lines accepted over the 300 limit.
