## Interface

```
baseGate1Gaps(records: object[], ticket: { id, repo }, body: string) -> string[]
// [] when the body has a `Base: <b>` line and b equals the ticket's run record base (any b when the record has none);
// else one gap naming the line owed, e.g. "a gate1 names its run's base: add `Base: hazzardrust-pilot`"
```

## Behaviours

1. `a gate1 with no base line is refused` (test): `baseGate1Gaps` → a body with no `Base:` line gives 1 gap naming the record's base.
2. `a gate1 naming another base is refused` (test): `baseGate1Gaps` → `Base: main` against a record base `hazzardrust-pilot` gives 1 gap.
3. `a matching base line is accepted` (test): `baseGate1Gaps` → `Base: hazzardrust-pilot` gives `[]`.

Rewrite check: whatever reads the body, a gate1 reaches the user only with the base its run record holds.
Misses: a gate1 posted before the record has a base; the gap then takes any `Base:` line, and the pilot's step 3 sends the base first.
