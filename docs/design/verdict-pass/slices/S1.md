## Interface

```
// A‹n› ids of §6 (the heading `## 6.`), in order; both `- **A3 Title.**` and `- **A1**` shapes
export function assumedIds(markdown: string): string[]
// the subset whose bullet holds no `Verdict: stands[ — <why>]` / `Verdict: overturned: <why>` line
export function unverdicted(markdown: string): string[]
// throws DeckRefusal: unverdicted ids named; ids missing from body named; artefact unreadable at sha
// a repo that is not a git repository is not checked; 5 s deadline, git without a shell
export function assertVerdicts(repo: string, gate: { sha: string, artefact: string, body: string }, opts?: { timeout?: number }): void
callTool('deck_post') with kind gate1: assertOnPilotTip, then assertVerdicts, then postItem
```

## Tests

1. `both bullet shapes are read`: `assumedIds` → A1 and A3 from a §6 holding `- **A1** x` and `- **A3 Title.** y`.
2. `a verdict line marks its own bullet only`: `unverdicted` → A3 alone when only A1's bullet holds `Verdict: stands`.
3. `an overturn needs its why`: `unverdicted` → A1 for `Verdict: overturned:` with nothing after it.
4. `a gate1 with an unverdicted A1 is refused naming it`: `callTool('deck_post')` → DeckRefusal containing `A1`, and no item stored.
5. `the same post passes once the verdict is committed`: `callTool('deck_post')` → `Posted itm_…`.
6. `a body missing an id is refused`: `assertVerdicts` → DeckRefusal naming `A2`.
7. `an artefact absent at sha is refused`: `assertVerdicts` → DeckRefusal naming the path and sha.
8. `no A‹n› passes and a non-git repo is not checked`: `assertVerdicts` → returns.

Rewrite check: if the markdown were parsed by a different reader, or read through another git call, every refusal and pass above would still hold.
