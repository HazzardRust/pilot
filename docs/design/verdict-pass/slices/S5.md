## Interface

```

## Measure: read audit-spend's `reports`, docs/design/*/run.json findings, and the repo's session transcripts;
  a move seen in >= 2 runs; grep agents/, skills/, deck/ for a step, record or refusal naming it
## Rows: finding "behaviour re-derived per run: <move>", command = the greps, output = the runs that show it,
  fix = the mechanism it should become (a step, a record or a refusal), spec = the ticket line
```

## Tests

1. `the area is registered`: `rederived.md frontmatter` → passes `audit-agent.test.mjs`'s frontmatter loop with `spec: [8]` and `model: sonnet`.
2. `two runs, no pin`: `## Measure` → names the two-run threshold and the grep for a pin.
3. `a row names its mechanism`: `## Rows` → names step, record or refusal as the fix.
4. `the auditor cites the principle`: `rederived.md frontmatter` → `agents/pilot-auditor.md` names ADR 0141, and `skills/audit/SKILL.md`'s pick step names rederived rows.

Rewrite check: if the area were reworded, the threshold, the pin grep and the mechanism column would still be there.
