## Interface

```
blockersOf(row): string[]            // row.after read as a list: undefined -> [], string -> [string]
identifierOf(name): string | null    // the leading /^S\d+\b/ of a slice name
graphOf(slices): {
  lanes: number,                                        // lane count, end point included
  dots: { id: string, name: string, phase: 'planned'|'doing'|'done'|null, row: number, lane: number }[],
  edges: { from: number, to: number, lane: number }[],  // row indices; to === dots.length is the end point; lane is the one the line runs down
}
renderRunGraph(run, name): string    // <section class="tree"> heading + <svg class="graph">
```

An `after` entry resolves by `sliceKey` of the full name or by identifier (L4). An unresolved entry is ignored at read time, because validation belongs to the write path.

## Tests

1. `the user's fixture forks at S1 into three lanes`: lanes S1 0, S2 0, S3 1, S9 2.
2. `S4 converges S2 and S3 on the leftmost lane`: S4 is on lane 0, and edge S3→S4 runs down lane 1.
3. `a chain keeps its lane beside its sibling`: S6 and S7 on lane 1, S5 on lane 0.
4. `every slice nothing comes after merges into the end point`: edges S8→end and S9→end, and no S9→S8 edge.
5. `a blocker implied by another is not drawn`: S4 after [S1,S2,S3] gives the same graph as [S2,S3].
6. `rows are topological, table order among the ready`: a blocker listed below its dependent is drawn above it.
7. `a string after reads as a one-item list`: a 0.7.20 row draws the same as `[name]`.
8. `the graph's only text is the identifiers`: the rendered `<svg>`'s `<text>` contents are exactly S1…S9, and a "Feature" row adds no dot.
9. `the full name is the dot's hover title, escaped`: one `<title>` per dot.
10. `row text drawn into the SVG is inert` (L10): a row named `S1 <img src=x onerror=alert(1)>` renders its title as `&lt;img …&gt;`, with no `<img` and no `onerror=` anywhere in the panel. A row named `<img src=x onerror=alert(1)> S1` has no leading identifier, so it gets no dot and none of its text reaches the SVG. No attribute carries row text unescaped.
11. `a dot's fill is its phase`: planned, implementing, integrated and free text give the four classes.
