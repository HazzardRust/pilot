# S8 One command bumps the version everywhere

Feature `bigger-jobs` · delivers spec 13 · source: `../architecture.md` §2, §5 L8 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer` (CLI argument, file writes)

## Files owned

- `scripts/bump.mjs` (new): writes one version into the four files.
- `package.json`: a `bump` script beside `adr-index`.
- `scripts/test/bump.test.mjs` (new): the bump on a temporary copy, and the agreement pin on the real tree.

## Interface

```
bump(version: string, { root: string }) -> string[]  // the four paths written; throws on a version that is not x.y.z
npm run bump <version>
files: package.json, package-lock.json (top and packages[""]), .claude-plugin/plugin.json, deck/client.mjs (Server version)
```

## Tests

1. `a bump writes all four files`: `bump` → each file on a temp copy carries the new version.
2. `the four agree today`: `bump` → the real tree's four versions are equal.
3. `a malformed version is refused and nothing is written`: `bump` → a throw, files unchanged.

Rewrite check: a bump that edits with a JSON parser rather than text keeps tests 1-3.

## Done

- **Expected**: `npm run bump 0.8.3` on a temp copy changes exactly the four files.
- **Verification**: `node --test scripts/test/bump.test.mjs`; `npm test`; live: `npm run bump 0.8.3` in a temp copy, then `git diff --stat` there.
- **Evidence**: tests red before, green after; the diff stat showing four files.
- **Prohibited**: bumping the real version in this slice; a shell line built from the version argument.
- **Done when**: the tests and suite are green and the temp copy's diff is the four files.
