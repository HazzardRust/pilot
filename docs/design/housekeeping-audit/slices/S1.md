## Tests

1. `a row without a command, its output or spec text, or an eleventh open row, is refused`: named; `saveReport` throws.
2. `a failed command is a valid row`: non-zero `exit` with its output passes (spec 11).
3. `rows rank by saving per run over effort`: a fixed set comes back in L6 order with ids F1..Fn.
4. `the deck body is a numbered list with no table; the file carries cost, exchange rate and unmeasured` (spec 13).
5. `a report is saved under the deck store and never in the repository`; `pilot audit save` exits 1 naming problems.
6. `the auditor measures in a detached worktree it removes and writes nothing else` (prose pins from here on).
7. `every command runs under a timeout, and a failure becomes a row`.
8. `the auditor reads every area file and briefs explorers by path, one at a time during a run` (A7).
9. `the audit skill snapshots git state before and compares after, and posts one audit item`.
10. `every file in skills/audit/areas carries the area-file frontmatter`, `model` when owned by an explorer.
11. `an audit item is in Yours, offers none beside the reply, cannot be dismissed, and holds back no spec`.
