# S4 The report shows context load and tooling per source

Feature `housekeeping-audit` · delivers spec 8, 9 · source: `../architecture.md` §2, L5, A4 · after: S1

## Files owned

- `scripts/audit-context.mjs` (new): measures every always-loaded source for a repository and a home directory,
  per source, and lists what each path-scoped rule matches; read-only, deterministic.
- `skills/audit/areas/context.md` (new): the context-and-tooling area, owner `explorer`, in S1's area-file format; it
  runs the script by `${CLAUDE_PLUGIN_ROOT}` path and judges the rows.
- `scripts/test/audit-context.test.mjs` (new): the pins. `scripts/test/fixtures/audit-home/**` (new): a home with a
  `CLAUDE.md`, a rule, a `react/` rule on `**/hooks/**/*.js`, a skill, two hooks, an MCP server; `.md`/`.json` only.

## Interface

```
// scripts/audit-context.mjs
type ContextKind = 'claude-md' | 'rule' | 'path-rule' | 'skill-description' | 'hook' | 'mcp-server'
type ContextSource = {
  source: string, scope: 'repo' | 'user', kind: ContextKind,   // source: repo-relative, or "~/…"
  tokens: number,            // bytes / 4, an estimate; a path rule's cost when it loads
  matches?: string[], matchCount?: number | null, skipped?: string[],   // path-rule only; null: git ls-files failed; skipped: globs past 12 wildcards. kind 'unreadable': a file that would not parse
  event?: string, matcher?: string,   // hook only
}
export async function measureContext(opts: { repo: string, home?: string }): Promise<ContextSource[]>
//   repo: CLAUDE.md, CLAUDE.local.md, .claude/rules/**, .claude/skills/*/SKILL.md, .claude/settings*.json, .mcp.json
//   home: .claude/CLAUDE.md, .claude/rules/**, .claude/skills/*/SKILL.md, .claude/settings.json
//   never this package's own agents or skills (A4); never installed_plugins.json (check-references forbids it)
CLI  node scripts/audit-context.mjs <repo> [--home <dir>]   // always JSON; formatContext was removed in the fix round (no caller)

skills/audit/areas/context.md   frontmatter { area: context, owner: explorer, model: haiku, spec: [8, 9] }   // rows: 'context' | 'tooling'
  ## Measure   the script's output; plugin hooks and MCP servers the script cannot see are named as unmeasured
  ## Rows      a path rule whose matches are not its language, a hook on a broad matcher, a large always-loaded
               source, a manual multi-step flow a missing MCP server or CLI would replace
  ## Return    rows in S1's Row shape, command = the script invocation
```

## Tests

1. `each always-loaded source is one row with its tokens and scope`: the fixture home plus a temp repo.
2. `a path-scoped rule lists the repository files its globs match`: `react/` on `**/hooks/**/*.js` matches
   `hooks/x.js` in a repo with no React (ADR 0036's example).
3. `a path rule that matches nothing is listed with a match count of zero`.
4. `a hook row names its event, its matcher and its size`.
5. `MCP servers from .mcp.json and settings are rows`.
6. `the CLI prints the rows as JSON`.
7. `the context area is owned by an explorer, runs the script by its plugin path, and excludes the pilot's own
   prompts` (A4).

## Done

- **Expected**: an audit shows a per-source token table for this repository and `~/.claude`, and names any path rule
  that loads into files outside its language with the files it matched.
- **Verification**: `node --test scripts/test/audit-context.test.mjs`, then `npm test`;
  `node scripts/audit-context.mjs . --home scripts/test/fixtures/audit-home`; then `/pilot:audit` live.
- **Evidence**: tests red before, green after; the CLI's table; the deck item's rows. **Done when** all three hold.
- **Prohibited**: reading `installed_plugins.json`; counting this package's agents (A4); a glob library dependency
  for a matcher `**`, `*` and `{a,b}` cover; an absolute home path in any fixture.
