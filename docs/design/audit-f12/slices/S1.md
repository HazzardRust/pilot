## Behaviours

1. `sed -i on a tracked file is refused` (test): `decide` → deny for each of `sed -i 's/a/b/' f.md`, `sed --in-place … C:/…/f.md`, `sed -i … /c/…/f.md`, `cd sub && sed -i 's/a/b/' f.md`, all tracked in a temp repo; reason names the path, `Edit` and `Write`.
2. `sed -i on an untracked file runs` (test): `decide` → null for an untracked and a git-ignored path, and for `cd "$D" && sed -i … f.md` (non-literal cd, L7).
3. `the refusal is not a blocked step` (test): `decide` → reason contains `not a blocked step` and does not start `Refused:`.
4. `the hook fails open` (test): `decide` → null for a non-object payload, a target dir outside any repo, and an `isTracked` that throws.
5. `no candidate spawns no git` (test): `decide` → null with an injected `isTracked` called 0 times for `ls -la`, `git status`, `npm test`.
6. `only pilot lanes are guarded` (test): `decide` → null for `agent_type` `Explore` with an `agent_id`, and for no `agent_type`.
7. `the manifest wires it on Bash` (test): `PreToolUse` → an entry in `hooks.json` whose command runs `shell-write-guard.js` with matcher `^Bash$`; a `spawnSync` of the hook on a refused payload prints the deny JSON and exits 0.
8. `a live sed -i is refused` (run): in a scratch clone session, step 1 of `../architecture.md` §9; file hash unchanged.

Rewrite check: swapping `git ls-files` for any other tracked lookup keeps results 1-2; replacing the parser keeps 1-6.
Misses: real-world command shapes no fixture has; QA's live calls and the fundamentalist read that.
