## Interface

```
stopScratch(pid: number): Promise<void>
  // refuses unless S6's registry names the pid AND its /api/health reports it; kills, then removes the dir and the registry
pilot deck --stop <pid>  -> exit 0 stopped | exit 1 'pid <n> is not a scratch deck'
```

## Tests

1. `stop ends it and its store`: `stopScratch` → health is refused and `dir` is gone.
2. `an unregistered pid is refused`: `stopScratch` → a live sleeper's pid is refused, and the sleeper is still alive.
3. `a reused pid is refused`: `stopScratch` → a registry entry whose health reports a different pid is refused, and nothing is killed.

## Done

- **Expected**: An agent ends its own scratch deck with one command and cannot end the user's deck by mistake.
- **Verification**: `node --test deck/test/scratch-stop.test.mjs`; `npm test`. By hand: `pilot deck --stop <4321's pid>` is refused.
- **Evidence**: The refusal text for the live pid. The scratch dir is absent after the stop.
- **Prohibited**: Do not fall back to killing a pid that has no registry entry. Never `taskkill /F /IM node.exe`.
- **Done when**: The three tests and `npm test` are green, and the live deck still answers after the refused stop.
