## Tests

1. `the seeded run is listed`: `seedRun` → `GET /api/runs` lists a run with that repo.
2. `the record reads back`: `seedRun` → `GET /api/record?repo=<worktree>` returns the record's slug and slices.
3. `a bad record is refused before the deck starts`: `pilot deck --scratch --seed-run <run.json>` → a run.json that fails `recordFields` exits 1, names the field, and leaves no deck running.
