# S1 The gate is red when the home store changed with no live deck

Feature `home-store-guard` · delivers spec 2, 3, 4, 5 · source: `../architecture.md` §2, §5 L1–L3, §6 A1 · after: –
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `scripts/gate.mjs`: `runGate` takes `homeStore` and `deckPid`, stats the store before the spawn and after the census, and prints and decides. The CLI entry passes `homeStore`.
- `scripts/test/gate-home-store.test.mjs` (new): the pins, with an injected `spawn` that touches, creates or deletes a temp store.
- `docs/adr/NNNN-home-store-guard.md` (new): L1–L4 and A1 as taken.

## Interface

```
runGate(args, { homeStore?: string, deckPid?: () => number | null | undefined, ...today }) -> 0 | 1
  // homeStore undefined: no stat, no line, today's behaviour (L1)
  // changed = exists, mtimeMs or size differ (L2); deckPid probed only when changed (L3)
  // changed, deckPid() === null      -> "home store changed: <homeStore>", exit 1
  // changed, deckPid() number|undef  -> "home store changed: <homeStore>; live deck <pid|unknown> up", status kept
CLI entry: runGate(argv, { ..., homeStore: path.join(os.homedir(), '.claude', 'pilot', 'deck.json') })
```

## Behaviours

1. `a touched store is red` (test): `runGate` → exit 1 and one `home store changed: <path>` line when the injected spawn bumps the store's mtime, and `deckPid` returns null.
2. `created or deleted is red, absent both ends is green` (test): `runGate` → 1, 1, 0 for a store created, deleted, and never present.
3. `the live deck's write stays green` (test): `runGate` → the suite's status and one `…; live deck 4242 up` line when `deckPid` returns 4242. Undefined prints `unknown`.
4. `an untouched store adds nothing` (test): `runGate` → exit 0, no `home store` line, and `deckPid` never called.
5. `existing gate tests unchanged` (run): `node --test scripts/test/gate*.test.mjs` passes with those files unedited.
6. `the real gate reports it` (run): in a scratch clone with a temp HOME and a planted store, a test that runs `fs.utimesSync` on it makes `npm test` exit 1 with the line, and `npm run test:changed -- --since=HEAD~1` does the same.

Rewrite check: replacing the stat with any other change signal keeps red for touched, created and deleted, and green for untouched and for the live-deck case.
Misses: a write between the two stats that restores mtime and size exactly. The fundamentalist and QA read that.

## Done

- **Expected**: a gate run whose suite changed the home store with no deck up is red and names the file. A clean run looks as it does today.
- **Verification**: `node --test scripts/test/gate-home-store.test.mjs scripts/test/gate.test.mjs scripts/test/gate-census.test.mjs`; `npm test`.
- **Evidence**: behaviours 1–3 failing before the change; the scratch-clone run's output with the line and exit 1.
- **Prohibited**: no default `homeStore` inside `runGate` (L1); no edit to the existing `gate*.test.mjs` files; no content read or hash of the store (L2); no probe of the deck on an unchanged store.
- **Done when**: behaviours 1–6 hold and `npm test` is green.
