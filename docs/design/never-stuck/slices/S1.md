## Tests

1. `a signed ticket re-cuts to red with its mark`: `recutTicket` → state red, `recut.from` the old plan sha, plan kept.
2. `a live co-pilot's ticket is refused`: `recutTicket` → throws naming the holder; state still yellow.
3. `the action answers with the lane line`: `deck_ticket` → `Re-cut <id>: red`.
4. `a gate1 on the re-cut ticket is accepted and its press replaces the plan`: `gate1 Sign off` → new sha, `recut` gone, yellow.
