## Tests

1. `an unchanged design dir keeps the signature`: `planUnchanged` → true; `replanTicket` → yellow, new sha, no gate1.
2. `one changed slice file refuses the replan`: `deck_ticket` → refusal naming the path; ticket still red.
3. `a gone old sha is never unchanged`: `planUnchanged` → false.
4. `a re-cut gate1 without the line is refused, with it accepted`: `gate1 post` → refusal, then posted.
5. `only the architect or the pilot replans`: `deck_ticket` → refused for `implementer`.

Rewrite check: replacing the git diff with a hash of the design dir keeps all five.
Misses: whether the architect re-posted a locked question; S6's prose forbids it.
