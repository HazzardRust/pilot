## Interface


## Tests

1. `an active architect with no wait loses its reply at 30 s`: `fallbackFor` → the reply the pilot's, `unheard by architect`.
2. `a parked architect wait keeps it`: `fallbackFor` → none; the architect's wait gets it.
3. `today's quiet-owner fallback is unchanged`: `fallbackFor` → the existing `fellBackNote` for a quiet owner.

Rewrite check: tracking listeners in the store instead of memory keeps the three results.
Misses: an owner whose wait parks after the 30 s; it then reads the thread.
