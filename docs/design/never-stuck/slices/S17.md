# S17 One trusted live root

Feature `never-stuck` · delivers spec 12 · source: `../architecture.md` §2, §3 Findings (trust), §6 A3 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — reads the user's `~/.claude.json` and touches workspace trust, the security trigger; A3 is assumed.

## Files owned

- `scripts/live-root.mjs` (new): `liveRoot`, creates `~/.claude/pilot/live` and reads its trust, read-only on `~/.claude.json`.
- `bin/pilot.mjs`: `pilot live-root [--dir <name>]` prints the root, `trusted` or `untrusted`, and with `--dir` makes a plain subdirectory.
- `scripts/test/live-root.test.mjs` (new): a temp HOME with a fixture `.claude.json`.

## Interface

```
export function liveRoot({ home, dir? }): { root: string, trusted: boolean, path?: string }
  // trusted: projects[root].hasTrustDialogAccepted === true; never writes .claude.json
  // dir: one path segment, [a-z0-9-]{1,40}, made under root, never `git init`
CLI: pilot live-root [--dir <name>] -> "<root> trusted|untrusted[ <path>]", exit 0; exit 1 on a bad name
```

## Tests

1. `an untrusted root says so`: `liveRoot` → `trusted: false`; the file is unchanged.
2. `a trusted root says so and makes a plain subdir`: `liveRoot` → `trusted: true`, the dir exists, no `.git`.
3. `a name with a separator or dots is refused`: `liveRoot` → throws; nothing made.

Rewrite check: reading trust from a future CLI flag keeps the three results.
Misses: the trust screen itself, seen only at the user's walkthrough.

## Done

- **Expected**: the user trusts one folder once, by opening Claude Code in it, and every later live check runs there with no trust screen.
- **Verification**: `node --test scripts/test/live-root.test.mjs`; `npm test`; `pilot live-root` on this machine.
- **Evidence**: tests red before, green after; the walkthrough step at QA: `claude` started once in the root, accepted, then `pilot live-root` reads `trusted`.
- **Prohibited**: no write to `~/.claude.json`; no `git init` under the root; no path outside it.
- **Done when**: the three tests and the gate are green and the real command prints the root.
