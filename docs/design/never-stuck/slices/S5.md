# S5 A yield drains its co-pilot before it frees the lane

Feature `never-stuck` · delivers spec 3 · source: `../architecture.md` §2, §4 Drain, §5 L6; ADR 0153 · after: S4 (`store-tickets.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — the yield's timing changes under a live co-pilot, a judgement across three modules.

## Files owned

- `deck/store-tickets.mjs`: `yieldTicket` marks `yielding` and keeps the slot; `finishYieldIn` flips an open yellow one green and paused (`finishYield` deleted in the principles round, F1: only tests called it).
- `deck/store-runs.mjs`: `setCoPilot(id, false)` releases through `finishYieldIn`.
- `deck/lanes.mjs`: `yieldsDue` skips a yielding ticket; no idle refusal while it drains; the line text is unchanged (S8 adds `draining` with the hook regex).
- `deck/test/yield.test.mjs`: the drain pins beside today's.

## Tests

1. `a yield keeps the ticket implementing and the slot held`: `yieldTicket` → yellow, slot live, `yielding` set.
2. `the release after the drain pauses it`: `setCoPilot(id, false)` → green, `paused.question` the question, slot free.
3. `a draining ticket never re-yields and is never refused idle`: `yieldsDue` → none, and `lanesFrom` gives a null refusal.
4. `an answer while draining cancels the yield`: `yieldTicket` → after the user's answer, yellow with `yielding` cleared.
5. `a pivot drops a yield its release never cleared` (principles round): `pivotTicket` → yellow, no `yielding`.
6. `a closed yielding ticket stays closed on its release` (principles round): `setCoPilot(id, false)` → no green, no `paused`.

Rewrite check: replacing the mark with a timer table keeps the four results.
Misses: whether the co-pilot really waits on every child; S6's prose and the harness's own wait carry that.
