## Interface

```
owedThreadsOf(items, repo) -> [{ id, why, line }]
  why: 'unanswered' | 'promised' | 'report owed' | 'architect owed'
  // report owed: a gate2 with landing.state 'landed' whose ticket is open; id the ticket, line its title
  // architect owed: a live red ticket with no open gate1; id the ticket, line its title
OWED_WHY   // hooks/session-handoff.js
renderCard(ticket) -> label "report owed" under the same rule
```

## Tests

1. `a landed gate2 with no report is owed`: `owedThreadsOf` → one `report owed` row; after the report, none.
2. `a live red ticket with no gate1 is owed an architect`: `owedThreadsOf` → one `architect owed`; with a gate1 open, none.
3. `the hook echoes both, quoted`: `OWED_WHY` → both rows in the notice, a crafted title JSON-quoted.
4. `the card reads report owed`: `renderCard` → the label.

Rewrite check: computing the rows in the hook instead keeps tests 1-3 through `/api/record`.
Misses: a session that starts without a hand-off (the notice says nothing then, `withLanes` :389).
