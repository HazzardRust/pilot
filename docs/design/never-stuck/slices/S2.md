           | { state: 'unchecked', reason: string }
  // gone: plan.sha not an ancestor of origin/<plan.branch> after `git fetch origin`

## Tests

1. `a slice's owned paths are read`: `ownedFiles` → the 3 paths of a fixture slice, `(new)` stripped.
2. `an owned file moved on pilot is drift`: `planDrift` → `moved` with that path.
3. `a force-pushed plan sha is gone`: `planDrift` → `gone` with the sha.
4. `an untouched plan is ok; a non-owned change is ok`: `planDrift` → `ok` twice.
5. `the first grant re-cuts a drifted plan`: `deck_ticket` → `Re-cut check due`, ticket red, no slot written.
6. `a successor's grant skips the check`: `deck_ticket` → granted with `plan.grantedAt` set, no git run.
7. `git failing grants with a reason`: `planDrift` → `unchecked`; `deck_ticket` → granted, `drift unchecked`.

Rewrite check: replacing git plumbing with a libgit binding keeps all seven results.
Misses: whether a moved file changes the plan's nature (L3: the architect judges, S6).
