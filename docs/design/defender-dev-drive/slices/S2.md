## Tests

1. `cannot tell with scanning on is due`: `defenderDue` → `due: true`, with the exclusion step first and the Dev Drive second (L8).
2. `a fail is due, a pass is not`: `defenderDue` → `not-excluded` is due; `dev-drive` gives `pass`.
3. `off Windows no probe runs`: `defenderDue` → `not windows`, and a `run` that throws is never called.
4. `advised silences due without probing`: `markAdvised` → then `defenderDue` gives `advised install <date>`, and the throwing `run` is never called.
5. `a bad where writes nothing`: `main` → `../x` and `itm_zz` return 2; no file appears in the store.
6. `a malformed marker reads as absent`: `defenderDue` → with garbage in the file, the advice is due again (L5).

Rewrite check: whatever stores the marker, due → advised → due reads due and then not due, and off Windows nothing is probed.
