# S4 The strip shows each deck's phase

Feature `thread-types-phase` · delivers spec 4, 5 · source: `../architecture.md` §2, F5, F8, L6, L8, L11, A1, A4, A8 · after: S3

## Files owned

- `deck/items.mjs`: `runPhaseOf(items, repo)`, a pure function. It reads the directory's items after its newest `report`. It returns `null` when a report exists and no question, spec, signoff or walkthrough follows it. Otherwise it returns `closing` if a gate-2 item is resolved, `implementing` if a gate-1 item is resolved, else `planning`.
- `deck/tabs.mjs`: `tabsOf` sets `tab.phase` from `runPhaseOf`. PR #215 adds `tab.wrapped` beside it, so a rebase is trivial.
- `deck/ui/render.mjs`: `renderStripLink` draws the phase word in a span carrying `data-phase`, in the slot the `ended` span
  takes today (L11): `ended` when the deck has ended, else the phase, else nothing. One slot, never both.
- `deck/ui/deck.css`: green, yellow and red for `data-phase`, in the strip's own style.
- `deck/test/phase.test.mjs` (new): the pins.
- `docs/adr/0052-the-run-phase-is-derived-from-gate-items.md` (new): L6, L7.

The name is `runPhaseOf`, not `phaseOf`: `deck/status.mjs` already has a `phaseOf(state)` for slice rows.

## Interface

```
// deck/items.mjs
export function runPhaseOf(items: Item[], repo: string): 'planning' | 'implementing' | 'closing' | null
// deck/tabs.mjs
Tab.phase: 'planning' | 'implementing' | 'closing' | null
```

## Tests

1. `a directory with no gate item resolved is planning`
2. `a resolved gate-1 sign-off makes it implementing, and an open one does not`
3. `a resolved gate-2 sign-off or gate-2 walkthrough makes it closing`
4. `a report clears it, and the next question after the report is planning again`: the old run's gates no longer count.
5. `full auto moves it at once`: a gate-1 sign-off posted under auto is implementing at post.
6. `another directory's gates do not count`, via `sameRepo`
7. `the strip link carries the word and data-phase, and none when null`
7b. `an ended deck says ended and not its phase`: `ended` wins the slot (L11).
8. `the phase survives a daemon restart`: `deckOnAPort` read back.
