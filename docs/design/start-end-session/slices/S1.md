# S1 Start opens a `pilot run` window on an ended tab (walking skeleton)

Feature `start-end-session` · delivers spec 1, 2, 6 · source: `../architecture.md` §2, §5 L2–L4, L6–L8 · after: –

## Files owned

- `deck/session.mjs` (new): the one module that starts a session. It holds the spawn shape, the env scrub and the refusals.
- `deck/server.mjs`: `POST /start-session`, behind `fromOwnPage`. It resolves the tab and calls `startSession`, then answers 303.
- `deck/ui/render.mjs`: `renderSession(tab)` in `renderEverything` beside `renderRemove`. Start only when `tab.ended` on win32.
- `deck/ui/deck.css`: Start drawn like Close.
- `deck/test/no-open.mjs`: also sets `PILOT_DECK_NO_START`.
- `deck/test/start-session.test.mjs` (new): the pins.
- `docs/adr/0050-a-deck-starts-a-visible-pilot-run-when-pressed.md` (new): supersedes ADR 0039 in part (L8).

## Interface

```
store.mjs: export class DeckRefusal extends Error { constructor(message, status?: 403 | 400 | 404 | 409) }
export function startSession(repo: string, deps?: { spawn?, platform?, env?, execPath?: string, bin?: string, now?: () => number }): void
export const PARENT_MARKERS: readonly string[]   // L4's twelve names
export function sessionEnv(env: NodeJS.ProcessEnv): NodeJS.ProcessEnv   // drops PARENT_MARKERS, any case
POST /start-session  form { repo, back? } -> 303 to the tab | 403 not own page | 303 to the tab with ?sessionRefused=<reason> (404 not a tab, 409 live, any startSession refusal)
spawn(`${SystemRoot}\System32\cmd.exe`, ['/d','/c','start','"pilot run"', `"${execPath}"`, `"${bin}"`, 'run'], { cwd: tab.repo, shell: false, detached: true, windowsHide: true, windowsVerbatimArguments: true, stdio: 'ignore', env: sessionEnv(env) })   // execPath or bin holding " or % refused
```

## Tests

1. `the spawn carries the directory only as cwd`: no spawn argument contains the repo, and `cwd` equals the tab's `repo`.
2. `sessionEnv drops the parent session's markers`: the four names are gone, and `PILOT_DECK_PORT` is kept.
3. `a POST with a foreign Origin, or with none, is 403 and spawns nothing`.
4. `a repo that is no tab is 404 and spawns nothing`: the tab's stored spelling is used, never the posted one.
5. `a live repo is 409 and spawns nothing` (spec 1's server half).
6. `an ended tab draws Start and a live one does not`, and nothing is drawn when the platform is not win32.
7. `PILOT_DECK_NO_START refuses before any spawn`.
8. `a package path containing " or % is refused`.

## Done

- **Expected**: on a scratch deck, an ended tab shows Start. Confirming it opens a visible terminal window in that directory
  running `pilot run`, and when the session registers the tab turns live without a reload.
- **Verification**: `node --test deck/test/start-session.test.mjs`; `npm test`. Then live: `PILOT_DECK_PORT=4397 node
  bin/pilot.mjs deck --foreground`, add a scratch directory, press Start and confirm.
- **Evidence**: tests 1–8 red, then green. A screenshot of the window that opened, with its working directory. The tab
  turning live, seen in the browser. `curl -X POST -H "Origin: http://evil.example"` answering 403.
- **Prohibited**: `shell: true`; the repo in any argv; `start /D`; a posted path used without the tab lookup; any kill;
  spawning `claude` directly or headless; turning `PILOT_DECK_NO_START` off in the suite.
- **Reviewers**: typescript-reviewer and security-reviewer.
- **Done when**: every test and `npm test` is green, and a real window has been seen opening from Start on the scratch deck.
