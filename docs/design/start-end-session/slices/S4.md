# S4 End ends that deck's `pilot run`

Feature `start-end-session` · delivers spec 5, 8 · source: `../architecture.md` §2, §5 L1, L5, L6 · after: S3

## Files owned

- `deck/session.mjs`: `endSession(repo)` sends `end` to `wrappersOf(repo)`, and to nothing else.
- `deck/server.mjs`: `POST /end-session`, behind `fromOwnPage`. It resolves the tab, answers 409 when no wrapper is
  there, then 303.
- `deck/tabs.mjs`: `tab.wrapped`, looked up like `tab.agents` from a map the caller passes, so the module reads nothing.
- `deck/ui/render.mjs`: `renderSession` draws End when the tab is live and `tab.wrapped`, with the same two-step confirm.
- `deck/run.mjs`: on `event: end` in `changes()`, `watch` calls a new `end` callback, which `run()` wires to its
  `stop` (`:646`).
- `deck/test/run.test.mjs`: the wrapper half.
- `deck/test/end-session.test.mjs` (new): the daemon half.

## Interface

```
export function endSession(repo: string): void   // wrappers told; none -> DeckRefusal 409
export function listWrapped(): Record<repoKey, true>   // the repos with a wrapper stream open
POST /end-session  form { repo, back? } -> 303 | 403 not own page | 303 to the tab with ?sessionRefused=<reason> (404 not a tab, 409 no wrapper)
tabsOf(runs, items, numbers, agents, added, wrapped?: Record<repoKey, true>)   // sets tab.wrapped
renderHomePage(items, runs, selected, all, numbers, agents, now, autos, added, refused, wrapped = listWrapped(), sessionRefused)
startUnderPty(...) -> { child, done, kill }   // kill(): kills the pty and settles done with 1
watch({ cwd, type, signal, end, ... })    // end(): void, called once when an `end` event arrives
S3's wrappersOf / WrapperStream.send('end')
```

## Tests

1. `End goes only to that repository's wrappers`: a second repo's stream receives nothing.
2. `End with no wrapper is 409`, and a foreign Origin is 403.
3. `a live tab with a wrapper draws End; a live tab without one draws nothing` (spec 8).
4. `an end event makes watch call end once and stop` (run.test.mjs, with a stubbed stream).
5. `run() kills its pty child on end` (with the injected pty).

## Done

- **Expected**: on a live tab started by `pilot run`, End then confirm closes that window, and the tab reads ended within
  a few seconds. A second live deck keeps running. A plain-`claude` live tab shows no End.
- **Verification**: `node --test deck/test/end-session.test.mjs deck/test/run.test.mjs`; `npm test`. Live on 4397: two
  started decks, End one of them.
- **Evidence**: tests red, then green. The window seen closing. The other deck's window still open, and its tab still
  live. `tasklist /FI "PID eq <wrapper pid>"` shows the pid gone.
- **Prohibited**: `taskkill`, `process.kill(pid)` or any pid read from the store, in the daemon; a name match; broadcasting
  `end` to every wrapper and filtering on the wrapper's side only.
- **Reviewers**: typescript-reviewer and security-reviewer.
- **Done when**: every test and `npm test` is green, and End has been seen closing exactly one window live.
