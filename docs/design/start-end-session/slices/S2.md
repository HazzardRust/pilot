# S2 Start refuses a missing directory and a second press

Feature `start-end-session` · delivers spec 3, 4 · source: `../architecture.md` §2, §5 L3 · after: S1

## Files owned

- `deck/session.mjs`: the directory check at press time, and the starting latch.
- `deck/server.mjs`: clears a repo's latch when `POST /api/runs` registers a run there.
- `deck/test/start-session.test.mjs`: the pins.

## Interface

```
S1's startSession(repo, deps) -> now also throws SessionRefusal 400 (not a directory) and 409 (starting)
export function clearStarting(repo: string): void      // called by /api/runs registration; matches by sameRepo
const STARTING_MS = 60_000                              // a latch older than this no longer refuses
deps.now?: () => number                                  // the clock seam for the latch test
```

## Tests

1. `a directory that no longer exists is refused with its reason and spawns nothing`.
2. `a path that is now a file is refused and spawns nothing`.
3. `a second Start inside the latch is 409 and spawns once` (spec 3).
4. `a Start 60 s after the first is allowed again`, driven by the injected clock.
5. `a registration in that repo clears the latch`, matched by `sameRepo` across case and separators.
6. `a failed spawn clears the latch`: the spawn's `error` event releases it, and the error is logged to stderr.
