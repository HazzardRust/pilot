# S3 A wrapper's stream turns its tab ended live

Feature `start-end-session` · delivers spec 7 · source: `../architecture.md` §2, §3 F1 F6, §5 L5 · after: S2

## Files owned

- `deck/run.mjs`: `changes()` (`:435`) opens `/events?wrapper=<cwd>` in place of `/events`.
- `deck/server.mjs`: the wrapper branch of `/events`. It refuses any request that carries an Origin, uses its own emitter
  event, and calls `announceChange` on close.
- `deck/session.mjs`: the in-memory registry of wrapper streams by repository.
- `deck/test/run.test.mjs`: the URL pin.
- `deck/test/wrapper-stream.test.mjs` (new): the pins.

## Interface

```
GET /events?wrapper=<cwd>   no Origin and no Sec-Fetch-Site -> text/event-stream ("event: changed"); either present -> 403
createDeckHttpServer({ open?, start?, wrapperGoneMs?: number[] })   // default WRAPPER_GONE_MS = [3_000, 20_000]: re-announces after a close
export function addWrapper(repo: string, stream: WrapperStream): () => void   // returns the removal, called on close
export function wrappersOf(repo: string): WrapperStream[]                     // sameRepo match
type WrapperStream = { send(event: 'changed' | 'end'): void }
browserCount()  // no longer counts wrapper streams
```

## Tests

1. `a wrapper stream is refused when an Origin is present`.
2. `a wrapper stream is not counted by browserCount`.
3. `closing a wrapper stream announces a change`: a page on `/events` receives `changed`.
4. `wrappersOf matches by sameRepo and forgets a closed stream`.
5. `the wrapper opens /events?wrapper= with its cwd encoded` (run.test.mjs).

## Done

- **Expected**: when a `pilot run` window is closed by hand, its tab turns ended within a few seconds, with no reload.
- **Verification**: `node --test deck/test/wrapper-stream.test.mjs deck/test/run.test.mjs`; `npm test`. Live on the 4397
  scratch deck: Start, then close the window with its ×.
- **Evidence**: tests red, then green. The tab seen flipping to ended in the browser after the window closed.
- **Prohibited**: polling pids on a timer to fake the flip; persisting the registry; accepting the stream with a
  same-origin Origin.
- **Reviewers**: typescript-reviewer and security-reviewer.
- **Done when**: every test and `npm test` is green, and the live flip has been seen.
