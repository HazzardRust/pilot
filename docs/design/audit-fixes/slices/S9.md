# S9 The ADR index is generated and checked

Feature `audit-fixes` · delivers spec 16 · source: `../architecture.md` §2, §5 L9, §6 Q6 · after: S8

## Files owned

- `scripts/adr-index.mjs` (new): writes or checks the index.
- `scripts/test/adr-index.test.mjs` (new): the pins, and the check over the real `docs/adr/` in `npm test`.
- `docs/adr/README.md` (new, generated).
- `package.json`: `"adr-index": "node scripts/adr-index.mjs"`.

## Interface

```
node scripts/adr-index.mjs [--dir docs/adr] [--check]
indexLines(dir: string): string[]   // "| NNNN | [title](file) | status | one sentence |", by number
checkIndex(dir: string): { ok: boolean, problems: string[] }   // stale or missing rows
// status: front matter `status`, else a `**Status:**` line's first word, else `accepted`
// sentence: the first sentence of the first body paragraph, cut at 160 chars
```

## Tests

1. `the index has one row per ADR file, by number`.
2. `regenerating changes nothing`: two writes, byte-identical.
3. `the check fails naming an ADR missing from the index`: a scratch dir with one extra ADR.
4. `the check fails on a stale row`: a changed title.
5. `status falls back from front matter to the prose line to accepted`.
6. `the real docs/adr index is current`.

## Done

- **Expected**: opening `docs/adr/` shows one table of every decision with its status; adding an ADR without regenerating fails `npm test`.
- **Verification**: `node scripts/adr-index.mjs`; `node scripts/adr-index.mjs --check`; `node --test scripts/test/adr-index.test.mjs`; `npm test`.
- **Evidence**: tests 3–4 red first; the generated README's line count against `git ls-files 'docs/adr/0*.md' | wc -l`.
- **Prohibited**: no hand-written index; no ADR edits here (S10 owns them); no network.
- **Done when**: the index lists every ADR and the check is in `npm test`.
