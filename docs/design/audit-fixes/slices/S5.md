## Files owned

- `hooks/session-handoff.js`: on delivering a hand-off, writes a pickup marker keyed on `session_id` naming the claim.
- `hooks/post-tool.js`: on a session's first tool call with a pickup marker, judges the role.
- `hooks/lib/deck.js`: `release(name)`, the inverse of `claim` (user-thread-listener S2–S3 also edit this file; add only `release`).
- `hooks/test/plain-pickup.test.js` (new): the pins.
- `docs/adr/0080-a-plain-pickup-is-warned-and-released.md` (new).

## Interface

```
release(name: string): boolean            // deletes <stateDir>/claims/<name>.claim; false when absent
pickup marker: <stateDir>/pickups/<session_id>.json  { claim: string, item: string, at: string }
PILOT_AGENT_TYPES = ['pilot:pilot', 'pilot']
// post-tool: marker present && agent_type not in PILOT_AGENT_TYPES -> release(claim),
//   delete marker, emit { systemMessage: "This session is not the pilot … run `pilot run` …" }
// marker present && pilot -> delete marker, silent
```

## Tests

1. `a plain session's first tool call after a pickup warns, naming pilot run`.
2. `the plain session's claim is released`: a following SessionStart delivers the same hand-off.
3. `a pilot session's first tool call is silent and keeps the claim`.
4. `a session with no marker is untouched`: no output, no file read past the marker check.
5. `the warning fires once`: a second tool call is silent.
6. `a subagent's tool call (agent_id set) never judges the main session's pickup`.
