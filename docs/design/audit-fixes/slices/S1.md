## Tests

1. `every tracked path is at most 90 characters`: runs `git ls-files`, fails naming each longer path and its length. Rewrite check: holds whatever renaming scheme is used.

3. Existing transcripts, telemetry and analytics-buckets tests pass unchanged in what they assert, only the ids differ.
