## Interface

```
pilot worktrees [--repo <dir>] [--base <ref>]          // list; base default origin/main, fetched first
pilot worktrees prune [--repo <dir>] [--base <ref>] [--dry-run]
type WorktreeState = 'main' | 'merged-clean' | 'merged-dirty' | 'open' | 'locked'
classify(repo: string, base: string): { path: string, branch: string | null, state: WorktreeState }[]
prune(repo: string, base: string, opts?: { dryRun?: boolean }): { removed: string[], kept: { path, state }[] }
// moved = HEAD differs from the oldest reflog entry's new value (branch reflog, or worktree HEAD reflog if detached); no reflog -> open
// merged = moved && HEAD is an ancestor of base; clean = `git status --porcelain --untracked-files=all` empty
// remove = `git worktree remove <path>` (no --force), then `git branch -d <branch>` (no -D)
```

As built: `prune` returns `{ removed, kept, failed }`, and the base defaults to `origin/<the default branch origin names>`, not `origin/main`.

## Tests

1. `list names each state`: a temp repo with merged-clean, merged-dirty (untracked file), unmerged, locked worktrees and main → five rows.
2. `prune removes only the merged-clean worktree and its local branch`.
3. `prune leaves a dirty merged worktree in place and names it`.
4. `prune leaves an unmerged worktree in place and names it`.
5. `prune never removes the main checkout or a locked worktree`.
6. `a failed fetch stops prune before anything is removed`.
7. `--dry-run removes nothing and names what it would`.
8. `a fresh worktree at main's tip is listed as open, not removed`: `worktree add -b x <p> origin/main` with no commits, and a detached one at the same tip, both stay.
9. `a worktree with no reflog is listed as open`.

## Done

- **Expected**: in a repo with stale worktrees, `pilot worktrees` shows which are merged, and `prune` removes only the ones whose work is safely in main.
- **Verification**: `node --test scripts/test/worktrees.test.mjs`; `node bin/pilot.mjs worktrees --repo <scratch clone>`; `npm test`.
- **Evidence**: tests 2–6 red first; both commands run on a throwaway clone with each kind of worktree (L8), their output read; never this repository's worktrees.
- **Prohibited**: no `--force`, no `-D`, no `fs.rm` on a worktree path, no remote branch deletion, no prune against an unfetched base.
- **Done when**: every test is green and the scratch-clone run removes exactly the merged-clean worktree.
