## Tests

1. `the pilot can spawn the co-pilot`: `pilot:pilot-co-pilot` is in pilot.md's `Agent(...)` list and ships as a file.
2. `the co-pilot never finishes a run or moves a ticket`: its tools carry no `deck_ticket`; its body says never `finished`.
3. `the co-pilot is spawned from the signed plan, never from the record alone`: the Yellow section's sentence pinned (L5).
4. `the co-pilot refuses instead of asking`: `permissionMode: dontAsk` in its frontmatter.
5. `pilot.md has no Sub-deck section`: no `## Sub-deck`, no "As sub-deck".
