# S6 A fresh session re-briefs the co-pilot after /clear or a closed terminal

Feature `yellow-agent` · delivers spec 6, 9 · source: `../architecture.md` §2, L3, L4, L5 · after: S5

## Files owned

- `deck/store.mjs`: `yellowHeadOf(dir)`: the directory's first open yellow ticket, its gate1 plan and `recordForTicket` record.
- `deck/server.mjs`: `GET /api/record` (no `ticket`) adds `yellow`.
- `hooks/session-handoff.js`: reads `source`; appends the yellow lane to a hand-off delivery always, and to a recovery or a bare start when `heldElsewhere` is false and its claim is new; never on `compact`.
- `hooks/test/session-handoff.test.js`: the pins.
- `agents/pilot.md`: the first-turn sentence: a yellow lane in the start notice means spawn the co-pilot from it (S1's Yellow section).

## Interface

```
yellowHeadOf(dir: string): { ticket: {id,title}, plan: {artefact,branch,sha,sliceCount}, record: Record|null } | null
GET /api/record?repo=<dir> -> { record, role, budget, yellow }
claim name: yellow-<ticketId>-<record.updatedAt | plan.sha>
```

## Tests

1. `a hand-off delivery carries the yellow lane`.
2. `a recovery with no live run carries the yellow lane`.
3. `a live run registered before the record's last save holds it: no lane`.
4. `compact carries no lane`.
5. `a yellow ticket with no record yet is named once, from its plan` (spec 9).
6. `the lane is fenced as saved state`: the record's `next` is quoted inside the begin and end markers.

## Done

- **Probe first**: on a scratch session, spawn a background agent, `/clear`, and record whether it is still running. If it survives, stop and report to `main`: test 1 changes.
- **Expected**: across a `/clear` or a closed terminal, the next session spawns a co-pilot that resumes at the record's `next`; the four waiting tickets start on the first main start.
- **Verification**: `node --test hooks/test/session-handoff.test.js deck/test/yellow-resume.test.mjs scripts/test/measure-prompt.test.mjs`; `npm test`; the scratch `/clear` run.
- **Evidence**: tests failing before and passing after; the probe's result; the scratch notice text and the resumed rows.
- **Payment**: the first-turn sentence replaces "If a run is live, resume it" wording it extends; net zero or less.
- **Prohibited**: no agent type, branch or artefact taken from the record (L5); no Stop-hook check; never the live daemon.
- **Done when**: the probe is recorded, the tests and the suite are green, and the scratch `/clear` resumed.
