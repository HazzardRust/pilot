# S2 A blocked yellow ticket turns red and the next one starts

Feature `yellow-agent` · delivers spec 5 · source: `../architecture.md` §2, L2, L9, A4 · after: S1

## Files owned

- `agents/pilot-co-pilot.md`: "Hand-back": it hands back when its ticket hits red as ADR 0066 defines it (L9): QA's walkthrough is posted, or everything left stands on an open blocking question, or the work is finished with nothing to walk; the hand-back names the questions by id, the decisions assumed and the blocked steps.
- `agents/pilot.md`: the Yellow section's hand-back sentence: on a co-pilot's hand-back, `deck_ticket need` its ticket (or, when no walkthrough and no question names it, post its `gate2`, which turns it red), then spawn a co-pilot for the next yellow ticket; an answer landing while a co-pilot is live is relayed to it with `SendMessage`. Step 6 names the yellow ticket as a question's `ticket`.
- `scripts/test/yellow-co-pilot.test.mjs`: the pins.

## Interface

```
Hand-back (co-pilot -> main), as a table:
```
