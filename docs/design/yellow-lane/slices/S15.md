## Tests

1. `a v1 store keeps every ticket's meaning`: `upgradeStore` → a planning ticket saved `green` reads `red`, a concluding `red` reads `green`, yellow and closed unchanged.
2. `it runs once`: `upgradeStore` → a v2 store comes back identical.
3. `the lanes read the new names`: `TICKET_STATES` → `nextTicketOf` picks a red planning ticket as it picked a green one.

4. `the plugin version moved with the store`: `STORE_VERSION` → `package.json` and `plugin.json` read the same version, and it is not 0.8.4.

Rewrite check: any storage of the state keeps each ticket's queue across the upgrade.
