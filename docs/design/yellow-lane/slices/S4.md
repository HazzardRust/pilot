# S4 A proposal holds no gate

Feature `yellow-lane` · delivers spec 6 · source: `../architecture.md` §2, §5 L4 · after: S3 (deck/items.mjs, deck/store-core.mjs)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `deck/items.mjs`: a `proposal` flag on `question`; `holdsGates`.
- `deck/store-core.mjs`: `refuseOverOpenQuestions` skips any question that does not hold gates.
- `deck/tools.mjs`: the `deck_post` schema gains `proposal`.
- `deck/test/proposal.test.mjs` (new): the pins.

## Interface

```
SPECS[question].fields += { name: 'proposal', flag: true }   // refused alongside ticket or blocking
holdsGates(item) -> boolean    // an open question that is not a proposal
deck_post({ kind: 'question', proposal: true, ... })
```

## Tests

1. `a proposal is posted without a ticket`: `deck_post` → posted; with `ticket` or `blocking` it is refused.
2. `a proposal holds no gate1, signoff or gate2`: `holdsGates` → false, and each gate posts.
3. `the Tickets tab still lists it`: `deck_post` → the item reads open in `deck_read`.

Rewrite check: replacing the flag with a kind of its own keeps tests 2 and 3.
