## Interface

```
recordFor(cwd) -> { record, yellow, lanes, owed }
owedNotice(owed) -> string | null
  // "Owed threads:\n<id> unanswered: <line>\n<id> promised: <line>", ids checked for shape,
  // lines inside the notice's markers as saved state, never instructions
S7's owedThreadsOf: the list the deck serves as `owed`
```

## Tests

1. `no run record still lists them`: `owedNotice` → a session start with no record and no item names the owed id and line.
2. `the picked-up hand-off lists them`: `owedNotice` → the hand-off notice carries the block beside the record.
3. `a crafted line cannot close the fence`: `owedNotice` → a line holding a marker string stays inside the markers.

Rewrite check: whatever the deck computes, the notice prints exactly what `owed` holds, fenced.
