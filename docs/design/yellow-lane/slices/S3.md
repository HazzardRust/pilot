## Interface

```
isBlocking(item) -> boolean                 // open question or walkthrough with blocking === true
gate2Blockers(items, ticketId) -> string[]    // ids of the ticket's open blocking items
SPECS[walkthrough].fields += { name: 'blocking', flag: true }
// refusal: "gate2 <id> waits on <n> open blocking item(s) on ticket <t>: <ids>"
```

## Tests

1. `a walkthrough takes blocking`: `isBlocking` → true for an open blocking walkthrough, false once it is resolved.
2. `a plain question never holds the press`: `gate2Blockers` → [] and Sign off on the gate2 succeeds.
3. `a blocking walkthrough holds post and press`: `gate2Blockers` → its id; both refusals name it and the word `blocking`.

Rewrite check: whatever stores the flag, post and press refuse on exactly the ids `gate2Blockers` returns.
