## Tests

1. `a fault stops the gate before the ledgers and the suite`: `runGate` → with `syntax` returning one Fault, exit 1, the `syntax:` line on stderr, 0 `ledgers` calls, 0 `spawn` calls; the same with `--since=HEAD`.
2. `a check that cannot run is red`: `runGate` → with `syntax` throwing, exit 1 and `syntax: could not check (…)`; `syntaxErrors` → throws for a `spawn` stub returning `{ error }` or empty stdout.
3. `every fault is named, untracked included, ignored skipped`: `syntaxErrors` → in a temp git repo with one tracked broken `.mjs`, one untracked broken `.js` and one ignored broken `.mjs`, exactly the first two, each with its line.
4. `its verdict matches node --check`: `syntaxErrors` → over a temp repo of at least 6 cases (ESM error in `.mjs`; top-level `return` in `.mjs`; sloppy CJS `.js` using `with`; ESM `.js`; top-level `return` in `.js`; `.js` mixing `import` and `with`), the faulted set equals the set `node --check` exits non-zero on.
5. `the real tree is clean and fast`: `syntaxErrors` → on the checkout, `errors` empty, `files` equal to the `git ls-files -co --exclude-standard` count, `ms` under 10 000.

Rewrite check: replacing the in-process parse with `node --check` per file keeps results 1-4; only 5's time bound would fail.
