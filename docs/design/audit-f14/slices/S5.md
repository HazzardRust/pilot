# S5 The ADR number rides on the feature branch

Feature `audit-f14` · delivers spec 9 · source: `../architecture.md` §2, §5 L7 · after: S4 (`afterGreen` in `scripts/land.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — the order of commit, suite and two pushes is where a collision hides (red team in §6).

## Files owned

- `scripts/land-adr.mjs` (new): `afterGreen`'s body. It allocates on a feat commit in the landing worktree after the suite is green, then remerges.
- `scripts/adr-allocate.mjs`: `allocateAdr` takes `onto`, either `merge` (amend, today's behaviour, for a legacy run) or `branch` (a new commit on feat).
- `scripts/sync.mjs`: `mergeIntoPilot` allocates only for a legacy run (:98). A main-cut run's allocation goes through `afterGreen`.
- `scripts/test/land-adr-branch.test.mjs` (new): the pins.

## Interface

```
allocateAdr(dir, { since, onto }): { from, to } | null   // onto: 'merge' | 'branch'
afterGreen(dir): { from, to } | null   // S4's hook, filled: commit on feat, then feat pushed, then pilot
```

## Behaviours

1. `the PR carries the number` (test): `afterGreen` → after a landing in a temp repo, `git diff --name-only main..feat/x` holds `docs/adr/0193-x.md` and 0 `NNNN-` paths.
2. `two landings take consecutive numbers` (test): `allocateAdr` → 0193 then 0194 for two features each holding a placeholder, landed in turn.
3. `a red suite pushes no number` (test): `afterGreen` → is not called when the suite fails, and origin's feat/x still holds `NNNN-x.md`.
4. `a legacy run allocates as today` (run): `node --test scripts/test/land-adr.test.mjs scripts/test/adr-allocate.test.mjs` passes unchanged.

Rewrite check: any allocation that commits on feat before both pushes keeps 1 and 3.
Misses: two decks landing at once in different repositories that share an ADR folder. That does not occur, since there is one lander per repository.

## Done

- **Expected**: a landed feature's PR lists `docs/adr/<number>-<slug>.md`, and `pilot land` prints `ADR NNNN-x is 0193` as today.
- **Verification**: `node --test scripts/test/land-adr-branch.test.mjs`; `npm test`.
- **Evidence**: 1 and 3 failing before and passing after.
- **Prohibited**: no push of feat before the suite is green; no edit of `scripts/land.mjs` (S4 owns it) beyond the one line that makes S4's exported no-op `afterGreen` call `land-adr.mjs` (seam, co-pilot: S4 passes `afterGreen` to `mergeIntoPilot` for a non-legacy run); no renumbering of an ADR that already has a number.
- **Done when**: 1-4 hold and the gate is green.
