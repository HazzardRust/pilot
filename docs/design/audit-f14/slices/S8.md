# S8 Restack rebases after a squash, leased

Feature `audit-f14` · delivers spec 6, 8 · source: `../architecture.md` §2, §5 L3 L12 · after: S7 (`scripts/stack.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the run's only forced push, an irreversible write to a shared branch.

## Files owned

- `scripts/stack.mjs`: in `restack`, a lower branch whose PR reads merged but whose tip is not in the default branch is a squash. The upper branch is then `rebase --onto <default> <lower tip>` and pushed `--force-with-lease=refs/heads/feat/<s>:<tip fetched in this run>`, only when feat/<s> has landed on pilot (L3).
- `scripts/test/restack-squash.test.mjs` (new): the pins.

## Interface

```
restack({ cwd, git, host }): { lines, exitCode }   // S7's, gains:
// `rebased feat/<s> onto <default> (squash of feat/<lower>)` | `not rebased feat/<s>: <why>`
```

## Behaviours

1. `a squash leaves B with only its commits` (test): `restack` → `git rev-list origin/main..origin/feat/b` holds only B's commits after A is squashed into main.
2. `the lease holds` (test): `restack` → `not rebased feat/b: moved since fetched` and origin's feat/b unchanged, when feat/b moved between the fetch and the push.
3. `an unlanded run is never rewritten` (test): `restack` → `not rebased feat/b: not landed on pilot` for a feature with no `Merge feat/b into pilot`.
4. `pilot is never forced` (test): `restack` → the git log of pushes in the temp origin holds 0 forced updates of `pilot` or `main`, and `pilot sync` then reports `pilot already has main@…` (L12).

Rewrite check: any rewrite that keeps the lease and the landed check keeps 2 and 3, because the tests read origin's refs only.
Misses: a human who has pushed to feat/b by hand from another clone. The lease refuses that, and the line tells the pilot.

## Done

- **Expected**: under squash, B's PR shows only B after one `pilot restack`, and nothing but feat/b was forced.
- **Verification**: `node --test scripts/test/restack-squash.test.mjs scripts/test/sync.test.mjs`; `npm test`.
- **Evidence**: 1-4 failing before and passing after.
- **Prohibited**: no `--force` without a lease; no lease without the explicit sha; no rebase of a branch whose run is still building; no reading `pilot.merge` to decide (spec 7).
- **Done when**: 1-4 hold and the gate is green.
