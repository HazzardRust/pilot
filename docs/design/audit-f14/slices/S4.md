# S4 The landing opens no release PR for a main-cut run

Feature `audit-f14` · delivers spec 4, 8, 12 · source: `../architecture.md` §2, §5 L2 L12, §6 A3 · after: S3 (`prBase`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — it changes the landing's last line, which the deck parses, and keeps a legacy path beside the new one.

## Files owned

- `scripts/land.mjs`: for a record base that is not `pilot`, there is no `releasePr`, no `retarget` (it moves to S7), and no merged poll in `comment`. `featureLine` is printed last. `landCaughtUp` calls `afterGreen(dir)`, a hook that does nothing here and that S5 fills (:206-253).
- `scripts/release.mjs`: unchanged in behaviour. Its doc comment names it the legacy path (A3).
- `scripts/test/land-feature-line.test.mjs` (new): the pins.

## Interface

```
featureLine({ number, base, below, why, host }): string
// `feature PR: #<n> into <base>` [+ ` (after #<below>)`] | `feature PR: none (no host)` | `feature PR: unknown (<why>)`
land(inject): { head, sha, …, feature: { number, base, below? } }   // `main` only for a legacy run
afterGreen(dir): { from, to } | null   // S5's hook; null here
```

## Behaviours

1. `a main-cut landing opens no PR from pilot` (test): `land` → the stub host saw 0 `open` calls with head `pilot`, and the last line is `feature PR: #12 into main`.
2. `a stacked landing names the PR below` (test): `featureLine` → `feature PR: #13 into feat/a (after #12)`.
3. `the landing still merges onto pilot with the full suite` (run): `node --test scripts/test/land.test.mjs scripts/test/land-suite.test.mjs` passes unchanged.
4. `a legacy run keeps the release PR` (run): `node --test scripts/test/release.test.mjs scripts/test/land-main-pr.test.mjs` shows 19 of 19 passing, with record base `pilot`.
5. `no wait for a PR that cannot read merged` (test): `land` → returns without calling `host.review` for a PR whose base is main.

Rewrite check: a landing that computes the PR by any route keeps 1, because the test counts host `open` calls and reads the last line.
Misses: the deck's parse of the new line. S6 pins that, and until S6 lands the closing report says `main gets pilot: not printed by land` for a main-cut run.
