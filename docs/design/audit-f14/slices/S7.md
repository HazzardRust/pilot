# S7 Restack retargets and merges forward

Feature `audit-f14` · delivers spec 6, 10 · source: `../architecture.md` §2, §5 L2 L4, §6 A5 A6 · after: S3 (`scripts/stack.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new CLI verb that pushes branches and writes PR bases, which is the security trigger.

## Files owned

- `scripts/stack.mjs`: `restack`. For each open own-repo PR with head `feat/`, if `prBase` differs from its base, it retargets. If its branch does not merge clean onto its base, it merges the base in (generated paths regenerated through `merge-generated.mjs`) and pushes unforced. It takes over `land.mjs`'s `retarget`.
- `bin/pilot.mjs`: the `restack` verb. Its help line, and `land`'s help no longer saying `main gets pilot` (:94, :116).
- `scripts/test/restack.test.mjs` (new): the pins, in temp repos with a stub host.

## Interface

```
pilot restack   // no arguments; exit 0 level, 1 failed, 3 a conflict (names each path); one line per PR
restack({ cwd, git, host }): { lines: string[], exitCode: 0 | 1 | 3 }
// lines: `retargeted #<n> to <base>` | `merged <base> into feat/<s>` | `conflict feat/<s>: <paths>` | `level #<n>`
```

## Behaviours

1. `a merge commit retargets without a rewrite` (test): `restack` → B's PR edited to base main after A merges into main with a merge commit, and feat/b's tip unchanged.
2. `a fix on A reaches B` (test): `restack` → `merged feat/a into feat/b`, with feat/b holding the fix and pushed with no force flag.
3. `a sibling's generated clash heals` (test): `restack` → B merges main clean when only `docs/adr/README.md` clashed after A merged (A5).
4. `a hand conflict stops` (test): `restack` → exitCode 3 and `conflict feat/b: src/x.mjs`, with origin's feat/b unchanged.
5. `the verb runs` (run): `node bin/pilot.mjs restack` in a repo with no open feature PR prints nothing and exits 0.

Rewrite check: any restack built on other git plumbing keeps 1-4, because the tests read only origin's refs and the stub host's edits.
Misses: GitHub's own auto-retarget racing ours. `host.edit` to the same base is a no-op, and QA reads it live.

## Done

- **Expected**: after the user merges #A, one `pilot restack` points #B at main, and B keeps any fix A took.
- **Verification**: `node --test scripts/test/restack.test.mjs`; `node bin/pilot.mjs restack`; `npm test`.
- **Evidence**: 1-4 failing before and passing after; the CLI run's output read.
- **Prohibited**: no forced push here (S8 alone, L3); no push to pilot or the default branch; no PR whose head is not `feat/` or that is cross-repo.
- **Done when**: 1-5 hold and the gate is green.
