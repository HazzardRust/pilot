## Behaviours

1. `an unchained run on origin is cut from the default branch` (test): `base` → prints `base main <sha7>` in a temp repo whose origin HEAD is main and that has a host.
2. `a fork remote keeps pilot` (test): `base` → prints `base pilot <sha7> on fork` under `pilot.remote=fork`.
3. `a gate1 cut from main is accepted` (test): `assertOnPilotTip` → returns for a design branch on main's tip with base main, and throws naming `origin/main` for a branch carrying a copy of one of main's commits.
4. `an option-shaped base is refused` (test): `RUN_BASE` → does not match `--upload-pack=x` or `-x`.
5. `the architect cuts from the named base` (read): `agents/pilot-architect.md` holds no literal `<remote>/pilot` in the cut, rebase or cherry lines.

Rewrite check: replacing `pilotLineage`'s git calls with any other ancestry walk keeps 3, because the test reads only accept or refuse.
Misses: whether a live pilot session reads the new base line correctly. S9's prose and QA's take walkthrough read that.
