## Tests

1. `a CRLF working copy is named`: `crlfFiles` → `['b.md']` in a scratch repo where `b.md` was rewritten with CRLF after checkout and `a.md` was left LF.
2. `a mixed file is named too`: `crlfFiles` → names a file with one CRLF line among LF ones.
3. `this checkout has none`: `crlfFiles` → `[]` on the repository root, the failure message listing each path.

Rewrite check: replacing `git ls-files --eol` with a byte scan of every tracked file keeps the three results above.
