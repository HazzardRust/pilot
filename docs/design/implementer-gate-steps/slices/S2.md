## Interface

```
agents/pilot-implementer.md
  ## Where you work   + install the worktree's dependencies before the first test run (`npm ci` in a Node repo) (spec 7)

  ## The loop         + red and green run only the slice's own test files (`node --test <files>`); the full suite

```

## Tests

1. `the edit rule is in Where you work`: `## Where you work` → carries L1's sentence, flattened, verbatim.
2. `the worktree is installed before the first test`: `## Where you work` → names `npm ci` after `git worktree add`, and no junction.
3. `red and green run the slice's own files`: `## The loop` → names `node --test <files>` and "once, at the phase gate".
4. `the gate runs the suite past the 120 s default`: `## The loop` → step 3 names `run_in_background`, `600000` and reading the log.
5. `the pin figure has its command`: `## The loop` → names `node scripts/measure-prompt.mjs` and headroom.
6. `a reviewer runs in the implementer's worktree`: `## The loop` → the review paragraph says the reviewer installs nothing.

Rewrite check: rewording any sentence keeps the six results as long as its pinned phrase survives.
