## Interface

```
scripts/test/lib/area-file.mjs
  frontmatterOf(source: string) -> string   // the leading block's lines joined by '\n', '' when none; LF or CRLF
  bodyOf(source: string) -> string          // the text after the leading block; the whole text when none
scripts/measure-prompt.mjs (existing, read only)
  split(text) -> { front: string[], body: string }
```

## Tests

1. `frontmatterOf reads a CRLF file as its LF copy`: `frontmatterOf` → `'area: x'` for both `---\nb\n` shapes, LF and CRLF.
2. `bodyOf drops the block in either ending`: `bodyOf` → the same body for an LF and a CRLF copy, and the whole text with no block.
3. `no test parses a leading frontmatter by its own LF regex`: `frontmatterOf` → a scan of `scripts/test/*.test.mjs` finds no `/^---\n` regex outside `adr-format.test.mjs` (its block is a template inside the file, not its frontmatter).

Rewrite check: replacing `split` with a YAML parser keeps the three results above.
