# S4 A stop on the ADR index names its generator

Feature `implementer-gate-steps` · delivers spec 4 · source: `../architecture.md` §2, §3 Seams, L8 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the skill is agent configuration (`skills/`), the security trigger, and it is vendored under a provenance header.

## Files owned

- `scripts/merge-generated.mjs`: `conflictPaths` appends the regeneration hint when the stopped paths hold the index.
- `skills/resolving-merge-conflicts/SKILL.md`: step 3 names a generated file's regeneration; the `adapted:` line says so.
- `vendor/methodology.md`: the skill's ledger row names the new clause.
- `scripts/test/land-generated.test.mjs`: line 144's pinned stop line gains the hint.
- `VENDOR.md`: regenerated by `node scripts/build-vendor-ledger.mjs`.
- `scripts/test/adr-index-stop.test.mjs` (new): the pins.

## Interface

```
scripts/merge-generated.mjs
  conflictPaths(left: string[], why?: string) -> string
    // unchanged for any list without docs/adr/README.md; with it, appends
    // "; regenerate docs/adr/README.md with `node scripts/adr-index.mjs`, never by hand"
skills/resolving-merge-conflicts/SKILL.md
  3. Resolve each hunk. ... + a generated file is regenerated by its generator, never merged by hand:
     this package's `docs/adr/README.md` by `node scripts/adr-index.mjs`
```

## Tests

1. `a stop holding the index names adr-index`: `conflictPaths` → `['docs/adr/README.md', 'a.mjs']` ends with the hint; `['a.mjs']` prints as today.
2. `the hint survives a resolver failure`: `conflictPaths` → with a `why`, the list, the why and the hint all appear.
3. `the skill names the generator`: `3. Resolve each hunk.` → the step names `node scripts/adr-index.mjs` and "never merged by hand".

Rewrite check: moving the hint from `conflictPaths` into each of its three callers keeps results 1 and 2 at every stop line.
