## 1. Problem

Every piloted run on this Windows machine re-learns the same lessons at the implementer's expense:
- shell edits mangle escapes or write CRLF (12 runs);
- the pinned prompt share is re-measured by hand, because `measure-prompt` does not print it (5);
- a stopped landing on `docs/adr/README.md` is hand-merged instead of regenerated (6);
- the 4.6-minute suite is killed by the 120 s Bash default (5);
- the red-green loop runs the whole suite instead of the slice's own files;
- a fresh worktree has no `node_modules` (3).

On top of that, a CRLF working copy makes nine test parsers see no frontmatter, and the failures do not name the cause (F5). The fix is to put each lesson where the agent reads it, pinned by a test, and to make `measure-prompt` print the figure the pins count.

## 4. Ubiquitous language

- **Own share**: an agent's (definition + skills + tools) / 4, unrounded. It is the only figure a pin counts.
- **Pin**: the number in an `own <= N` assertion that caps one agent's own share.
- **Headroom**: pin minus own share.
- **Inner loop**: the red and green runs of the slice's own test files.
- **Phase gate**: the once-per-slice run of the project's checks on the final state, the full suite included.
- **Generated file**: a tracked file a script writes from other tracked files. It is regenerated, never merged.

## 5. Locked decisions

- **L1** One sentence, verbatim, in both definitions: "Change a file with the Edit or Write tool, never a heredoc, `sed -i` or Python's text mode: on Windows those mangle escapes and write CRLF." Rejected: a Windows-only section. A shell edit misquotes on every platform, and a section costs more tokens.
- **L2** Depth is **forks**, as the user answered on itm_46641eaa4905. Only questions that fork the deliverable are posted. The rest are decided here as A‹n›.
- **L3** `measure-prompt` reads each pin from the test that names its agent (`row.agent === '<a>'` and `own <= N`). Rejected: a pins JSON that both read. It would break `resolvePin`'s pin-file shape (ADR 0140), and the pin file belongs to another lane.
- **L4** `measure()`, `formatTable` and `--json` are unchanged, and the pinned table is printed second. Rejected: new columns. They break `measure-prompt.test.mjs:58-100` and `measuredPilot`'s reader.
- **L5** F6's wording goes in the implementer's "The loop", not in `tdd-workflow`. Rejected: editing the vendored skill's upstream runner table. QA does not preload that skill either.
- **L6** The worktree gets dependencies from `npm ci`, never a junction. Rejected: a junction to the checkout's `node_modules`. An install in the worktree would then write into the shared checkout, which every crew agent is forbidden to edit.
- **L7** No slice edits `agents/pilot.md`, and no implementer pin is added. QA's pin moves by its measured delta. Rejected: pinning the implementer, which is a scope widening the audit did not ask for.
- **L8** F3 is a hint in `conflictPaths` plus a sentence in the skill. What `mergeResolved` resolves is unchanged (ADR 0129). Rejected: a hint in `pilot.md`'s landing step (another lane), or making a hand merge automatic.
- **L9** The F5 helper lives in `scripts/test/lib/area-file.mjs`, built on `measure-prompt`'s `split`. `adr-format.test.mjs` keeps its regex, because its block is a template mid-file. Rejected: a second CRLF-safe parser.
- **L10** Each slice pins into a new test file, or into the file it already owns. That keeps owned files disjoint. Rejected: adding to `pilot-agents.test.mjs` (1746 lines, shared by every wording slice).
- **L11** QA's environment: the definitions are text, so QA runs on this machine from its worktree. The steps are `npm ci`, the new pin files, then `node scripts/measure-prompt.mjs` read for the pilot row (unmoved) and the QA row (headroom 0 at its new pin). Then a planted CRLF file in a scratch copy, run against `line-endings.test.mjs`, and a `conflictPaths` stop line printed with the index. There is no deck surface to drive.
