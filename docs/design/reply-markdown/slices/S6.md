2. `the thread's headings use the same sizes` (test): `theme::markdown_style` → its heading fonts are 17, 15, 13, 13.
3. `a heading typed and sent looks the same` (test + look): one test compares the box's span size to the thread's per level; the live window, both themes.
4. `the rule says where it bends and nothing else changes size` (test + look): the existing type-scale test still passes for header, body, caption; `theme.json`'s every key is checked; a snap of a screen without headings differs by 0 px from before.
