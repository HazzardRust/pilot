# S2 Headings, list markers and inert links render, within a frame

Feature `reply-markdown` · delivers spec 1, 4, 6 · source: `../architecture.md` §2, §5 L5, L6 · after: S1 (`preview::spans`, `preview.rs`)
Reviewers: `pilot:rust-reviewer`, `pilot:security-reviewer`
Model: opus — links from typed text are the security frontier, and A1 is assumed.

## Files owned

- `deck/rune/src/preview.rs`: headings, list item markers, links, in S1's `spans`.
- `deck/rune/tests/preview.rs`: the pins and the timing.
- `deck/rune/tests/reply.rs`: the inert-link pin.

## Interface

```
S1's preview::spans: unchanged signature; adds heading, list-marker and link spans
```

## Behaviours

1. `headings render in the header type` (test): `preview::spans` → `"# H\nx"`, caret on line 2: a span over `H` with `type_::HEADER`'s size and weight; `#` quiet.
2. `list markers render quiet` (test): `preview::spans` → `"- a\n1. b\nx"`, caret on line 3: quiet spans over `- ` and `1. `, none over `a`, `b`.
3. `a link renders as a link and is never followed` (test): `preview::spans` → `"[t](https://e.x)\nx"`: `t` underlined in the link colour, `[`, `](https://e.x)` quiet; a press on `t` in `box_drawn` posts no `Action` and the draft is unchanged.
4. `a long draft is styled within a frame` (test): `preview::spans` → a 300-line mixed draft in < 16 ms.
5. `the box shows it` (look): `--snap` of the three kinds; the live window, link clicked.

Rewrite check: any preview built on decorations keeps 3's "no action posted".
Misses: layout cost of re-keyed spans per frame on a long draft, and how a taller heading line feels under the
caret; QA's walkthrough reads both.

## Done
