## Interface

```
// deck/rune/src/table.rs
pub struct Table { /* rows of cells, row 0 the header */ }
Table::new(rows: usize, cols: usize) -> Table
Table::size(&self) -> (usize, usize)              // (rows, cols)
Table::cell(&self, r: usize, c: usize) -> &rune::TextEdit
Table::cell_mut(&mut self, r: usize, c: usize) -> &mut rune::TextEdit
/// Canonical GFM: header, `| --- |` delimiter, body; `|` in a cell written `\|`, every other byte as typed.
Table::markdown(&self) -> String
// deck/rune/src/regions/reply.rs
pub tables: Vec<(Table, rune::TextEdit)>          // on Local: each grid and the prose part after it
Local::text(&self) -> String                      // prose parts and tables joined, one blank line between
Local::insert_table(&mut self)                    // 2 x 2 after the caret's line; splits that prose part
```

## Behaviours

1. `the Table button inserts a 2 x 2 grid after the caret's line` (test): `Local::insert_table` → on draft `"a\nb"` with the caret on line 1: `draft.text == "a"`, one table of size (2, 2), its prose part after `"b"`.
2. `a grid shows boxes, not pipes, and typing fills a cell` (test): `Local::text` → after typing `Name` into cell (0, 0) through `box_drawn`, `text()` holds `| Name |`; the drawn tree has key `cell-0-0-0` and no text element showing `|`.
3. `the sent table reads back as the same cells` (test): `Table::markdown` → pulldown-cmark with `ENABLE_TABLES` over `text()` yields one table whose cells equal the typed ones, cell `a | b` included.
4. `send and the option presses carry the table` (test): `Local::text` → `send` and `press` post `Action::Reply.text == text()`, prose before and after byte for byte.
5. `a taken reply empties the box, table and all` (test): `Local::text` → after `acted` on the posted text, `draft.text == ""` and `tables` is empty.
6. `the grid shows it` (look): `--snap` of a draft with a line, a grid and a line; the live window on a scratch deck, then the sent reply in the thread.

Rewrite check: any store of cells that keeps `text()` the one sent string keeps 3 and 4.
Misses: a cell holding `\|` as typed, and how the grid reads on both themes; QA's walkthrough reads them.
