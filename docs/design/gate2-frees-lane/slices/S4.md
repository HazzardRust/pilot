# S4 Report due reaches the pilot and its findings append

Feature `gate2-frees-lane` · delivers spec 4 · source: `../architecture.md` §2, §3 Nudge · after: S1 (`deck/store-items.mjs`), S3 (`deck/closing-report.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a hook's text reaches the pilot's context, and the report's reply rule is a trust boundary (ADR 0148).

## Files owned

- `deck/closing-report.mjs`: `closeLanded` posts the `report due` deck line on the report.
- `deck/store-items.mjs`: the pilot's `Findings:` reply on a report is taken and appended to its body; the user's is still refused.
- `hooks/inbox-alert.js`: a deck line's notice is worded from its kind: a short landing as today, a `report due` as its own.
- `deck/test/report-due.test.mjs` (new): the deck pins.
- `hooks/test/inbox-alert.test.js`: the notice pin.

## Interface

```
deck/closing-report.mjs
  REPORT_DUE = 'report due: add the findings and the human steps with a Findings: reply'
  closeLanded(gate2Id)   // S3's, now also one from:'deck' line with a seq on the report item
deck/store-items.mjs
  addPilotMessage(id, text)   // on a report: 'Findings: …' from the pilot appends to the body; asks refused (report-shape)
hooks/inbox-alert.js
  notice(replies, items) -> { systemMessage, additionalContext }   // 'report due' heading for that deck line
```

## Tests

1. `landed posts report due once`: `closeLanded` → one line `REPORT_DUE` with `from: 'deck'` and a `seq`.
2. `the pilot's findings append`: `addPilotMessage` → the report body ends with the findings; a second `Findings:` appends again.
3. `findings that ask are refused`: `addPilotMessage` → a refusal naming the line.
4. `the next tool call shows report due`: `notice` → a heading naming the report due, not "ended short".

Rewrite check: delivering the nudge through a new post-tool lane instead of inbox-alert keeps results 1 to 3.

## Done

- **Expected**: after a deck report, the pilot's next tool call carries `report due`, and its `Findings:` reply shows on the report.
- **Verification**: `node --test deck/test/report-due.test.mjs hooks/test/inbox-alert.test.js`; `npm test`.
- **Evidence**: the pins red before, green after.
- **Prohibited**: accepting the user's reply on a report (ADR 0148); a notice that reads as the user.
