# S3 The deck writes the closing report on landed

Feature `gate2-frees-lane` · delivers spec 2, 4 · source: `../architecture.md` §2, L3, A2 · after: S2 (`stopReason` reads a deck finish)
Reviewers: `pilot:typescript-reviewer`
Model: opus — it closes tickets and writes records with no session present, and a wrong write loses a report.

## Files owned

- `deck/closing-report.mjs` (new): the minimal report's body, and its post with the record finish.
- `deck/store-runs.mjs`: `finishRecord` (new); `noteLanding` writes `landing started` on the feature row at begin.
- `deck/landing.mjs`: a `landed` settle calls `closeLanded`; the begin calls `noteLanding`.
- `deck/daemon.mjs`: `closeOwed()` after `interruptLandings()` at start.
- `deck/test/closing-report.test.mjs` (new): the pins.

## Interface

```
deck/closing-report.mjs
  closingReportOf(record, gate): { title, body }
    // landing SHA, the merge-first line, slices and PRs from record.slices, worktrees kept (land's kept/cleared
    // lines), friction from rankFriction(record.friction); asks nothing (report-shape)
  closeLanded(gate2Id): { report } | null
    // resolves the gate2 if open, posts the report item (closes the ticket), finishRecord; never chainNext
  closeOwed(): number   // every landed gate2 whose open ticket has no report, closed; how many
deck/store-runs.mjs
  finishRecord(repo, ticketId, { finished: FINISHED_CLEAN, report })   // on recordForTicket's record
  noteLanding(repo, ticketId, { ok, line })   // the feature row: `landing started` at begin, then the settled line
```

## Tests

1. `the report names what landed`: `closingReportOf` → a body with the SHA, the merge-first line, each slice and PR, the kept worktrees and the ranked friction; `reportAskGaps` finds nothing.
2. `landed closes the ticket with no session`: `closeLanded` → a report item, the ticket `closed`, the record `finished: closing report posted`, and no hand-off item.
3. `the row reads landing started, then landed`: `noteLanding` → the feature row's state at begin and after settle.
4. `a restart writes an owed report`: `closeOwed` → 1 for a planted landed gate2 with an open ticket; 0 run again.

Rewrite check: building the body from the gate2's line alone, not the record, keeps results 2 to 4.
