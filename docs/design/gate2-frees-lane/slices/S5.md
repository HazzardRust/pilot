# S5 The deck retries pr ready before asking

Feature `gate2-frees-lane` · delivers spec 3 · source: `../architecture.md` §2, L4, A2 · after: S3 (`deck/landing.mjs`, `closeLanded`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new argv on a process the daemon starts, and timers that outlive the press.

## Files owned

- `scripts/land.mjs`: `main(['--ready'])` runs `ready()` alone, refusing unless the feature is already on pilot.
- `deck/landing.mjs`: on `pr ready failed`, retries at `READY_DELAYS_MS`; `askReady` only past the bound; `closeLanded` once ready settles.
- `deck/test/landing-ready.test.mjs` (new): the deck pins, spawn and clock injected.
- `scripts/test/land-ready.test.mjs` (new): the flag's pins, gh injected.

## Interface

```
scripts/land.mjs
  main(['--ready'])   // exit 0 'ready: #N' or 'pr ready failed: …'; exit 1 'NOT readied: <head> is not on pilot'
deck/landing.mjs
  READY_DELAYS_MS = [0, 60_000, 300_000]   // three attempts after the landed line
  startLanding(gate2Id, { spawn, clock, … })
    // argv [PILOT_BIN, 'land', '--ready'] on a retry, nothing else from the store
closeOwed()   // S3's, also retries a ready a restart cut short
```

## Tests

1. `ready runs alone`: `main(['--ready'])` → `ready: #N`, with no sync, suite or push call on the injected gh and git.
2. `ready refuses an unlanded feature`: `main(['--ready'])` → exit 1, `NOT readied`.
3. `one failure is retried silently`: `startLanding` → ready fails, then passes on the retry; no question; the report is written once.
4. `past the bound one question`: `startLanding` → three failures post exactly one `Mark #N ready` question on the signed ticket, then the report (A2).

Rewrite check: retrying with a daemon-side `gh` call instead of the flag keeps results 3 and 4.

## Done

- **Expected**: a transient `gh pr ready` failure clears itself with no question to the user.
- **Verification**: `node --test deck/test/landing-ready.test.mjs scripts/test/land-ready.test.mjs deck/test/landing.test.mjs`; `npm test`.
- **Evidence**: the pins red before, green after; a spawn's argv logged in the test equals the constant.
- **Prohibited**: anything from the store or the request in argv; rerunning land whole; a real `gh` in a test.
- **Done when**: the pins and the suite are green.
