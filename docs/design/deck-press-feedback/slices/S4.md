# S4 An agent-closed thread leaves a notice the user clears

Feature `deck-press-feedback` · delivers spec 7, 8, 10, 11 · source: `../architecture.md` §2, L6, L7, A3, A4 · after: S3

## Files owned

- `deck/items.mjs`: `SILENT_KINDS` beside `STANDING_KINDS`, and `noticesOf`.
- `deck/store.mjs`: `resolveItem` sets `notice` in the same write; `clearNotice`.
- `deck/server.mjs`: the thread GET clears; `POST /clear-notice` checks the own-page Origin.
- `deck/ui/render.mjs`: notice rows at the top of the Notifications panel.
- `deck/ui/js/notifications.mjs`: a notice's × posts `/clear-notice`.
- `deck/test/notices.test.mjs` (new): the pins.
- `docs/adr/0076-an-agent-closed-thread-leaves-a-notice.md` (new): L6, L7.

## Interface

```
items.mjs  SILENT_KINDS: readonly string[]          // [KIND_HANDOFF, KIND_CREW_HANDOFF, KIND_REPORT] (A3)
items.mjs  noticesOf(items): Item[]                 // closed items with notice === true, newest resolvedAt first
store.mjs  clearNotice(id): Item                    // deletes item.notice; DeckRefusal if no such item
item.notice?: true                                  // set by resolveItem: agent author, kind not silent, last choice not Sign off
POST /clear-notice  { id }  -> 303 back (backPath) | 403 not own page
```

## Tests

1. `an agent resolving a question and a user thread leaves two notices, a handoff none`.
2. `a resolve after the user's Sign off leaves none`.
3. `Close and Dismiss by the user leave none`.
4. `notices survive a reopened store`: write, re-read with a fresh module.
5. `opening the thread clears its notice`: GET `/thread/<id>`.
6. `the × clears it, and a foreign Origin is refused`.
7. `the panel lists notices newest first with kind, title and the resolution's first line, escaped`.
8. `closing reports render and hide as before`: `record-report` and `standing` stay unchanged.

## Done

- **Expected**: when the pilot closes a question while the user is away, the Notifications tab shows it until they open it or press ×.
- **Verification**: `node --test deck/test/notices.test.mjs deck/test/notifications.test.mjs deck/test/record-report.test.mjs`, then `npm test`.
- **Evidence**: tests 1, 4 and 5 fail before and pass after. A scratch-deck run: resolve with no browser open, restart the daemon, then open the deck and the notice is there.
- **Prohibited**: no notice in `localStorage`; no clearing on resolve or restart; no change to closing reports.
- **Done when**: the eight tests and `npm test` are green and the restart run has been seen.
