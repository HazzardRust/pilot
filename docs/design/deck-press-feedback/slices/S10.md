## Tests

1. `a repository without package.json and without --test is refused before any merge`: the branch is unmerged and the message names `--test`.
2. `the same repository with --test "cargo test" integrates`: it uses the fixture's passing command.
3. `an npm repository without --test still runs npm test`: unchanged.
4. `npm ci never runs without package.json`.
