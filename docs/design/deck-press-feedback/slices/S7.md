# S7 Weekly alerts toggle, and weekly alerts at 95% only

Feature `deck-press-feedback` · delivers spec 15, 16 · source: `../architecture.md` §2, L9 · after: S6

## Files owned

- `deck/alert-switch.mjs` (new): read and set `<storeDir>/alerts.json`, in the shape of `usage-switch.mjs`.
- `deck/server.mjs`: `POST /alerts`, with the own-page Origin check, then 303 back through `backPath`.
- `deck/ui/render.mjs`: the Weekly alerts toggle in `<aside class="strip right">` (`renderEverything`).
- `hooks/context-usage-alert.js`: weekly bands to 95 only; reads `alerts.json` through the statusline's path rule.
- `hooks/test/context-usage.test.js`, `deck/test/alert-switch.test.mjs` (new): the pins.
- `docs/adr/0077-weekly-alerts-are-a-per-user-switch.md` (new).

## Interface

```
alert-switch.mjs  alertSwitchFile(): string
alert-switch.mjs  readAlertSwitch(): { weekly: boolean }       // absent or unreadable → { weekly: true }
alert-switch.mjs  setAlertSwitch({ weekly: boolean }): { weekly: boolean }   // tmp file + rename
POST /alerts  { weekly: 'on'|'off', back }  -> 303 back | 403 not own page
hook: band(pct, track): 0 | 90 | 95    // weekly: 95 only; session: 90 and 95
```

## Tests

1. `weekly 92 alerts nothing, 95 alerts`.
2. `session 90 still alerts`.
3. `weekly off in alerts.json: 96 alerts nothing; the session track is unaffected`.
4. `an absent or corrupt alerts.json means on`.
5. `POST /alerts from the page flips it, and a foreign Origin is refused`.
6. `the right strip draws the toggle in its current state`.

## Done

- **Expected**: the user switches Weekly alerts off in the right strip, and a session past 95% weekly gets no alert. The session alerts still come.
- **Verification**: `node --test hooks/test/context-usage.test.js deck/test/alert-switch.test.mjs`, then `npm test`.
- **Evidence**: tests 1, 3 and 5 fail before and pass after. A scratch store (`PILOT_DECK_DIR`): toggle in the browser, then the `alerts.json` content and a hook run against a 96% state file, pasted.
- **Prohibited**: no edit to `deck/usage-switch.mjs` (the base's); no HTTP call from the hook; no write to `~/.claude/pilot/` in tests.
- **Done when**: the six tests and `npm test` are green and the live toggle-then-hook run has been seen.
