## Tests

1. `the owned files stay green`: `lint` → `node --test` over the owned files passes.
2. `a kept lint still bites`: `lint` → on a scratch copy, adding its forbidden pattern or deleting its step turns it red (shown, not committed).
3. `no phrase pin is left`: `PIN block` → the reviewer's re-classification of the owned files finds 0 PIN and 0 MIXED blocks.

Rewrite check: rewording any agent, skill, rule or doc keeps the owned files green unless it adds a forbidden pattern or drops a linted step.
Misses: a prompt edit that drops a rule nobody lints (the guard L6 trades away).
