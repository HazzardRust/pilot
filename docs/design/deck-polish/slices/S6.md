# S6 A card remembers its pick, and lists read and sort by the last message's time

Feature `deck-polish` · delivers spec 2, 10 · source: `../architecture.md` §2, F2, F10, L2, L11, L13 · after: S5 (shares `render.mjs`)

## Files owned

- `deck/items.mjs`: `chosenOf(item)` and `lastSaidAt(item)`, each one spelling.
- `deck/ui/render.mjs`: `renderChoice` marks the chosen option as a live press does (`sent`, the row disabled, L11), on the card and on the page. `renderCard` (`:662`) and the thread KIND line (`:1876`) pass `lastSaidAt(item)` to `renderTime`. `daySections` (`:1604`) keys each card on `lastSaidAt(item)` instead of `postedAt`, and within a section cards go newest-said first; the open cards a deck's overview draws (`renderQueue`, `:1658`, its `waiting`) are ordered newest-said first before they reach it. The Tickets queue (`queueHeadOf`, the Tickets tab) is not touched (L13).
- `deck/test/card-history.test.mjs` (new): the pins.

## Interface

```
// deck/items.mjs
export function chosenOf(item: Item): string | null
  // open item only; the option (from item.options) that the user's newest reply equals or begins with + blank line; else null
export function lastSaidAt(item: Item): string   // newest message's repliedAt, else item.postedAt
```

`lastSaid` (`items.mjs`) already exists and means the last message. `lastSaidAt` is its time, and must agree with it
for a pass that carries replies.

## Tests

1. `the option the user's newest reply chose is chosen`: choice alone, and choice plus a note.
2. `a typed reply after a press unchooses it; a closed thread chooses nothing`.
3. `the card and the page draw the chosen option pressed and the row disabled`: `renderCard` and `renderThreadPage`.
4. `time ago reads the newest message, whoever sent it`: posted 19 hours ago with a reply a minute old gives a `datetime` of the reply's time, on the card and on the page.
5. `a thread with no messages reads its posting time`.
6. `a fresh reply moves an open card to the front, and a settled card into today's section`: two items posted on different days, the older one replied to now — it is first among open cards, and `daySections` files it under today.
7. `a comment on a ticket does not move it in the Tickets queue` (L13).
