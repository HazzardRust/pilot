# S2 Reopen only reopens

Feature `deck-polish` · delivers spec 11 · source: `../architecture.md` §2, F11, L8 · after: S1 (shares `deck/store.mjs`)

## Files owned

- `deck/store.mjs`: `reopenItem` stops pushing `REOPENED` and stops bumping `deck.seq`. The no-seq "Closed with …" line stays.
- `deck/test/reopen.test.mjs`: the pins are rewritten to the silent reopen.
- `deck/test/close.test.mjs`: any assertion on "Reopened." after a close.
- `deck/test/dismiss-item.test.mjs`: the same.
- `docs/adr/0049-reopen-is-silent.md` (new): L8 and the 2026-09-28 incident, in the `domain-modeling` ADR format.

## Interface

```
// deck/store.mjs — unchanged signature, changed contract
export function reopenItem(id: string): Item
  // clears resolution/resolvedAt/resolvedBy; adds no user message; leaves deck.seq as it was
// items.mjs REOPENED stays exported: chain.mjs:22 still filters it out of old data
```

## Tests

1. `reopening adds no user message and leaves the sequence number alone`: messages before and after; `deck.seq` unchanged.
2. `a pilot's resolution is still kept as its no-seq history line`: the "Closed with …" line is present and has no `seq`.
3. `a wait taken before the reopen is not woken by it`: `awaitsPilot(item, baseline)` is false.
4. `a reply typed into a closed thread reopens it and wakes the pilot as that reply`: the reply is the last message and carries the new seq.
5. `the reopened thread shows a reply box and no "Reopened."`: thread page render.

## Done

- **Expected**: Reopen on a closed thread gives a reply box, the thread holds no "Reopened.", and a `pilot wait` in a
  terminal does not return.
- **Verification**: `npm test`; `node scripts/check-references.mjs`; on the preview deck, `pilot wait` running while Reopen is pressed.
- **Evidence**: tests 1–5 red before and green after (test 4 may be green before, which is its point); the wait seen
  still waiting.
- **Prohibited**: deleting `REOPENED` or the chain's filter; an empty-text user message in its place; changing `addReply`'s wake.
- **Diff limit / done when**: about 80 changed lines, and past 300 stop and ask `main`. Done when the five pins are green
  and the wait has been seen not waking.
