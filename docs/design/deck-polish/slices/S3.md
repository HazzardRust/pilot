## Tests

1. `a swap while scrolled up keeps the scroll position`: the time text has been rewritten, a refresh arrives, and `scrollTop` is unchanged.
2. `a swap while at the bottom follows to the new bottom`.
3. `a deferred swap applied on click keeps the position too`.
4. `opening Chat still lands at the bottom`: the existing install and toggle pins stay green.
5. `a chat message's table is wrapped to scroll sideways`: a CSS rule check in the house style of the existing css pins, or a render check if one exists.
