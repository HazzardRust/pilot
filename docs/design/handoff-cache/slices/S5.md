# S5 The crew's survival across the clear is counted

Feature `handoff-cache` · delivers spec 7 · source: `../architecture.md` §2, §3, §6 A2 A5 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — the probe reproduces a timing failure, and its verdict decides A2.

## Files owned

- `docs/design/handoff-cache/probes/crew/` (new): a scratch plugin whose mod clears the main session on a signal, and `run.mjs`, which starts a session that spawns one background agent told to `SendMessage` main at a set point.
- `docs/design/handoff-cache/probes/crew.md` (new): one row per run.

## Interface

```
probes/crew/run.mjs: node run.mjs --at before|during|after --runs <n> --model sonnet
  -> JSON lines: {run, at, agentAlive, agentId, sent, receivedByNewContext, endedBy?}
```

## Behaviours

1. `the agent's life is counted` (run): 10 runs; per run, whether the background agent is in `$.agent.list()` after the clear and finishes its task.
2. `each send point is counted` (run): sends before, during (between `command.run` starting and the fresh turn) and after the clear, at least 3 runs each; per run, whether the fresh context's first turns hold the message.
3. `a loss stops the line` (read): `crew.md` ends with `verdict: no loss, n of n` or `verdict: loss at <point>, k of n`, and on a loss the implementer sends main the verdict and stops: A2 goes to the user as a question before S6 starts.

Rewrite check: not applicable, a probe ships no interface; a rerun by hand must give the same counts within 1.
Misses: the old interactive failure may need a longer agent life than a probe; QA's walkthrough runs one real hand-off with a live implementer.

## Done

- **Expected**: the user reads, with counts, whether a crew agent and its message to main survive the mod's clear.
- **Verification**: the runs above; `claude plugin validate docs/design/handoff-cache/probes/crew`.
- **Evidence**: run output in `crew.md` with the `claude` version and date.
- **Prohibited**: no run in a live session; nothing under `hooks/` or `agents/`; no fewer than 10 runs.
- **Done when**: `crew.md` holds 10 rows or more and a verdict, and main has the verdict.
