# S1 The first turn after a hand-off prints beside a cold start's

Feature `handoff-cache` · delivers spec 1 · source: `../architecture.md` §2, §3, §5 L2, §6 A3 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — spec 1 rests on assumed A3, and the clear-mid-file segmenting is a judgement.

## Files owned

- `scripts/audit-session-start.mjs`: `--first-turn` flag; segments a transcript at each clear; splits the first turn's usage through `deck/transcripts.mjs`'s `tokenCounts`.
- `scripts/test/audit-session-start.test.mjs`: the pins.
- `docs/design/handoff-cache/measurements.md` (new): the two rows from the user's transcripts on disk, with the command and date.

## Interface

```
measureSessionStarts({ repo, home?, limit?, firstTurn?: boolean }) -> Session[]
// Session gains: segments: { byClear: boolean, pickup: boolean, gapMs: number|null,
//   firstTurn: { input, cacheRead, cacheWrite5m, cacheWrite1h } }[]
firstTurnRows(sessions: Session[]) -> { kind: 'after-handoff'|'cold', n, input, cacheRead, cacheWrite5m, cacheWrite1h, cachedShare, medianGapMs }[]
CLI: node scripts/audit-session-start.mjs <repo> --first-turn [--home <dir>] [--limit <n>]
```

## Behaviours

1. `a clear mid-file starts a new segment` (test): `measureSessionStarts` → a fixture with a cold start then a `/clear` and pickup gives 2 segments, the second `byClear` and `pickup` true.
2. `the first turn keeps its four counts apart` (test): `firstTurnRows` → fixture usage {2, 30000 read, 500 write 1h} prints input 2, cacheRead 30000, cacheWrite1h 500, cachedShare 0.98; a `<synthetic>` or zero-usage entry is skipped.
3. `the two rows print from real transcripts` (run): `node scripts/audit-session-start.mjs C:/Users/Hazzard/Projects/pilot --first-turn` prints 1 after-handoff and 1 cold row, n of 3 or more each.
4. `the numbers are recorded` (read): `measurements.md` holds the run's output, the command and date, and one line on whether `/clear` started a new file in the sample.

Rewrite check: reading usage from another source (the mod's `turn.complete`) would keep the same four columns per kind.
Misses: whether the sample is typical of hand-offs (A3); the ledger in S11 reads the counts against that.
