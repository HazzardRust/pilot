# S7 A proven restart replaces `/clear`

Feature `handoff-cache` · delivers spec 4 · source: `../architecture.md` §2, §5 L1 L7 · after: S4 (`probes/restart.md` verdict)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — edits the hand-off mod (agent configuration) on a probe's verdict.

## Files owned

- `hooks/handoff-mod.mjs`: `handOff` runs the adopted restart instead of `command.run({command:'clear'})`, falling back to the clear when it is refused.
- `hooks/test/handoff-mod.test.mjs`: the pins.

## Interface

```
register(on)   // unchanged; handOff($, mod, id) now: adopted restart, else clear, then prompt.submit as today
```

## Behaviours

1. `the gate is read first` (read): `probes/restart.md`; on `verdict: /clear stays`, stop, write the numbers for S11, change no code.
2. `the adopted restart runs` (test): `register` → a fake `$` at `turn.complete` with an open hand-off sees the adopted call, then `prompt.submit` with the pickup prompt; 0 `clear` calls.
3. `a refusal falls back` (test): `register` → a fake `$` whose adopted call rejects sees `command.run({command:'clear'})` once, then the submit.
4. `a real hand-off picks up` (run): one hand-off in a scratch pilot session on this branch; `wrapper.log` has `mod: submitted <id>` and the first turn row from `--first-turn` meets L7's bar.

Rewrite check: any mod that restarts then submits once, with the clear as fallback, passes 2 and 3.
Misses: interactive behaviour after Esc (the Stop hold); QA's walkthrough runs one real hand-off.

## Done

- **Expected**: a hand-off restarts the cheaper way the probe proved, or the ledger says `/clear` stays.
- **Verification**: `node --test hooks/test/handoff-mod.test.mjs`; `claude plugin validate .`; `npm test`.
- **Evidence**: tests 2-3 failing before and passing after; the run's log lines and row.
- **Prohibited**: no change to the claim, cooldown or hold (handoff-mod spec 4-5); no restart without the fallback.
- **Done when**: behaviour 1 closed it, or 2-4 hold and the gate is green.
