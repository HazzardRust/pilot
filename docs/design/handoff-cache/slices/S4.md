# S4 Each mod restart is tried once and recorded

Feature `handoff-cache` · delivers spec 4 · source: `../architecture.md` §2, §3, §5 L3 L7, §6 A5 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — probes undocumented mod calls whose results are read, not asserted.

## Files owned

- `docs/design/handoff-cache/probes/restart/` (new): a scratch plugin whose mod, on a large enough context, runs one restart per `MODE` and logs `turn.complete` usage of the next turn; and `run.mjs`.
- `docs/design/handoff-cache/probes/restart.md` (new): one row per mode.

## Interface

```
probes/restart/mod.mjs: register(on)   // MODE = clear | compact | compact-keep-head | branch
probes/restart/run.mjs: node run.mjs --mode <MODE> --model sonnet -> JSON lines: {mode, result, contextAfter, firstTurn usage, pickupRan}
```

## Behaviours

1. `/clear is the baseline` (run): `--mode clear` gives the row every other mode is compared with.
2. `compact is tried` (run): `--mode compact` calls `$.session.compact({instructions})` from `turn.complete`; the row says works, refused or absent, the context after, and the first turn's cache read and write.
3. `a kept head is tried` (run): `--mode compact-keep-head` returns `{messages}` holding the first N messages from the `session.compact` hook; the row says whether the live context was cut to them.
4. `branch is tried` (run): `--mode branch` runs `$.command.run({command:'branch'})`; the row records its result.
5. `the verdict is written` (read): `restart.md` ends with `verdict: <mode> adopted` only where L7's two bars hold (1,000 tokens saved, pickup 3 of 3), else `verdict: /clear stays, <numbers>`.

Rewrite check: not applicable, a probe ships no interface; a rerun by hand must give the same verdict.
Misses: interactive timing (A5); QA's walkthrough runs the adopted mode on a real hand-off if any is adopted.

## Done

- **Expected**: the user reads whether any restart beats `/clear`, with numbers per mode.
- **Verification**: the four runs; `claude plugin validate docs/design/handoff-cache/probes/restart`.
- **Evidence**: the output in `restart.md` with the `claude` version and date.
- **Prohibited**: no run in a live session; nothing under `hooks/`; no mode recorded as works without its usage row.
- **Done when**: 4 rows and a verdict line stand in `restart.md`.
