# S8 A pilot session drops the prompt sections it does not need

Feature `handoff-cache` · delivers spec 5 · source: `../architecture.md` §2, §5 L1 L5 · after: S2 (`probes/sections.md` verdict)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new mod in `hooks/` (agent configuration) on a probe's verdict.

## Files owned

- `hooks/prompt-mod.mjs` (new): a `prompt.section` hook returning `text: null` for the sections `sections.md`'s verdict names, in the main `pilot:pilot` session only.
- `hooks/test/prompt-mod.test.mjs` (new): the pins.
- `hooks/hooks.json`: `modules` gains `./prompt-mod.mjs`.

## Interface

```
hooks/prompt-mod.mjs: register(on)   // on 'prompt.section': drop a named section when the session is the main pilot session
TRIMMED: readonly string[]           // the section names from probes/sections.md's verdict
```

## Behaviours

1. `the gate is read first` (read): `probes/sections.md`; on `verdict: ruled out`, stop, write the number for S11, change no code.
2. `the main pilot session drops them` (test): `register` → a fake `prompt.section` for each name in `TRIMMED`, in a main `pilot:pilot` session, returns `{ text: null }`; any other name passes through.
3. `crew and plain sessions keep them` (test): `register` → the same events in a crew agent or a session without the pilot agent pass through untouched (L5).
4. `the start shrinks and still works` (run): a scratch `pilot start`-style session: first-turn tokens down by the verdict's number within 10%, and the first turn runs `deck_status`, 3 of 3.

Rewrite check: any hook that drops exactly `TRIMMED` in the main pilot session passes 2 and 3.
Misses: a section a later Claude Code renames; the hook then drops nothing, and `pilot doctor` does not see it.

## Done

- **Expected**: a pilot session starts smaller by what the probe proved, and nothing else changes.
- **Verification**: `node --test hooks/test/prompt-mod.test.mjs`; `claude plugin validate .`; `npm test`.
- **Evidence**: tests 2-3 failing before and passing after; the run's rows.
- **Prohibited**: no section dropped that the verdict does not name; no change to `hooks/handoff-mod.mjs`.
- **Done when**: behaviour 1 closed it, or 2-4 hold and the gate is green.
