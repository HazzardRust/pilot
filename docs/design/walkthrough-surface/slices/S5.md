## Interface

```
commandWord(half: string, isInstruction: boolean) -> string | null   // now exported, unchanged

```

## Tests

1. `a command step renders its prefix`: `renderSteps` → for ``Run `npm test` `` with shell `PowerShell` and dir `C:\x`, the step's html contains `PowerShell · C:\x` before the command.
2. `a prose step renders no prefix`: `renderSteps` → `Open the deck → the Tickets tab` has no `step where` span.
3. `a walkthrough keeps its shell`: `deck_post` → a posted walkthrough with `shell: 'Git Bash'` reads back `shell: 'Git Bash'`.

Rewrite check: any render that puts shell and directory on the line above each command keeps the user's "where do I run this" answered.
