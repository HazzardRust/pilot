# S3 A full-run gate2 without a walkthrough carries the checks table

Feature `walkthrough-surface` · delivers spec 3, 4 · source: `../architecture.md` §2, §5 L11 · after: S2 (`deck/gate2-evidence.mjs`, `ticket.plan.surface`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — the table parse and the reason line decide what QA must write.

## Files owned

- `deck/gate2-evidence.mjs`: `gate2EvidenceGaps` gains the full-run rules.
- `deck/test/gate2-checks-table.test.mjs` (new): the pins, through `postItem`.

## Interface

```
S1's gate2EvidenceGaps, extended:
  // full run: plan.sliceCount > 2 and typeof plan.surface === 'boolean'
  //   surface true, no walkthrough, no reason line -> ['a gate2 on a plan with a surface names its walkthrough or says why not: surface planned, no walkthrough: <reason>']
  //   surface true, no walkthrough, body has a line starting `surface planned, no walkthrough:` with text after the colon -> no gap from this rule (the table rule still applies)
  //   no walkthrough, no checks table -> ['a gate2 with no walkthrough carries the checks table: | spec line | result | evidence |']
  //   a table row with an empty cell -> ['checks table row <n> has an empty cell']
  // legacy plan (no surface) or short path: unchanged
checks table: a markdown head naming spec, result, evidence (case-blind), its rule line, one row or more
```

## Tests

1. `a no-surface gate2 with the table is accepted`: `gate2EvidenceGaps` → `[]` for a plan of 3, `surface: false`, a 2-row table.
2. `a gate2 with neither is refused`: `gate2EvidenceGaps` → the table gap; `postItem` refuses with it.
3. `a row without evidence is refused`: `gate2EvidenceGaps` → `checks table row 2 has an empty cell`.
4. `a surface gate2 without its walkthrough or a reason is refused`: `gate2EvidenceGaps` → the walkthrough gap, table present; the same body plus `surface planned, no walkthrough: the screen QA planned to show did not change` → `[]`.
5. `a legacy full run is unchanged`: `gate2EvidenceGaps` → `[]` for a plan of 3 without `surface` and a bare body.

Rewrite check: any parser that keeps these five results keeps QA's gate2 contract.

## Done

- **Expected**: on a full run with no surface, the gate2 the user presses shows QA's checks table; without one it cannot be posted.
- **Verification**: `node --test deck/test/gate2-checks-table.test.mjs deck/test/qa-gate2.test.mjs deck/test/short-path-gate2.test.mjs`; `npm run test:changed -- --since=<base sha>`.
- **Evidence**: tests 1–4 failing before; on a scratch deck the accepted gate2 rendered with its table, looked at.
- **Prohibited**: no edit to `store-items.mjs`; no rule on short-path gate2s; no table check on a gate2 that names a walkthrough; the reason line never stands in for the table.
- **Done when**: five tests pass, the `qa-gate2` and short-path suites pass unchanged, and the scratch render is seen.
