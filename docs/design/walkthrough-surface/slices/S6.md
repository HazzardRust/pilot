# S6 A command step without a directory is refused; the shell defaults to the platform's

Feature `walkthrough-surface` · delivers spec 9 · source: `../architecture.md` §2, §6 A3 · after: S2 (`deck/store-items.mjs`), S5 (`item.shell`, `commandWord`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — spec 9 is assumed (A3), and the refusal sits on every wizard post.

## Files owned

- `deck/step-shell.mjs` (new): `defaultShell`, `stepShellGaps`.
- `deck/store-items.mjs`: `postItem` fills `shell` with `defaultShell()` on a walkthrough or report with a command step, and refuses on `stepShellGaps`; net 3 lines or fewer.
- `deck/README.md`: the module row.
- `deck/test/step-shell.test.mjs` (new): the pins.

## Interface

```
// deck/step-shell.mjs
defaultShell(platform = process.platform, env = process.env) -> string
  // 'win32' -> 'PowerShell'; else basename of env.SHELL ('bash', 'zsh'), 'sh' when unset
postItem({ kind: 'walkthrough' | 'report', shell?, dir?, screens, … })   // shell filled with defaultShell(); refused on stepShellGaps
stepShellGaps(screens: string[], { shell?: string, dir?: string }) -> string[]
  // a command step (S5's commandWord non-null) and no dir: [`step <n> runs a command: name its directory as dir`]
```

## Tests

1. `a command step with no dir is refused naming it`: `stepShellGaps` → `['step 2 runs a command: name its directory as dir']`; `postItem` refuses a wizard stage with it.
2. `a prose stage needs neither`: `stepShellGaps` → `[]` for steps with no command and no dir.
3. `Windows defaults to PowerShell`: `defaultShell` → `'PowerShell'` for `win32`.
4. `elsewhere the login shell`: `defaultShell` → `'zsh'` for `darwin` with `SHELL=/bin/zsh`.
5. `the default is stored`: `postItem` → a command stage posted with `dir` and no `shell` reads back the platform default.

Rewrite check: any rewrite that keeps these five results keeps every command step's prefix filled.
