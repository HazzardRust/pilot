## Interface

```
// deck/telemetry.mjs
export function repoOf(cwd): Promise<string>      // signature unchanged
  1. git rev-parse --git-common-dir, as today (L6): async, 5 s timeout, a success cached
  2. git cannot answer -> the run records: a run whose slice, feature or QA worktree is this
     directory, or an ancestor of it, answers with that run's repo
  3. no record -> the folder name: walking up from cwd, the first ancestor named
     <name>-<something> whose sibling <name> exists and git resolves as a repository
     answers with that repository; the longest matching <name> wins
  4. none of these -> cwd itself, as today, asked again next time
every answer is a repoKey, case-folded on Windows
```

## Tests

1. `a removed worktree named in a run record keys under that run's repository`.
2. `a removed worktree no record names keys under the sibling repository its folder name begins with`.
3. `a subdirectory of a removed worktree resolves as the worktree does`.
4. `a removed folder whose prefix names no living repository keys itself`: `pilot-notes` beside nothing called `pilot`, and a nested `.claude/worktrees/<x>` folder.
5. `of two sibling repositories the longest name wins`: `pilot-deck-s1` beside both `pilot` and `pilot-deck` keys under `pilot-deck`.
6. `a living directory that is no repository still keys itself`: rules 2 and 3 are for directories that no longer exist.
7. `an unresolved directory is asked again next time`: today's pin, kept.
