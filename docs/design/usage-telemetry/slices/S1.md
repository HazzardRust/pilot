# S1 Walking skeleton: a line of totals every half hour

Feature `usage-telemetry` · delivers spec 1 (window, `total`), 2, 4, 8, 9 · source: `../architecture.md` §2, L1–L5, L7 · after: –

## Files owned

- `deck/telemetry.mjs` (new): the usage log: its path, the tick schedule, one appended line per window.
- `deck/transcripts.mjs`: gains `readWindow`, the window reader, reusing `tokenCounts` and the once-per-id rule.
- `deck/daemon.mjs`: `main()` starts the log and prints its path once.
- `deck/test/telemetry.test.mjs` (new): the pins.
- `deck/test/fixtures/telemetry/` (new): a projects root of two small sessions with hand-summed totals.

## Tests

1. `readWindow sums the fixture's window to the hand total`: every kind equals the figures written in the fixture's README.
2. `a message split over two entries counts once, in its first entry's window`: second entry past the boundary does not count again.
3. `a window with no entries is all zeros`.
4. `files modified before the window are not read`: a fixture file with an older mtime and in-window timestamps is skipped (mtime is the filter).
5. `startUsageLog appends one line per boundary with a stubbed schedule and clock`: two fired ticks, two lines, windows `[b-30m, b)`.
6. `main prints the log path once`: stderr carries `[deck] usage log <path>` exactly once.

## Done

- **Expected**: with the deck running, a JSON line of token totals lands in `usage.jsonl` at every :00 and :30; the page is unchanged.
- **Verification**: `node --test deck/test/telemetry.test.mjs`; `npm test`; start `node bin/pilot.mjs deck --foreground` with `PILOT_DECK_DIR` a temp dir and read the printed path.
- **Evidence**: tests 1 and 5 red before, green after; the foreground start's stderr line.
- **Prohibited**: no second transcript parser (ADR 0042); no `readFileSync` in the tick path; no timer in `startDaemon` (the suite would start ticking); no route, tool or UI change.
- **Done when**: the suite is green and a foreground daemon prints the path and, with a 1-second stub interval in a scratch run, writes a line.
