# S2 The line carries models, repositories and the snapshot

Feature `usage-telemetry` · delivers spec 1, 3, 5 · source: `../architecture.md` §2, §3, L6 · after: S1

## Files owned

- `deck/transcripts.mjs`: `readWindow` also returns `byModel` and `byCwd`.
- `deck/usage.mjs`: gains `readSnapshot`, the whole snapshot with its mtime, beside `readUsage`.
- `deck/telemetry.mjs`: resolves each `cwd` to its main checkout and writes `byModel`, `byRepo`, `snapshot`.
- `deck/test/telemetry-line.test.mjs` (new): the pins.

## Interface

```
// deck/transcripts.mjs (S1's readWindow, widened)
readWindow(...): Promise<{ total: Counts, byModel: Record<string, Counts>, byCwd: Record<string, Record<string, Counts>>, skippedLines: number }>
// deck/usage.mjs
export type Snapshot = { at: string, session: Limit | null, weekly: Limit | null, decks: Record<string, number> }
export function readSnapshot(): { snapshot: Snapshot } | { snapshot: null, snapshotError: 'absent' | 'malformed' }
// deck/telemetry.mjs
export function repoOf(cwd: string): Promise<string>   // git common dir's parent, 5 s timeout, cached; cwd itself on failure
UsageLine += { snapshot: Snapshot | null, snapshotError?: 'absent' | 'malformed', tokens: { total, byModel, byRepo: Record<string, Record<string, Counts>> } }
```

`Limit` is `readUsage`'s `{ pct, resetsAt }`; `decks` keeps only entries inside `DECK_WINDOW_MS`, as `readUsage` does.

## Tests

1. `byModel sums per model and total is their sum`.
2. `a worktree cwd lands under its main checkout`: fixture repo with `git worktree add`, entry `cwd` the worktree.
3. `an unresolvable cwd keys itself`.
4. `the snapshot is logged with the file's mtime as at`.
5. `an absent snapshot logs snapshot null and snapshotError absent`; `a half-written one logs malformed`; the line is still appended.
6. `readUsage is unchanged`: `deck/test/usage.test.mjs` passes as it did (its clock test is known flaky; rerun once, do not edit it).

## Done

- **Expected**: a line names each model and each repository that spent in the window, and the limits as the status line last wrote them, with when.
- **Verification**: `node --test deck/test/telemetry-line.test.mjs deck/test/usage.test.mjs`; `npm test`.
- **Evidence**: tests 2 and 5 red before, green after.
- **Prohibited**: no `execFileSync` in the daemon (async with timeout only); no returning prompt or tool text from `readWindow` (ADR 0042); no change to `readUsage`'s return shape; no write to the snapshot file.
- **Done when**: the suite is green and a line written against the fixture carries all three of `byModel`, `byRepo` and `snapshot`.
