# S4 A closing report is data in the run record

Feature `usage-telemetry` · delivers spec 11 · source: `../architecture.md` §2, L10, L11, A2 · after: –

## Files owned

- `deck/runs.mjs`: `report` joins `RECORD_ORDER` and `recordFields` validates it.
- `deck/tools.mjs`: `deck_status`'s schema gains `report`.
- `deck/server.mjs`: passes `args.report` beside `args.findings` (`:703`).
- `deck/test/record-report.test.mjs` (new): the pins.
- `skills/pilot/SKILL.md`: "Ending a run" sends `report` in the `deck_status` call that sets `finished`.
- `agents/pilot.md`: where it names `finished`, it names `report` beside it.

## Interface

```
deck_status({ ..., report?: ClosingReport })
type ClosingReport = {
  featurePr: { number: number, state: string, mergeSha?: string },  // state as the closing report words it; mergeSha once merged
  slices: { slice: string, pr: number, mergeSha: string }[],   // mergeSha 7-40 hex
  assumed: { id: string, decision: string, taken: string }[],  // id A<n>
  friction: { agent: string, what: string, evidence: string }[],
  humanSteps: string[],
  worktreesLeft: string[],
}
// every list at most MAX_FINDINGS; every string non-blank, at most MAX_STATE_CHARS
RECORD_ORDER: [..., 'findings', 'report', 'next', 'finished', ...]
```

## Tests

1. `a deck_status with report writes it into the store's record in RECORD_ORDER`.
2. `a report missing featurePr, or with a non-hex mergeSha, or an unknown key, is refused naming the field`.
3. `a later call without report keeps it`.
4. `the pilot skill sends report with finished`: `skills/pilot/SKILL.md` names `report` in "Ending a run", in the call that sets `finished`.

## Done

- **Expected**: after a run finishes, its record in the deck's store holds the closing report as fields, and a malformed one is refused in one line.
- **Verification**: `node --test deck/test/record-report.test.mjs deck/test/record.test.mjs scripts/test/measure-prompt.test.mjs`; `npm test`.
- **Evidence**: test 2 red before, green after; the record the test wrote to a temp store, read.
- **Prohibited**: no free-form `report` object passed through unvalidated; no change to `findings`' format; no pushing the prompt past its `measure-prompt` budget; no conversion of past reports (A2); nothing may depend on `report` reaching the repository (L11).
- **Done when**: the suite is green and a record test round-trips a full `report` through the store.
