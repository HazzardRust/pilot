# S5 The audit states the measured spend

Feature `usage-telemetry` · delivers spec 10 (log, period, spend) · source: `../architecture.md` §2, L8 · after: S3

## Files owned

- `scripts/audit-spend.mjs` (new): read-only, JSON-only; the repository's spend from the usage log.
- `scripts/test/audit-spend.test.mjs` (new): the pins.
- `deck/audit.mjs`: `validateReport` and the renderers take an optional `measured`.
- `deck/test/audit-measured.test.mjs` (new): the pins.
- `agents/pilot-auditor.md`: runs the script before the areas and copies its block into the report.

## Interface

```
node scripts/audit-spend.mjs <repo> [--log <file>]      // exit 0, JSON on stdout, always
-> { log: string, lines: number, from: string | null, to: string | null, spend: Counts | null, skippedLines: number }
// repo matched to byRepo keys by S2's repoOf rule; spend null when lines is 0
Report += { measured?: { log: string, from: string, to: string, spend: Counts } }
// validateReport: measured well-formed, or unmeasured has a line starting "measured spend:"
```

## Tests

1. `audit-spend sums the repository's byRepo over the fixture log`: other repositories excluded.
2. `no log gives lines 0 and spend null, exit 0`.
3. `a torn line is skipped and counted`.
4. `validateReport refuses a malformed measured`; `refuses neither measured nor a measured spend line`.
5. `the deck body names the log path and period`.
6. `the auditor runs audit-spend before the areas`: `agents/pilot-auditor.md` names it and `measured`.

## Done

- **Expected**: an audit posted in a repository the log has seen opens with the tokens its sessions spent, the period and the log's path; with no log it says so under Unmeasured.
- **Verification**: `node --test scripts/test/audit-spend.test.mjs deck/test/audit-measured.test.mjs scripts/test/audit-agent.test.mjs`; `npm test`; `node scripts/audit-spend.mjs .` on this machine.
- **Evidence**: test 4 red before, green after; the live command's JSON.
- **Prohibited**: no new `AREAS` entry or area file (L8); no write anywhere; no printing transcript or snapshot text beyond counts, paths and stamps.
- **Done when**: the suite is green and `audit save` accepts a report with `measured` and refuses one with neither.
