# S6 The audit carries the latest runs' figures

Feature `usage-telemetry` · delivers spec 10 (runs, share per row) · source: `../architecture.md` §2, L9, A6 · after: S5

## Files owned

- `scripts/audit-spend.mjs`: adds the three newest finished runs' figures.
- `scripts/test/audit-spend-runs.test.mjs` (new): the pins.
- `deck/audit.mjs`: validates `measured.runs` and renders each row's saving as a share of a measured run.
- `deck/test/audit-share.test.mjs` (new): the pins.
- `deck/analytics.mjs`: `unrecordedAgents` exported, body unchanged (seam change, pilot, 2026-09-28).

## Interface

```
S5's audit-spend output += { runs: { slug: string, finishedAt: string, tokens: number, toolCalls: number, costUSD: number | null }[] }
// runs: every docs/design/*/run.json at <repo>'s HEAD (on the default branch means merged; `finished`
// is sent after the merge and is on HEAD for 2 of 6 records), newest 3 by updatedAt (A6), `finishedAt` its updatedAt;
// toolCalls summed over readRun(repo, slug).agents; tokens and costUSD over those agents plus analytics' own
// "not in transcripts" rows (unrecordedAgents), so they equal pilot analytics' Total row (L9); costUSD from costOf
// and loadPrices, null when unpriced
// measured.runs is optional in validateReport: validated when present, absent means no share column
Report.measured += { runs: <the same> }
// render: a row's share = saving.tokens / mean(runs.tokens), shown as a percentage; no runs, no share column
```

## Tests

1. `runs lists the newest three run.json by updatedAt, finished or not`.
2. `a run's tokens equal the total pilot analytics prints for it`: same fixture through `analytics.main` and the script.
3. `an unpriced model gives costUSD null, never zero`.
4. `each row shows its share of a measured run`; `no runs, no share`.
