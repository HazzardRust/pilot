## Tests

1. `vertical-slicing names ten fields, Interface and Tests among them`: the anatomy table has those ten rows, in order.
2. `the worked slice carries roles, an Interface block and ordered Tests`: the example has each, and every Files owned
   line in it carries a role.
3. `a seam is stated once, in the slice that creates it`: the skill says so and names the `S<n>'s <symbol>` form.
4. `a slice's fields live in its own slice file`: both the skill and item 8 name `slices/S<n>.md`, and item 8 names
   the link.
5. `the architect caps architecture.md at 300 lines and a slice file at 60`: the cap sentence says both.
6. `the architect writes no code past signatures`: "Scope discipline" forbids function bodies and pseudo-code.
7. `nothing a sign-off needs lives only in a slice file`: item 8 says so in those words (L8).
