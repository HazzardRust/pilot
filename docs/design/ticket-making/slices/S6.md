In flight lasts from `startTicket` until that walkthrough is resolved (A7). No run record is written or read here:
`recordFor` (`store.mjs:1293`) is untouched.

## Tests

1. `starting a small ticket marks it started and takes it out of the queue`; a regular ticket refuses `start`.
2. `a second start in the same repo is refused by name while one is in flight`; another repo's start is not.
3. `a walkthrough with ticket must name the ticket in flight`.
4. `resolving that walkthrough closes the ticket, and the next small ticket may then start`.
5. `under full auto the walkthrough is answered and the ticket closes with it` (L12).
6. `the larger run's spec and signoff post while a small ticket's walkthrough is open`.
7. `the tab shows started, with no arrows, on a ticket in flight`.
