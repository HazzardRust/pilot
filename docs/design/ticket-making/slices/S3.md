# S3 A chained hand-off carries the ticket's comments

Feature `ticket-making` · delivers spec 9 · source: `../architecture.md` §2, L4 · after: – (runs beside S1)

## Files owned

- `deck/chain.mjs`: `chainNext` builds the hand-off body from the ticket's body and its comments.
- `deck/test/chain.test.mjs`: the pins, beside the existing ones.

## Interface

```
// deck/chain.mjs (module-private)
function handoffBody(ticket: Item): string
  // ticket.body when it has no comments, byte for byte
  // otherwise ticket.body + "\n\n## Comments on this ticket\n\n" + one block per comment, in replies order:
  //   "**<who>** (<repliedAt>): <text>"   who = reply.author ?? reply.from  ('user' | 'pilot' | an author kind)
  // a comment is any reply whose text is not CLOSED or REOPENED and does not start with CLOSED_WITH (items.mjs:152-173)
chainNext(repo, opts) — unchanged signature; posts { ..., body: handoffBody(head), next: head.id }
```

## Tests

1. `a ticket with two comments chains to a hand-off holding the body, then both comments in order`.
2. `a ticket with no comments chains to a hand-off whose body is byte-identical to the ticket's`: the existing pin at `:53` still holds.
3. `each comment is labelled by who said it`: one user, one pilot with an `author`.
4. `reopen and close markers are not comments`: a reopened ticket's hand-off carries only the real comments.
