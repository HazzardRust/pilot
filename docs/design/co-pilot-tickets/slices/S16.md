## What it adds (S1's review findings, kept; whatever S1 moved out to fit 200 lines, as its PR body lists "moved to S16")

- (a) The code/prose split for a bare `foreman` reads the whole text, not one line: a multi-line template literal (with `${}`), a `/* */` block and a quote inside a regex literal are each classified right. The CLI refuses to write a `.js`/`.mjs`/`.cjs` file that then fails `node --check`, and leaves it as it was.
- (c) `renamePath` leaves a path under a whole-file exception where it is (`skills/iterative-retrieval/**`, the vendored text in §7).
- (d) The CLI never stops partway: a deleted tracked file, an existing destination or a path outside the repository prints one stderr line, the rest are processed, and the exit code is 1.
- (e) `--word` without a value and an unknown flag are a usage error; exception paths match by `startsWith` on the repository-relative path.
- (f) A tracked symlink is skipped.
