Feature `handoff-no-wait` · delivers spec 2, 4, 7, 8 · source: `../architecture.md` §3 Probes, §5 L9 · after: –

## Files owned

- `scripts/probe-clear-survival.mjs` (new): E3 and E5 as one script, in a temporary directory it removes.
- `scripts/test/probe-clear-survival.test.mjs` (new): the step judge on recorded stream lines.

## Interface

```
node scripts/probe-clear-survival.mjs [--keep]   // exit 0: "survived +<s>s; sendmessage ok; report reached"; exit 1: "failed at <step>"
judge(lines: string[], marks: { clear: number }, wroteAt: number | null) -> { ok: boolean, step?: string, after?: number }
```

## Behaviours

1. `a passing stream is judged survived` (test): `judge` → `{ ok: true }` with `after` in seconds on E3/E5-shaped lines.
2. `each missing step is named` (test): `judge` → `{ ok: false, step }` naming `worker`, `sendmessage` or `report` when that line is cut.
3. `the probe runs on this machine` (run): `node scripts/probe-clear-survival.mjs` exits 0 in under 4 minutes; the output is pasted in the slice report.

Rewrite check: a judge that reads any stream format still names the first missing step.
Misses: the interactive mod path; QA's scratch run reads it.
