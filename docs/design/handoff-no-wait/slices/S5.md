# S5 The fresh pilot adopts and resyncs the survivor

Feature `handoff-no-wait` · delivers spec 3, 4 · source: `../architecture.md` §2, §5 L5, L6 · after: S1 (`agents/pilot.md`), S4 (`/api/record`'s `coPilot.agent`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it edits a SessionStart hook and two agent definitions, the agent-configuration trigger.

## Files owned

- `hooks/session-handoff.js`: `yellowNotice` names the survivor and the resync line.
- `agents/pilot.md`: the Yellow first-turn rule sends `resync <clearedAt>` to the named id and spawns none.
- `agents/pilot-co-pilot.md`: Hand-back gains the resync answer.
- `hooks/test/session-handoff-yellow.test.js`: the notice pins.
- `scripts/test/handoff-no-wait-prompts.test.mjs` (new): the wording pins on both agent files.

## Interface

```
yellowNotice(yellow, coPilot: { ticket, live, at, agent? } | null, now) -> string
  // live + agent: "co-pilot <agent> is live on <ticket>: it survived the /clear; SendMessage <agent> `resync <the notice's time>`, spawn none"
  // live, no agent: today's "a co-pilot is live on <ticket>" text; otherwise "may have survived"
pilot-co-pilot.md: on `resync <time>`, resend its last hand-back before <time> and every question and hand-back since, then carry on
```

## Behaviours

1. `a stamped survivor is named with its resync` (test): `yellowNotice` → `co-pilot a1b2 is live on itm_x` and `resync`.
2. `an unstamped one keeps today's text` (test): `yellowNotice` → the current live and "may have survived" texts.
3. `an agent id of the wrong shape is never echoed` (test): `yellowNotice` → no id for `agent: "a; rm"`.
4. `both prompts carry the resync` (read): the pilot's first-turn rule and the co-pilot's Hand-back clause; the `measure-prompt` growth is under 400 characters. The planned `scripts/test/handoff-no-wait-prompts.test.mjs` was not written (ADR 0180: a prose pin); this is a read.

Rewrite check: any notice that names a live, well-shaped id and asks for a resync passes 1-3.
Misses: whether a real co-pilot repeats the right messages; QA's scratch run reads it.
