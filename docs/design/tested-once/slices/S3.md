# S3 The phase gate defers the fallbacks and cargo

## Files owned

- `scripts/select-tests.mjs`: `selectTests` takes `scope`; at `'slice'` a trigger, a lonely script or argv overflow keeps the matched files and sets `deferred`; `scopeLine` appends `; deferred: <reason>`; `SCOPE` matches it.
- `scripts/gate.mjs`: reads `PILOT_TEST_SCOPE` once; passes `scope` to `select`; `cargoStep` returns `{ skip: 'rune deck: deferred to integrate' }` at slice scope and the scope line says `deferred: cargo`.
- `docs/OPERATING.md`: the table at `:53` names slice scope for the phase gate, wide for integrate, sync, land.
- `scripts/test/select-scope.test.mjs` (new): the pins.

## Interface

```
selectTests({ cwd, since, git, scope = 'wide' }) -> { files, total, since, changed?, reason?, deferred?: string[] }
scopeLine(selection) -> 'selected <n> of <m> test files since <sha7>[; deferred: <reason>, ...]' | 'full suite: <reason>'
cargoStep(env, which, platform, selection) -> { skip } | { steps }
env PILOT_TEST_SCOPE = 'slice'   // set by S1's `pilot test --scope slice`; anything else is wide
```

## Behaviours

1. `a lonely file selects nothing at slice scope` (test): `selectTests` → a changed script no test reaches gives `files: []`-plus-tree-tests and `deferred: ['<file> reaches no test']` at `scope: 'slice'`, and `files: null` (full) at wide.
2. `a trigger file defers at slice scope` (test): `selectTests` → `package.json` changed: deferred at slice, full at wide.
3. `cargo waits for integrate` (test): `cargoStep` → at slice scope with `deck/` changed, the skip line `rune deck: deferred to integrate`.
4. `the scope line says what was deferred` (test): `scopeLine` → `selected 3 of 400 test files since abc1234; deferred: x.mjs reaches no test`, and `scopeOf` reads it back.

Rewrite check: moving the scope decision into `gate.mjs` alone keeps 1-4's outputs.
Misses: a cross-file break the narrow run cannot see; integrate's wide run and land catch it (the risk the user accepted).
