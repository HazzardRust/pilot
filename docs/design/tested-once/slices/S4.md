## Behaviours

1. `a proved tip starts no test` (test): `testCli` → with a stub host answering three green `gate (<os>)` jobs on the tip's tree, `--as qa` prints `tests reused: ci proved` and the counting test script stays at 0.
2. `two jobs prove nothing` (test): `testCli` → a stub with two jobs, or one red, runs the selection once.
3. `a proved tree that differs runs only the difference` (test): `testCli` → a proved tree one file behind runs `test:changed -- --since=<tree>`.
4. `an integrate row does not stand for QA` (test): `testCli` → a green row since the feat tip's parent does not satisfy `--since <pilot>`; it runs.
5. `QA and the lander are told the command` (read): `pilot-qa.md` and `pilot-lander.md` name `pilot test --as qa|lander`.
