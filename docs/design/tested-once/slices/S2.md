# S2 Integrate reuses the phase gate's run

Feature `tested-once` · delivers spec 1 · source: `../architecture.md` §2, §3, §5 L3, L4 · after: S1 (`scripts/integrate.mjs`, `reusableRun`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — skipping a test run on a recorded proof is the trust boundary L3-L4 guard.

## Files owned

- `scripts/integrate.mjs`: in `integrate()`, after the slice merge and install, `reusableRun({ tree: worktreeTree(cwd), since: start })` before `runChosen`; on a row, the success line reads `tests reused: <where> <sha7>`. Only when `test` is undefined (an injected command always runs).
- `scripts/test/integrate-reuse.test.mjs` (new): scratch bare origin, feat branch, slice branch, scratch home.

## Interface

```
integrate(branch, { cwd, test, push, trailers, host, install, home }) -> { ok, line, failing }
// line on reuse: `integrated <slice> at <sha7> (base <name>@<sha7>): tests reused: <where> <sha7>; pushed`
S1's reusableRun, worktreeTree
```

## Behaviours

1. `an unmoved slice is not tested again` (test): `integrate` → with a green complete row for the slice's tree since the feat tip, no test process starts (a counting `test:changed` script stays at 0) and the line says `tests reused: implementer`.
2. `a moved base runs` (test): `integrate` → after a commit lands on the base, the same row is not reused and the script runs once.
3. `a red or deferred row runs` (test): `integrate` → an `exit: 1` row, or one whose scope says `deferred`, for the same tree: the script runs once.
4. `the reused integrate still commits and pushes` (test): `integrate` → the merge commit and its trailers exist on origin, as on a run.

Rewrite check: computing the merge tree with `git merge-tree` instead of the index keeps 1-4.
Misses: two slices integrated in a row, where the second's tree always differs; QA's walkthrough reads the line on a real run.

## Done

- **Expected**: integrating a slice whose phase gate passed on the same tree and base takes seconds, not minutes, and says so.
- **Verification**: `node --test scripts/test/integrate-reuse.test.mjs scripts/test/integrate-select.test.mjs`.
- **Evidence**: 1-3 red before, green after; the counted spawns.
- **Prohibited**: no reuse when `test` is given; no match on branch name; no change to `pruneSlice` (PR #152 edits it).
- **Done when**: 1-4 hold and the gate is green, within 200 changed lines.
