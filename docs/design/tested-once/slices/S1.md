# S1 `pilot test` runs and records every test run

Feature `tested-once` · delivers spec 4 · source: `../architecture.md` §2, §3 Seams, §5 L3-L5, L8, §6 A1, A2, A6 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the ledger's trust rule (L3, L4) is the feature's security frontier, and it edits `agents/`.

## Files owned

- `scripts/test-ledger.mjs` (new): the ledger: row shape, append, tree hashing, reuse lookup, rows by slug.
- `scripts/test-cli.mjs` (new): `pilot test`, ledger reuse then `testCommand` through `runTests`; `--scope slice` sets `PILOT_TEST_SCOPE`.
- `bin/pilot.mjs`: dispatches `test` beside `integrate`.
- `scripts/integrate.mjs`: `runTests` takes `where`, `branch`, `since` and appends one row after the process exits; `runChosen` passes `where: 'integrate'`.
- `scripts/sync.mjs`: `:124` passes `where` (`sync` or `land`) and `branch`.
- `agents/pilot-implementer.md`: step 3 of the phase gate runs `pilot test --as implementer --scope slice --since origin/feat/<slug>`; a fix round `--since <the sha before the fix>`; never write the ledger.
- `scripts/test/test-ledger.test.mjs` (new): the pins.
- `docs/adr/0229-tested-once.md` (new): L3-L8.

## Interface

```
// scripts/test-ledger.mjs
type LedgerRow = { at: string, where: string, branch: string, slug: string|null, sha: string, tree: string,
  since: string|null, scope: string|null, exit: number|string, minutes: number, platform: string, node: number }
worktreeTree(cwd) -> string                 // tree sha of the worktree, untracked included, run.json from HEAD
recordRun(row: LedgerRow, { home }) -> void // one jsonl line, 0600; slug from feat/<slug>, slice|fix/<slug>-s<n>, qa/<slug>
reusableRun({ tree, since, home }) -> LedgerRow|null   // exit 0, complete, same tree, since equal or a full row, same platform and node major
testRunsFor({ slug, home }) -> LedgerRow[]
// scripts/integrate.mjs
runTests(cwd, test, { label, where, branch, since, home, slots, slot }) -> { status, counts, failing, log, scope, minutes }
// scripts/test-cli.mjs
pilot test [--as <role>] [--scope slice] [--since <ref>]   // `tests reused: <where> <sha7>` | the run's counts and minutes
testCli(argv, { cwd, home, host }) -> exit code
```

## Behaviours

1. `a run writes one row with its own exit` (test): `runTests` → a command exiting 3 in a scratch repo leaves one row with `exit: 3`, `where`, `minutes` and the worktree's tree; a green one a row with `exit: 0`.
2. `a red row is never reused` (test): `reusableRun` → null for the tree of an `exit: 3` row, and for a row whose scope says `deferred`; the `exit: 0` row's tree returns it.
3. `reuse is the exact tree` (test): `reusableRun` → null after one byte changes in an untracked file, and null for a row from another platform; equal after `docs/design/x/run.json` alone changes.
4. `pilot test reuses a green tree` (test): `testCli` → a second `pilot test` on an unchanged tree prints `tests reused: implementer <sha7>` and starts no test process; a changed tree runs.
5. `no row from inside the suite` (test): `runTests` → with `PILOT_GATE_HOME_STORE` set and no `home`, no ledger file is created.
6. `the implementer is told one command` (read): `agents/pilot-implementer.md` step 3 names `pilot test --as implementer --scope slice`.

Rewrite check: replacing the jsonl file with a SQLite table keeps 1-5.
Misses: a process of the user forging a row by hand; L4 names the backstop and the security reviewer reads it.

## Done

- **Expected**: every test run an agent or a CLI makes leaves one ledger row with its exit and minutes, and an unchanged green tree is not tested twice.
- **Verification**: `node --test scripts/test/test-ledger.test.mjs scripts/test/integrate-select.test.mjs scripts/test/gate-slots.test.mjs`; `pilot test --as implementer --since origin/feat/tested-once` twice in the slice worktree, under a scratch `HOME`.
- **Evidence**: behaviours 1-5 red before, green after; the second `pilot test`'s `tests reused` line.
- **Prohibited**: no row from parsed output, an argument or an env var's say-so; no ledger write in `gate.mjs`; no reuse by branch or sha alone.
- **Done when**: 1-6 hold and the gate is green, within 400 changed lines.
