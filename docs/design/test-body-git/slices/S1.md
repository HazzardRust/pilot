## Interface

```
type Commit = { branch: string, files: Record<string, string>, message: string, merge?: string[], from?: string }  // merge: branch names joined; from: a branch already in history
seed(dir: string, history: Commit[], refs?: Record<string, string>): { origin: string, sha: Record<string, string> }  // origin = <dir>/origin.git, HEAD main; refs: new branch -> existing branch, set to its tip after history; sha by branch tip, refs included
// a branch's first commit grows from `from`'s tip when given, else from the previous commit in history; each commit's tree is its parent's files plus its own; a merge's tree is the first parent's files with each merged branch's files laid over, then its own
// commit times count up from a fixed epoch in history order; author and committer from the fixture's global config identity
node docs/design/test-body-git/census.mjs <test files...>      // prints file, built, body, lib, total
node docs/design/test-body-git/assert-count.mjs <ref> <files...>  // prints file, tests before/after, asserts before/after
```

Seam change (co-pilot accepted), 2026-11-27: two branches on one commit for integrate's builder (`refs`, an optional third argument, still 2 git).
Seam change (co-pilot accepted, made in S2), 2026-11-27: a branch cut from any earlier branch's tip (`from`, an optional commit field, still 2 git).

## Behaviours

1. `a seeded origin equals a built one` (test): `seed` → for a history of 3 branches, a merge and 4 commits, every branch's tree, parents' shape, subject and author equal the porcelain build's, in 2 git (both counts in the test, `countGit` or the spawn binding).
2. `integrate's builder is cheaper` (run): `census.mjs scripts/test/integrate.test.mjs` before and after: fixture git 113 → ≤ 56, every integrate test passing.
3. `nothing weakened` (read): `assert-count.mjs origin/main scripts/test/integrate.test.mjs`: tests equal, asserts ≥.
4. `the census of the base` (run): `census-before.txt` covers ≥ 99% of the base's fixture git (its total line against the gate's).

Rewrite check: a `seed` written with plumbing per commit keeps 1's trees, subjects and authors.
Misses: a test relying on a commit's wall-clock date; the fold slices' full-file runs read it.
