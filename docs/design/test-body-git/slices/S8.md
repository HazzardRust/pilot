## Behaviours

1. `these files spawn half the fixture git` (run): `node docs/design/test-body-git/census.mjs <files owned>` on the slice's base and tip: fixture git summed 421 → ≤ 210 (probe 2026-11-26; the base's own number replaces 421 if it differs), every test passing.
2. `nothing weakened` (read): `node docs/design/test-body-git/assert-count.mjs origin/main <files owned>`: per file, tests equal and asserts equal or higher.
3. `no product line` (read): `git diff --stat origin/main` lists only the files owned.

Rewrite check: the census counts processes, so any fold that keeps the files' tests and asserts and halves the git meets 1.
Misses: an assert that now reads a fixture shared with an earlier test's leftovers; `gitFixture` restores per test, and the reviewer reads each moved setup.
