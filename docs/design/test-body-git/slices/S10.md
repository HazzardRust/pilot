## Behaviours

1. `a seeded buildRepos makes the same repositories` (test): `buildRepos` → for `['a', 'b']`, each repository's refs by name, trees, parent shape, subjects, authors, HEAD, origin config and status equal the frozen base sequence's, in ≤ 40% of its git (both counts in the test).
2. `the builders' git falls` (run): `census.mjs` over the twelve `buildRepos` users (S11's and S12's files): built git under `land-repos.mjs` 398 → ≤ 160, every test passing.
3. `nothing weakened` (read): `assert-count.mjs origin/main scripts/test/lib/fixture-git.test.mjs`: tests equal, asserts ≥.

Rewrite check: a `buildRepos` on plumbing or on a copied template keeps 1's refs, trees and subjects.
Misses: a land test that read a SHA's commit date; S11 and S12 run those files whole.
