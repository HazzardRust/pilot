## Files owned

The test files whose names start `land`, `integrate`, `release`, `sync` or `restack`, under `scripts/test/` and
`deck/test/`, as `census-after.txt` (S13's census, copied here) lists them; S14 owns every other test file. Each one
this slice edits has its porcelain fixture builds written with S1's `seed`, its per-test setup moved into a
`gitFixture` key, or its reads batched per L5. `land-repos.mjs`, `seed.mjs` and `git-fixture.mjs` stay as they are.

## Interface

```
seed(dir, history, refs): S1's, as it is
gitFixture(t, key, build): as it is; new keys only
```

## Behaviours

1. `the owned files spawn 300 fewer fixture git` (run): `census.mjs <the files edited>` on this tip against their rows
   in `census-after.txt`: fixture git (built + body + lib) summed down by at least 300, product git unchanged, every
   test passing.
2. `nothing weakened` (run): `assert-count.mjs origin/hazzardrust-pilot <the files edited>` prints `0 files lower`; no
   test deleted, skipped or `todo`.
3. `owned files only` (read): `git diff --name-only origin/feat/test-body-git...HEAD` lists only owned test files,
   this slice file and `census-after.txt`; no `countGit` bar and no product file changed.

Rewrite check: the census counts processes, so any fold that keeps the tests, the asserts and the product bars and
cuts 300 meets 1.
Misses: a test whose assert depends on a commit time or a reflog a porcelain build wrote and `seed` does not; the
reviewer reads each rewritten builder against what its tests read.
