## Behaviours

1. `these bodies spawn half the git` (run): `census.mjs <files owned>` on S10's tip and this tip: fixture git outside `buildRepos` summed 207 → ≤ 103 (probe 2026-11-26; S10's tip's own number replaces 207 if it differs), every test passing.
2. `nothing weakened` (read): `assert-count.mjs origin/main <files owned>`: per file, tests equal and asserts equal or higher.
3. `product counts unchanged` (read): every `countGit` bar in the files owned reads the same number as on the base (`git diff` shows none changed).

Rewrite check: the census counts processes, so any fold that keeps the tests, asserts and product bars and halves the git meets 1.
Misses: a pin whose printed lines depend on a SHA that the seeded history changed; the pins normalise SHAs, and the reviewer reads each.
