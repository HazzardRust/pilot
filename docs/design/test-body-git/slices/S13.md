2. `the suite meets them` (run): `npm run test:cost` once, alone, prints spawns ≤ 11,000 and git ≤ 10,000, saved as `cost-after.txt`.
3. `the highest runner meets them` (run): the feature PR's CI windows-latest gate line ≤ 11,000 / 10,000, quoted in the report.
4. `the census after` (read): `census-after.txt` against `census-before.txt`: fixture git down ≥ 1,824 in total, ≥ 99% of the run's fixture git covered.

Rewrite check: any gate that turns red over either number keeps 1.
