# S5 the Linux holder is proved on CI (added)

Feature `stay-awake` · delivers spec 2, 8; acceptance 5 · source: `../architecture.md` §2, §6 A4, A7, §9 · after: S2 (`deck/test/awake-holder.test.mjs` `linuxSkip`, `settled`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it grants a CI runner a logind privilege and changes when a holder test may skip (security trigger).

Found issue, built under the build-now rule; no spec line narrowed. S2 integrated with "Linux lists the
inhibitor while held" and "the linux holder dies with its pid" skipped on ubuntu-latest: logind refused the
inhibitor ("Failed to inhibit: Access denied as the requested operation requires interactive
authentication", run 45481769402), so spec 2 and 8's Linux evidence and acceptance 5 were unmet.

## Files owned

- `.github/workflows/gate.yml`: one ubuntu-only step granting the runner user the two inhibit actions, and the flag on the test step.
- `deck/test/awake-holder.test.mjs`: the Linux skip rule (`linuxSkip`, `settled`) and its cases.
- `docs/design/stay-awake/slices/S5.md`, the §8 row.
- Outside, the smallest change: `scripts/test/gate-workflow.test.mjs` pins gate.yml's run steps and allowed no step-level `if`; it now pins the grant step and allows its one `runner.os == 'Linux'`.

`deck/awake.mjs` is not owned: `holderFor`'s argv (A4 `--what=sleep:idle`, no sudo) stays as built.

## Interface

```
// deck/test/awake-holder.test.mjs
REQUIRE_LINUX_HOLDER = 'PILOT_REQUIRE_LINUX_HOLDER'   // '1' in gate.yml's ubuntu job only
linuxSkip({ host, unavailable, env }): string | false // another OS always skips; on linux, unavailable skips unless required
cannotHold(why, env): string                          // the skip reason, or throws when env requires the holder
```

## Behaviours

1. `the ubuntu job runs the Linux holder` (read): on ubuntu-latest, "Linux lists the inhibitor while held" and "the linux holder dies with its pid" run and pass, not skip; the gate run's ubuntu log for the pushed sha, quoted.
2. `CI grants the inhibit, the package does not` (read + test): the grant is a polkit rule written by an ubuntu-only gate.yml step, allowing `org.freedesktop.login1.inhibit-block-sleep` and `-idle` to the runner user only; nothing in `deck/` or `bin/` gains sudo or a polkit file.
3. `where CI requires the holder, a refusal fails` (test): `linuxSkip`, `cannotHold` → with `PILOT_REQUIRE_LINUX_HOLDER=1` a refused or unavailable Linux holder fails the case; without it the case still skips naming why (a dev box with no logind).
4. `macOS and Windows jobs unchanged` (read): their holder cases still pass in the same run.

Chosen: a polkit rule for the runner user. *Rejected:* running the test file under root in its own step;
root bypasses logind's polkit check (`CAP_SYS_ADMIN`), so it would prove a privilege the deck never has, and
run the file twice on ubuntu.

Misses: a desktop Linux session, where logind grants the inhibitor to an active session without a rule (A7: CI only).

## Done

- **Expected**: the ubuntu job's holder cases run and pass; a refusal there is red, not a silent skip.
- **Verification**: `node --test deck/test/awake-holder.test.mjs` locally; `npm test` once; `gh workflow run gate.yml --ref slice/stay-awake-s5` and its three job logs read.
- **Evidence**: the ubuntu-latest log with both Linux cases `ok`, the macos-latest and windows-latest holder cases `ok`.
- **Prohibited**: sudo or polkit in `deck/` or `bin/`; changing `holderFor`'s argv; changing another job's behaviour; a skip with `skip: null`.
- **Done when**: four behaviours hold and `npm test` is green. Estimate about 60 lines.
