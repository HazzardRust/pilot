# S2 macOS and Linux hold by their own means

Feature `stay-awake` · delivers spec 2, 3 · source: `../architecture.md` §2, §5 L1, L5, §6 A4 · after: S1 (`deck/awake.mjs` `holderFor`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — A4 is assumed and the slice starts processes (security trigger).

## Files owned

- `deck/awake.mjs`: `holderFor`'s darwin and linux rows; on POSIX the holder is spawned in its own process group and stopped by the group.
- `deck/test/awake-holder.test.mjs`: the darwin and linux cases beside S1's win32 one.

## Interface

```
S1's holderFor(platform, pid), now with:
  darwin: /usr/bin/caffeinate -i -w <pid>
  linux:  systemd-inhibit --what=sleep:idle --who=pilot --why="pilot: work in flight" --mode=block
          tail --pid=<pid> -f /dev/null          // A4: no handle-lid-switch
holderUnavailable(platform): string | null       // why this OS cannot hold here (no systemd-inhibit on PATH), for the log
holdAwake({ ..., killGroup })                     // as built: killGroup(pid) ends a posix holder's process group; injected so tests kill nothing
```

## Behaviours

1. `macOS lists the assertion while held` (test): `holderFor` → on darwin `pmset -g assertions` shows 1 `caffeinate` PreventUserIdleSystemSleep for the child, 0 within 5 s of stop.
2. `Linux lists the inhibitor while held` (test): `holderFor` → on linux `systemd-inhibit --list` shows 1 `pilot` sleep:idle block, 0 within 5 s of stop; with no logind the test reads `holderUnavailable` and skips naming why.
3. `the holder dies with its pid` (test): `holderFor` → on darwin and linux the child exits within 5 s of its watched pid exiting, and no `tail` is left.
4. `no lid lock is taken` (test): `holderFor` → the linux argv's `--what` is exactly `sleep:idle`.
5. `the CI matrix runs it` (read): `gate.yml`'s macos-latest and ubuntu-latest logs show behaviours 1-3 run, not skipped, or name the skip's reason.

Rewrite check: swapping `caffeinate` for an IOKit helper keeps behaviours 1 and 3.
Misses: lid-close behaviour on a real Mac or Linux laptop (out of scope by spec 3); QA reads CI only (A7).

## Done

- **Verification**: `node --test deck/test/awake-holder.test.mjs` on each OS (CI with label `all-os`); `npm test` once locally.
