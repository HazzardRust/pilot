## Files owned

- `.gitattributes`: adds `docs/adr/README.md merge=union`.
- `scripts/merge-generated.mjs` (new): the generated-file rules and their resolver.
- `scripts/sync.mjs`: `mergeIntoPilot` calls the resolver on a stopped merge and after a clean one; `sync` passes `side: 'ours'`.
- `scripts/adr-index.mjs`: exports `renderIndex` (today's `render`) and `GENERATED_HEADER`.
- `scripts/test/merge-generated.test.mjs` (new): the pins, in a scratch repository with this repo's `.gitattributes`.

## Interface

```
// scripts/adr-index.mjs
export function renderIndex(dir: string): string
export const GENERATED_HEADER: string // the "Generated by `npm run adr-index`" line
// scripts/merge-generated.mjs
export type Side = 'ours' | 'theirs' // the writer side: 'theirs' is the merged-in source
// Resolves each generated path in `paths` inside the merge worktree `dir`, stages it, answers the rest.
export function resolveGenerated(dir: string, paths: string[], opts: { side: Side }): { resolved: string[], left: string[] }
// Regenerates the index of a merged tree when it differs; answers whether it changed.
export function refreshIndex(dir: string): boolean
// scripts/sync.mjs
mergeIntoPilot({ ..., side?: Side }) // default 'theirs'; a stop on generated paths only commits and goes on
```

## Tests

1. `two branches each adding an ADR row merge with no conflict`: `resolveGenerated` → not reached; `git merge` exits 0 under `.gitattributes`, both rows present.
2. `rows merged out of number order are regenerated`: `refreshIndex` → true, and `checkIndex` ok after.
3. `mergeIntoPilot lands two features that each add an ADR`: `mergeIntoPilot` → `merged: true`, pilot's index lists both, `checkIndex` ok.
4. `a hand-written README is not regenerated`: `resolveGenerated` → the path in `left`.
5. `the gitattributes line is pinned`: `resolveGenerated` → a repo without the line conflicts and is resolved, and `.gitattributes` holds `docs/adr/README.md merge=union`.

Rewrite check: replacing union with a custom driver keeps tests 2-4; replacing the renderer keeps all five.
