# S7 `test:quiet` ends with one count line

Feature `clean-landing` · delivers spec 11 · source: `../architecture.md` §2, §3 "Legibility" · after: –
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `package.json`: `test:quiet` uses the reporter.
- `scripts/quiet-reporter.mjs` (new): a `node --test` reporter: failing tests by name as they fail, then one count line.
- `scripts/test/quiet-reporter.test.mjs` (new): the pins.

## Interface

```
// A node:test custom reporter: an async generator over the test event stream.
export default async function* quietReporter(source: AsyncIterable<TestEvent>): AsyncGenerator<string>
// last line: `tests <n> · pass <p> · fail <f>`; one `✖ <name>` line per failure, nothing per pass
```

## Tests

1. `a green run prints one count line equal to the spec reporter's`: `quietReporter` → counts equal `npm test`'s summary.
2. `a red run names each failing test`: `quietReporter` → one `✖ <name>` per failure, read by `failingNames`.
3. `the whole suite's quiet output is under 10 KB on green`: `quietReporter` → `npm run test:quiet` output size.

Rewrite check: replacing the generator with a Transform-stream reporter keeps all three.

## Done

- **Expected**: `npm run test:quiet` ends with one line a person or agent can read.
- **Verification**: `node --test scripts/test/quiet-reporter.test.mjs`; `npm run test:quiet | tail -1`; `npm test`.
- **Evidence**: the last line and the byte count before (3236 bytes of dots, no count) and after.
- **Prohibited**: dropping failure output; a dependency for the reporter.
- **Done when**: the three tests and `npm test` are green and the quiet run ends with the count line.
