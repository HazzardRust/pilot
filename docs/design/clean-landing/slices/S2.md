## Tests

1. `a run.json changed on both sides lands with the feature's record`: `land` → `landed`, pilot's `run.json` equals the feature's.
2. `a source conflict beside an index conflict names only the source file`: `land` → exit 3, the line names `src/a.mjs` and not `docs/adr/README.md`.
3. `a kept resolution re-merged after pilot moved resolves the index`: `land` → `landed` through `resume`, `checkIndex` ok.
4. `sync keeps pilot's run.json`: `sync` → with `side: 'ours'`, pilot's copy staged.

Rewrite check: storing the run record anywhere else keeps tests 2 and 3.
