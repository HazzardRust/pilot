## Interface

```
// Fetches origin/<head>; fast-forwards the worktree to it when behind; answers how far it moved.
// Throws (exit 1, nothing pushed) on a diverged branch, naming both SHAs, or tracked changes, naming the files.
export function catchUp(opts: { cwd: string, git: (args: string[]) => string, head: string }): { moved: number }
land(...) // prints `caught up <n> commits from origin/<head>` above its line when n > 0
// `NOT landed: <head> has diverged from origin/<head> (local <sha7>, origin <sha7>); nothing pushed`
// `NOT landed: <cwd> has uncommitted changes in <files>; nothing pushed`
export function main(argv: string[], inject?: object): number // `pilot land` alone; `--test` or any argument is usage, exit 1 (L12, ADR 0110 L11)
```

## Tests

1. `a worktree one commit behind origin lands with origin's commit`: `catchUp` → `moved: 1`, pilot holds origin's tip.
2. `a diverged worktree is refused with both SHAs`: `catchUp` → exit 1, the line names both, origin and pilot unmoved.
3. `tracked changes are refused by name; an untracked file is not`: `catchUp` → exit 1 naming `a.mjs`; with only `tmp.log` untracked it goes on.
4. `no origin branch yet lands as today`: `catchUp` → `moved: 0`, the first push creates it.
5. `pilot land --test is a usage error`: `main` → `--test "<cmd>"` prints `usage: pilot land`, exit 1, the command never runs; the pins at `scripts/test/test-command.test.mjs:49` and `scripts/test/cli-wiring.test.mjs:41` stay green.
