# S4 A landing removes its run's merged worktrees and names the rest

Feature `clean-landing` · delivers spec 7, 8, 9 · source: `../architecture.md` §2, §5 L5, L6, §6 A1 · after: S3 (`scripts/land.mjs`), S2 (`scripts/land.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer` (process start: directory removal)

## Files owned

- `scripts/worktrees.mjs`: `runOf` and `prune`'s `run` filter; `pilot worktrees prune --run <slug>`.
- `scripts/land.mjs`: its last step: `chdir` to the main checkout, prune the run against `origin/pilot`, print the lines.
- `scripts/test/worktrees.test.mjs`: the filter's pins.
- `scripts/test/land-clear.test.mjs` (new): the landing's pins.

## Interface

```
// The slug a branch belongs to among `slugs`, longest match first, or null:
// feat|design|fix/<slug>, slice|fix/<slug>-s<n>, qa/<slug>.
export function runOf(branch: string, slugs: string[]): string | null
export function prune(repo: string, base: string, opts?: { dryRun?: boolean, run?: string }): { removed: string[], kept: { path: string, state: string }[], failed: { path: string, reason: string }[] }
// land prints after `merge first:` one line per worktree of the run, never changing its exit code:
// `removed <path>` | `kept <state> <path>` | `NOT removed <path>: <reason>`
```

Fix round (K9): `runOf(branch, slugs)` is replaced by `isRunBranch(branch: unknown, slug: string): boolean`; its one caller passes one slug, so the longest-first sort had nothing to order.

## Tests

1. `prune with run removes that slug's merged-clean worktrees only`: `prune` → another slug's merged-clean worktree kept.
2. `a slug that prefixes another does not take its branches`: `runOf` → `slice/clean-landing-s1` is `clean-landing` when both `clean` and `clean-landing` are known.
3. `a landing removes the feat, design and slice worktrees it landed`: `prune` → through `land`, none listed, local branches gone, `origin/feat/<slug>` present.
4. `a dirty slice worktree is kept and named`: `prune` → through `land`, `kept merged-dirty <path>` printed, exit 0.

Rewrite check: matching the run by the record's worktree list instead of branch names keeps tests 1, 3 and 4.

## Done

- **Expected**: after a press the run's worktrees are gone, and anything kept is named on the gate2 thread.
- **Verification**: `node --test scripts/test/worktrees.test.mjs scripts/test/land-clear.test.mjs scripts/test/land.test.mjs`; `npm test`; `git worktree list` after a scratch landing.
- **Evidence**: tests 1, 3 and 4 red before, green after; the scratch `git worktree list` output.
- **Prohibited**: `--force`, `branch -D`, deleting a remote branch, removing outside the slug, a removal failure failing the landing.
- **Done when**: the four tests and `npm test` are green and the scratch list shows none of the run's worktrees.
