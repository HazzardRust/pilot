## Tests

1. `a free port passes`: `checkAll` → `port` row `pass` "free" on a closed port.
2. `our deck on the port passes with its pid`: `checkAll` → `pass` naming the scratch deck's pid.
3. `a stranger on the port fails`: `checkAll` → `fail` "held by another program" against a plain listener.
4. `an older deck fails the version row`: `checkAll` → `fail` naming both versions, with a probe answering 0.9.0.
5. `a current deck passes the version row`: `checkAll` → `pass` with the plugin's own version.

Rewrite check: replacing the probe with a raw socket read keeps every result above.
