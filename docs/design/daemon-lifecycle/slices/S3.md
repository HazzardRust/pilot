# S3 A session whose deck went away rejoins on its next call

Feature `daemon-lifecycle` · delivers spec 6 · source: `../architecture.md` §2, §5 L5 · after: S1 (client.mjs)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it changes when a session starts a process (the security trigger) and ADR 0120's cap must hold.

## Files owned

- `deck/client.mjs`: `callDeckTool` rejoins once on a connection refused.
- `deck/test/client-rejoin.test.mjs` (new): the pins.

## Interface

```
// deck/client.mjs
callDeckTool(name, args, pollMs?, onEmptyPoll?): Promise<ToolResult>
  // a fetch that fails with cause.code ECONNREFUSED forgets the join (onTheDeck = null),
  // awaits ensureOnTheDeck() once more and retries the call once; a second failure is the tool error it is today
ensureOnTheDeck(): Promise<boolean>   // unchanged: at most JOIN_ATTEMPTS daemon starts per session (ADR 0120)
```

## Tests

1. `a call after the deck died answers from a new deck`: `callDeckTool` → `deck_read` succeeds; health reports a pid other than the dead one.
2. `the session registers again on the new deck`: `callDeckTool` → the new deck's `/api/runs?live=1` lists this session's pid.
3. `the rejoin never passes three starts`: `callDeckTool` → after three failed starts a call is a tool error and no fourth daemon is spawned.
4. `a refusal is not a reason to rejoin`: `callDeckTool` → a 400 from a live deck returns the error with no new join.

Rewrite check: replacing the error-code test with a health probe before each call keeps every result above.

## Done

- **Expected**: when the deck crashes or idles out under a session, the session's next deck call brings a deck
  back and answers, instead of failing for the rest of the session.
- **Verification**: `node --test deck/test/client-rejoin.test.mjs deck/test/startup.test.mjs`; `npm test`.
- **Evidence**: tests red before, green after.
- **Prohibited**: no retry loop past one; no new start counter beside `starts`; no rejoin on a 4xx or 5xx answer.
- **Done when**: the four tests pass and the gate is green.
