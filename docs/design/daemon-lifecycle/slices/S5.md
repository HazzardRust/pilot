# S5 pilot doctor runs every local check as a row

Feature `daemon-lifecycle` · delivers spec 10 · source: `../architecture.md` §2, §3 Seams, §6 A5 · after: S1 (bin/pilot.mjs)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it starts `gh`, `git` and `claude` (a process start, the security trigger), and A5 is assumed.

## Files owned

- `deck/doctor.mjs`: `checkAll` and its rows; `checkScanner` becomes the Defender row; `main` returns 1 on a fail.
- `deck/test/doctor.test.mjs`: today's pins kept, a pin per new row.
- `bin/pilot.mjs`: the `doctor` usage text and its exit code.

## Interface

```
// deck/doctor.mjs
type Row = { name: string, verdict: 'pass' | 'fail' | 'cannot tell', detail: string, steps?: string[] }
export function checkAll(deps?: {
  platform?, run?, root?, nodeVersion?: string, engines?: string,
  resolveDep?: (name: string) => boolean,          // '@modelcontextprotocol/sdk' resolvable from the plugin root
  storeDir?: string, canWrite?: (dir: string) => boolean,
  onPath?: (cmd: 'gh' | 'git' | 'claude') => boolean | null,   // `<cmd> --version` by argv array, no shell; null = cannot tell
}): Row[]
export function rowLine(row: Row): string          // "<verdict>  <name>: <detail>", steps indented below
export function main(options?: {                    // seam change S5, accepted: probes and printer injected
  cwd?: string, deps?: Parameters<typeof checkAll>[0], log?: (line: string) => void,
}): number                                          // 1 when any row is 'fail', else 0; defaults are the real probes
checkScanner(...)                                   // unchanged signature; its state maps to the Defender row
```

## Tests

1. `an old Node fails its row`: `checkAll` → nodeVersion 20.0.0 against `>=22.8.0` is `fail` naming both.
2. `a missing dependency fails its row`: `checkAll` → resolveDep false is `fail` naming `npm ci` in the plugin root.
3. `an unwritable store fails its row`: `checkAll` → canWrite false is `fail` naming the directory.
4. `a CLI not on PATH fails, an unreadable answer cannot tell`: `checkAll` → false is `fail`, null is `cannot tell`.
5. `Defender keeps its states as a row`: `checkAll` → off/excluded/dev-drive pass, not-excluded fail, unknown cannot tell.
6. `doctor exits 1 on a fail and 0 otherwise`: `main` → 1 with one failing row, 0 with only pass and cannot tell.

Rewrite check: replacing each probe's implementation (a different version read, a different PATH lookup) keeps every result above.
