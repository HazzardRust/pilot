## Interface

```
// deck/version.mjs
export const PLUGIN_VERSION: string            // package.json "version"
export function isOlder(a: string | undefined, b: string): boolean  // undefined counts as older; numeric x.y.z compare

// deck/probe.mjs
export function probeDeck(url: string, options?: { timeoutMs?: number /* 1000 */ }): Promise<
  | { state: 'deck', pid: number, version?: string, startedAt?: string }
  | { state: 'none' }                       // connection refused
  | { state: 'foreign', why: string }>      // answered, but not as a deck; or timed out

GET /api/health -> { ok, pid, url, seq, rss, version: string, startedAt: string }
GET /api/agents -> { agents: { [repoKey]: { agentType: string, since: string }[] } }

// deck/status-command.mjs
export function statusLines(report: { url, probe, agents?, logTail: string[], pluginVersion: string, now: number }): string[]
export function main(options?: { url?: string, probe?: typeof probeDeck, logFile?: string, now?: () => number }): Promise<number>  // 0 up, 1 not
```

## Tests

1. `health names the plugin version and start`: `GET /api/health` → `version` is package.json's, `0.9.2` (plugin.json and the lock agree), `startedAt` an ISO time.
2. `the probe tells a deck, nothing and a stranger apart`: `probeDeck` → `deck` with pid, `none` on a closed port, `foreign` on a plain http listener.
3. `older reads an absent version as older`: `isOlder` → true for undefined and 0.9.0 against 0.9.1; false for equal and newer.
4. `status on a live deck prints every line`: `main` → url, pid, version, uptime, the agents, the log's last 20 lines; exit 0.
5. `status marks an older deck stale`: `statusLines` → the version line ends `stale`.
6. `status with no deck is one line and the log tail`: `main` → `no deck is running at <url>`, then the tail; exit 1.

Rewrite check: replacing the HTTP probe with a raw socket read keeps every result above.
