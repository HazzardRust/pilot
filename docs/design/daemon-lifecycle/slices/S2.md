# S2 A crash and every refusal reach deck.log; a held port names its holder

Feature `daemon-lifecycle` · delivers spec 1, 2, 7 · source: `../architecture.md` §2, §5 L1, L2, §6 A1 · after: S1 (server-routes.mjs, probeDeck)
Reviewers: `pilot:typescript-reviewer`
Model: opus — process-level handlers whose failure mode is a deck that dies silently.

## Files owned

- `deck/daemon.mjs`: crash handlers in `main`; the EADDRINUSE branch probes the holder.
- `deck/server-routes.mjs`: `createDeckHttpServer`'s error handler logs one line per 400 and 415, as it does the 500.
- `deck/test/daemon-lifecycle.test.mjs` (new): the pins.
- `deck/test/fixtures/throw-in-timer.mjs` (new): a `--import` preload that throws from a timer 500 ms in.

## Interface

```
// deck/daemon.mjs — main() after this slice
process 'uncaughtException' | 'unhandledRejection' -> stderr "[deck] crashed: <stack>"; shutdown; exit code 1;
                                                     a 2000 ms unref'd timer forces process.exit(1)
EADDRINUSE -> S1's probeDeck(deckUrl()):
  deck    -> "[deck] a deck is already serving <url> (pid <pid>, version <v>); nothing to start"
  foreign -> "[deck] <url> is held by another program, not a deck (<why>); free the port and start again"
  exit code 1 either way

// deck/server-routes.mjs — createDeckHttpServer error handler
400 | 415 -> stderr "[deck] <status> <METHOD> <path>: <message>"   // one line, path without the query
500     -> unchanged "[deck] request failed:" and the error
```

## Tests

1. `a throw in a timer leaves the stack and exit 1`: `uncaughtException` → deck.log holds `[deck] crashed:` and the planted message; exit code 1.
2. `a rejection nobody handles does the same`: `unhandledRejection` → the same line and exit 1.
3. `a refusal writes one line and the deck serves on`: `400` → one `[deck] 400 POST /api/tool:` line; health answers.
4. `a second deck names the first`: `EADDRINUSE` → stderr names the pid and version; exit 1.
5. `a stranger on the port is named as one`: `EADDRINUSE` → "held by another program, not a deck"; exit 1.

Rewrite check: replacing the stderr tee with a direct file append keeps every result above.
