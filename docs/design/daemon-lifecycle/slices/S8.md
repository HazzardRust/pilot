## Tests

1. `pilot's status lines go, a foreign one stays`: `removeOwnSettings` → ours removed; a user's own statusLine untouched.
2. `pilot's permission rules go, the user's stay`: `removeOwnSettings` → the deck and `Bash(pilot` rules gone; a user rule, the ask rules and WebFetch kept and named.
3. `settings.json is backed up first`: `removeOwnSettings` → a `settings.json.pilot-backup-*` holds the old bytes.
4. `unedited rules go, an edited one stays`: `removeShippedRules` → shipped copies gone; the edited file kept and named.
5. `the plan lists both without touching them`: `planUninstall` → dryRun lines; files byte-identical.

Rewrite check: replacing the JSON edit with a parse-and-rewrite of the whole file keeps every result above.
