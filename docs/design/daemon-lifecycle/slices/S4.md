# S4 A session replaces an older deck

Feature `daemon-lifecycle` · delivers spec 4, 5 · source: `../architecture.md` §2, §5 L3, L4, L8, L11, §6 A2 · after: S2 (daemon.mjs, server-routes.mjs), S3 (client.mjs)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a write route that stops the daemon and a kill by pid (the security trigger).

## Files owned

- `deck/client.mjs`: `ensureDaemon` reads the deck through `probeDeck` (folding `isDeckUp`) and replaces an older one.
- `deck/server-routes.mjs`: `POST /api/exit`; `createDeckHttpServer` takes an `exit` seam.
- `deck/daemon.mjs`: `main` passes its shutdown as `exit`.
- `deck/test/daemon-replace.test.mjs` (new): the pins.
- `docs/adr/<next>-a-session-replaces-an-older-deck.md` (new): L3, L4 and A2.
- `docs/adr/README.md`: regenerated with `node scripts/adr-index.mjs`.

## Interface

```
POST /api/exit { version: string } -> 202 { ok: true }      // then exit() runs; caller's version newer than PLUGIN_VERSION
                                   -> 409 { error }          // not newer, or landingsRunning() > 0
createDeckHttpServer(options?: { open?, start?, land?, wrapperGoneMs?, exit?: () => void })  // exit defaults to a no-op

// deck/client.mjs
ensureDaemon(): Promise<boolean>
  // S1's probeDeck: deck and S1's isOlder(version, PLUGIN_VERSION) -> replaceOlder, then spawn as today
replaceOlder(found: { pid: number, version?: string }, deps?: { post?, table?, kill? }): Promise<'replaced' | 'kept'>
  // versioned: POST /api/exit, wait until probeDeck is none; 409 -> one stderr line, 'kept'
  // unversioned: kill(pid) only when table() shows pid running deck/daemon.mjs, else 'kept'
```

## Tests

1. `an older deck is asked once and replaced`: `replaceOlder` → the deck sees one `/api/exit`; health answers a new pid.
2. `an unversioned deck is stopped by pid`: `replaceOlder` → a planted 0.9.1-shaped daemon is gone; a new pid serves.
3. `a pid that is not a deck is never killed`: `replaceOlder` → 'kept'; kill not called.
4. `a same or newer deck keeps serving`: `ensureDaemon` → no exit request; pid unchanged.
5. `a landing keeps the old deck`: `POST /api/exit` → 409; the client writes one line and the pid is unchanged.
6. `the exit route refuses an older caller`: `POST /api/exit` → 409 for an equal or older version.

Rewrite check: replacing the exit route with a signal the daemon traps keeps every result above.

## Done

  the middle of a landing finishes it first.
- **Verification**: `node --test deck/test/daemon-replace.test.mjs deck/test/daemon.test.mjs`; `npm test`;
  `node scripts/adr-index.mjs --check`.
