## Interface

```
install(env): void   // inplace.mjs: a submit from form[data-in-place] is fetched, not navigated
<form method="post" action="/route" data-in-place>   // the opt-in, nothing else
```

- A 303, or a 2xx, is taken. The deck's change announcement redraws the region through live.mjs (ADR 0016).
- A refusal, or a request that never arrives, posts the form for real (reply.mjs's `resend` rule), so the user reads why.
- reply.mjs keeps its own option path. Folding it into this seam is not this slice.
