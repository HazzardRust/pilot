## Files owned

- `deck/ui/thread.html`: the arrow's `href="/"` becomes `href="<!--BACK-->"`.
- `deck/ui/render-pages.mjs`: `renderThreadPage` fills `BACK` with `escapeHtml(hrefFor(tab, all))`.

- `deck/ui/js/escape.mjs`: a private `leave()` (back on a deck-page referrer, not a thread, with history (decision itm_498a61106fc8), else `location.assign(arrow.href)`), called by Esc's keydown and by a plain left click on `a.back`.
- `deck/test/live.test.mjs`: the spec 5 pin at :1308 moves to the owner's href; the new render tests.

## Interface

```
renderThreadPage(item, items, runs, agents, numbers, all, added, refused, lanes): string
  // a.back href = hrefFor(tabFor(tabsOf(...), item.repo), all), HTML-escaped
thread.html slot <!--BACK-->   // the arrow's href; <!--HOME--> unchanged
install(env: { document, location, history }): void
  // escape.mjs: keydown Escape and a plain click on a.back both call leave();
  // a click with a modifier or a non-zero button is left to the browser
```

## Tests

1. `the arrow goes to the deck that owns the thread`: `renderThreadPage` → `<a class="back" href="/?run=<encoded R>"` for an item of repo R with R's run.
2. `under Everything the arrow keeps all`: `renderThreadPage` → `href="/?run=<encoded R>&amp;all=1"` when called with `all`.
3. `a thread no deck owns goes to the overview`: `renderThreadPage` → `href="/?run="` for an item with no repo.
4. `a click on the arrow from a deck page goes back`: `install` → `history.back()` called once, nothing assigned, the click's default prevented, when the referrer is this deck and history is 2.
5. `a click on the arrow with nothing behind it follows the owner`: `install` → `location.assign` receives the arrow's `…/?run=R` when there is no referrer, or when history is 1.
6. `a modified click on the arrow is the browser's`: `install` → neither back nor assign, default not prevented, for a ctrl-click and a middle click.
7. `Esc and the arrow agree`: `install` → the same back or assign for Escape as for a click, in each case of tests 4 and 5.

Rewrite check: however the arrow were built or wired, tests 1-3 read the same href off the rendered page, and tests 4-7 hold for any handler that leaves the page the same way for both triggers.
