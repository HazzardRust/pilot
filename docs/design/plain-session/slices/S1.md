## Interface

```
type Level = 'nothing' | 'rules' | 'everything'
PLUGIN_ID = 'pilot@pilot'
readReach({ home? }) -> { level: Level, chosen: boolean }   // absent/unreadable -> { 'everything', false } (A2)
rulesRoot({ home? }) -> string                                // <home>/.claude/pilot/rules-root
rulesPlan(level) -> { home: 'all'|'scoped'|'none', root: 'all'|'always'|'none' }   // §5 L4
runSettings(level, pluginRoot, { home? }) -> { settings: object, addDirs: string[], env: object }
  // settings: { agent:'pilot:pilot', enabledPlugins:{[PLUGIN_ID]:true}, statusLine? (below everything) }
claudeArgs(reach, pluginRoot) -> string[]   // ['--add-dir', root?, '--agent', 'pilot:pilot', '--settings', json, RESUME_PROMPT]
runEnv(reach) -> object                      // adds CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1 below everything
```

## Tests

1. `nothing enables the plugin for this process only`: `runSettings` → `enabledPlugins[PLUGIN_ID] === true`, `statusLine` set, `addDirs` is `[rulesRoot]`.
2. `everything adds no rules root and no statusLine`: `runSettings` → `addDirs` empty, no `statusLine`.
3. `the prompt stays last after a variadic --add-dir`: `claudeArgs` → `--add-dir` precedes `--agent`; the last entry is `RESUME_PROMPT`.
4. `no reach file reads as everything, not chosen`: `readReach` → `{ level: 'everything', chosen: false }`; a malformed file → same.
5. `the plan matches the level table`: `rulesPlan` → the three rows of §5 L4.
6. `both spawn paths carry the args and env`: `runEnv` → `pty.spawned[0].env` and the plain spawn's env carry it, with `claudeArgs` as argv.

Rewrite check: replacing `reach.json` with any other store keeps every argv and plan above for each level.
