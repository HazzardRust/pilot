## Interface

```
INSTALL.md headings: "## The four questions to ask" (4. "How much should a plain claude session carry?"),
```

## Tests

1. `INSTALL asks the reach and runs pilot reach`: `INSTALL.md headings` → the question and `pilot reach` present.
2. `the excerpt is offered only at everything`: `INSTALL.md headings` → step 7 names the condition.
3. `no doc starts the pilot bare`: `INSTALL.md headings` → a grep of README, INSTALL, OPERATING and the excerpt finds no bare `claude --agent pilot:pilot` start.

Rewrite check: rewording the prose keeps the question, the command and the condition findable.
