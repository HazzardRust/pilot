## Files owned

- `deck/items.mjs`: gate2 `pr` shape also takes `feat/<slug>`; the line edited in place (file at the 800 bar).
- `deck/ui/render-parts.mjs`: a branch `pr` renders as code text, not a link.

## Interface

```
gate2 pr: /^(#\d+|https?:\/\/\S+|feat\/[a-z0-9][a-z0-9-]*)$/
MAIN_LINE alternative: `merge (\S+) into main by hand`
human step: `Human step: Merge <x> into main with a merge commit.`
```

## Tests

1. `a gate2 at none names the branch`: `gate2 pr` → `pr: feat/<slug>` with a sha is accepted; `pr: main` refused.
2. `the report at none names branches`: `MAIN_LINE` → the land output `main gets pilot: merge pilot into main by hand` yields the merge step and 0 `#\d+` in the report.
3. `a fixture run at none ends landed`: `MAIN_LINE` → bare remote, `pilot.host none`, integrate and land a slice, render the report: 0 host calls, 0 `#\d+`.

Rewrite check: a different report renderer over the same land line keeps the merge step and the 0 counts.
