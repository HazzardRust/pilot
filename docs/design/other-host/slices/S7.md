# S7 The GitLab adapter passes the contract

Feature `other-host` · delivers spec 4, 6 · source: `../architecture.md` §2, §3 Seams, §6 A3 · after: S1 (`deck/host.mjs`, contract test)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — an unfamiliar CLI and a process start, the security trigger.

## Files owned

- `deck/host-gitlab.mjs` (new): `gitlabHost(run)` over `glab api` REST v4 on `projects/:id/merge_requests…`, bodies by `--input -`; `opened→open`, `iid→number`, `sha→headSha`, a draft as a `Draft: ` title; `upsertComment` lists notes, matches `whoami` and the marker, then `PUT …/notes/:note_id`; `signedIn` is `glab auth status`'s exit code; `glabRun(cwd)` with its own verb allowlist.
- `deck/host.mjs`: `hostFor` returns `gitlabHost(glabRun(cwd))` at `gitlab`.
- `deck/test/host-contract.test.mjs`: the gitlab column of S1's table.
- `deck/test/fixtures/glab/*.json` (new): REST answers from the docs, replaced by recorded ones in QA (A3).

## Interface

```
S1's Host, Review and the contract table
gitlabHost(run: (args) => string) -> Host
glabRun(cwd) -> (args) => string     // allowlist: api GET/POST/PUT on projects/:id/merge_requests[/…], api user, auth status
```

## Tests

1. `every verb returns its shape`: `gitlabHost` → S1's contract table over the fixtures returns the same `Review` shapes as github.
2. `the upsert edits its own note`: `gitlabHost` → 2 `upsertComment` calls with one marker make 1 `POST …/notes` then 1 `PUT …/notes/<id>`.
3. `off the list is refused`: `glabRun` → `api -X DELETE projects/:id` throws, 0 processes.
4. `no token is read`: `gitlabHost` → `signedIn` over a fake printing a token line returns `true` and nothing carries the line.

Rewrite check: replacing `glab api` with direct HTTPS keeps the contract table's results.

## Done

- **Expected**: at `pilot.host gitlab`, every host verb runs on `glab` and returns what the GitHub adapter returns.
- **Verification**: `node --test deck/test/host-contract.test.mjs`; `npm run test:changed`.
- **Evidence**: the gitlab rows red before the adapter, green after; QA's live run (spec 4) records the fixtures.
- **Prohibited**: `glab mr` porcelain; `-F @file`; a token in any argv or env the adapter sets; a real gitlab.com call in tests.
- **Done when**: the four tests and the gate are green.
