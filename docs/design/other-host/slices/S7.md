# S7 The install asks the host; `pilot host <name>` writes it

Feature `other-host` · delivers spec 1 · source: `../architecture.md` §2, §6 A1–A3 · after: S1 (`HOST_NAMES`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument written into the user's global gitconfig, the security trigger.

## Files owned

- `scripts/host-setting.mjs` (new): `pilot host <name>` checks the name and runs `git config --global pilot.host <name>`.
- `bin/pilot.mjs`: dispatches `host`; one help entry.
- `scripts/uninstall.mjs`: unsets the global `pilot.host`.
- `docs/INSTALL.md`: a fourth question, the host, with `pilot host <name>` as its step.
- `docs/adr/NNNN-the-host-is-a-setting.md` (new): L2–L5, A1–A3; number allocated at landing.
- `docs/adr/README.md`: its index row.
- `scripts/test/host-setting.test.mjs` (new): the pins over a fake git.

## Interface

```
pilot host <github|gitlab|none>       // exit 0 `host: <name>`; 1 `pilot.host: "<x>" is not one of github, gitlab, none`
main(argv, inject?: { git }) -> number
S1's HOST_NAMES: the accepted names
```

## Tests

1. `each answer writes the setting`: `main` → for each of the 3 names, 1 `git config --global pilot.host <name>`.
2. `another name is refused`: `main` → `pilot host gitea` exits 1, 0 git calls.
3. `uninstall unsets it`: `main` → the uninstall runs `git config --global --unset pilot.host`, exit 5 (unset) tolerated.
4. `the install names the question`: `main` → `docs/INSTALL.md` holds the host question and `pilot host` once.

Rewrite check: storing the setting elsewhere behind `hostOf` keeps the exit codes and lines.

## Done

- **Expected**: the install asks which host; `pilot host gitlab` makes every repository default to GitLab.
- **Verification**: `node --test scripts/test/host-setting.test.mjs`; `npm run test:changed -- --since=<base>`; `npm test` once.
- **Evidence**: tests 1–4 red on the base, green after; `pilot host none` then `git config --get pilot.host` here.
- **Prohibited**: a shell; writing repository config from the install; a name outside `HOST_NAMES`.
- **Done when**: four tests and the gate are green and `pilot help` names `pilot host`.
