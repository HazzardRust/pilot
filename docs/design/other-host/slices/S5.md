## Interface

```
S1's Host.reviews, Host.open, Host.edit, Host.upsertComment and hostFor
syncFeaturePr({ host: Host | null, git, record }) -> { line, wrote: 'created'|'edited'|'unchanged'|'none' }
```

## Tests

1. `none writes nothing`: `syncFeaturePr` → with `host: null`, `{ line: 'no PR: host none', wrote: 'none' }` and 0 host calls.
2. `create then edit`: `syncFeaturePr` → over `githubHost(fake)` the first run `open`s a draft, the second with a new body `edit`s, the third is `unchanged`.
3. `one QA comment`: `syncFeaturePr` → two runs with a QA comment make 1 comment, then 1 edit of it.

Rewrite check: replacing the adapter keeps `wrote` and the one-comment result.
