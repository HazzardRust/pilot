## Interface

```
gitlabHost(run) -> S1's Host        // cli 'glab'
reviews  -> glab api 'projects/:id/merge_requests?source_branch=<h>&state=<s>' ; state opened->open
open     -> glab api -X POST projects/:id/merge_requests --input <json file>   // draft via `draft: true`
editBody -> glab api -X PUT projects/:id/merge_requests/<iid> --input <json file>
upsertComment -> notes list, then POST or PUT .../notes/<id> by marker
ready    -> PUT draft=false ; whoami -> glab api user .username ; signedIn -> `glab auth status` exit 0
```

## Tests

1. `gitlab answers the verb table`: `gitlabHost` → every row of S1's table passes over the glab fixtures.
2. `an opened MR reads as open`: `gitlabHost` → fixture `state: "opened"` → `Review.state` `open`, `iid` → `number`.
3. `two upserts leave one note`: `gitlabHost` → the second call PUTs the note found by marker, 1 POST total.
4. `no token crosses argv`: `gitlabHost` → 0 argv elements match `token|PRIVATE-TOKEN`, 0 env reads named `*TOKEN*`.

Rewrite check: replacing `glab api` with `fetch` on REST v4 keeps the table and the counts.
