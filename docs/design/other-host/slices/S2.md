## Tests

1. `a merged review deletes, an open one keeps`: `deleteMerged` → over `githubHost(fake)` a `merged` review with a matching `headSha` deletes, an `open` one is kept with its reason.
2. `none judges by ancestry`: `deleteMerged` → with `host: null`, a branch merged into `into` is deleted and 0 host calls are made.
3. `a failed read keeps everything`: `deleteMerged` → a throwing host keeps every branch with `host failed: <line>`.

Rewrite check: replacing `Host` with another adapter keeps which branches are deleted and kept.
