# S2 land, branches and tickets go through Host

Feature `other-host` · delivers spec 2, 3 · source: `../architecture.md` §2, §3, §5 L4 · after: S1 (`Host`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — landing writes to the host and the grep bar moves, the security trigger.

## Files owned

- `scripts/land.mjs`: slice comment/close, main-review lookup and open become `Host` calls; at `none` the main
  line is `main gets pilot: merge pilot into main by hand` and no comment failure is printed.
- `scripts/branches.mjs`: `prsByHead` reads `host.reviews({ state: 'all', limit })`.
- `deck/tickets.mjs`: `openRuns` reads `host.whoami()` and `host.reviews({ mine: true, state: 'open' })`.
- `scripts/test/host-bar.test.mjs`: the bar widens to `gh` and `glab` starts, allowed only in `deck/host-*.mjs`.
- `scripts/test/land-none.test.mjs` (new): land over a fixture at `none`.

## Interface

```
S1's Host, hostFor: every caller below takes `host` injected, default hostFor(cwd)
land({ cwd, git, host, test, gc, holder }) -> unchanged result   // `gh` option gone
openRuns(records, { host })                                      // deck/tickets.mjs
main(argv, inject?: { host })                                    // scripts/branches.mjs
main line at none: `main gets pilot: merge pilot into main by hand`
```

## Tests

1. `no host process starts outside the adapters`: `hostFor` → a scan of `deck/` and `scripts/` (tests excluded) finds `gh` or `glab` process starts only in `deck/host-*.mjs`.
2. `land at none prints the by-hand merge and no failure`: `land` → output has `main gets pilot: merge pilot into main by hand`, 0 `pr comment failed`, 0 host calls.
3. `land at github keeps its writes`: `land` → over a fake GitHub host, 1 `close` of the open slice review with the landing comment, 1 `open` of the main review.
4. `branches at none judges by ancestry`: `main` → a merged branch is pruned with 0 host calls.
5. `tickets at none is an empty queue`: `openRuns` → `[]`, no error line.

Rewrite check: replacing the host behind `Host` keeps every line and count above.
