# S8 `pilot review open|view` for the crew

Feature `other-host` · delivers spec 5 · source: `../architecture.md` §2, §6 A8 · after: S7 (`bin/pilot.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — CLI arguments reach a host write, and an allow rule is added, the security trigger.

## Files owned

- `scripts/review.mjs` (new): `pilot review open` and `pilot review view` through `hostFor(cwd)`.
- `bin/pilot.mjs`: dispatches `review`; one help entry.
- `scripts/install-settings.mjs`: `Bash(pilot review *)` joins `PILOT_MERGE_ALLOW`.
- `scripts/test/review.test.mjs` (new): the pins over a fake host.

## Interface

```
pilot review open --base <b> --head <h> --title <t> --body-file <f>   // always draft; prints `#<n> <url>` or `no review: host none`
pilot review view <n>                                                 // prints the body and state, or `no review: host none`
main(argv, inject?: { host }) -> number
S1's Host: open, view
```

## Tests

1. `open makes one draft review`: `main` → 1 `host.open({ draft: true })`, stdout `#<n> <url>`, exit 0.
2. `at none open says the branch stands`: `main` → `no review: host none`, exit 0, 0 writes.
3. `a missing flag is refused`: `main` → `open` without `--base` exits 1 naming it, 0 host calls.
4. `the install allows it`: `main` → `PILOT_MERGE_ALLOW` holds `Bash(pilot review *)`.

Rewrite check: a different host behind `Host` keeps every line and exit code.

## Done

- **Expected**: the implementer opens its draft slice review with one pilot command on any host.
- **Verification**: `node --test scripts/test/review.test.mjs`; `npm run test:changed -- --since=<base>`; `npm test` once.
- **Evidence**: tests 1–4 red on the base, green after.
- **Prohibited**: a shell; a non-draft open; the body through argv.
- **Done when**: four tests and the gate are green and `pilot help` names `pilot review`.
