# S10 The install asks the host; `pilot host <name>` writes it

Feature `other-host` · delivers spec 1 · source: `../architecture.md` §2, §5 L2, L3 · after: S1 (`HOST_NAMES`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument written to the user's global git config, the security trigger.

Cut from pilot after handoff-mod (itm_97c9e8fdf1d2) lands: its S7 and S12 own `bin/pilot.mjs`.

## Files owned

- `scripts/host-setting.mjs` (new): `pilot host [<name>] [--local]`: no name prints the host in force; a name in `HOST_NAMES` runs `git config --global pilot.host <name>` (`--local` in the repository); any other name is refused naming `pilot.host`.
- `bin/pilot.mjs`: the `host` dispatch and usage line.
- `scripts/uninstall.mjs`: unsets the global `pilot.host`.
- `docs/INSTALL.md`: a fifth question (:32-59), the host, default `github`; the "What this changes" row for the global git config.
- `docs/adr/NNNN-the-host-is-a-setting.md` (new), `docs/adr/README.md`: ADR for L1–L4, amending ADR 0182's "not a host abstraction".
- `scripts/test/host-setting.test.mjs` (new): the pins.

## Interface

```
S1's HOST_NAMES and hostOf
main(argv: string[], inject?: { git? }) -> exit code     // scripts/host-setting.mjs
pilot host [github|gitlab|none] [--local]
```

## Tests

1. `three answers, three values`: `main` → over a fake git, each of `github`, `gitlab`, `none` writes that value globally, `--local` in the repository.
2. `a fourth name is refused`: `main` → `gitea` exits 1 naming `pilot.host`, 0 git writes.
3. `no name prints the host in force`: `main` → unset prints `github`.

Rewrite check: replacing git config with another store keeps all three results.

## Done

- **Expected**: `pilot host gitlab` sets the host; the install asks for it once.
- **Verification**: `node --test scripts/test/host-setting.test.mjs`; `npm run test:changed`; `pilot host` and `pilot host gitea` run for real.
- **Evidence**: tests red on the base, green after; both outputs read.
- **Prohibited**: writing through a shell; a value off `HOST_NAMES` reaching argv.
- **Done when**: the three tests and the gate are green and both commands were run.
