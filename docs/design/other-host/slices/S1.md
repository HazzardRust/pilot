## Interface

```
HOST_NAMES = ['github', 'gitlab', 'none']
hostOf(git: (args) => string) -> 'github' | 'gitlab' | 'none'   // only reader of pilot.host; unset -> 'github'; else throws naming the key
hostFor(cwd, deps?: { git?, run?: (cmd, args) => string, name? }) -> Host   // gitlab throws `no adapter` until S5
type Review = { number: number, state: 'open' | 'merged' | 'closed', base: string, head: string, headSha: string, title: string, url: string }
type Host = {
  name, cli: 'gh' | 'glab' | null,
  reviews({ head?, base?, state: 'open' | 'all', mine?: boolean, limit? }) -> Review[],
  view(number) -> { body: string, state } | null,
  open({ base, head, title, bodyFile, draft }) -> Review | null,     // none: null
  editBody(number, bodyFile), comment(number, text), close(number, text), ready(number),
  upsertComment(number, marker, bodyFile) -> 'created' | 'edited' | 'none',
  whoami() -> string | null, signedIn() -> boolean | null,          // exit status only, never a token
}
githubHost(run) -> Host
```

## Tests

1. `the verb table answers one shape on github and none`: `Host` → each verb's result matches `Review`/its return type for `githubHost` over fixture `gh` JSON and for `hostFor(…, { name: 'none' })`.
2. `none starts no process`: `hostFor` → at `none` every verb returns `[]`/`null`/`'none'` and the fake `run` records 0 calls.
3. `a bad pilot.host stops naming the key`: `hostOf` → `pilot.host names "gitea": no adapter` thrown; unset → `github`.
4. `github keeps today's verbs and filters`: `githubHost` → `reviews({ head, state: 'all', limit: 1 })` runs `gh pr list --head <b> --state all --limit 1 --json <A5 set>`.
5. `integrate at none merges with no host call`: `hostFor` → `pilot integrate` with `pilot.host none` merges `Merge <branch>` and the fake `run` records 0 calls.

Rewrite check: replacing `gh` with the REST API inside `githubHost` keeps every shape and count above.
