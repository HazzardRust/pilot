## Interface

```
HOST_NAMES: readonly ['github', 'gitlab', 'none']
hostOf(git: (args) => string) -> 'github' | 'gitlab' | 'none'   // unset -> 'github'; throws naming pilot.host
hostFor(cwd, deps?: { git?, run? }) -> Host | null              // null at none
Review = { number, state: 'open'|'merged'|'closed', base, head, headSha, title, body, url, crossRepo }
Host = { name, cli, whoami(), reviews({ head?, base?, state, mine?, limit? }) -> Review[], review(n) -> Review,
         open({ base, head, title, body, draft?, label? }) -> number, edit(n, { base?, title?, body?, label? }),
         comment(n, body), upsertComment(n, marker, body), signedIn() -> boolean }
githubHost(run: (args) => string) -> Host
ghRun(cwd) -> (args) => string     // assertHostVerb, then execFileSync('gh', args), no shell
openRuns(records, { host }), tickets({ host })
```

## Tests

1. `unset reads as github, none as null`: `hostFor` → over a fake git, unset gives a Host named `github`, `none` gives `null`, `gitea` throws naming `pilot.host`.
2. `every verb returns its shape`: `githubHost` → the contract table over a fake `gh` returns `Review` with `state` in `open|merged|closed` for all 9 verbs.
3. `the upsert edits its own comment`: `upsertComment` → 2 calls with one marker make 1 `pr comment` then 1 `api … PATCH`.
4. `no CLI at none`: `tickets` → at `none` a fake `run` that throws is never called and the queue prints.
5. `the allowlist still refuses`: `ghRun` → `pr merge` throws naming the verb, 0 processes.

Rewrite check: replacing `gh` with the REST API behind `githubHost` keeps the contract table and `tickets`' output.
