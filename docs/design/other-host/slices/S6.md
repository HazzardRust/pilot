## Tests

1. `none checks no host CLI`: `checkAll` → rows hold no `gh` or `glab` row, `host` row `pass`.
2. `gitlab with glab missing fails naming it`: `checkAll` → a `glab` row `fail`, step `install glab and put it on PATH`.
3. `signed out names the login step`: `checkAll` → `host` row `fail`, step `glab auth login`.
4. `no token is printed`: `checkAll` → the row text holds no character run of the fake status output's token line.

Rewrite check: reading the host another way keeps the four rows' verdicts and text.
