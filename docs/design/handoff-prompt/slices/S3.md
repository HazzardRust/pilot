## Interface

```
export const TAKEN_WAIT_MS = 60_000;   // A1
export function promptTaken(opts: { since: number, type: (s: string) => void, signal: AbortSignal, pollMs?: number, takenWaitMs?: number }):
  Promise<'taken' | 'retyped' | 'not started' | 'stopped'>
  // waits for S2's lastToolRan() >= since; else types "\r" once and waits again
  // logs "run: prompt taken", "run: retyped Enter", "run: hand-off not started" to wrapper.log
clearOnce({ ..., takenWaitMs = TAKEN_WAIT_MS })   // on 'not started': sayAloud(handoff, cwd, read, text, signal)
sayAloud(handoff, cwd, read, text, signal): Promise<void>   // the thread, then this directory's chat; each failure logged
```

## Tests

1. `a session that stamps at once is taken`: `promptTaken` → `'taken'`, nothing typed, log `prompt taken`.
2. `a session that stamps after the retype`: `promptTaken` → `'retyped'`, typed `['\r']`, logs `retyped Enter`, `prompt taken`.
3. `a session that never stamps`: `promptTaken` → `'not started'`, typed `['\r']`, log `hand-off not started`.
4. `a stop during the check types nothing`: `promptTaken` → `'stopped'`, typed `[]`.
5. `not started is said on the thread`: `clearOnce` → a `deck_reply` on the hand-off naming it not started.
6. `a closed thread falls back to the chat`: `clearOnce` → the reply lands on this directory's chat item.

Rewrite check: a different wait or stamp store keeps the four outcomes, the one retype, the log lines and the replies.
