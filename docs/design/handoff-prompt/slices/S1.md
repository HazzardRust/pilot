## Interface

```
export const SETTLE_MS = 300;
export const pasted = (text: string) => string;   // "\x1b[200~" + text + "\x1b[201~"
export function submitPrompt(text: string, opts: { type: (s: string) => void, signal: AbortSignal, settleMs?: number }): Promise<boolean>
  // types pasted(text), waits settleMs, types "\r" alone; false when signal aborts before the "\r"
clearOnce({ ..., settleMs = SETTLE_MS }) -> Promise<boolean>   // unchanged otherwise; still logs "typed the prompt"
```

## Tests

1. `the prompt and its Enter are two writes`: `submitPrompt` → typed is `[pasted(text), '\r']`.
2. `the Enter waits the settle`: `submitPrompt` → the `\r` is written no sooner than `settleMs` after the paste.
3. `a stop before the Enter types no Enter`: `submitPrompt` → aborted mid-settle, typed is `[pasted(text)]`, result false.
4. `a hand-off types /clear, the paste, then Enter alone`: `clearOnce` → typed equals `['/clear\r', pasted(prompt), '\r']`.

Rewrite check: replacing the timer with any other wait keeps the two writes, their order, the gap and the abort result.
