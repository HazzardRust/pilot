# S2 The pilot's prompt in a live run goes to the deck

Feature `gate-no-stall` · delivers spec 4 · source: `../architecture.md` §2, L5, A1 · after: S1 (`postBlocked`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `hooks/permission-refuse.js`: `decide`, async; the crew refusal unchanged; the pilot session's prompt refused and posted while a run is live.
- `hooks/test/permission-refuse.test.js`: the pins, the existing ones kept.

## Interface

```
decide(payload: PermissionRequestPayload, deps?: { deck?, post?: S1's postBlocked }) => Promise<HookOutput | null>
HookOutput: { hookSpecificOutput: { hookEventName: 'PermissionRequest', decision: { behavior: 'deny', message: string, interrupt: false } } }
refuse(payload) => HookOutput | null   // kept: the crew case, sync, as today
```

## Tests

1. `the pilot session's prompt in a live run is denied and posted`: `decide` → deny with the blocked-step message, one post naming the command.
2. `with no live run the pilot's prompt is the user's`: `decide` → null.
3. `a deck that does not answer leaves the prompt to the user`: `decide` → null inside the 5 s timeout.
4. `a crew agent's prompt is denied as before, and posted`: `decide` → the existing message, one post.
5. `a plain session and another plugin's agent are untouched`: `decide` → null.

Rewrite check: replacing how a live run is found keeps all five results.

## Done

- **Expected**: in a run the pilot never waits on a terminal prompt; the step is a blocking item on the deck and the pilot carries on.
- **Verification**: `node --test hooks/test/permission-refuse.test.js`; `npm test`; a scratch pilot session (`claude --agent pilot:pilot -p`, auto mode) on a scratch deck with a planted `ask` rule on a harmless command.
- **Evidence**: test output; the scratch transcript showing the deny message and no prompt; the item on the scratch deck. This run probes whether `PermissionRequest` fires for auto mode's fallback prompt: if it does not, stop and tell `main`.
- **Prohibited**: `behavior: 'allow'` anywhere; refusing a session that is not a pilot lane; failing closed when the deck is down.
- **Done when**: the five tests and `npm test` are green and the scratch transcript has been read.
