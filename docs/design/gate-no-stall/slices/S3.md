# S3 The landing says what it readied

Feature `gate-no-stall` · delivers spec 1 · source: `../architecture.md` §2, L6 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `scripts/land.mjs`: `readyLine`; `main()` prints a `ready:` line on every landing.
- `deck/landing.mjs`: a settle whose line holds `pr ready failed` posts a blocked item on the gate2's ticket.
- `agents/pilot.md`: step 9 drops the `gh pr ready` retry; a `pr ready failed` is the deck's blocked item; a denied call is never retried.
- `scripts/test/measure-prompt.test.mjs`: the pilot pin moves by the measured cost, with a dated comment line.
- `scripts/test/land-ready.test.mjs` (new): the land pins.
- `deck/test/landing-ready.test.mjs` (new): the settle pin.

## Interface

```
readyLine(readied: number[], readyFailed?: string, { head, base }?: { head: string, base: string }) => string
  // seam change 2026-10-13 (co-pilot): head/base added so the none line can name them; land() also returns readied and base
  // 'ready: #576' | 'ready: none (no open draft PR from <head> to <base>)' | 'pr ready failed: <first 200 chars>'
startLanding(gate2Id, deps)   // signature unchanged; its settle posts
  { kind: 'question', blocking: true, ticket, title: 'Mark #<pr> ready', options: ['Done', 'Leave it draft'], recommended: 'Done' }
agents/pilot.md step 9: holds no `gh pr ready`
```

## Tests

1. `a landing that readies a PR says which`: `readyLine` → `ready: #576`.
2. `a landing with no draft PR says none`: `readyLine` → `ready: none (...)`.
3. `a refused ready names the failure`: `readyLine` → `pr ready failed: ...`.
4. `a settled pr ready failed posts one blocked item on the ticket`: `startLanding` → one blocking question naming the PR.
5. `step 9 runs no gh pr ready`: `agents/pilot.md step 9` → no match for `gh pr ready`.

Rewrite check: replacing `gh` with the REST API keeps all five results.
