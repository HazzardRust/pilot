# S6 `pilot integrate --default` takes the default branch

Feature `gate-no-stall` · delivers spec 5 · source: `../architecture.md` §2, L8, A2, A3 · after: S3 (`agents/pilot.md`, the pilot pin), S5 (the refusal names the command)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `scripts/integrate.mjs`: `--default` fetches, merges `origin/<default>`, resolves, tests, pushes, reads mergeable.
- `scripts/merge-generated.mjs`: the pin rule: a conflict in `scripts/test/measure-prompt.test.mjs` keeps both sides' comments and the measured number.
- `bin/pilot.mjs`: the usage line for `--default`.
- `agents/pilot.md`: step 9 runs `pilot integrate --default` before the gate2 and posts the sha it prints.
- `scripts/test/measure-prompt.test.mjs`: the pilot pin by the measured cost.
- `scripts/test/integrate-default.test.mjs` (new): the pins, on scratch repositories.

## Interface

```
pilot integrate --default [--trailer "<line>"]...
integrate({ cwd, git, gh, test, base: 'default' }) => { tip: string, mergeable: 'MERGEABLE' | 'CONFLICTING' | 'UNKNOWN' }
  // prints 'mergeable: <state> at <sha7>'; exit 1 on red, 3 on a conflict left
mergeResolved(dir, ref, message, { side, measurePins?: boolean })
```

## Tests

1. `a default branch that moved is merged and pushed`: `integrate` → a merge commit with `origin/main` as second parent, pushed.
2. `a pin conflict resolves to the measured value`: `mergeResolved` → the pin line holds what `measure` answers, both comment blocks kept.
3. `mergeable is read and printed`: `integrate` → `mergeable: MERGEABLE at <sha7>` from an injected `gh`; UNKNOWN polled, then printed.
4. `a red gate resets and pushes nothing`: `integrate` → the branch at its start, nothing pushed.

Rewrite check: replacing the merge strategy behind `integrate` keeps all four results.
