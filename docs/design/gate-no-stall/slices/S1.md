# S1 A denied pilot call becomes a blocked item

Feature `gate-no-stall` · delivers spec 3 · source: `../architecture.md` §2, L1-L4, A4 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `hooks/lib/blocked.js` (new): `postBlocked`, the one place a blocked step becomes a deck item.
- `hooks/permission-denied.js` (new): the `PermissionDenied` hook; a pilot lane's denial goes to `postBlocked`.
- `hooks/hooks.json`: registers `PermissionDenied`, id `denied:any:blocked-item`, timeout 5.
- `hooks/lib/deck.js`: `liveTicket(repo)`, a `GET /api/tickets?repo=` read for its `live` field.
- `hooks/test/permission-denied.test.js` (new): the pins.

## Interface

```
postBlocked(step: { repo: string, command: string, reason: string, agent: string, session: string,
                    source: 'denied' | 'refused' /* S7: which lead the body opens with */ },
            deps?: { deck?, claims?: string /* claim dir */, now?: () => number /* the clock a claim is aged by */,
                     live?: boolean /* the caller already found the run live: runs() is not asked again (fix round F2) */ })
  => Promise<string | null>  // item id, or null when nothing posted
onDenied(payload: PermissionDeniedPayload, deps?) => Promise<null>   // never outputs: a denial stays a denial
liveTicket(repo: string) => Promise<{ id: string } | null>             // hooks/lib/deck.js
item: { kind: 'question', blocking: true, ticket, title: 'Blocked: <command, first 80>', body, options: ['I ran it', 'Skip it'], recommended: 'Skip it', repo }
```

## Tests

1. `a pilot session's denial in a live run posts one blocking item`: `onDenied` → one `deck_post` naming `tool_input.command` and `reason`, `ticket` the live ticket.
2. `the same command denied again posts nothing`: `postBlocked` → null on the second call with the same session and command.
3. `a crew agent's denial posts too, another plugin's agent does not`: `onDenied` → one post for `pilot:pilot-qa`, none for `other:agent`.
4. `no live run, or a deck that does not answer, posts nothing and throws nothing`: `postBlocked` → null.
5. `no live ticket posts a plain question`: `postBlocked` → a post without `ticket` or `blocking`.
6. `a tool other than Bash is named by its tool name`: `onDenied` → title `Blocked: <tool_name>`.

Rewrite check: replacing the claim files with any other record of what was posted keeps all six results.
