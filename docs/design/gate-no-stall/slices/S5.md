# S5 A gate2 behind the default branch is refused

Feature `gate-no-stall` · delivers spec 5 · source: `../architecture.md` §2, L7, A5 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `deck/gate2-base.mjs` (new): `holdsDefault`.
- `deck/server-tools.mjs`: a `deck_post` of kind `gate2` calls `holdsDefault` first and answers its refusal.
- `deck/test/gate2-base.test.mjs` (new): the pins, on a scratch git repository.

## Interface

```
holdsDefault(repo: string, sha: string, deps?: { git?: (cwd, args) => string }) =>
  { ok: true } | { ok: false, branch: string, tip: string /* sha7 */, why?: string }
refusal: 'NOT posted: <sha> does not hold origin/<branch> at <tip>; run pilot integrate --default in the feat worktree and post the sha it prints'
```

## Tests

1. `a sha behind the default branch is refused naming the command`: `holdsDefault` → `{ ok: false }`, and the post's refusal names `pilot integrate --default`.
2. `a sha holding the default tip passes`: `holdsDefault` → `{ ok: true }`.
3. `an unknown sha or no origin/<default> refuses with what git said`: `holdsDefault` → `{ ok: false, why }`.

Rewrite check: replacing git with libgit2 keeps the three results.

## Done

- **Expected**: the pilot cannot put a gate2 in front of the user for a feature its PR cannot merge cleanly into.
- **Verification**: `node --test deck/test/gate2-base.test.mjs`; `npm test`; a scratch deck refusing then accepting a gate2.
- **Evidence**: test output; the scratch refusal text.
- **Prohibited**: a shell; `git fetch` or `gh` in the post path; a sha reaching argv unchecked (`/^[0-9a-f]{7,40}$/` first).
- **Done when**: the three tests and `npm test` are green and the scratch refusal has been seen.
