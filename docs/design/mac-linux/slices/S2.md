## Tests

3. `a network path is refused on Windows and a relative one everywhere`: `addDeck` → the win32 refusal names a network path, and the POSIX refusal says not absolute.
4. `the session slug is the host path with each non-alphanumeric a dash`: `projectSlug` → the expected slug for the host's path.
