# S6 The process table reads macOS ps

Feature `mac-linux` · delivers spec 8 · source: `../architecture.md` §3 F5 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — one argv and one parse, fixed by the Interface and the fixtures; no security trigger.

## Files owned

- `deck/procs.mjs`: darwin runs `ps -axo pid=,ppid=,etime=,comm=,args=` and parses `etime`.
- `deck/test/procs.test.mjs`: a darwin fixture replaces the "etimes: keyword not found" case (245).

## Interface

```
processTable(opts?: { platform?: string, run?: (cmd: string, args: string[]) => string }): ProcessRow[]
ProcessRow: { pid: number, ppid: number, ageS: number, name: string, command: string }
elapsedSeconds(etime: string): number   // '[[dd-]hh:]mm:ss' -> seconds
```

## Tests

1. `macOS rows parse from etime`: `processTable` → for darwin fixture output, `ageS` 65 for `01:05` and 90061 for `1-01:01:01`.
2. `linux keeps etimes`: `processTable` → the linux argv is unchanged.
3. `elapsed forms parse`: `elapsedSeconds` → `00:07` is 7, `02:00:00` is 7200, and `3-00:00:00` is 259200.
4. `the real table reads on this host`: `processTable` → a non-empty list containing `process.pid`.

Rewrite check: replacing the regex parse with a split-based one keeps every result above.
