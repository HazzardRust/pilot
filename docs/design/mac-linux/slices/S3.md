# S3 One repository behind a symlink is one path key

Feature `mac-linux` · delivers spec 2, 6 · source: `../architecture.md` §2, §5 L1–L3 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — `hooks/lib/` is agent configuration, and the key change touches persisted state.

## Files owned

- `hooks/lib/platform.js` (new): the platform seam; this slice adds `hostPlatform`, `isWindows`, `pathKey`.
- `hooks/test/platform.test.js` (new): table tests over win32, darwin, linux.
- `deck/items.mjs`: `repoKey` returns `pathKey(repo)`.
- `hooks/lib/deck.js`: `repoKey` returns `pathKey(dir)`; `samePath` unchanged.
- `scripts/install-settings.mjs`: `isInPluginCache` folds through `pathKey` (735).
- `deck/test/path-key.test.mjs` (new): the symlinked-dir pin.

## Interface

```
// hooks/lib/platform.js (CommonJS)
hostPlatform(): NodeJS.Platform          // reads process.platform on each call (L2)
isWindows(platform?: string): boolean    // platform defaults to hostPlatform()
pathKey(p: string, opts?: { platform?: string, realpath?: (p: string) => string }): string
  // realpath.native when p exists, else path.resolve; lower-case on win32 only (L3)
repoKey(repo: string): string            // deck/items.mjs and hooks/lib/deck.js, both = pathKey
```

## Tests

1. `the seam answers per platform`: `isWindows` → true for win32, false for darwin and linux.
2. `a path key folds case on win32 only`: `pathKey` → `C:\A` and `c:\a` equal on win32, and `/A` and `/a` distinct on darwin and linux.
3. `a missing path keys by resolve`: `pathKey` → `path.resolve` of a path that does not exist.
4. `a symlinked repo is one tab`: `repoKey` → `registerRun` through a link and `addDeck` of the real dir give 1 tab (skipped on symlink EPERM).
5. `the hooks agree through a link`: `pathKey` → `samePath(link, real)` is true.

Rewrite check: replacing realpath with any canonicaliser that resolves symlinks keeps every result above.
