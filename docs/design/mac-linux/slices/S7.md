# S7 The store and pilot-inbox are private on POSIX

Feature `mac-linux` · delivers spec 5 · source: `../architecture.md` §2, §5 L6 · after: S3 (`hooks/lib/deck.js`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — file modes on the deck's state are the security trigger, and `hooks/` is agent configuration.

## Files owned

- `hooks/lib/atomic-write.js`: the tmp write is 0600; adds `privateDir`.
- `hooks/test/private-store.test.js` (new): the mode pins.
- `deck/store-core.mjs`: `writeDeck` makes its dir with `privateDir`.
- `deck/daemon.mjs`: start calls `privateDir(storeDir())`.
- `hooks/lib/deck.js`: each `pilot-inbox` mkdir goes through `privateDir`.

## Interface

```
// hooks/lib/atomic-write.js (CommonJS)
atomicWriteFileSync(targetPath: string, contents: string | Buffer, options?: object): void
  // the tmp file is written with mode 0o600, so the renamed target is 0600
privateDir(dir: string, options?: { onKept?(err: Error): void }): string   // mkdirSync({ recursive: true, mode: 0o700 }), then chmodSync(dir, 0o700); returns dir; an EPERM chmod is kept and passed to onKept (A5)
```

## Tests

1. `an atomic write lands 0600`: `atomicWriteFileSync` → `stat.mode & 0o777` is `0o600` (skipped on win32).
2. `an existing 0755 store dir becomes 0700`: `privateDir` → `0o700` for a dir made at 0755.
3. `writeDeck leaves the store private`: `privateDir` → after a scratch `writeDeck`, the dir is 0700 and deck.json 0600.
4. `pilot-inbox is private`: `privateDir` → after a hook state write, `~/.claude/pilot-inbox` is 0700 under a fake home.

Rewrite check: replacing mkdir-plus-chmod with an umask-scoped mkdir keeps every result above.

## Done

- **Expected**: on a shared Mac or Linux box another user cannot list or read `~/.claude/pilot`.
- **Verification**: `node --test hooks/test/private-store.test.js hooks/test/atomic-write.test.js`; `npm test`.
- **Evidence**: the pins pass on ubuntu and macos (S1's run) and show as skipped on win32.
- **Prohibited**: no process-wide `umask` change; no chmod of anything outside the two dirs.
- **Done when**: the pins pass and the gate is green.
