## Tests

1. `a wait on a directory no run and no open thread names says NO DECK on line 2`: line 1 `listening on <dir>`, line 2 the `NO DECK` line naming it, then `NO REPLY after …` at the timeout.
2. `a wait on a repository with a run prints no NO DECK line`.
3. `a wait on a repository with an open thread and no run prints no NO DECK line`.
4. `a deck that does not answer the check is the unreachable line and exit 1`: line 1 still printed first.
5. `a wait on an unknown directory still takes a reply that arrives later` (A1).

## Done

- **Expected**: a wait pointed where nobody will post says so immediately and names the directory; a wait on a known repository prints exactly what it prints today.
- **Verification**: `node --test deck/test/wait.test.mjs`; `npm test`.
- **Evidence**: tests 1–5 failing before and passing after; on a scratch deck, `pilot wait --timeout 0.05` from a fresh `git init` directory, its output read.
- **Prohibited**: no new field on `deck_wait` or change to the daemon; no check repeated per poll; no exit on an unknown directory (A1 stands until the user answers); no probing on the live deck at 4321.
- **Done when**: the five tests are green and the scratch-deck output shows the `NO DECK` line under `listening on`.
