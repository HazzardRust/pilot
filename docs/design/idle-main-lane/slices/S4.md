# S4 The SessionStart notice names both lanes

Feature `idle-main-lane` · delivers spec 4 · source: `../architecture.md` §2, A2 · after: S1 (`/api/record` `lanes`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `hooks/session-handoff.js`: `recordFor` (`:379`) keeps `lanes`; wherever the hook already speaks (pickup, recovery, yellow lane) the additionalContext ends with the two lane lines, outside every fence.
- `hooks/test/session-handoff-lanes.test.js` (new): the hook against a deck on a port.

## Interface

```
recordFor(cwd): Promise<{ record, yellow, lanes: { main: string, co-pilot: string } | null }>
lanesNotice(lanes): string | null   // 'Lanes now:\nmain: …\nco-pilot: …'; null unless both lines match /^(main|co-pilot): [\w →itm_]+$/
S1's Lanes (GET /api/record lanes)
```

## Tests

1. `a hand-off pickup with an empty main lane names both lanes`: `lanesNotice` → the payload's additionalContext ends with `main: empty → next green itm_X` and `co-pilot: itm_Y`.
2. `a recovery and a yellow re-brief carry the same lines`: `lanesNotice` → both payloads end with them.
3. `a line of another shape is never echoed`: `lanesNotice` → null for a `main` carrying a newline or free text.
4. `a bare start with nothing to say stays silent`: `lanesNotice` → no payload when the hook had none.

Rewrite check: any notice text that keeps the two lane lines outside the fences keeps tests 1 to 4.

## Done

- **Expected**: a fresh session told about a co-pilot is also told the main lane is empty and what it takes next.
- **Verification**: `npm test -- hooks/test/session-handoff-lanes.test.js hooks/test/session-handoff.test.js`; `npm test`.
- **Evidence**: test 1 failing before and passing after; a `/clear` on a scratch deck (L9) whose SessionStart context shows both lines.
- **Prohibited**: no lane text inside a record fence; no echo of a line that fails its shape check; no new SessionStart payload where none was said.
- **Done when**: the full suite is green and the scratch SessionStart context showed both lines.

## Seam change (co-pilot, during S4)

The Interface shape check `/^(main|co-pilot): [\w →itm_]+$/` was too loose for text placed outside every fence (security MEDIUM, PR #552). As built, `lanesNotice` checks the lane grammar: `main: (empty( → next (red|green) itm_\w{1,40})?|itm_\w{1,40})` and `co-pilot: (none|itm_\w{1,40})`. The hook carries a copy of the grammar `deck/lanes.mjs` spells; a new spelling there drops both lines here until this check learns it. No spec line or locked decision moves.
