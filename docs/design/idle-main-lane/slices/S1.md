## Interface

```
type Lanes = {
  main: string            // 'main: itm_X' | 'main: empty → next <red|green> itm_X' | 'main: empty'
  co-pilot: string         // 'co-pilot: itm_Y' (live) | 'co-pilot: none'
  mainClause: string      // 'Main: itm_X live' | 'Main: empty, next <red|green> itm_X' | 'Main: empty'
  refusal: string | null  // 'main lane empty; itm_X is queued <red|green> — deck_ticket take it first'; null unless deckStateOf is 'queued' and no handoff is open in repo
}
lanesFrom(items, repo, { switching, co-pilot }): Lanes   // pure; co-pilot = coPilotFor's { ticket, live } | null
lanesOf(repo): Lanes                                     // one store read
GET /api/record?repo=  -> { record, yellow, budget, co-pilot, lanes: Lanes }
wait({ kind = 'pilot', ... }): Promise<0|1>             // prints Lanes.refusal and answers 0 when kind is 'pilot' and it is non-null
```

## Tests

1. `a green pick with no live ticket is refused`: `lanesFrom` → `refusal` names the green ticket and `main` reads `main: empty → next green itm_X`.
2. `a red ticket is named before an earlier green one`: `lanesFrom` → `refusal` names the red ticket.
3. `nothing red or green queued refuses nothing`: `lanesFrom` → `refusal` null, `main: empty`.
4. `a live ticket or a pending main switch refuses nothing`: `lanesFrom` → `refusal` null, `main: itm_X`.
5. `an open handoff in the directory refuses nothing`: `lanesFrom` → `refusal` null.
6. `a live co-pilot is named and a released one is none`: `lanesFrom` → `co-pilot: itm_Y` / `co-pilot: none`.
7. `the record route carries the lanes`: `GET /api/record?repo=` → `lanes.refusal` for a green pick.
8. `the pilot's wait ends at once on an idle main lane`: `wait` → prints the refusal line, answers 0, no `deck_wait` posted; red, green and none queued.
9. `an architect's wait parks beside a green pick`: `wait` → `NO REPLY` after its timeout with `kind: 'architect'`.

Rewrite check: replacing `deckStateOf` and `nextTicketOf` with another reading of the queue keeps every line above.
