# S1 A typed reply leaves a gate signed; a landed gate2 refuses every press and still closes (walking skeleton)

Feature `gate-stays-signed` · delivers spec 1, 2, 3, 5 · source: `../architecture.md` §2, §3, L1-L3, A1 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `deck/items.mjs`: `chosenOf` on an `isGate` kind reads the newest user message that is a press of one of its options. Other kinds are unchanged. Its doc comment says so.
- `deck/store-items.mjs`: in `addReply`, a press of any option on a gate2 whose own landing is `running` or `landed` is refused with the landing's line. The cross-repository "other gate2 landing" check stays Sign off only.
- `deck/test/gate-stays-signed.test.mjs` (new): the pins.

## Interface

```
chosenOf(item) -> string | null   // gate1/gate2: newest press; any other kind: newest user message, as today
addReply(id, said) -> item        // throws DeckRefusal "gate2 <id> is landed at <sha7>; nothing run" for any press on a landed gate2
resolveItem(id, resolution, author) -> item   // unchanged signature; reads chosenOf
postItem(item) -> item            // unchanged; a report posts once its gate2 is resolved
```

## Tests

1. `a typed reply after Sign off leaves a gate1 signed`: `resolveItem` → closes the gate1, and its ticket is yellow with a plan.
2. `a typed reply after Sign off leaves a gate2 signed`: `chosenOf` → `Sign off` after `addReply(id, 'added the rule')`.
3. `Not yet after Sign off withdraws it`: `resolveItem` → throws the "has not signed" refusal.
4. `every press on a landed gate2 is refused and stores nothing`: `addReply` → throws `is landed at 97b4833` for Sign off and for Not yet, and the reply count is unchanged.
5. `a landed gate2 with a typed reply after its press closes, and the report posts`: `resolveItem` → closed; `postItem` of a `report` on the ticket → posted.
6. `a question's typed reply after a press still chooses nothing`: `chosenOf` → `null`.

Rewrite check: storing the press as a field instead of reading it back keeps all six results above.
