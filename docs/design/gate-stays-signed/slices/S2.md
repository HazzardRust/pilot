# S2 A signed gate's reply box says the press stands

Feature `gate-stays-signed` · delivers spec 4 · source: `../architecture.md` §2, A2 · after: S1 (`chosenOf`)
Reviewers: `pilot:typescript-reviewer`

## Files owned

- `deck/ui/render-parts.mjs`: `renderReplyForm` labels a gate whose `chosenOf` is Sign off "Signed off. The press stands; what you type is a comment for the pilot." Every other thread keeps `replyPrompt(kind)`.
- `deck/test/gate-signed-render.test.mjs` (new): the pins.
- Added by the co-pilot after S1 (seam change, spec 1; no locked decision moves): `hooks/lib/deck.js` `isUnsignedGate` and `notToClose` decide a gate unsigned from its newest *press* over the item's user messages, as S1's `chosenOf` does, not from the newest reply's text; callers in `hooks/stop-gate.js` and `hooks/inbox-alert.js` pass what that needs. Otherwise a typed reply on a signed gate makes the hooks tell the pilot `never deck_resolve it unsigned`, and the pilot asks for a press a landed gate2 now refuses: the incident's loop through the hook. Pin it in the hooks' existing test file.

## Interface

```
renderThreadPage(item, items) -> html   // a signed gate's reply label is SIGNED_GATE_LABEL
SIGNED_GATE_LABEL = 'Signed off. The press stands; what you type is a comment for the pilot.'  // private to render-parts.mjs
isUnsignedGate(item) -> boolean   // hooks/lib/deck.js: the item's newest user press is not Sign off
notToClose(item) -> string   // hooks/lib/deck.js: was (kind, text); the gate or user-thread sentence, else ''
S1's chosenOf: what decides that a gate is signed
```

## Tests

1. `a signed gate2 with a later typed reply shows the signed label`: `renderThreadPage` → the label text and the Sign off button drawn pressed.
2. `an unsigned gate1 keeps Your verdict`: `renderThreadPage` → `Your verdict` and no signed label.
3. `a gate withdrawn with Not yet keeps Your verdict`: `renderThreadPage` → `Your verdict`.
4. `a signed gate with a later typed reply gets no unsigned-gate sentence from the hooks`: `notToClose(item)` → `''` for a signed gate, the gate sentence once Sign off is followed by Not yet.

Rewrite check: moving the label into `replyPrompt` or a stored flag keeps all three pages the same.
