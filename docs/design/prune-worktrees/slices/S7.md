## Interface

```
worktreesRow(deps: { repo, git, statfs, now, sizeOf, budgetMs }) -> { name: 'worktrees', verdict, detail, steps? }
// detail: `<n> trees, <s> stale (>14 d, not in pilot), <u> untagged detached, <o> orphan dirs; <free> GB free of <total>; stale build output <size|≥size>`
S2's tagOf
```

## Behaviours

1. `stale trees are counted` (test): `worktreesRow` → `1 stale` for one tree whose last commit is 15 days old and not in `pilot`.
2. `untagged detached and orphans are counted` (test): `worktreesRow` → `1 untagged detached, 1 orphan dirs` for an untagged detached tree and a `<repo>-x` dir git does not list.
3. `low disk fails` (test): `worktreesRow` → verdict `fail` under 10% free from `statfs`; `pass` at 30%.
4. `the size walk stops at its budget` (test): `worktreesRow` → a detail carrying `≥` when `sizeOf` runs past `budgetMs`.
5. `the row runs here` (run): `pilot doctor` on this machine prints the row in under 15 s, free GB within 1 GB of `Get-PSDrive C`.

Rewrite check: any census reading git and the volume gives the same counts for the same seeded repo.
Misses: build output outside the stale trees; the user reads the free-GB figure.

## Done

- **Expected**: `pilot doctor` tells the user how many trees are stale, untagged or orphaned and how much disk is free.
- **Verification**: `node --test deck/test/doctor-worktrees.test.mjs deck/test/doctor*.test.mjs`; `node bin/pilot.mjs doctor`; `npm run test:quiet`.
- **Evidence**: behaviours 1-4 red before and green after; the real row's line in the report.
- **Prohibited**: no removal from doctor; no walk of a non-stale tree; no `fail` for stale trees alone.
- **Done when**: the five behaviours hold and the gate is green.
