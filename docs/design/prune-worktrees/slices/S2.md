## Behaviours

1. `a tagged detached tree is the run's` (test): `runWorktrees` → includes a tree added with `add --run x --detach`, excludes one tagged `y`.
2. `a landed prune takes tagged trees wherever they live` (test): `S1's removeTree` → called for a tagged detached tree and a tagged tree under a temp dir outside the repo's parent, by a landed `prune --run`; 0 left in `git worktree list`.
3. `the report's left list sees them` (test): `runWorktrees` → names a dirty tagged tree a landed prune kept, so the closing report's "Worktrees left" lists it.
4. `isRunBranch is unchanged` (test): `isRunBranch` → the `worktrees.test.mjs` pins hold, `slice/clean-landing-s1` still not `clean`'s.

Rewrite check: any store of the tag keeps a run's tree findable after its branch is detached or its dir moved.
