## Interface

```
childStarts(source: string, declared: string[] = []): string[] // each call's text, from the callee to its matching ')'
  // callee: a bare (not after '.') spawn*, execFile, execFileSync, execSync, exec or fork, '(' next;
  // a `function` declaration of that name is not a call; nor is a match on a comment line (//, /*, *),
  // nor a call of a non-child_process name in `declared` (functions the scanned trees declare)
EXEMPT: { file: 'deck/run.mjs', callee: 'spawn', inside: 'startPlain', why: string }[]   // the only entry
scanned: every non-test .mjs/.js/.cjs under scripts/, deck/, bin/, hooks/ (not */test/**, not *.test.*)
rule: each childStarts entry outside EXEMPT contains `windowsHide: true`
```

## Tests

1. `childStarts finds multi-line and injected calls`: `childStarts` → on a fixture holding a multi-line `spawn(`, a
   `spawnOpener(`, a `pty.spawn(` and a regex `.exec(`, it returns the first two and not the last two.
2. `every child the pilot starts has its console hidden`: `rule` → red today, naming the 21 unhidden sites
   (`file: call`); green after the edits.
3. `the one exemption is the interactive session`: `EXEMPT` → has exactly one entry, and that call in
   `deck/run.mjs` still matches it (a stale exemption fails).

Rewrite check: if `childStarts` used a JS parser in place of paren-matching, all three results above would stay the same.

## Done

- **Expected**: no pilot command, deck action or script opens a console window on Windows; a new unhidden
  spawn anywhere in those trees fails `npm test` and names its file and call.
- **Verification**: `node --test scripts/test/hidden-spawns.test.mjs scripts/test/install-command.test.mjs`; `npm test`.
- **Evidence**: test 2's red output listing the 21 sites before the edits, then green; full suite green.
  The live check (spec 2, 3) belongs to QA on this machine.
- **Prohibited**: no exemption beyond `startPlain`; no `windowsHide` passed via a shared spread the scan cannot
  see; no changing other options (stdio, shell, timeout) on any call; no new git-runner module (L5).
- **Done when**: tests 1–3 pass, `npm test` is green, and the diff stays under 150 changed lines.
