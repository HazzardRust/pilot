## Interface

```
resolveItem(id, resolution, author)   // gate1 | gate2 with chosenOf(item) !== SIGN_OFF -> DeckRefusal:
  "<id> is a <kind> the user has not signed: ask them to press Sign off on it, or to Dismiss it there; typed approval does not pass a gate"
fresh reply: { itemId, title, repo, owner, open, kind, ...reply, seq }
gate sentence (both hooks): "A gate passes only on its Sign off press: reply with deck_reply asking for it; never deck_resolve it unsigned."
```

## Tests

1. `deck_resolve on a gate1 with no Sign off is refused naming the press`, and the ticket stays green with no plan.
2. `deck_resolve on a gate1 whose reply is typed approval is refused`.
3. `deck_resolve on a gate2 with no Sign off is refused`.
4. `a pressed Sign off still resolves the gate and moves the ticket` (kept behaviour).
5. `the inbox notice on a gate reply asks for the press and does not say close it with deck_resolve`.
6. `the stop gate's reason on a gate item asks for the press`, and a `deck_reply` still ends the turn.
