# S1 Voice is measurable from a run's transcripts

Feature `crew-voice-rules` · delivers spec 2, 3, 5 (the measure) · source: `../architecture.md` §2, L3, L11 · after: –

## Files owned

- `deck/transcripts.mjs`: gains one export that sizes a run's text without returning it.
- `scripts/measure-voice.mjs` (new): the CLI that prints the voice table for a run slug.
- `scripts/test/measure-voice.test.mjs` (new): the pins, over a fixture transcript.

## Interface

```
voiceOf(repo: string, slug: string, opts?: { projectsRoot?: string }) -> {
  agents: Array<{ agent: string, turns: number, textBytesMedian: number }>,
  deck: Array<{ kind: string, count: number, bodyBytesMedian: number }>  // deck_post by kind, deck_reply as 'reply'
}
node scripts/measure-voice.mjs --slug <slug> [--repo <dir>] [--json]
```

A turn is one assistant message with a text block; `textBytes` is the sum of that
message's text blocks. A deck body is the `body` input of a `deck_post` or `deck_reply`
tool_use. Run selection is `readRun`'s (A4 of transcripts).

## Tests

1. `counts assistant text bytes per turn, not tool output`: a fixture with a tool_result of 10 kB leaves textBytes unaffected.
2. `groups deck bodies by kind and replies as reply`: two questions and one reply give two rows.
3. `returns no text`: the result's JSON contains none of the fixture's words.
4. `a message seen twice counts once`: the same message.id at two sizes counts the larger, as readRun does.

## Done

- **Expected**: `node scripts/measure-voice.mjs --slug start-end-session` prints the per-agent
  median text bytes per turn and the per-kind deck body medians for that past run. This is the baseline.
- **Verification**: `node --test scripts/test/measure-voice.test.mjs`; `npm test`; the command above.
- **Evidence**: the baseline table, pasted into the PR body.
- **Prohibited**: returning or logging any transcript text; a second transcript parser beside transcripts.mjs.
- **Done when**: the tests pass and the baseline table for one real past run is in the PR.
