# S5 The deck refuses an unshaped ticket

Feature `crew-voice-rules` · delivers spec 14 · source: `../architecture.md` §2, L12, A8 · after: S1

## Files owned

- `deck/ticket-shape.mjs` (new): the pure shape check.
- `deck/store.mjs`: `postItem` calls it for `kind: ticket` beside the question-length check.
- `deck/tools.mjs`: `deck_post`'s description names the ticket shape.
- `deck/testUtils.mjs`: a `shapedTicketBody()` helper for tests.
- `deck/test/ticket-shape.test.mjs` (new): the pins.
- The deck tests that post tickets, moved to `shapedTicketBody()`: `audit-pick`, `card-history`, `chain`,
  `dismiss-item`, `make-tickets`, `move`, `parallel`, `small-flight`, `small`, `standing`, `ticket-tool`.

## Interface

```
ticketShapeGaps(body: string, opts: { size?: 'small' }) -> string[]   // [] when shaped; else each gap named
  gaps: 'the user's words quoted (a > line)', 'numbered spec lines', 'evidence in italics on line <n>',
        'the thread id (itm_…)', '## Answered before posting (small ticket)'
  passes whole when body names docs/design/<slug>/architecture.md   // run-split tickets, A8
postItem refusal: DeckRefusal("a ticket's body is not in ticket-making's shape; missing: <gaps joined>")
```

## Tests

1. `an unshaped body is refused naming every gap`: the plain sentence body gives all four gaps.
2. `a shaped body is stored`.
3. `a small ticket without Answered before posting is refused`.
4. `a run-split ticket naming its artefact is stored`.
5. `the refusal comes before anything is written`: the deck file is unchanged after a refusal.

## Done

- **Expected**: posting a ticket whose body is "fix the thing" is refused with a message listing what
  is missing; a body in the ticket-making shape lands in the queue.
- **Verification**: `node --test deck/test/ticket-shape.test.mjs`; `npm test`; with the daemon up, one `deck_post` of each kind against a scratch deck.
- **Evidence**: the refusal text seen from a real post; the full suite green.
- **Prohibited**: loosening the check to make old tests pass instead of moving them to the helper; a flag that skips the check.
- **Done when**: the five tests and the full suite pass, and the diff is under 400 lines (stop and ask past it).
