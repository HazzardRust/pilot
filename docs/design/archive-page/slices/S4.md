Feature `archive-page` · delivers spec 3, 6 · source: `../architecture.md` §2, §3 Seams, §5 L4, §6 A7 · after: S1 (record-kind seam)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — three adapters on S1's fixed `ArchiveKind` shape, every field named here, no trust boundary.

## Files owned

- `deck/archive-kinds/reports.mjs` (new): settled `report` items as rows.
- `deck/archive-kinds/handoffs.mjs` (new): settled `handoff` and `crew-handoff` items as rows.
- `deck/archive-kinds/threads.mjs` (new): every other settled item kind (question, walkthrough, signoff, gate1, gate2, chat, user, audit, lesson) as rows.
- `deck/test/archive-items.test.mjs` (new): the pins.

## Interface

```
S1's ArchiveKind, S1's ArchiveRow, S1's ArchiveSource
reports  : ArchiveKind  // kind 'report', files ['deck.json', 'deck.archive-*.json']; fields Ticket, Feature, Landed, Posted, Body
handoffs : ArchiveKind  // kind 'handoff'; fields Kind, Next ticket, Resolution, Posted, Closed, Body
threads  : ArchiveKind  // kind 'thread'; fields Kind, Ticket, Resolution, Replies (count), Posted, Closed, Body
// each rowsOf(source) takes settled items only (resolvedAt set, A7); href `/archive/<id>`; at = lastSaidAt
```

## Behaviours

1. `a closing report reads as named fields` (test): `reports` → a seeded report gives one row of kind `report` with Ticket and Feature labels and no `{"`.
2. `both hand-off kinds are one kind` (test): `handoffs` → one `handoff` and one `crew-handoff`, both settled, give 2 rows; an open one gives none.
3. `each item is listed once` (test): `threads` → over a store of every item kind, no id appears under two kinds across tickets, reports, handoffs and threads.
4. `archived items are included` (test): `reports` → a report only in a month file is a row.

Rewrite check: storing reports in a separate file keeps 1-4 if `rowsOf` still reads them.
Misses: how a long body reads; QA's walkthrough reads the page.
