# S9 Deck and wrapper logs, line by line

Feature `archive-page` · delivers spec 3, 6, 8 · source: `../architecture.md` §2, §5 L5, §6 A6 · after: S1 (record-kind seam)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — free-text logs can echo a caller's field, the secrets trigger.

## Files owned

- `deck/archive-kinds/textlogs.mjs` (new): newest 2,000 lines of `deck.log`, `wrapper.log`, `wrapper.log.old`.
- `deck/test/archive-textlogs.test.mjs` (new): the pins.

## Interface

```
S1's ArchiveKind, S1's archiveRows
textlogs : ArchiveKind  // kind 'log', files ['deck.log', 'wrapper.log', 'wrapper.log.old']
         // id `<file>:<line n>`; at the line's leading ISO stamp, else the file's mtime (A6)
         // fields File, Line; title the line clipped to 120 chars
LOG_TAIL = 2000
```

## Behaviours

1. `each line is a row with its time` (test): `textlogs` → a `wrapper.log` of 3 stamped lines gives 3 rows at those times.
2. `only the newest 2,000 lines` (test): `textlogs` → a 2,500-line `deck.log` gives 2,000 rows, the last line included.
3. `a token in a log line is withheld` (test): `archiveRows` → a `deck.log` line holding `Bearer` and a token reads `<withheld: credential>`.
4. `the raw test logs stay unread` (test): `archiveRows` → a planted `logs/x.log` holding a token: no row, and the file is never opened (spy).

Rewrite check: structured JSON logs later keep 1-4 with the same labels.
Misses: secret shapes beyond `findCredential`; the security reviewer reads it.
