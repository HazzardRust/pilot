## Files owned

- `deck/credential.mjs`: the 'secret assigned to a name' rule split into a short-value and a long-value rule; the flags and vendor prefixes below.
- `deck/test/classifier-log.test.mjs`: its table of credential shapes, the prose that stays as it was, and the 64 KiB probes.

## Interface

```
findCredential(text: string) : string | null   // unchanged signature; the shape's name, or null
```

## Behaviours

1. `each shape S13's review left open is caught` (test): `findCredential`, through `appendRefusal`/`readRefusals` → each reads back `<withheld: credential>`: a short value (6+ chars with a non-letter) or a long one (16+ with a digit or mixed case) under a camelCase (`apiKey`, `clientSecret`) or plural (`secrets`, `tokens`, `passwords`) name, a value holding `.@!#%*`; `--secret <v>`, `--pass <v>`, `docker login -p <v>`, `redis-cli -a <v>`, `htpasswd -b <file> <user> <v>`; an `hf_`, `SG.`, `pypi-`, `shpat_`, `sbp_`, `lin_api_`, `whsec_`, `ya29.` token, an `AccountKey=` value, and an `Authorization: Basic` value with no digit.
2. `prose and code that must pass stay null` (test): `findCredential` → every S13 B2 row, `sk-learn-pipeline`, and five rows of ordinary prose about tokens and secrets read back as they were.
3. `the scan stays linear` (test): `findCredential` → a 64 KiB adversarial string aimed at each added or changed rule is checked in under 50 ms.

Rewrite check: a credential check moved to a scanner library keeps 1-3 if `findCredential` calls it.
Misses: vendor shapes not listed here; a value of letters only (the `--password` rule's precedent) or digits only under a name.
Fails closed: prose or code with a digit in the value after a name (`token: v1.2.3-beta`, `secret: e2e-tests`, `secret: rotate-quarterly-per-policy-doc-v2`, `const token = this.state.token1;`) is refused; the rule cannot tell it from a password.
