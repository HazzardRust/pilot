# S6 The classifier log, credentials withheld

Feature `archive-page` · delivers spec 3, 6, 8 · source: `../architecture.md` §2, §5 L4-L5 · after: S1 (record-kind seam)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the log holds commands an agent tried to run, the secrets trigger.

## Files owned

- `deck/archive-kinds/classifier.mjs` (new): one row per classifier refusal.
- `deck/test/archive-classifier.test.mjs` (new): the pins.

## Interface

```
S1's ArchiveKind, S1's archiveRows
classifier : ArchiveKind  // kind 'classifier', files ['classifier.log']; reads through readRefusals({ dir })
           // id `classifier:<line n>`; at when; title `<verdict>: <tool>`
           // fields Verdict, Repo, Ticket, Agent, Tool, Command, Reason
```

## Behaviours

1. `a refusal reads as its fields` (test): `classifier` → a seeded line gives one row with Verdict, Tool and Command labels.
2. `a token is withheld on the page` (test): `archiveRows` → a planted line whose `command` holds `sk-` plus 40 characters, written raw past `appendRefusal`, gives Command `<withheld: credential>`, and the token appears nowhere in `/archive`'s HTML.
3. `a torn line is skipped, not fatal` (test): `classifier` → a log with one torn line among 2 good ones gives 2 rows.
4. `no log is no rows` (test): `classifier` → 0 rows and no throw without `classifier.log`.

Rewrite check: a log moved to SQLite keeps 1-4 if `rowsOf` reads it.
Misses: credential shapes `findCredential` does not know; the security reviewer reads the pattern list.

## Done

- **Expected**: every classifier refusal is on the page; a credential in one reads withheld.
- **Verification**: `node --test deck/test/archive-classifier.test.mjs`; `npm test`.
- **Evidence**: behaviour 2 red with withholding disabled, green after; 1, 3, 4 output.
- **Prohibited**: no second credential filter in the adapter; no reading `classifier.log` around `readRefusals`; no skipping withholding for one field.
- **Done when**: the four behaviours hold and `npm test` is green.
