## Behaviours

1. `a trace line reads as its fields` (test): `trace` → a seeded crew `posted` line gives one row with Kind, Step and Item labels.
2. `the rotated file is read too` (test): `trace` → 2 lines in `handoff-trace.jsonl` and 1 in `.old` give 3 rows.
3. `a torn line is skipped, not fatal` (test): `trace` → `not json` between 2 good lines gives 2 rows.
4. `no file is no rows` (test): `trace` → 0 rows and no throw without either file.

Rewrite check: a trace moved to the deck store keeps 1-4 if `rowsOf` reads it.
Misses: step names a later writer adds; the coverage test (S10) and the fundamentalist read the writers.
