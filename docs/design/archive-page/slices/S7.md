## Files owned

- `deck/archive-kinds/usage.mjs` (new): one row per `usage.jsonl` window.
- `deck/archive-kinds/memory.mjs` (new): one row per `memory.jsonl` sample.
- `deck/test/archive-telemetry.test.mjs` (new): the pins.

## Interface

```
S1's ArchiveKind, S1's ArchiveSource
usage  : ArchiveKind  // kind 'usage', files ['usage.jsonl']; at window.to
       // fields From, To, Session %, Weekly %, Tokens, By model, By repo, Error (snapshotError)
memory : ArchiveKind  // kind 'memory', files ['memory.jsonl']; at at
       // fields Process, Pid, Event, RSS (MB), Free (MB)
```

## Behaviours

1. `a usage window reads as numbers with labels` (test): `usage` → a seeded window gives one row with Session % and Tokens; By model reads `name: n` pairs, no `{"`.
2. `a window without a snapshot says why` (test): `usage` → `snapshot: null` gives Error with its `snapshotError`.
3. `memory samples are rows in MB` (test): `memory` → a seeded sample with rss 104857600 reads RSS `100`.
4. `torn lines skipped` (test): `memory` → 1 torn line among 2 good gives 2 rows.

Rewrite check: rotating either file keeps 1-4.
Misses: whether hundreds of memory samples bury the rest; the kind filter and the walkthrough answer it.
