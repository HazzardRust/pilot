# S8 Audit reports and switch files

Feature `archive-page` · delivers spec 3, 6 · source: `../architecture.md` §2, §3, §5 L4, §6 A2 · after: S1 (record-kind seam)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — two adapters over fixed JSON files, fields named here.

## Files owned

- `deck/archive-kinds/audits.mjs` (new): each `audits/<repo>/<stamp>.json` report and each `record.json`.
- `deck/archive-kinds/switches.mjs` (new): `alerts.json`, `usage-log.json`, `start-settings.json`, one row each.
- `deck/test/archive-audits.test.mjs` (new): the pins.

## Interface

```
S1's ArchiveKind, S1's ArchiveSource
audits   : ArchiveKind  // kind 'audit-file', files ['audits/*/*.json']; at startedAt ?? file mtime
         // report fields Repo, Started, Rows (n), Top rows (first 5, `what — size`); record fields Repo, Offers, Hand-offs
switches : ArchiveKind  // kind 'switch', files ['alerts.json', 'usage-log.json', 'start-settings.json']; at file mtime
         // one field per top-level key, nested objects as `key: value` lines
```

## Behaviours

1. `an audit report reads as its top rows` (test): `audits` → a seeded report with 7 rows gives one row, Rows `7`, 5 Top rows.
2. `the audit record is its own row` (test): `audits` → a `record.json` gives Offers and Hand-offs counts.
3. `each switch file is one labelled row` (test): `switches` → the three files give 3 rows; `alerts.json` `{weekly:false}` reads Weekly `false`.
4. `a missing switch file is no row` (test): `switches` → only `alerts.json` present gives 1 row.

Rewrite check: moving audits out of `audits/` keeps 1-2 if `files` is updated.
Misses: `.md` audit renderings, which duplicate the JSON; the coverage list (S10) names them.
