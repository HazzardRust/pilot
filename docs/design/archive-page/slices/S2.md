## Behaviours

1. `a ticket's detail joins its thread, plan and report` (test): `archiveDetail` → a seeded closed ticket with 2 replies, a plan and a report gives 2 replies, the plan's fields and the report's title.
2. `an archived ticket opens too` (test): `archiveDetail` → a ticket only in a month file gives its title and report.
3. `opening a detail writes nothing` (test): `archiveDetail` → for an item carrying a `notice`, `deck.json`'s sha256 is unchanged and the notice stays.
4. `a press opens the detail and Back returns` (test): `regions::archive_detail::draw` → after clicking `archive-row-<id>`, `archive-detail` shows the report title; `archive-back` draws the list again.
5. `the detail reads as named fields and markdown` (look): the user opens one closed ticket on the Rune deck.

Rewrite check: replacing the join with a stored index keeps 1-3.
Misses: very long reports' layout; the walkthrough looks.
