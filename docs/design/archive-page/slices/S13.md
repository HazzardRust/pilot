## Files owned

- `deck/credential.mjs`: `CREDENTIAL_SHAPES` gains the shapes below.
- `deck/test/classifier-log.test.mjs`: its table of credential shapes, the plain commands that stay as they were, and the 64 KiB probes.

## Interface

```
findCredential(text: string) : string | null   // unchanged signature; the shape's name, or null
```

## Behaviours

1. `each missed shape is caught` (test): `findCredential`, through `appendRefusal`/`readRefusals` → each of these reads back `<withheld: credential>`: a `glpat-`, `npm_`, `AIza` and `dop_v1_` token; `Authorization: token <v>`; `--token <v>`, `--token=<v>`, `--api-key <v>`, `--api-key=<v>`; `_authToken=<v>`; `sshpass -p <v>`; `mysql -p<v>`; a quoted JSON key `"password":"<v>"`.
2. `prose and code that must pass stay null` (test): `findCredential` → `const apiKey = process.env.PILOT_API_KEY;`, `the token field … secret rotation`, `TOKEN_LIMIT=4096`, `--token-limit 5`, `mysql -p` alone, `mysql -p mydb`, `sshpass -e ssh -p 22 host`, `--token $GH_TOKEN`, and a JSON `"password": ""` read back as they were.
3. `the scan stays linear` (test): `findCredential` → each 64 KiB adversarial string aimed at a new shape is checked in under 50 ms.

Rewrite check: a credential check moved to a scanner library keeps 1-3 if `findCredential` calls it.
Misses: vendor shapes not listed here; a password spelt only in letters after a quoted JSON key (the `--password` rule's precedent).
