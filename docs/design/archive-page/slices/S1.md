## Interface

```
ArchiveSource = { dir: string, deck: object, months: object[] }   // read once per request, no readDeck
ArchiveKind   = { kind: string, label: string, files: string[], rowsOf(source: ArchiveSource): ArchiveRow[] }
ArchiveRow    = { kind: string, id: string, at: string|null, title: string, fields: { label: string, value: string, markdown?: true }[] }
archiveRows(dir?: string): ArchiveRow[]        // every kind's rows, every string through findCredential
archiveKinds(): ArchiveKind[]                  // read from deck/archive-kinds/*.mjs (L4)
NEVER_SHOWN: string[]                          // 'deck.secret', 'deck-open.html', 'logs/*.log'
archivedItems(): object[]                      // store-archive.mjs, every month file
archive region (view JSON, screen=archive):    // {} on any other screen
  { kinds: [{ kind, label, count }], days: [{ key, heading, open, rows: ArchiveRow[] }] }
GET /api/view?screen=archive[&id=<id>]         // never calls seeThread
GET /api/view?screen=home                      // its archive region is {}; archiveRows not called
strip.archive = { here: boolean }
regions::archive::draw(region, &Archive, cx)   // rows keyed `archive-row-<id>`, sections `archive-day-<key>`
regions::strip::archive_page(s: &mut State)    // go(Query { screen: "archive", id: None, .. })
```

## Behaviours

1. `closed tickets from both stores are rows` (test): `archiveRows` → a scratch store with 3 closed tickets, 1 only in a month file, gives exactly 3 `tickets` rows and no open ticket.
2. `rows sit in daySections' sections` (test): `GET /api/view?screen=archive` → the `archive` region's headings and counts equal `daySections` on the same dates.
3. `the screen writes nothing` (test): `GET /api/view?screen=archive` → the sha256 of `deck.json` and the month file are unchanged, and an item's `notice` survives `&id=<that id>`.
4. `a credential is withheld and never-shown files are not read` (test): `archiveRows` → a ticket title holding `sk-` plus 40 characters reads `<withheld: credential>`; a read spy sees no `NEVER_SHOWN` path.
5. `the Archive button opens the screen` (test): `regions::strip::archive_page` → after a click on `strip-archive` against a scratch daemon, `archive-day-<key>` and 3 `archive-row-<id>` keys are drawn, each with its fields' labels as text, and no "No finished threads yet." text.
6. `other screens never read the archive` (test): `GET /api/view?screen=home` → the `archive` region is `{}` and a read spy sees no month file or log opened by `archiveRows`.
7. `the user opens it on the running Rune deck` (look): Archive beside Items, the closed tickets under Today / day / month.

Rewrite check: replacing the month-file reader with a database keeps 1-3; replacing `regions::archive` keeps 5's keys.
Misses: how a long list scrolls and reads; the walkthrough looks.
