S1's archive region, S1's regions::archive::draw

## Behaviours

1. `a date sort gives the exact order both ways` (test): `sort_rows` → 5 rows over 3 days, Date ascending then descending, match the two fixed orders.
2. `search leaves exactly a ticket's rows` (test): `filter_rows` → searching one ticket title leaves its 2 rows and empties every other section.
3. `a kind filter shows exactly its count` (test): `filter_rows` → kind `tickets` leaves the region's `kinds` count for it.
4. `typing filters with no request` (test): `regions::archive::draw` → typing into `archive-search` changes the drawn rows and the scratch daemon's request count is unchanged.
5. `a frame stays under 50 ms at real scale` (test): `regions::archive::draw` → a recorded view of 10,000 rows with only Today open frames in under 50 ms, 3 runs.

Rewrite check: moving sort into the server keeps 1-3 on the same inputs.
Misses: how the search feels to type; the walkthrough looks.
