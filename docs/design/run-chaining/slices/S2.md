## Tests

1. `Create starts no process`: `/create` with no live run leaves `deck/launch.mjs` unimported and no spawn stub called.
2. `a created thread waits until the pilot's first reply`: `isQueued` true, then false after one pilot write.
3. `a live pilot on the repository hears a created thread`: `deck_wait` returns its first message.
4. `deck_launch is an unknown tool`: `/api/tool` refuses it by name.
5. `no pilot prompt or tool list names deck_launch or headless`: `pilot-agents.test.mjs`.
6. `the pilot share falls`: record the new number from `measure-prompt.mjs` in the PR body.
