## Interface

```
// deck/run-env.mjs
/** The pilot lines, appended after "$defaults"; constant, no string read from disk (spec 2, L3, L4). */
export const CLASSIFIER_ENVIRONMENT: readonly string[]
/** The off switch's variable name; the value "off" omits the block (A3). */
export const CLASSIFIER_SWITCH = 'PILOT_CLASSIFIER_ENV'
runSettings(level, pluginRoot?, { home?, env? = process.env }) -> { settings: { ..., autoMode?: { environment: string[] } }, addDirs, env }
startArgs(reach, { settingsFile?, home?, env? = process.env }) -> string[]
```

## Behaviours

1. `every level writes the pilot lines after the defaults` (test): `runSettings` → for nothing, rules, everything: `autoMode.environment[0] === "$defaults"`, the rest equal `CLASSIFIER_ENVIRONMENT`, one line names `<repo>-*` and git worktree, one names git-ignored build output.
2. `the prose is the same from any repo` (test): `startArgs` → two scratch homes, Starts from two repo dirs: the two files' `autoMode` byte-identical.
3. `it loosens no rule` (test): `CLASSIFIER_ENVIRONMENT` → `autoMode` keys exactly `["environment"]`; every line matching delete/remove/rm also names git-ignored and worktree; no line has `rm -rf`, `any file` or a path.
4. `the user's settings are untouched` (test): `startArgs` → a scratch home with `.claude/settings.json` carrying its own `autoMode`: its bytes equal before and after.
5. `the off switch omits the block` (test): `runSettings` → `env: { PILOT_CLASSIFIER_ENV: 'off' }`: no `autoMode`; other keys deep-equal the switched-on settings.
6. `Claude Code reads it` (run): `claude --settings <scratch start-settings.json> auto-mode config` lists the pilot lines last; `claude auto-mode critique` output read, the pilot lines' remarks quoted in the report.

Rewrite check: any composer that keeps the block in the one `--settings` file keeps 1-5.
Misses: whether the classifier actually allows more; QA runs spec 6 in a live pilot session and the user's runs show it.

## Done

  lines; `auto-mode config` shows them; `PILOT_CLASSIFIER_ENV=off` drops them; user settings untouched.
- **Verification**: `node --test deck/test/classifier-env.test.mjs deck/test/start-session.test.mjs deck/test/pilot-start.test.mjs`; `npm test`; behaviour 6's two commands.
- **Evidence**: 1-5 red before `CLASSIFIER_ENVIRONMENT` exists, green after; behaviour 6's output in the report.
- **Prohibited**: no string from `cwd`, `home`, git or the repo in the prose; no `allow`/`soft_deny`/`hard_deny`
  key; no write to `~/.claude/settings.json`; tests never read the real `process.env` or real home.
- **Done when**: 1-6 hold and `npm test` is green.
