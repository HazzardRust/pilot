## Behaviours

1. `no autoMode block passes` (test): `autoModeRow` → `{}`: verdict pass.
2. `a block keeping the defaults passes` (test): `autoModeRow` → `environment: ["$defaults", "x"]`: pass.
3. `a block dropping them fails and names the fix` (test): `autoModeRow` → `environment: ["x"]`: fail, detail names `environment`, a step names `claude auto-mode reset`.
4. `unreadable settings cannot tell` (test): `autoModeRow` → `null`: cannot tell.
5. `doctor shows it` (run): `pilot doctor` on this machine prints the row failing on today's user block.

Rewrite check: any reader that checks each set list for "$defaults" keeps 1-4.
Misses: whether dropping defaults was the user's intent; the step tells them, never acts.
