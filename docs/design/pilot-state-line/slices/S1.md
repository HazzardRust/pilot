## Tests

1. `an open hand-off reads handing off from its postedAt`: `pilotStateOf` → `{ state: 'handing off', since: postedAt }`.
2. `a crew-handoff is not the pilot's`: `pilotStateOf` → not `handing off`.
3. `a held wait reads listening from its start`: `pilotStateOf` → `listening`, since the held time.
4. `an ended tab reads no session`: `pilotStateOf` → `no session`.
5. `the line names the live ticket or says none`: `pilotStateOf` → `ticket` is `liveTicketOf`'s title, else null.
6. `the line sits under the last card`: `renderHomePage` → `pilot-state` after the last card.
7. `an empty tab shows the line under Nothing is waiting on you`: `renderHomePage` → both, in that order.
8. `the line escapes the ticket title and carries a time`: `renderStateLine` → escaped title, `<time datetime=…>`.

Rewrite check: whatever reads the signals, a planted item, held map or ended tab yields the same state word and time.
