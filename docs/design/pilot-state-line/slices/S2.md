## Interface

```
// deck/pilot-state.mjs
export const PICKED_UP_MS = 5 * 60_000
export const WORKING_MS = 10 * 60_000
S1's pilotStateOf, now also:
  newest `handoff` in tab.repo resolved within PICKED_UP_MS -> 'picked up', since resolvedAt
  newest of max(tab.runs[].lastSeenAt) within WORKING_MS, or any tab.agents entry (signal at `now`) -> 'working', since it;
    until = lastSeenAt + WORKING_MS when a write holds it alone, null while an agent does (the roster sweep announces its departure)
  (seam change 2026-10-15, co-pilot: listAgents() in deck/agents.mjs returns only { agentType, since }; a roster agent is
   seen within LIVE_WINDOW_MS, inside WORKING_MS, so its presence is the signal. Moves no spec line or locked decision.)
  live tab, none of these -> 'quiet', since the newest signal
  until: the ms at which the state's window lapses, or null
  // `until` removed in the principles round: no reader; S4 computes its own lapse.
```

## Tests

1. `a hand-off resolved four minutes ago reads picked up`: `pilotStateOf` → `picked up`, since `resolvedAt`.
2. `a hand-off resolved six minutes ago does not`: `pilotStateOf` → not `picked up`.
3. `a deck write nine minutes ago reads working`: `pilotStateOf` → `working`, since `lastSeenAt`.
4. `a live crew agent reads working`: `pilotStateOf` → `working` with no recent write.
5. `a live run silent for eleven minutes reads quiet`: `pilotStateOf` → `quiet`.
6. `precedence holds`: `pilotStateOf` → open hand-off over a held wait over a pickup over a write.
7. `until is the window's lapse`: `pilotStateOf` → `until` = `resolvedAt + PICKED_UP_MS` for a pickup.

Rewrite check: any implementation keeps the same word at each planted clock offset and the same precedence.
