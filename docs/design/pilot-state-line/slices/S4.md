## Tests

1. `a pickup's lapse announces once`: `armStateTimers` → one `changed` at `resolvedAt + PICKED_UP_MS`.
2. `a write's lapse announces once`: `armStateTimers` → one `changed` at `lastSeenAt + WORKING_MS`.
3. `arming twice keeps one timer`: `armStateTimers` → still one `changed` per lapse.
4. `a lapse already past arms nothing`: `armStateTimers` → no timer.

Rewrite check: any scheduler keeps one page refresh per lapse and none for a past one.
