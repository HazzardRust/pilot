## Tests

1. `a hold records when it began and a second hold keeps it`: `heldWaits` → the first hold's time.
2. `the last release empties the repository`: `heldWaits` → no key after both releases.
3. `quietAt still treats a held kind as now`: `quietAt` → `now + LIVE_WINDOW_MS` while held.
4. `first hold and last release announce, the middle ones do not`: `holdWait` → the watcher called twice.
5. `a parked deck_wait turns the tab's line to listening`: `GET /` → `data-pilot-state="listening"`, then not once it returns.

Rewrite check: replacing the Map with any registry keeps a parked wait visible as `listening` and gone on return.
