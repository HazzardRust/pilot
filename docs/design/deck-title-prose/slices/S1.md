## Interface

```
deck.css    .ref { … }                 // tinted chip, box-decoration-break: clone; no nowrap, no text-overflow
render.mjs  setOff(text: string): string            // <span class="ref">escaped text</span>
            ticketLink(ticket, cls?: string): string    // <a class="ref[ cls]" href="/thread/<id>">escaped title</a>
            titleOf(item, items): string            // escaped title; a chain hand-off whose title is exactly
                                                    // `Next run: ${ticket.title}` (ticket = items[item.next]) gives
                                                    // "Next run: " + setOff(ticket.title)
            renderAsked(item, items): string        // each link carries class="ref"
thread.html slots: TITLE (plain, for <title>), HEADING (titleOf, for the <h2>)
```

## Tests

1. `a card's ticket line wraps the ticket title`: `ticketLink` → the kind line holds `<a class="ref ticket" href="/thread/<ticket>">`.
2. `the thread header's ticket line and a gate's Ticket row wrap it too`: `ticketLink` → both carry `class="ref`.
3. `Waits on wraps each question title`: `renderAsked` → every link in `.asked` carries `class="ref"`.
4. `Switch to wraps the ticket title`: `setOff` → the sure step reads `Switch to <span class="ref">…</span>?`.
5. `a chain hand-off's card, heading and notices set its ticket off`: `titleOf` → "Next run: " then a `ref` span with the ticket title, on the card h2, the thread h2 and both notice rows.
6. `a hand-off whose ticket was renamed, or a plain hand-off, is drawn plain`: `titleOf` → no `ref`, escaped title.
7. `the tab title stays plain text`: `titleOf` → `<title>` holds no `<span`.
8. `a 120-character title is drawn whole and escaped`: `setOff` → all 120 characters inside the span, `<b>` escaped.
9. `one stylesheet rule`: `.ref` → `deck.css` holds exactly one `.ref` selector, and its block has no `nowrap` or `text-overflow`.

Rewrite check: if the helpers were rewritten, every placed title would still come out of the renderer inside one `class="ref"` element, styled by one rule.
