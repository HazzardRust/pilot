## Interface

```
readFlow(readme: string): { nodes: string[], edges: { from: string, to: string, label: string }[] }
  // parses the first mermaid fence under "## How it fits together"; throws if there is none
moving subcommands: run, handoff, integrate, sync, land, landing, wait, tickets, ready
  // the test names the non-moving rest (deck, base, worktrees, branches, audit, analytics, logging, budget, ps, gc, doctor)
```

## Tests

1. `every agent file is a node`: `readFlow` → each `agents/*.md` name (reviewers and helpers inside the one listed node) appears in `nodes`.
2. `every moving subcommand is a node`: `readFlow` → each subcommand `pilot help` prints is a node or in the named non-moving list.
3. `every edge is labelled`: `readFlow` → no edge has an empty `label`.
4. `a fence is required`: `readFlow` → throws on a README with no mermaid fence under the heading.

Rewrite check: re-laying the graph out (other direction, other node ids) keeps all four results, because they read names and labels, not positions.
