## Interface

```
GET /api/view?screen=home|thread|items&run=&all=1&ticket=&id=  -> 200 View | 404 { error }   // behind the secret
View = { screen: string, seq: number, regions: { [region: string]: object } }
viewOf(reads: DeckReads, query: ViewQuery): View          // deck/view/index.mjs, pure
```

## Behaviours

1. `the view names every region of the screen` (test): `viewOf` → for `screen=home`, `regions` holds all 14 region names.
2. `the view route is behind the secret` (test): `GET /api/view` → 401 without a bearer; 200 `View` with it.
3. `the client refuses a non-loopback base` (test): `Client::from_env` → `Err` for host `example.com`; no request made.
4. `an unknown kind still has its tab counted` (test): `viewOf` → a `steps` item on a run counts in its tab.
5. `the window shows the scratch deck's tabs` (test): `Client::view` → against a scratch daemon, drawn headless, `rt.elements()` holds each tab's `code` text.
6. `the window opens` (run): `cargo run --release` with the user's deck up shows the tab strip; `--snap` PNG in the PR.

Rewrite check: any client reading the view over loopback with the secret keeps 2, 3 and 5.
Misses: whether Rune builds on CI runners; S19 reads that. Region looks; each region slice.
