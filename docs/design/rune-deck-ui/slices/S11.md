# S11 The chat panel

Feature `rune-deck-ui` · delivers spec 2, 3, 4 · source: `../architecture.md` §2, §3 · after: S5 (`Action::Reply`)
Reviewers: `pilot:rust-reviewer`, `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the send box is user input, the security trigger.

## Files owned

- `deck/view/chat.mjs`: the chat region of the selected deck.
- `deck/test/view-chat.test.mjs` (new): the view pins.
- `deck/rune/src/regions/chat.rs`: messages stuck to the bottom, the send box.
- `deck/rune/tests/chat.rs` (new): the pins.

## Interface

```
chatView(reads, query): { id?: string, messages: { by, at, text }[] }   // id: the deck's chat thread
chat::Local { draft: TextEdit, at_bottom: bool }
```

## Behaviours

1. `the chat is the page's` (test): `chatView` → the messages `renderChat` draws, in order.
2. `a sent line lands` (test): `chat::Local` → Enter posts one `Action::Reply` to the chat id; the draft empties on `Taken`.
3. `a new message keeps the reader's place` (test): `chat::Local` → at the bottom, a new message scrolls to it; scrolled up, the offset stays.

Rewrite check: any chat panel sending through the reply route keeps 2-3.
Misses: long-message wrapping; the user's look.

## Done

- **Expected**: the chat panel reads and sends as on the page.
- **Verification**: `node --test deck/test/view-chat.test.mjs`; `cargo test --manifest-path deck/rune/Cargo.toml --test chat`; `npm test`.
- **Evidence**: 1-3 red before, green after.
- **Prohibited**: no second send path; no draft on disk; no spacing literal, `theme::space` only (L10).
- **Done when**: 1-3 hold and `npm test` is green.

## Seam change (co-pilot, 2026-11-20)

The send box posts off the UI thread: `Client::act` on a spawned thread into a slot in `chat::Local`, and S11 adds one
call, `regions::chat::settle(s)`, to `app::poll` (S1's file, ~4 lines) so a `Taken` empties the draft. S7's option
press, if moved off the thread, takes the same shape (`regions::queue::settle`). Moves no spec line and no locked
decision; unifying the two is left to the principles review.
