## Behaviours

1. `the walk is the page's walk` (test): `threadView` → `nav.prev`, `nav.next` and `position` equal `renderThreadPage`'s for open and `all=1`.
2. `reading a thread clears its notice` (test): `threadView` → via `/api/view?screen=thread`, a closed thread's notice is gone and one change announced.
3. `an unknown kind reads` (test): `threadView` → a `steps` thread's body, messages and kind line.
4. `Escape goes back` (test): `regions::thread::draw` → an Escape key moves `State.query` to the owning deck's screen.

Rewrite check: any thread view walking the overview's order keeps 1 and 3.
Misses: how markdown tables look; the user's look.
