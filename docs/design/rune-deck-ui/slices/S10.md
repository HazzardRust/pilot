Feature `rune-deck-ui` · delivers spec 2, 3 · source: `../architecture.md` §2, §6 A4 · after: S6 (`DeckAction::ClearNotice`)
Reviewers: `pilot:rust-reviewer`, `pilot:typescript-reviewer`

## Files owned

- `deck/view/notifications.mjs`: notices and open threads with each one's write count.
- `deck/test/view-notifications.test.mjs` (new): the view pins.
- `deck/rune/src/prefs.rs`: `Prefs` load and save.
- `deck/rune/src/regions/notifications.rs`: the panel, badge, ×, Mark all seen.
- `deck/rune/tests/notifications.rs` (new): the pins.

## Interface

```
notificationsView(reads, query): { notices: { id, title, href, at }[], open: { id, title, href, writes }[] }
Prefs { seen: Map<id, u32>, folds: Map<repo, Set<String>>, open_panels: Set<String>,
        sizes: Map<String, (f32, f32)>, hidden_reports: Set<id> }
Prefs::load(dir: &Path) -> Prefs   // ~/.claude/pilot/rune-deck.json; missing or bad file -> default
Prefs::save(&self, dir: &Path) -> Result<()>   // write-then-rename
```

## Behaviours

1. `the notices are the page's` (test): `notificationsView` → the ids `renderNotifications` draws.
2. `prefs survive a restart` (test): `Prefs::save` → `Prefs::load` returns the same values; a corrupt file loads default.
3. `seen hides until the next write` (test): `Prefs::load` → an open thread marked seen at 3 writes is hidden at 3 and back at 4.
4. `× and Mark all seen clear the deck's notices` (test): `notificationsView` → empty after `ClearNotice` and `ClearNotices` on a scratch daemon.

Rewrite check: any prefs store round-tripping the fields keeps 2-3.
Misses: the badge's look; the user's look.
