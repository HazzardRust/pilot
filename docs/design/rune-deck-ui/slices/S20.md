# S20 The panels open, close and resize with springs, and stay as left

Feature `rune-deck-ui` · delivers spec 2, 5, 6d, 6e · source: `../architecture.md` §2, §5 L10, §6 A4, A5 · after: S10 (`Prefs`)
Reviewers: `pilot:rust-reviewer`
Model: opus — the feel the user asked for lives here, and A4 is assumed.

## Files owned

- `deck/rune/src/layout.rs`: the left strip's six panels and the right strip, stacked, springing, resizable; each panel's header with its count.
- `deck/rune/tests/layout.rs` (new): the pins.

## Interface

```
layout::strips(state: &State, cx: &mut Cx<State>) -> El
layout::toggle(prefs: &mut Prefs, panel: &str)          // open set, saved
layout::resize(prefs: &mut Prefs, panel: &str, size: (f32, f32))   // per deck scope, saved on release
layout::count_cell: 4ch   // a header's count, right-aligned, one line, `999+` past 999
```

Seam (co-pilot, during S20): `strips` takes no centre column, so it draws the whole window (left strip, `app::center`, right strip) and `app::view` delegates to it; the right strip S17 drew at the column foot now stands at the window's right edge. The first toggle stores a `"~"` marker in `open_panels` so a user who shut every panel is told apart from a first start. Sizes are kept per panel name for the window. No spec line or locked decision moves.

## Behaviours

1. `chat and status open by default` (test): `layout::strips` → with empty `Prefs`, those two panels are open.
2. `a panel opens with a spring` (test): `layout::toggle` → over the next frames its height passes through values between closed and open.
3. `open panels and sizes survive a restart` (test): `layout::resize` → saved sizes and the open set come back from `Prefs::load`.
4. `a drag tracks the pointer` (test): `layout::resize` → a scripted drag across the default size gives monotonic frame sizes, each within 1 px of the pointer, no snap at the default (the user's bug).
5. `a three-digit count moves nothing` (test): `layout::count_cell` → panel bounds at a notification count of 99 and of 100 are identical; the header is one line (the user's bug).
6. `the panels feel right` (look): open, close and drag on the walkthrough.

Rewrite check: any layout saving the open set and sizes keeps 1 and 3.
Misses: the taste call; the user's look.

## Done

- **Expected**: the side panels move like a modern app's and stay as the user left them.
- **Verification**: `cargo test --manifest-path deck/rune/Cargo.toml --test layout`; `npm test`.
- **Evidence**: 1-5 red before, green after; `--snap` frames of an opening panel.
- **Prohibited**: no spring or snap during a drag; no header width taken from the count's text; no instant toggle in place of the spring; no prefs saved per frame; no spacing literal, `theme::space` only (L10).
- **Done when**: 1-6 hold and `npm test` is green.
