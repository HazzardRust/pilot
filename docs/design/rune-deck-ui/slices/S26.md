## Behaviours

1. `every control hovers` test: on the overview, an open thread and the items page (the existing fixtures), every element in the headless tree with a press handler or the button role reports a hover colour and `Cursor::Pointer`. 0 that do not.
2. `plain text is still` test: a body text and a label in the same trees have no hover colour.
3. `theme` test: every colour still equals deck.css, light and dark. No type, spacing or radius is compared.
4. Every existing behaviour replay stays green unchanged.
5. *added (feedback 15)* `tab order` test: from the reply box's input, Tab reaches the reply buttons and Shift+Tab comes back. `theme::control` sets `.focusable(true)`, and the app turns on Rune's `App::tab_visits_controls(true)` (rune app.rs:247); main.rs is in scope for it.
