## Interface

```
regions::reports::draw   // S1's draw signature
listAgents(now): { [repoKey]: { agentType, since, lastSeen }[] }   // lastSeen added (L11)
agentsView(reads, query): { agents: { name, kind, model?, since, quietS, quiet }[] }   // quietS: whole s since lastSeen; quiet: quietS >= 30
reportsView(reads, query): { reports: { id, title, href, at }[] }
```

## Behaviours

1. `the agents are the roster` (test): `agentsView` → the agents `renderAgents` draws for a fixture roster.
2. `the reports are the page's` (test): `reportsView` → the reports the page's Reports tab lists.
3. `a hidden report stays hidden` (test): `regions::reports::draw` → an id in `Prefs.hidden_reports` is not drawn; × adds it.
4. `each agent row shows its last-seen age and dims when quiet` (test): `agentsView` → for a roster seen 5 s and 45 s ago, `quietS` 5 and 45, `quiet` false then true; an agent seen 91 s ago absent.

Rewrite check: any panels listing the same ids keep 1-2; any roster keeping the 90 s window keeps 4's ages and the absent agent.
Misses: the user's look, and how the dim reads; QA's walkthrough reads it.
