# S19 `npm test` and CI run the Rune deck's tests

Feature `rune-deck-ui` · delivers spec 7, 8 · source: `../architecture.md` §2, §6 A3 · after: S1 (`deck/rune/Cargo.toml`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — CI configuration and a process start in the gate, and A3 is assumed.

## Files owned

- `scripts/gate.mjs`: runs `cargo test` for the Rune deck when cargo is on PATH, else one skip line; inside
  `runGate`'s home-store window (after `storeStat`, before `homeStoreLine`) with `gateEnv`'s env, its status
  joined to the landed return (home-store-guard L1, L4).
- `scripts/test/gate-cargo.test.mjs` (new): the pins.
- `.github/workflows/ci.yml`: one `windows-latest` job with Rust.

## Interface

```
cargoStep(env, which: (cmd) => string | null): { command, args } | { skip: string }
  // { command: 'cargo', args: ['test', '--manifest-path', 'deck/rune/Cargo.toml'] } or
  // { skip: 'rune deck: cargo not on PATH, skipped' }
```

Seam (co-pilot, during S19): `cargoStep(env, which, platform = hostPlatform())`; `command` is the absolute path `which` found, never the bare `cargo` (security: Windows resolves a bare name in the cwd first), absolute PATH directories and `cargo.exe` only, through `onSearchPath`. Off win32 it skips (`rune deck: cargo test runs on Windows only, skipped`), and a gate started inside the gate skips; ci.yml's windows job is the CI evidence. No spec line or locked decision moves.

## Behaviours

1. `cargo runs where it is` (test): `cargoStep` → with cargo found, the command above, `windowsHide` set.
2. `no cargo is one skip line` (test): `cargoStep` → with none, the skip line; the gate's exit is the suite's.
3. `a failing Rune test fails the gate` (run): a deliberately broken region on a branch makes `npm test` exit non-zero.
4. `CI builds the Rune deck` (run): the workflow's Windows job builds and tests on the PR; whether it paints headless is recorded.
5. `no pilot file names Rune` (read): `git grep -i rune -- agents rules skills` prints nothing.

Rewrite check: any gate step that runs cargo when present and skips loudly keeps 1-2.
Misses: macOS and Linux CI; out of scope.

## Done

- **Expected**: a broken Rune screen turns the gate red where Rust is installed and in CI.
- **Verification**: `node --test scripts/test/gate-cargo.test.mjs`; `npm test`; the CI run.
- **Evidence**: 1-2 red before, green after; the broken-branch exit; the CI log.
- **Prohibited**: no cargo run outside the home-store window or without the guard env, so a Rust test's
  scratch daemon cannot write `~/.claude/pilot/deck.json` unseen; no silent skip; no network fetch in the gate beyond cargo's own; no secret in the workflow.
- **Done when**: 1-5 hold and `npm test` is green.
