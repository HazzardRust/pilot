## Behaviours

1. `the queue is the page's queue` (test): `queueView` → the same ids in the same order as `renderHomePage`'s cards for a fixture store.
2. `labels come from the server` (test): `queueView` → a `steps` item's card carries its kind and state strings.
3. `a card draws its parts` (test): `regions::queue::card` → title, state line, excerpt and each option label in `rt.elements()`.
4. `an option press is sent once` (test): `regions::queue::card` → two presses in one frame post one `Action::Reply`; the button shows sent.
5. `the lane lines are columns in phase order` (test): `queueView` → for the user's three lanes, planning then implementing then concluding; drawn, each line's state, name and time start at one x.
6. `a card arrives with a spring` (look): a new card slides in; `--snap` frames in the PR.
