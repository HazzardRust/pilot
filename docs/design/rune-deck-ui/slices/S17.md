## Behaviours

1. `the controls are the page's` (test): `stripView` → Start, Close and the repo list exactly where `renderEverything` draws them.
2. `create checks the name before Next` (test): `strip::Local` → a name outside `[A-Za-z0-9 _-]{1,60}` keeps Next disabled.
3. `the toggle flips the scope` (test): `regions::strip::draw` → Open/All sets `State.query.all`.
4. `a create opens the new thread` (test): `strip::Local` → Confirm posts `Create`; the `Taken` location's thread is the next screen.

Rewrite check: any strip showing the page's controls keeps 1 and 3.
Misses: Start opening a terminal; QA's walkthrough.
