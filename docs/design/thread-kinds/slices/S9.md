# S9 Silence on a hand-off is a state

Feature `thread-kinds` · delivers spec 19, 21 · source: `../architecture.md` §2, §4, F12, L7, A8 · after: S3, S4, S8

## Files owned

- `deck/items.mjs`: `HANDOFF_ACK_MS` (3 min) and `isUnacknowledged`; `threadState` returns `unacknowledged` for such an item.
- `deck/server.mjs`: one `setTimeout(announceChange, …).unref()` per open hand-off at its `postedAt + HANDOFF_ACK_MS`, modelled on the due timers (`:520-575`), so the page repaints when it crosses.
- `deck/tabs.mjs`: `tab.unacknowledged` true when the tab's directory has one.
- `deck/ui/render.mjs`: `STATE_BUCKETS` entry for `unacknowledged`; the tab strip's mark.
- `deck/ui/deck.css`: the state's colour.
- `deck/test/handoff-unacked.test.mjs` (new).

## Interface

```
// deck/items.mjs
export const HANDOFF_ACK_MS = 3 * 60 * 1000;
export function isUnacknowledged(item, now = Date.now()): boolean
// open, kind 'handoff', no message from the pilot, now - postedAt >= HANDOFF_ACK_MS;
// a chain hand-off resolved by the lane is not open, so never unacknowledged (spec 21)

```

## Tests

1. `a hand-off 3 min old with no pilot message is unacknowledged`; `2 min old is not`.
2. `a pilot reply ends it`; `a resolved chain hand-off is never unacknowledged`.
3. `threadState names it and the card and thread draw it`.
4. `the tab carries unacknowledged while one is open in its directory`.
5. `the daemon repaints when a hand-off crosses the interval` (fake clock).
