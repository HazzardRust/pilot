## Interface

```
// deck/items.mjs
export function cycleStartOf(items, repo): string | null
// ISO time of the newest of: a small ticket's startedAt in repo; a `handoff` (never a crew-handoff),
// a `question` or a `gate1` posted while the phase of the items before it was concluding
S2's runPhaseOf(items, repo): reads gate threads posted at or after cycleStartOf
```

A `crew-handoff` is a crew agent's, mid-slice; it never resets. A hand-off, question or gate1 posted while planning
or implementing is not a cycle start (L13: yellow holds, the user's answer on itm_497c0390c3ae). The `spec` kind is
retired by S12 (L15), so no spec trigger exists; a `gate1` posted while concluding is both the cycle start and,
once signed, the move to implementing.

## Tests

1. `a hand-off posted while concluding resets the phase to planning`.
2. `a hand-off posted while implementing leaves it implementing` (L13).
3. `a question posted while concluding resets to planning; a question while planning changes nothing`.
4. `a gate1 posted while concluding resets to planning, and signing it moves to implementing`.
5. `a small ticket started after a gate2 resets to planning`.
6. `a gate1 signed after the reset moves it to implementing again` (the old run's gates no longer count).
7. `a crew-handoff never resets`.
