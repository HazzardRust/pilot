# S4 A gate thread draws its evidence block

Feature `thread-kinds` · delivers spec 13 · source: `../architecture.md` §2, F10, L5 · after: S1

## Files owned

- `deck/ui/render.mjs`: `KIND_RENDERERS[gate1|gate2].detail` draws the kind's fields as the `<dl class="detail">` `renderWalkthroughDetail` draws (artefact path, SHA, locked count, slice table for Gate 1; PR link, walkthrough id linking its thread, tip SHA for Gate 2); the type note from S1's `GATE_NOTES` shown as for other kinds.
- `deck/ui/deck.css`: a gate card's accent, one rule per kind if the existing detail styles do not cover the slice table.
- `deck/test/gate-render.test.mjs` (new).

## Tests

1. `a gate1 card's detail lists artefact, sha, locked and slices as dt/dd pairs`.
2. `a gate2 card's detail links the walkthrough id to its thread and the PR`.
3. `a gate card draws Sign off and Not yet and no Dismiss`.
4. `a field value is escaped` (a `<` in the slice table renders as text).
