## Interface

```
rulesLedgerText(root: string): string
  // the rendered scripts/shipped-rules.json for the checkout at root: every rules/ blob in
  // history plus the working tree, one line per path; throws on a shallow clone
node scripts/build-rules-ledger.mjs [--check]   // unchanged: writes, or exits 1 when stale
```

## Tests

1. `a rule edited in the working tree adds its hash`: `rulesLedgerText` → on a temp repo with `rules/a.md` committed and then edited, the text lists both hashes under `a.md`.
2. `the repository's own ledger is what the builder renders`: `rulesLedgerText` → equals `scripts/shipped-rules.json` at `ROOT`.
3. `a shallow clone is refused`: `rulesLedgerText` → throws, naming the shallow clone.

Rewrite check: replacing the history walk with any other reader of the same blobs keeps all three results above.
