# S3 A hold past 20 minutes types the /clear anyway

Feature `held-handoff` · delivers spec 4, 6 · source: `../architecture.md` §2, §5 L4-L6 · after: S2 (`holdFor`, `deck/run.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — a timer in the watch loop beside the cooldown, and an ADR reversal to word.

## Files owned

- `deck/run.mjs`: `HOLD_BOUND_MS`; `holdFor`'s bound; `clearOnce` takes `now` and `wake`; `watch` keeps one bound timer.
- `deck/test/run.test.mjs`: the faked-clock pins.
- `docs/adr/0089-a-chain-hand-off-waits-for-the-co-pilots-release.md`: an Amended paragraph, the bound in place of "no time bound".
- `docs/adr/README.md`: regenerated by `npm run adr-index`.

## Interface

```
HOLD_BOUND_MS = 20 * 60 * 1000
S2's holdFor, widened:
  -> { clear: true, why: 'free' | 'rearmed' | 'bound', since } | { clear: false, ticket, until: number }
  // until = earliest hold.at among cwd's open hand-offs + HOLD_BOUND_MS; 'bound' once now >= until
clearOnce({ ..., now = Date.now, wake = (at: number) => {} })   // wake(until) on every hold
```

## Tests

1. `a hold under 20 minutes stays held`: `holdFor` → `clear: false` at 19:59 with `until` at 20:00.
2. `a hold at 20 minutes clears with the co-pilot live`: `holdFor` → `{ clear: true, why: 'bound' }`.
3. `the bound counts from the earliest held hand-off in the directory`: `holdFor` → `until` from the oldest `hold.at`.
4. `the bound fires on a timer with no change event`: `clearOnce` → `wake(until)` called, and `watch`'s timer types `/clear` after it.
5. `the forced /clear is logged with the live ticket`: `clearOnce` → wrapper.log `run: hold on <id> past 20 min, typed /clear with the co-pilot on <ticket> live`.

Rewrite check: any implementation that keeps the clock in the items, not in memory, gives the same `until` after a wrapper restart.

## Done

- **Expected**: a held hand-off whose co-pilot never hands back gets its `/clear` 20 minutes after the first hold, with nobody pressing anything.
- **Verification**: `node --test deck/test/run.test.mjs`; `npm run adr-index`; `git diff --exit-code docs/adr/README.md`; `npm test`.
- **Evidence**: the faked-clock tests failing first; ADR 0089's status line `amended`.
- **Prohibited**: no real 20-minute wait in a test; no second timer beside `lookWhenCool`'s when one bound timer will do; no TTL on the co-pilot entry.
- **Done when**: the five tests pass, the ADR reads amended and the gate is green.
