## Tests

1. `a live entry is named`: `yellowNotice` → `a co-pilot is live on itm_x` and `spawn none`.
2. `no entry, or a released one, keeps may have survived`: `yellowNotice` → the current text.
3. `the ticket id outside the fence is shape-checked`: `yellowNotice` → no live line for a `coPilot.ticket` that is not `itm_\w+`.
4. `pilot.md tells the fresh session to adopt`: `agents/pilot.md` → its first-turn rule names `SendMessage`, `spawn none` and `release`.

Rewrite check: any notice text that names the live ticket and says spawn none passes tests 1 and 4.
