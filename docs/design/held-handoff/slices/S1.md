## Files owned

- `deck/ui/render-cards.mjs`: the `held` state label beside `unacknowledged` (:254).

## Interface

```
markHold(id: string, ticket: string): boolean      // true when it wrote; keeps the first `at`; refuses a non-handoff or a closed item
POST /api/hold { id, ticket } -> 200 { held: boolean }   // announceChange() only when held is true
item.hold: { ticket: string, at: string /* ISO */ }
noteFor(item) -> "held: /clear waits on <ticket>'s co-pilot" when item.hold and open
threadState(item) -> 'held' when item.hold, before 'unacknowledged'
isUnacknowledged(item) -> false when item.hold
```

## Tests

1. `a held hand-off's card reads held`: `noteFor` → `held: /clear waits on itm_x's co-pilot`, not "A fresh session picks this up".
2. `a hold is written once`: `markHold` → true then false, and `hold.at` is the first call's time.
3. `a held hand-off's press carries no pickedUpAt`: `markHold` → the press `addReply` then stores has no `pickedUpAt`.
4. `a held thread reads held, not unacknowledged`: `threadState` → `held` past `HANDOFF_ACK_MS`.
5. `the route refuses a cross-site write`: `POST /api/hold` → 403 with a foreign Origin.
6. `the wrapper marks the hold and logs the same ticket`: `POST /api/hold` → called with the co-pilot's ticket; wrapper.log `run: held <id> for the co-pilot on <ticket>`.

Rewrite check: storing the hold anywhere other than on the item keeps the card line, the `held` state and the absent `pickedUpAt`.
