# S2 Handoff failed on a held hand-off re-arms the /clear

Feature `held-handoff` · delivers spec 3 · source: `../architecture.md` §2, §5 L3 · after: S1 (`deck/store-items.mjs`, `deck/run.mjs`, `item.hold`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — `holdFor` is the seam S3 and the landing ticket build on, and the turn-end ordering is easy to get wrong.

## Files owned

- `deck/store-items.mjs`: `addReply`'s Handoff failed branch sets `hold.rearmedAt` on a held hand-off.
- `deck/items.mjs`: `noteFor` reads `re-armed: /clear at the next turn end` when `hold.rearmedAt`.
- `deck/run.mjs`: `holdFor` (new, exported) replaces the inline live check; `clearOnce` waits past `rearmedAt`.
- `deck/test/handoff-hold.test.mjs`: the press pins.
- `deck/test/run.test.mjs`: the re-arm pins.

## Interface

```
item.hold: { ticket, at, rearmedAt?: string /* ISO, the press's time */ }
addReply(id, 'Handoff failed') on a held hand-off -> sets hold.rearmedAt; no pickedUpAt
noteFor(item) -> "re-armed: /clear at the next turn end" when item.hold.rearmedAt
holdFor(items: object[], cwd: string, coPilot: { ticket, live, at } | null, now: number)
  -> { clear: true, why: 'free' | 'rearmed', since: number }   // since: the turn end must come after it
   | { clear: false, ticket: string }
// 'rearmed' when any open hand-off of cwd carries hold.rearmedAt, whatever coPilot says
```

## Tests

1. `the press on a held hand-off re-arms it`: `addReply` → `hold.rearmedAt` set, no `pickedUpAt`.
2. `a re-armed directory clears with the co-pilot live`: `holdFor` → `{ clear: true, why: 'rearmed' }`.
3. `a re-arm on a superseded hand-off clears the newest`: `holdFor` → `clear: true` when only the older item is re-armed.
4. `the re-armed /clear waits for a turn end after the press`: `holdFor` → `since` is `rearmedAt`, and `clearOnce` types nothing before then.
5. `the card says re-armed`: `noteFor` → `re-armed: /clear at the next turn end`.

Rewrite check: any `holdFor` body that reads the same items gives the same `{ clear, why }` for live, free and re-armed.

## Done

- **Expected**: the user presses Handoff failed on a held hand-off; when the session's turn ends the wrapper types `/clear` and the prompt, co-pilot live or not.
- **Verification**: `node --test deck/test/handoff-hold.test.mjs deck/test/run.test.mjs`; `npm test`.
- **Evidence**: tests failing first; wrapper.log `run: re-armed by the user, typed /clear for <id>` in the run test's scratch home.
- **Prohibited**: no `/clear` typed mid-turn on a re-arm; no change to a chain hand-off's ticket put-down on the press (`store-items.mjs:333-344`).
- **Done when**: the five tests pass and the gate is green.
