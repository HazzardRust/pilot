# S1 A slice file's tests are checked for seam-first shape (walking skeleton)

Feature `deep-modules` · delivers spec 1 · source: `../architecture.md` §2, §3 Seams, L2–L4 · after: –

## Files owned

- `scripts/check-slices.mjs` (new): checks slice-file text for the seam-first shape; CLI over paths.
- `scripts/test/check-slices.test.mjs` (new): the seam's tests.
- `scripts/test/fixtures/slices/*.md` (new): one good slice file and one per broken rule.
- `skills/vertical-slicing/SKILL.md`: Tests row says the seam-first shape and the rewrite check; worked example converted.
- `scripts/test/slice-interface.test.mjs`: the worked-example regexes replaced by one `checkSlice` call.

## Interface

```
checkSlice(text: string): Problem[]       // [] when the slice file is seam-first
type Problem = { line: number, rule: Rule, message: string }
type Rule = 'tests-shape' | 'symbol-not-in-interface' | 'rewrite-check' | 'length'
node scripts/check-slices.mjs <path>...   // a dir means its *.md; a SKILL.md means its ````markdown example
  exit 0: "<n> slice file(s) checked"; exit 1: one "<file>:<line> <rule> <message>" per problem
Tests line: 1. `<name>`: `<Interface symbol>` → <observable result>
Rewrite check: <what stays true if the implementation behind the interface were replaced>
```

## Tests

1. `a seam-first slice file has no problems`: `checkSlice` → `[]` for `fixtures/slices/good.md`.
2. `a test naming no symbol is refused`: `checkSlice` → one `tests-shape` problem at that line.
3. `a symbol absent from the Interface block is refused`: `checkSlice` → one `symbol-not-in-interface` naming it.
4. `a slice file without a rewrite check is refused`: `checkSlice` → one `rewrite-check` problem.
5. `a 61-line slice file is refused`: `checkSlice` → one `length` problem.
6. `the CLI exits 1 and names each problem`: `check-slices` → exit 1, one line per fixture problem.
7. `the skill's worked example is seam-first`: `check-slices` → exit 0 on `skills/vertical-slicing/SKILL.md`.

Rewrite check: replacing `checkSlice`'s parser (regex for a markdown walker) keeps every result above.

## Done

- **Expected**: anyone can run one command on a slice directory and be told which test lines
  name no seam, which seams are missing from the Interface block, and whether the rewrite
  check and the 60-line cap hold.
- **Verification**: `node --test scripts/test/check-slices.test.mjs scripts/test/slice-interface.test.mjs`;
  `node scripts/check-slices.mjs scripts/test/fixtures/slices skills/vertical-slicing/SKILL.md`; `npm test`.
- **Evidence**: tests 1–7 red before `check-slices.mjs` exists, green after; the CLI output on
  the fixtures read, one line per bad fixture.
- **Prohibited**: no check that passes on the bad fixtures by matching only the first test line;
  no edit to the anatomy's ten field names (pinned); no retrofitting other features' slice files.
- **Done when**: `npm test` is green and `check-slices` exits 0 on the skill and 1 on the fixtures.
