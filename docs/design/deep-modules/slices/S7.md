3. `the pilot's context notice is what the guard prints`: `hooks/post-tool.js` → the notice read from its stdout for a pilot payload.
4. `the hand-off notice opens with the pickup mark`: `notice` → it starts with `PICKUP_MARK` for a pending hand-off.

green while the text a model receives is unchanged.
