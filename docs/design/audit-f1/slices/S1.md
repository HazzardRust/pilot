## Tests

1. `the pilot tip ahead of HEAD is answered`: `pilotTip` → `{ ref: 'origin/pilot', sha: <tip>, behind: 3 }`.
2. `the run remote and local mode name their ref`: `pilotTip` → `fork/pilot` under `pilot.remote=fork`, `pilot` under `none`.
3. `a bad remote, no repo and no ref answer null`: `pilotTip` → null three times, nothing thrown.
4. `fetch reads the remote's newer tip, offline keeps the tracking ref`: `pilotTip` → remote sha; old sha with the remote unreachable.
5. `the auditor cuts at the CLI's sha and records base`: `auditor cut` → prompt matches `pilot-tip.mjs --fetch` and `base`, not `… HEAD$`.
6. `the audit item names its base`: `renderReport` → `at origin/pilot <sha>`; without `base`, today's line.

Rewrite check: replacing the git calls behind `pilotTip` with another ref reader keeps tests 1-4, and the CLI line keeps 5.
