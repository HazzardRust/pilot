# S2 A session start in a stale checkout warns once

Feature `audit-f1` · delivers spec 2, 4, 5 · source: `../architecture.md` §2, §3, §5 L2-L5 · after: S1 (scripts/pilot-tip.mjs)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new SessionStart hook in `hooks/hooks.json` reads hook stdin, the security trigger.

## Files owned

- `scripts/pilot-tip.mjs`: `BEHIND_BAR`, `staleNotice`, the `--session-start` mode.
- `hooks/hooks.json`: entry `start:any:stale-checkout`, timeout 5.
- `hooks/test/stale-checkout.test.js` (new): the script spawned by absolute path over temp repos, stdin a SessionStart payload.

## Interface

```
// scripts/pilot-tip.mjs (adds to S1's pilotTip)
export const BEHIND_BAR = 100
export function staleNotice(tip): object | null
  // tip.behind > BEHIND_BAR -> { systemMessage: line, hookSpecificOutput: { hookEventName: 'SessionStart', additionalContext: line } }
  // line: "This checkout is <n> commits behind <ref> (<short sha>): cut a worktree from <ref> before working here."
// CLI: node scripts/pilot-tip.mjs --session-start   stdin: hook payload { cwd, ... }; cwd falls back to process.cwd()
  // stdout: JSON.stringify(staleNotice(pilotTip({ cwd }))) or nothing; exit 0 always; never fetches
// hooks.json SessionStart: { id: 'start:any:stale-checkout', command: 'node "${CLAUDE_PLUGIN_ROOT}/scripts/pilot-tip.mjs" --session-start', timeout: 5 }
```

## Tests

1. `the bar is strictly over 100`: `staleNotice` → a notice at 101, null at 100 and 99.
2. `a stale checkout prints one line`: `--session-start` → stdout JSON whose `systemMessage` names `101` and `origin/pilot`, one line.
3. `no pilot ref, no repo, bad remote: silent`: `--session-start` → empty stdout, exit 0, each case.
4. `the hook is registered`: `hooks.json SessionStart` → the entry by id with that command and timeout 5.

Rewrite check: any ref reader behind `pilotTip` keeps tests 1-3; the line's wording may change, the count and ref may not.
