# S1 Walking skeleton: a no-verdict whose reissue runs leaves no thread

Feature `blocked-steps` · delivers spec 1, 3, 4 · source: `../architecture.md` §2, §3, §5 L1-L3 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a hook (`hooks/`) decides what reaches the user, the security trigger.

## Files owned

- `hooks/lib/blocked.js`: `postBlocked` takes `source: 'no-verdict'`; the first sight of a `(session, key)` writes a marker and posts nothing; a second within `WINDOW_MS` posts with the `denied` lead.
- `hooks/permission-denied.js`: `reason === 'Classifier unavailable'` (exact) → `source: 'no-verdict'`, keyed by the tool input (L3); exports `isFileTool`.
- `hooks/permission-refuse.js`: a file-tool prompt is still denied, but `post` is not called.
- `hooks/hooks.json`: the two descriptions say so.
- `hooks/test/permission-denied.test.js`: the no-verdict pins.
- `hooks/test/permission-refuse.test.js`: the file-tool pin.

## Interface

```
postBlocked(step: { repo, session, command, reason, agent, source: 'denied'|'refused'|'no-verdict', key?: string }, deps?) -> Promise<string|null>
  // 'no-verdict': null on first sight of (session, key ?? command) in WINDOW_MS; posts on the second
onDenied(payload, deps?) -> Promise<null>
isFileTool(toolName: string) -> boolean   // Edit, Write, NotebookEdit
decide(payload, deps?) -> Promise<{ hookSpecificOutput } | null>   // file tool: deny, no post
NO_VERDICT = 'Classifier unavailable'
```

## Tests

1. `a no-verdict whose reissue ran posts nothing`: `onDenied` → one no-verdict payload, 0 `deck.post` calls.
2. `a second no-verdict of the same call posts once`: `onDenied` → two identical no-verdicts, 1 post, its body's lead the `denied` one.
3. `two different SendMessage no-verdicts are two calls`: `onDenied` → two no-verdicts with different `tool_input`, 0 posts.
4. `a refusal with a verdict still posts at once`: `onDenied` → reason `[Merge Without Review]`, 1 post; reason `The server-side auto mode classifier judged this action dangerous (it gave no explanation)`, 1 post.
5. `a refused file-edit prompt posts nothing`: `decide` → crew `Edit` payload, deny output, 0 posts; crew `Bash`, deny, 1 post.
6. `the file tools are one list`: `isFileTool` → true for `Edit`, `Write`, `NotebookEdit`; false for `Bash`.

Rewrite check: storing the first-sight marker anywhere else keeps 1-4; moving the file-tool test keeps 5-6.
