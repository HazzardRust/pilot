# S4 A scratch clone lands on PILOT_BRANCH with no file edit

Feature `blocked-steps` · delivers spec 7 · source: `../architecture.md` §2, §3, §6 A4 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it chooses which branch `land` pushes (a push guard), and spec 7 is assumed (A4).

## Files owned

- `scripts/pilot-branch.mjs`: `PILOT_BRANCH` read once from `process.env.PILOT_BRANCH`, default `pilot`; a value failing `PLAIN`, or starting `refs/`/`heads/`, throws at import naming the env. `assertPushable` unchanged.
- `scripts/test/pilot-branch-env.test.mjs` (new): the pins, each in a child process with its env.
- `bin/pilot.mjs`: `pilot help`'s environment block lists `PILOT_BRANCH`.

## Interface

```
PILOT_BRANCH: string   // process.env.PILOT_BRANCH || 'pilot'; PLAIN-checked
assertPushable(ref, { git }) -> void   // unchanged: refuses the remote's default branch
pilot help  -> environment block names PILOT_BRANCH
```

## Tests

1. `the env names the pilot branch`: `PILOT_BRANCH` → `qa-scratch` with the env set, `pilot` without.
2. `a bad name is refused at start`: `PILOT_BRANCH` → `--all` or `a..b` throws naming `PILOT_BRANCH`.
3. `the default branch stays refused`: `assertPushable` → with `PILOT_BRANCH=main` and a bare remote whose HEAD is `main`, `ensurePilotBranch` throws `refusing to push`.
4. `help names the env`: `pilot help` → prints `PILOT_BRANCH`.

Rewrite check: reading the env per call instead of at import keeps 1-4.

## Done

- **Expected**: QA sets `PILOT_BRANCH=<scratch>` in its clone's shell and `pilot base`, `integrate` and `land` use that branch, with no file edit; `main` is still refused.
- **Verification**: `node --test scripts/test/pilot-branch-env.test.mjs`; `npm test`; in a scratch clone with a bare remote, `PILOT_BRANCH=qa-scratch pilot base`.
- **Evidence**: tests red before, green after; the scratch `pilot base` line quoted.
- **Prohibited**: no `PILOT_DEFAULT_BRANCH`; no change to `assertPushable` or `remoteDefaultBranch`; no push to the real origin from a test.
- **Done when**: tests 1-4 pass and `npm test` is green.
