# S3 The install allows the read-only pilot commands and the source-tree scratch deck

Feature `blocked-steps` · delivers spec 5, 6 · source: `../architecture.md` §2, §3, §5 L4, §6 A3, A6 · after: S8 (`scripts/install-permissions.mjs`: `PILOT_MERGE_ALLOW`, `isOwnAllow`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it widens what runs unreviewed machine-wide (`settings.json`), the security trigger.

## Files owned

- `scripts/install-permissions.mjs`: five rules appended to S7's `PILOT_MERGE_ALLOW` with a comment line naming this feature; `Bash(node bin/pilot.mjs ` added to the own-rule prefixes behind S7's `isOwnAllow`, so uninstall removes it. A3 and A6 are the user's answers (2026-11-17).
- `scripts/test/install-allow-reads.test.mjs` (new): the pins, modelled on `install-allow-gc.test.mjs`.
- `docs/INSTALL.md`: the allow-rule list gains the five.
- `docs/adr/NNNN-blocked-steps.md` (new): amends ADR 0110: read-only pilot commands and the source-tree scratch deck are allowed; no `git` rule (A6).

## Interface

```
PILOT_MERGE_ALLOW += [
  'Bash(pilot wait)', 'Bash(pilot wait *)', 'Bash(pilot budget)', 'Bash(pilot tickets)',
  'Bash(node bin/pilot.mjs deck --scratch *)',
]
installSettings({ settingsPath, pluginRoot, pilotMerge: true }) -> report.pilotMerge.{ added, covered, alreadyPresent }
removeOwnSettings({ settingsPath }) -> removes every rule isOwnAllow claims
S7's isOwnAllow(rule) -> boolean   // + 'Bash(node bin/pilot.mjs '
```

## Tests

1. `the install writes the five rules`: `installSettings` → each in `permissions.allow` and in `report.pilotMerge.added`, once.
2. `nothing wider`: `installSettings` → no `Bash(pilot *)`, no `Bash(node *)`, no `Bash(node bin/pilot.mjs *)`, no `Bash(git` rule.
3. `a user's deny on pilot wait wins`: `installSettings` → `Bash(pilot wait *)` absent, in `covered`, named in notes.
4. `a second install adds nothing`: `installSettings` → byte-identical file, `changed: false`.
5. `the doctor names a missing read rule`: `PILOT_MERGE_ALLOW` → `deck/doctor.mjs`'s check over a settings file without `Bash(pilot wait *)` names it.
6. `uninstall removes the node-spelling rule`: `removeOwnSettings` → no `Bash(node bin/pilot.mjs` rule remains; a user's own `Bash(node foo.js)` stays.

Rewrite check: moving the rules to their own list and step keeps 1-6.

## Done

- **Expected**: after `pilot install`, `pilot wait`, `pilot budget`, `pilot tickets` and `node bin/pilot.mjs deck --scratch …` never reach the classifier in auto mode; a deny or ask of the user's still wins; uninstall takes all five back.
- **Verification**: `node --test scripts/test/install-allow-reads.test.mjs scripts/test/install-allow-gc.test.mjs`; `npm test`; `pilot install --settings <scratch>` then read the file.
- **Evidence**: tests red before, green after; the scratch settings file's allow list quoted in the PR.
- **Prohibited**: no wildcard wider than the five; no rule written to the user's real `~/.claude/settings.json` by a test; no change to `--repair`; no rule in `install-settings.mjs` itself.
- **Done when**: tests 1-6 pass, `npm test` is green, and the ADR names ADR 0110 as amended.

## Seam (co-pilot, during build)

The ADR stays `NNNN-…` until landing (ADR 0167); 0184 collided with handoff-books.
