## Interface

```
conflictLine({ head: string, onto: string, paths: string[], dir: string }) -> string
  // '<head> conflicts with <onto> in <paths>; the lander resolves in <dir>'; each caller adds its own prefix
LANDER_LINE: RegExp   // captures <dir> from the last '; the lander resolves in <dir>' at the line's end
autoResolves(path: string) -> boolean   // the ADR index, a run.json, the prompt pin: what resolveGenerated settles
```

## Tests

1. `a conflict names the lander and the kept dir`: `conflictLine` → land's exit-3 line ends `; the lander resolves in <checkout>-land-<slug>`.
2. `the deck stores the dir the lander line names`: `LANDER_LINE` → `landing.conflict.dir` is that dir, and a path named `x; the lander resolves in y` does not move it.
3. `the generated files are named once`: `autoResolves` → true for `docs/adr/README.md` and `docs/design/x/run.json`, false for `README.md`.

Rewrite check: any formatter that keeps the line's tail keeps all three results.
