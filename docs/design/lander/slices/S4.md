# S4 A default-branch conflict is kept for the lander and resumes

Feature `lander` · delivers spec 2 · source: `../architecture.md` §3, §5 L3 · after: S2 (`conflictLine`)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — the keep path, the resume and three tests are fixed here; about 100 lines; no security trigger.

## Files owned

- `scripts/integrate.mjs`: `takeDefault` (`:413`) merges in a kept `<checkout>-default-<slug>` instead of resetting in the feat worktree; a re-run resumes a committed merge there.
- `scripts/test/integrate-default.test.mjs`: the conflict case and the resume.

## Interface

```
takeDefault({ cwd, git, head, test, trailers }) -> { line, code }
  // exit 3: 'default NOT taken: origin/<default> conflicts with <head> in <paths>; the lander resolves in <dir>'
  // a re-run with a committed merge in <dir>: after a green test, fast-forwards <head> to it and pushes origin <head>
```

## Tests

1. `a conflict no rule resolves keeps the default worktree for the lander`: `takeDefault` → exit 3; the feat worktree is unchanged and clean, and the dir is mid-merge.
2. `a committed resolution is tested, taken and pushed`: `takeDefault` → `took origin/<default> into <head>`, and the feat tip is the resolution.
3. `a red resolution is not taken`: `takeDefault` → exit 1, with the feat tip unmoved.

Rewrite check: resolving anywhere but the feat worktree keeps all three.

## Done

- **Expected**: QA's integrate step never leaves a half-merge in QA's own worktree; the lander finishes it in the kept one.
- **Verification**: `node --test scripts/test/integrate-default.test.mjs`; `npm test`.
- **Evidence**: test 1 failing before (no dir kept) and passing after.
- **Prohibited**: a forced push; resetting the kept dir; taking a resolution before its test is green.
- **Done when**: the three tests and `npm test` are green.
