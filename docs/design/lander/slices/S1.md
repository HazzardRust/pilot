## Tests

1. `the lander's Land again starts the landing`: `landingReply` → a refused gate2 with a conflict goes `running` on a `lander` reply.
2. `Land again from qa is refused`: `landingReply` → a DeckRefusal naming `qa`.
3. `the lander maps to its kind`: `authorKind` → `'lander'` for `pilot:pilot-lander`.
4. `the lander never pushes pilot`: `agents/pilot-lander.md` → it holds `never git push`, `Land again` and `resolving-merge-conflicts`, and no `pilot land` command line.
5. `the lander never edits destructively mid-merge`: `agents/pilot-lander.md` → it names `sed -i`, `checkout --ours` and `--abort` as never.

Rewrite check: replacing the reply-word parser keeps tests 1-3, as long as the deck answers the same states.
