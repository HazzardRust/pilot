# S14 A run record keeps its own feature name, not the session's

Feature `lander` · delivers spec 12 (added) · source: found issue, verified by the co-pilot · after: –
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — one expression in one function and one new test file, all fixed here; under 40 lines; no security trigger.

## The issue

`deck/store-runs.mjs` `setSlices` keeps the feature name on the session's run (`:590`, `run.feature = name`),
and `upsertRecord` writes `feature: run.feature ?? previous.feature` (`:664`) into whichever slug's record the
call names. One pilot session writes several slugs' records (a co-pilot per ticket), so the last name any call
sent renames every other slug's record on its next call. Seen: `docs/design/lander/run.json` read
`"feature": "Runs on macOS and Linux"`, the mac-linux ticket's name.

## Files owned

- `deck/store-runs.mjs`: `upsertRecord` takes this call's name (`name` from `setSlices`, `undefined` when the
  call sent none) and writes `feature: name ?? previous.feature`. The tab's `run.feature` (`:590`) is unchanged.
  The `recordOf` comment's "the feature is the name the run has" reads "the name this slug was given".
- `deck/test/record-feature.test.mjs` (new).

## Interface

```
upsertRecord(deck, run, table, fields, name)   // name: string | undefined, this call's feature
```

## Tests

1. `a slug keeps its own feature name`: one run; `setSlices(run, rows, 'Alpha', { slug: 'a' })`, then
   `setSlices(run, rows, 'Beta', { slug: 'b' })`, then `setSlices(run, rows, undefined, { slug: 'a' })`:
   record `a` reads `Alpha`, record `b` reads `Beta`. Fails before (record `a` reads `Beta`).
2. `a slug first written without a name stays unnamed`: a call with a slug and no feature after another slug was
   named writes no `feature` from the other slug.

## Done

- **Expected**: one session writing two slugs' records keeps each record's own feature name.
- **Verification**: `node --test deck/test/record-feature.test.mjs`; `npm test`.
- **Evidence**: test 1 failing before and passing after.
- **Prohibited**: changing the tab's name (`run.feature`) or the record's other fields.
- **Done when**: both tests and `npm test` are green.
