## Why it is added

S10's slice file called `deck/closing-report.mjs` new, but gate2-frees-lane already has the deck post the
closing report on `landed` (`closeLanded`, called at `deck/landing.mjs:277,292,351` and from `closeOwed`,
`deck/landing.mjs:414`, run at start-up by `deck/daemon.mjs:223`). That report closes the ticket, so a
lander's `report` after it is refused (`deck/store-items.mjs` `TICKET_STATES_FOR`: report on green only).
The user locked L12 as written: the lander posts it, and there is no orphan fallback. Sized at about 300
changed lines on the deck side, past what S10 could take, with files disjoint from S10's; so it runs as its
own lane beside S10's finish.

## Interface

```
deck/closing-report.mjs  closeLanded(gate2Id, { past }) -> resolves the gate2 only; null when nothing to resolve
                         closingReportOf(record, gate) -> { title, body, screens }   (+ the merge-first human step)
deck_post { kind: 'report', ticket, author: lander }   // no body: the deck fills it from the record, notes REPORT_DUE
```

Kept, not removed (the user's deterministic rule): **a closing report is still needed to close a ticket.** The
deck's rule that a ticket closes only when its report lands, and that a report is refused before its gate2 is
signed (`deck/store-items.mjs:159-215`), stays as it is, and its tests stay green. Only the deck's own report
write on `landed` goes.

## Tests

1. `landed posts no report`: a landing that reaches `landed` resolves the gate2, leaves the ticket open and
   green, posts no `report` and leaves the record unfinished. Fails before (the deck posts it).
2. `the lander's bodiless report is filled from the record`: the lander posts `report` with no body on that
   ticket: it is stored with the landing sha, the merge-first line and each worktree kept in its body,
   closes the ticket, and carries one `REPORT_DUE` line.
3. `the human step names what merges first`: `closingReportOf` with a merge-first PR reads
   `Merge <pr>, then #<this>`; with `merge first: none` it reads `#<this> alone`.
4. `a restart writes no owed report`: a landed gate2 with an open ticket at start-up stays without a report;
   a ready press the restart cut short is still retried.
5. `a report past the ready bound is accepted` (A2): with the ready question open on the ticket, the
   lander's report is still accepted.
