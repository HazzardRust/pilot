# S7 `pilot integrate` deletes the slice it merged

Feature `pilot-fork` · delivers spec 6, 8 · source: `../architecture.md` §2, L4, L5, A1, A2 · after: S3 (integrate.mjs), S6 (deleteMerged)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `scripts/integrate.mjs`: after a successful push, it calls S6's `deleteMerged` for the slice, with `into` set to the feat branch. With a PR it waits up to 30 s for gh to report MERGED; with none it judges by ancestry. The result line ends `; deleted <slice>` or `; kept <slice>: <why>`. Under `none` the slice is local and nothing is deleted (A2).
- `scripts/test/integrate-prune.test.mjs` (new): with gh injected.

## Interface

```
integrate(branch, options & { wait?: number }): { ok, line, failing, code? }
  // line suffix: "; deleted <slice>" | "; kept <slice>: <why>"; --no-push deletes nothing
S6's deleteMerged
```

## Tests

1. `a merged slice is deleted after the push`: `integrate` → the line ends `; deleted slice/x-s1`, and origin no longer lists it.
2. `a PR gh still reads open keeps the branch`: `integrate` → with `wait: 0`, `; kept slice/x-s1: PR #4 open`, and the branch is still on origin.
3. `a red integration deletes nothing`: `integrate` → `ok: false`, and the slice branch is still there.
4. `a PR-less slice on the second remote is deleted by ancestry`: `integrate` → `; deleted slice/x-s1`, and the second remote no longer lists it.

Rewrite check: waiting on a webhook instead of polling keeps all four results.

## Done

- **Expected**: after `pilot integrate slice/…` the slice branch is gone from where it lived, and its PR, if it has one, reads merged. A slice whose PR GitHub has not yet marked merged is kept and named.
- **Verification**: `node --test scripts/test/integrate-prune.test.mjs scripts/test/integrate*.test.mjs`; `npm test`.
- **Evidence**: tests 1, 2 and 4 red before, green after.
- **Prohibited**: no deletion before the push succeeds; no deletion with `--no-push`; no direct `git push --delete`.
- **Done when**: the four tests and the suite are green.
