## Interface

```
deck/rune/release.json: { version: 'x.y.z', tag: string,
  assets: { 'win32-x64'|'darwin-arm64'|'linux-x64': { file: string, sha256: string /* 64 hex */ } } }
readPin(root: string, version: string, target: string): { url, file, sha256 } | { reason: string }
type Host = { platform: string, arch: string, version: string }
type RuneState = { source: 'built'|'fetched', file: string } | { source: null, reason: string, fetchable: boolean }
findRune(root: string, host: Host): RuneState              // sync, never calls the network; deletes a fetched file whose hash differs
type Get = (url: string, opts: { signal: AbortSignal }) => Promise<{ status: number, headers, body: AsyncIterable<Uint8Array> }>
ensureRune(root: string, host: Host, get: Get): Promise<RuneState & { line?: string }>   // the only caller of get
defaultGet: Get                                            // global fetch with redirect: 'manual'
```

## Behaviours

1. `a pinned download is fetched once and then reused` (test): `ensureRune` → first call 1 `get` and `{ source: 'fetched' }`, second call 0 `get`.
2. `a tampered download is never stored` (test): `ensureRune` → with bytes not matching the pin, `{ source: null }`, 0 files in `fetched/`, a line naming both hash prefixes.
3. `a stored file changed on disk is refused at reuse` (test): `findRune` → after one byte flipped, `{ source: null }` and the file deleted.
4. `a local build wins and lookup never downloads` (test): `findRune` → `{ source: 'built' }` with both present; the auto-open path makes 0 `get` calls.
5. `pilot deck names the fetched copy` (run): `node bin/pilot.mjs deck` with a stub `get` in a test prints `open <...>/target/run/pilot-deck-<n>[.exe]`.

Rewrite check: replacing fetch with any HTTP client keeps 0 files stored for bytes that do not match the pin.
Misses: a real GitHub download and a real window; S4's scratch release and QA on HazzardLaptop read them.

## Done

- **Expected**: with a pin for its version and no local build, `pilot deck` downloads once, verifies, stores with mode 0755, and names the fetched copy; a mismatch stores and runs nothing.
- **Verification**: `npm run test:changed -- --since=<base sha>`; `node --test deck/test/rune-bin.test.mjs deck/test/open.test.mjs deck/test/open-copy.test.mjs`.
- **Evidence**: behaviour 2 failing before the hash check exists and passing after; the test output.
- **Prohibited**: no real network in a test; no URL or path from env or config; no skipping the hash on reuse; no `shell: true`.
- **Done when**: the five behaviours pass and the gate is green.
