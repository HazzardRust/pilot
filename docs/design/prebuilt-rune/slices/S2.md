# S2 every failure opens HTML with one line

Feature `prebuilt-rune` · delivers spec 5, 6, 10 · source: `../architecture.md` §2, §5 L4, L6, §6 A2, A5 · after: S1 (`deck/rune-bin.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the redirect and size rules are the download's trust boundary, the security trigger.

## Files owned

- `deck/rune-bin.mjs`: the hop rule, the timeout, the size cap, the no-pin and no-target reasons, the Smart App Control read.
- `deck/test/rune-fail.test.mjs` (new): one test per failure, a stub `get` and a stub `run`.

## Interface

```
S1's ensureRune, S1's findRune: unchanged signatures; Host gains run?: (cmd, args) => string (the registry read, Windows only)
  // findRune reads Smart App Control only through host.run; doctor and ensureRune pass it, auto-open does not
smartAppControl(run): 'on' | 'evaluation' | 'off' | 'unknown'
defaultRun: (cmd, args) => string                         // execFileSync, hidden, 5 s
  // reg.exe query HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy /v VerifiedAndReputablePolicyState: 1 on, 2 evaluation, 0 off
RUNE_LIMITS: { hops: 5, timeoutMs: 30000, maxBytes: 104857600 }
```

## Behaviours

1. `offline opens HTML with one line` (test): `ensureRune` → a `get` that rejects gives `{ source: null }`, one line, 0 files left.
2. `a non-200 opens HTML` (test): `ensureRune` → status 404 gives `{ source: null }` and one line naming the status.
3. `a slow download stops at the limit` (test): `ensureRune` → a body that never ends is aborted at `RUNE_LIMITS.timeoutMs` (fake timers), 0 files left.
4. `an oversized body is cut off` (test): `ensureRune` → past `RUNE_LIMITS.maxBytes` gives `{ source: null }`, the `.part` removed.
5. `a redirect off https is refused` (test): `ensureRune` → a 302 to `http://` gives `{ source: null }` and 1 `get` call; 6 hops give the same.
6. `no pin or no target asks nothing` (test): `findRune` → no `release.json`, another version, or `darwin-x64` gives `fetchable: false` and `ensureRune` makes 0 `get` calls.
7. `Smart App Control enforced downloads nothing` (test): `smartAppControl` → `'on'` for value 1, and `ensureRune` then makes 0 `get` calls with one line.

Rewrite check: any download implementation keeps every failure at 0 files in `fetched/` and one line out.
Misses: a real network drop mid-download and a real SAC machine; QA's walkthrough and the doctor row read them.

## Done

- **Expected**: every listed failure leaves `fetched/` empty, prints one line saying why, and `pilot deck` still opens HTML with its exit code unchanged.
- **Verification**: `node --test deck/test/rune-fail.test.mjs deck/test/rune-bin.test.mjs`; `npm run test:changed -- --since=<base sha>`.
- **Evidence**: behaviour 5 failing on `redirect: 'follow'` and passing after the hop rule; the test output.
- **Prohibited**: no real network or registry in a test; no logging of a redirect `Location`; no retry loop.
- **Done when**: the seven behaviours pass and the gate is green.
