## Tests

1. `a short head tells the pilot to build it`: `lanesFrom` → for a yellow head with a plan of 1 and of 2, `refusal` is the short-path line and `coPilot` ends `(short path)`.
2. `a long head keeps today's line`: `lanesFrom` → for a plan of 3, `refusal` is `yellow lane empty; <id> is planned — deck_ticket co-pilot it first`.
3. `a held short ticket refuses nothing`: `lanesFrom` → with `coPilot: { ticket: <short id>, live: true }`, `refusal` is null and `coPilot` is `co-pilot: <short id>`.

Rewrite check: any rewrite of `lanesFrom` that keeps these three strings keeps `pilot wait` and the stop hook telling the pilot the same thing.
