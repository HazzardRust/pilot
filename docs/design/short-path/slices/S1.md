## Tests

1. `a plan of 2 or fewer is short path`: `isShortPath` → true for plans of 1 and 2, false for 3 and for a ticket with no plan.
2. `the plan decides, not the ticket's count`: `isShortPath` → true for `{ sliceCount: 5, plan: { sliceCount: 2 } }`.
3. `the row marks a short ticket`: `renderTicketRow` → contains `class="short-path"` for a plan of 1 and 2; absent for a plan of 3 and an unsigned ticket of `sliceCount: 1`.

Rewrite check: replacing the predicate's body or the span's markup with any other keeps all three results so long as a signed plan of 2 or fewer is marked and nothing else is.
