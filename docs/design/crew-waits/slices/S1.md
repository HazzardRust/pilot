## Interface

```
pilot wait [--as pilot|qa|teacher|auditor] [--item <id>] [--timeout <minutes>]
  // --as defaults to pilot; exit codes and the printed shape are unchanged
parseArgs(argv): { timeoutMinutes, kind, item? } | { error }
deck_wait args += untaken?: boolean   // only replies not yet delivered to this kind, on open items, whatever `since` is
deck_wait args += item?: string       // only this thread's replies
  // every deck_wait marks the replies it returns deliveredTo the waiter's kind, inside waitForReplies via its take (markDelivered), so a second untaken wait of that kind never gets them
```

## Tests

1. `a wait as qa exits on a reply on QA's walkthrough and not on a pilot question`.
2. `a wait as pilot exits on a pilot question and not on QA's walkthrough reply`.
3. `two untaken waits as one kind: one prints the reply, and the other is still waiting`.
4. `a Sign off is taken once by a qa wait and once by a pilot wait`.
5. `untaken reaches a reply older than a full page of other replies`: the paging does not hide an old untaken reply.
6. `a pilot wait still prints an owner-fallback reply with its note`: parity with today's `fallenBack`.
7. `--as with an unknown kind is refused by name, exit 1`.
8. `pilot-qa.md starts pilot wait --as qa in the background, ends its turn, and lists no deck_wait`.
