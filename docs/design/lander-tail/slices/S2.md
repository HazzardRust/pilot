## Interface

```
landedRun(repo, base, slug) -> boolean
  // feat/<slug>'s head, trailing run-record-only commits stripped, is an ancestor of base
runWorktrees(repo, slug) -> string[]   // the run's worktree paths
  // isRunBranch(branch, slug) or path === keptDir(mainCheckout, `feat/${slug}`); never the main checkout
prune(repo, base, { dryRun, run, merged, keep, holder, landed = false }) -> { removed, kept, failed }
  // landed: unmoved heads and untracked files no longer keep a tree; a head merged after stripping its record-only
  // tail counts as merged; tracked dirt (run.json excepted) keeps it as merged-dirty; a live holder as `live <pid>`;
  // removal `git worktree remove --force` only after that check; run branches merged after stripping go with -D
main(['prune', '--run', slug, …]) -> exit code   // sets landed from landedRun
```

## Tests

1. `a landed run's prune removes all but tracked dirt`: `prune` → a fixture of 6 (feat with a record-only tail and run.json modified, unmoved qa with an untracked file and `node_modules/`, fix, slice, a detached land dir, a slice with a modified tracked file), `landed: true`: 5 removed, 1 kept `merged-dirty`.
2. `the same fixture before landing removes nothing it did not before`: `prune` → with `landed` false the results equal today's (`open` for the unmoved, `merged-dirty` for untracked).
3. `a record-only tail is still landed`: `landedRun` → true for a feat head one `run.json`-only commit past base; false for a head one source commit past.
4. `the land dir is the run's`: `runWorktrees` → includes the detached `<checkout>-land-<slug>` and no other slug's trees.
5. `the CLI prunes a landed run`: `main` → `prune --run <slug>` over test 1's fixture exits 0 and prints 5 `removed` lines and 1 `kept merged-dirty` line.

Rewrite check: replacing the git-plumbing behind `prune` keeps all five results, because they are read from the trees left on disk and the lines printed.
