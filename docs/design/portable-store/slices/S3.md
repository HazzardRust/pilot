# S3 Month archives and audit folders hold no absolute path

Feature `portable-store` · delivers spec 1, 3 · source: `../architecture.md` §2, §3 F5, §5 L1 · after: S1 (`encodePath`)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — two call sites take S1's codec; the migration rule and its backup are named below.

## Files owned

- `deck/store-archive.mjs`: month files written with S1's `toStored`, read with `fromStored`; a v3 month file migrated once with its backup.
- `deck/audit.mjs`: `directoryFor(repo)` hashes S1's `encodePath(repo)`; an old-named dir renamed once.
- `deck/test/store-archive-v4.test.mjs` (new), `deck/test/audit-dir.test.mjs` (new): the pins.

## Interface

```
S1's encodePath / toStored / fromStored, by reference
migrateMonthFile(file: string, roots: Roots): boolean      // true when it rewrote; backup `<file>.v3-<date>` first
directoryFor(repo: string, roots: Roots): string           // from the stored path, so equal on two machines
```

## Behaviours

1. `a month archive is rewritten once with its backup` (test): `migrateMonthFile` → a seeded v3 month file gets its byte-equal backup, 0 absolute structured paths, equal item count; a second call returns false.
2. `an audit folder has one name on two machines` (test): `directoryFor` → the same name for `C:\Users\a\Projects\pilot` under home `C:\Users\a` and `/home/b/Projects/pilot` under home `/home/b`.
3. `an old audit folder is found again` (test): `directoryFor` → after the rename pass, the seeded `audits/<old>/record.json` reads through the new name.

4. `a month file that cannot be read, decoded or backed up is left as it is` (test, added at the co-pilot's word): an unparseable month file is untouched and passed over by the migration, named on stderr (an item moving into that very month refuses the pass, items staying live); a month file with an undecodable path is never overwritten; a failed backup throws and leaves the file; a backup already there is never overwritten (the copy goes to `-2`).
5. `an old and a new audit folder are both kept` (test, added at the co-pilot's word): with both present nothing is deleted or merged, the new name is read, one line on stderr.

Rewrite check: any naming scheme that depends only on the stored path keeps 2.
Misses: an archive file being written by the daemon's 24 h pass at the same moment; the reviewer checks the pass and the migration run in one process (store-durability L4).
