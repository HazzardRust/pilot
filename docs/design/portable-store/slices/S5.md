# S5 A bundle imports on another machine and nothing else gets in

Feature `portable-store` · delivers spec 5, 12 · source: `../architecture.md` §2, §5 L3-L5, L7 · after: S4 (`store-bundle.mjs`, `store-move.mjs`, `bin/pilot.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the bundle is untrusted input that ends as paths the deck later runs git in.

## Files owned

- `deck/store-bundle.mjs`: `unpackBundle` and its checks.
- `deck/store-move.mjs`: `importStore`, roots mapping, staging, `--replace`, `--dry-run`.
- `bin/pilot.mjs`: `pilot store import` dispatched and in the usage text.
- `deck/test/store-import.test.mjs` (new), `deck/test/store-import-hostile.test.mjs` (new): the pins.

## Interface

```
pilot store import <bundle> [--root <name>=<path>]... [--replace] [--dry-run]
unpackBundle(bytes: Buffer, { maxBytes: number }): { manifest: Manifest, entries: Map<name, Buffer> }   // throws, naming the check
importStore(argv: string[], deps: { storePid, home, platform, now, out }): number
S2's writeMachine, by reference: a fresh machine.json with the mapped roots
```

## Behaviours

1. `a bundle opens under another home` (test): `importStore` → into a scratch home whose path differs, every item, record and chat decodes to a path under the new home, the queue order equal.
2. `an unknown root must be named` (test): `importStore` → a bundle using root `drive-d` on a machine with no `D:` exits non-zero naming `--root drive-d=<path>`, 0 files written.
3. `a non-empty store is kept` (test): `importStore` → a second import without `--replace` exits non-zero, the store's bytes unchanged; with it, the old files sit under `replaced-<date>/`.
4. `a hostile bundle writes nothing` (test): `unpackBundle` → throws for an entry `../x`, an entry outside the allowlist, a stored path with `..`, an absolute structured path, store version 5, a sha256 mismatch, gunzipped size over the bound; the store dir is unchanged in each case.
5. `a dry run writes nothing` (test): `importStore` → `--dry-run` prints the entries and roots and writes 0 files.
6. `the move works between two homes` (run): S4's bundle of the real copy imported into a second scratch home with another home path; the deck opens threads, the queue and chat in a browser; export again and compare manifests.

Rewrite check: any import that stages then renames keeps 3-5.
Misses: two imports racing each other; the reviewer checks the staging dir name is per process.

## Done

- **Expected**: a bundle from one machine opens on another, and a bundle the deck did not write cannot plant a file or a path.
- **Verification**: `node --test deck/test/store-import.test.mjs deck/test/store-import-hostile.test.mjs`; `npm run test:changed -- --since=<base sha>`; the run of 6.
- **Evidence**: 1-5 red before, green after; 6 seen in a browser.
- **Prohibited**: no write before every check passes; no import while `storePid` answers; no prompt on stdin (agents run it).
- **Done when**: tests and gate are green and 6 has been seen. Estimate 350 lines.
