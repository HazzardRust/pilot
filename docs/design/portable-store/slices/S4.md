# S4 One command exports the portable store

Feature `portable-store` · delivers spec 4, 9, 12 · source: `../architecture.md` §2, §3 F5-F6, §5 L4, L7, §6 A2, A5 · after: S2 (`machine.json`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument and secrets that must stay out of a file the user carries off the machine.

## Files owned

- `deck/store-bundle.mjs` (new): the allowlist, the manifest, `packBundle`.
- `deck/store-move.mjs` (new): `exportStore`, the remote check, writing `exported.json`.
- `bin/pilot.mjs`: `pilot store export` dispatched beside `store restore` (:555) and in the usage text.
- `deck/test/store-bundle.test.mjs` (new), `deck/test/store-export.test.mjs` (new): the pins.

## Interface

```
pilot store export [<file>] [--logs]        // default file pilot-store-<host>-<yyyy-mm-dd>.pilotstore in cwd
ENTRY_NAMES: readonly RegExp[]              // L4's allowlist; --logs adds the log names
packBundle(dir: string, { logs: boolean }): { bytes: Buffer, manifest: Manifest }
type Manifest = { format: 1, storeVersion: 4, host: string, exportedAt: string,
                  counts: { items, records, archives }, entries: Record<name, sha256> }
exportStore(argv: string[], deps: { git, now, host, out }): number   // exit code; lists unpushed work, never refuses
exported.json: { at: string, file: string }                         // machine-only, written after the bundle
```

## Behaviours

1. `a bundle carries no secret` (test): `packBundle` → for a scratch store with `deck.secret`, `machine.json`, `deck.pid`, `deck.v3-*.json` and `deck-open.html`, 0 entries with those names and 0 occurrences of the secret's value in the gunzipped bytes.
2. `logs travel only when asked` (test): `packBundle` → `{ logs: true }` adds `deck.log`; `{ logs: false }` has no log entry.
3. `the manifest counts the store` (test): `packBundle` → manifest counts equal the scratch store's items, records and month files; each sha256 matches its entry.
4. `unpushed work is listed and the bundle still written` (test): `exportStore` → a scratch repo whose run worktree has one commit not on its upstream prints that worktree and `1`, exits 0, the bundle exists.
5. `the real store exports` (run): `pilot store export` on S1's real copy; size, counts and the listed worktrees in the report.

Rewrite check: any bundle format keeps 1-3 as long as the allowlist holds.
Misses: a secret pasted by a user into a thread's prose travels in `deck.json`; the security reviewer states it, A1 owns it.
