# S6 An imported store waits on nothing from the old machine

Feature `portable-store` · delivers spec 8, 11 · source: `../architecture.md` §2, §3 F4, §6 A3 · after: S5 (`importStore`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — spec 8 and 11 are assumed (A3) and the landing states are read from the code.

## Files owned

- `deck/store-gone.mjs` (new): `markGone` and `rebuildLines`.
- `deck/store-move.mjs`: one call to each from `importStore`.
- `deck/test/store-gone.test.mjs` (new): the pins.

## Interface

```
markGone(deck: Deck, sourceHost: string, at: string): Deck     // a running or queued landing -> state 'interrupted', line 'interrupted on <host>'
rebuildLines(deck: Deck, exists: (path) => boolean): string[]  // one `git -C <repo> worktree add <worktree> <branch>` per open run whose worktree is missing
S5's importStore, by reference
```

## Behaviours

1. `a running landing reads interrupted` (test): `markGone` → a seeded running landing and a queued one read `interrupted` with the source host in their line; a landed one is unchanged.
2. `a missing worktree gets one rebuild line` (test): `rebuildLines` → for two open runs, one with its worktree present, exactly one line, naming the run's branch.
3. `an imported store waits on no foreign pid` (run): a scratch store with a running landing exported and imported; `pilot wait` and the deck name no pid from the source; the rebuild lines printed; 0 worktrees created.

Rewrite check: any rewrite that leaves no running landing and no foreign pid keeps 1 and 3.
Misses: a landing whose push reached the remote before the move; QA checks the remote by hand in the walkthrough.

## Done

- **Expected**: after an import the deck shows the old machine's work as interrupted and says how to rebuild it.
- **Verification**: `node --test deck/test/store-gone.test.mjs deck/test/store-import.test.mjs`; `npm run test:changed -- --since=<base sha>`; the run of 3.
- **Evidence**: 1-2 red before, green after; 3's output.
- **Prohibited**: no `git worktree add` run by the import; no change to a landed landing.
- **Done when**: tests and gate are green and 3 has run. Estimate 120 lines.
