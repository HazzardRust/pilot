## Interface

```
type Roots = Record<string, string>          // name -> absolute dir; home, drive-<x> or '/' by default
defaultRoots(home: string, platform: string): Roots
encodePath(abs: string, roots: Roots): string          // '@<root>/<rel>', realpath spelling, '/' separators
decodePath(stored: string, roots: Roots): string       // absolute; throws on '..', an unknown root, a non-stored value
toStored(deck: Deck, roots: Roots): Deck               // every F2 field and map key encoded
fromStored(stored: Deck, roots: Roots): Deck           // decoded; map keys and records[].repo re-folded by pathKey
upgradeV3(deck: Deck, roots: Roots): Deck              // v3 -> v4
PATH_FIELDS: readonly string[]                         // the field map, e.g. 'records[].record.slices[].worktree'
```

Seam (built, accepted by the co-pilot): the posix default root is named `root` (`@root/<rel>`), and `PATH_FIELDS`
carries `runs[].slices[].worktree` beside F2's list (15 in the real store).

## Behaviours

1. `a path round-trips through its root` (test): `decodePath` → `C:\Users\a\Projects\pilot` for `encodePath` of it under `home = C:\Users\a`, and the same under posix paths; `@home/../x` throws.
2. `spellings of one repo collapse` (test): `toStored` → one stored value for `C:/Users/a/projects/pilot` and `c:\users\a\Projects\pilot` when the dir exists as `Projects`.
3. `a v3 store migrates with its backup first` (test): `upgradeV3` → through `readDeck` on a seeded v3 store, `deck.v3-<date>.json` byte-equal to the input, counts equal, version 4, a second read writes nothing.
4. `no structured field keeps an absolute path` (test): `PATH_FIELDS` → a scan of the written `deck.json` finds 0 drive or home paths outside the prose fields of F2; a seeded unknown path field fails the scan by its name.
5. `the real store migrates` (run): a copy of `~/.claude/pilot` in a scratch `PILOT_DECK_DIR`; scan 0, the 967/161-style counts equal, distinct repos equal distinct `pathKey`s before, `writeDeck` timing before and after in the report.

Rewrite check: replacing the codec with any other encoding keeps 3 and 4: backup byte-equal, counts equal, 0 absolute paths.
Misses: a path field added after this slice that no seed carries; the scan guard in 4 reads only seeded fields, so the reviewer greps `deck/` for new `worktree`/`repo`/`dir` writers.
