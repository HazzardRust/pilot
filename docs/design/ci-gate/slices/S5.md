# S5 A gate2 carries its green checks

Feature `ci-gate` · delivers spec 4 · source: `../architecture.md` §2, §5 L6, A2, A5 · after: S1 (`parseCheckLine`, `ciConfigured`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new `deck_post` field, an API boundary, and its policy is assumed (A2, A5).

## Files owned

- `deck/items.mjs`: `GATE2_FIELDS` gains optional `checks`, one line, at most 600 chars.
- `deck/gate2-checks.mjs` (new): `checksRefusal`, local git only under the 5 s deadline, no host CLI.
- `deck/server-tools.mjs`: one call beside `assertCleanOnPilot` (`:195`) for a gate2.
- `deck/test/gate2-checks.test.mjs` (new): refusals and accept on scratch repos.

## Interface

```
gate2 field  checks?: string   // S1's checkLine as `pilot checks <sha>` printed it
checksRefusal(repo: string, sha: string, checks: string|undefined) -> string|null
  // null: CI not configured at sha (no field needed), or a green line whose sha7 prefixes sha
  // else `NOT posted: <why>`: missing, `at <other sha7>, the gate2 is <sha7>`, or `checks <state>` not green
```

## Behaviours

1. `no line, no post` (test): `checksRefusal` → a repo with `.github/workflows/gate.yml` and no `checks` refuses naming the field.
2. `another sha, no post` (test): `checksRefusal` → a green line at another sha7 refuses naming both.
3. `not green, no post` (test): `checksRefusal` → a red line refuses naming its checks.
4. `a green line posts` (test): `checksRefusal` → null; the gate2 is stored with `checks`.
5. `no CI, no field` (test): `checksRefusal` → a repo with no workflow file is null; `deck/test/gate2-*.test.mjs` green unedited.

Rewrite check: moving the check into `postItem` keeps 1-5 if `store-items.mjs` stays under 800 lines.
Misses: a stale green line at the sha; land's re-read (S3) catches it.

## Done

- **Verification**: `node --test deck/test/gate2-checks.test.mjs deck/test/gate2-*.test.mjs deck/test/facades.test.mjs`; `npm test`.

- **Prohibited**: no `gh` or `glab` from the daemon; no edit to `store-items.mjs`; no field required on a repo with no CI.
- **Done when**: five behaviours hold and `npm test` is green. Estimate about 90 lines.
