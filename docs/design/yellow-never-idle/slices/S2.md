# S2 A yellow ticket with no crew for 20 minutes refuses the pilot's stop

Feature `yellow-never-idle` · delivers spec 5, 6, 8 · source: `../architecture.md` §2, §5 L4-L6, §6 A2 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — the threshold is assumed (A2) and the rule must leave the 8 test files that call `lanesFrom` unchanged.

## Files owned

- `deck/lane-ticket.mjs`: exports `isYellowCrew`, the crew list plus `pilot:pilot-qa`.
- `deck/agents.mjs`: `crewSeenAt`, the yellow crew's last heartbeat per repository (worktrees folded by `repoOf`), `startedAt` when unseen.
- `deck/lanes.mjs`: `IDLE_MS`, `idleYellowOf`, `lanesFrom`'s optional crew input and its refusal; `lanesOf` passes `crewSeenAt` and now.
- `deck/test/lanes-idle.test.mjs` (new): the rule's cases.
- `hooks/test/stop-gate-idle-yellow.test.js` (new): the hook against a deck on a free port.

## Interface

```
isYellowCrew(agentType: string) -> boolean
crewSeenAt(repo: string) -> number            // ms; the daemon's startedAt when no crew heartbeat yet
IDLE_MS = 20 * 60_000
idleYellowOf(items, repo, held, crewSeenAt, now) -> { ticket: string, at: number } | null
  // held: the live co-pilot's ticket id; at = crewSeenAt + IDLE_MS, returned even when at > now (S3 re-arms on it);
  // null when held is not open yellow in repo, is yielding, or has an unanswered blocking item
lanesFrom(items, repo, { switching, coPilot, crewSeenAt?, now? }) -> lanes
  // refusal, after the stage lanes': `yellow lane idle; <id> has had no crew for 20 min — deck_ticket need it if its
  // walkthrough or gate2 is up, else release it and spawn its successor` when idleYellowOf(...).at <= now
```

## Behaviours

1. `a quiet crew is named` (test): `lanesFrom` → refusal naming the id at crew seen 21 min ago; none at 19 min.
2. `a blocked or draining ticket is not idle` (test): `idleYellowOf` → null with an unanswered blocking question, and with `yielding`.
3. `a restart is a heartbeat` (test): `crewSeenAt` → the daemon's start for a repository no crew has reported in.
4. `only the crew counts` (test): `crewSeenAt` → unchanged by an `Explore` heartbeat, moved by a `pilot:pilot-implementer` one from a worktree.
5. `the Stop hook blocks on it` (test): `lanesFrom` → served on `/api/record`, `stop-gate.js` `run` returns `block` with the id; with a 1-min-old crew heartbeat, null.

Rewrite check: storing the crew heartbeat on disk instead of in memory keeps 1-5.
Misses: a real co-pilot's silence pattern over a run; QA's scratch-deck walk and the next live run read it.
