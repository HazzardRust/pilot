# S3 The CI red line names the failing tests and goes to its ticket

Feature `debug-workflow` · delivers spec 2, 5 · source: `../architecture.md` §2, §4, §5 L1, L5 · after: S1 (ci-watch.mjs, pollCi), S2 (ciSummary, cleanField)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — untrusted CI text is put into the pilot's context, the security trigger.

## Files owned

- `deck/ci-watch.mjs`: `pollCi` takes `records`, fetches S2's `ciSummary` for each run it is about to announce, builds the full line and routes it.
- `deck/test/ci-route.test.mjs` (new): the routing and line pins. It reads S2's fixture by path and does not change it.

## Interface

```
pollCi({ items, records, gh, now, note, log }) -> { noted }   // S1's, plus records (listRuns()) and the route
routeOf(branch: string, repo: string, records, items): { ticket: string } | null
  // ^(feat|slice|fix|qa)/<slug>(-s\d+)?$ against records of this repo; that record's ticket open and yellow or green; else null
redLineOf(run: S1's RedRun, summary: S2's CiSummary): string   // <= 1500 chars
  // `CI red: run <id>#<attempt> on "<branch>" (<event>) <url> — failed <job> (<n>): <file> <name>: "<message>"; … (+k more) · passed <job>, … — <routed|unrouted>`
  // every free field through S2's cleanField, inside double quotes; at most 5 tests per job
```

## Tests

1. `the fixture run names its jobs and tests`: `redLineOf` → names `39530951687`, `gate (windows-latest) (8)`, `gate (macos-latest) (10)`, `passed gate (ubuntu-latest)`, with at most 5 tests per job and at most 1500 chars.
2. `a slice branch of a live ticket goes to the ticket`: `routeOf` → `slice/<slug>-s2` with a yellow ticket's record gives that ticket, and `pollCi` notes on the ticket's id.
3. `pilot, main and an unknown branch go to the chat`: `routeOf` → null, and `pollCi` notes on the chat with `unrouted`.
4. `a planning ticket is not routed`: `routeOf` → null for a red ticket's `design/<slug>` and for `feat/<slug>` while the ticket is red.
5. `the injected text stays data`: `redLineOf` → the planted name arrives clipped, ESC-free and inside quotes, with no newline in the line.
6. `three gh calls for an announced run`: `pollCi` → the list plus S2's two, and no log fetch for a run already announced.

Rewrite check: replacing branch routing with a lookup by head sha keeps tests 2–4 for these fixtures.
