## Files owned

- `deck/ci-watch.mjs` (new): lists red runs, drops forks and old runs, dedupes by marker, and writes the CI red line on the chat.
- `deck/daemon.mjs`: one `startCiWatch({ announce })` call beside the archive timer (`daemon.mjs:232`), never in `startDaemon`.
- `deck/test/ci-watch.test.mjs` (new): the pins, with `gh`, `note` and `now` injected.

## Interface

```
CI_EVERY_MS = 5 * 60_000; CI_WINDOW_MS = 6 * 3_600_000; CI_PER_POLL = 3
type RedRun = { id: number, attempt: number, branch: string, event: string, url: string, updatedAt: string }
redRunsOf(json: string, now: number): RedRun[]  // gh api …/gate.yml/runs?status=failure; own repo only (head_repository.full_name === repository.full_name); in window; newest first;
                                                 // id, attempt integers, event in a fixed list, url matching ^https://github\.com/[\w.-]+/[\w.-]+/actions/runs/\d+$, else dropped
ciMarker(run: RedRun): string                   // `CI red: run <id>#<attempt>`
pollCi({ items, gh, now, note, log }): { noted: Array<{ item: string, marker: string }> }
  // per repo with an open ticket: one gh call; skip runs whose marker is in any item's deck line; <= CI_PER_POLL; note(chatId, line)
startCiWatch({ announce, gh?, every? }): () => void  // setInterval(.unref) of pollCi over listItems(); announce() after a note; returns stop
gh argv: ['api', 'repos/{owner}/{repo}/actions/workflows/gate.yml/runs?status=failure&per_page=20'] in the repo's dir
line (S1): `CI red: run <id>#<attempt> (<event>) <url> — unrouted`   // no free text: S3 adds the branch and tests through S2's cleanField
```

## Tests

1. `a red own-branch run writes one line on the chat`: `pollCi` → `note` called once with the repo's chat id and a line starting `CI red: run 39530951687#1`.
2. `a polled run is not announced twice`: `pollCi` → the second poll over the same store (line present) notes nothing.
3. `forks, old runs and the cap`: `redRunsOf` → a fork run and a 7 h old run are absent; `pollCi` notes 3 of 5, then 2.
4. `gh failing or a note throwing logs one line and posts nothing`: `pollCi` → `log` called once, `note` never.
5. `a run with a field off its shape is dropped`: `redRunsOf` → a run whose event is not in the list, or whose url is not a GitHub run url, is absent.
6. `one gh call per repo with an open ticket, none without`: `pollCi` → the injected `gh` call count is 1 and 0.

Rewrite check: replacing `gh api` with `gh run list` keeps every result above.
