# S2 The deck refuses a gate1 off pilot's tip

Feature `design-docs-only` · delivers spec 2 · source: `../architecture.md` §2, L4, L5, L6, A2 · after: S1 (`pilotLineage`)

## Files owned

- `deck/server.mjs`: `callTool('deck_post')` refuses a gate1 by S1's `pilotLineage`, beside `isWorktree` (:808), before `postItem`.
- `deck/lineage.mjs` (new): `assertOnPilotTip(repo, branch)` runs S1's `pilotLineage` in a child node under the 5 s bound with `core.fsmonitor` off; `server.mjs` only calls it, since ADR 0039 keeps `child_process` out of `server.mjs` (seam change, co-pilot, 2026-10-10). The ADR 0111 lines take S2 past the 200-line limit; accepted, as the brief requires the ADR.
- `deck/test/gate1-lineage.test.mjs` (new): the pins, on real git repos in temp dirs with a local bare origin, through `callTool`.

## Interface

```
callTool('deck_post', { kind: 'gate1', repo, branch, ... })   // unchanged signature; may now throw DeckRefusal
// refusal, copies > 0: `a gate1's branch <branch> carries <n> copies of pilot's commits; rebase its docs commits onto pilot (git rebase origin/pilot) and post again`
// refusal, tip false:  `a gate1's branch <branch> is not on pilot's tip; rebase its docs commits onto pilot (git rebase origin/pilot) and post again`
// refusal, no origin/pilot in a git repo: names `pilot base`; branch unresolvable or git over 5 s: names the branch
// a repo that is not a git repository (repoOf null): not checked
S1's pilotLineage(cwd, ref)
```

## Tests

1. `a gate1 for a branch carrying a copied pilot commit is refused`: `callTool` → DeckRefusal naming the branch, `1 copies` and `git rebase origin/pilot`; no item stored.
2. `a gate1 for a branch cut from pilot's tip posts`: `callTool` → the item stored.
3. `a gate1 for a branch merely behind pilot is refused`: `callTool` → the not-on-tip refusal.
4. `a gate1 in a git repo with no origin/pilot is refused`: `callTool` → refusal naming `pilot base`.
5. `a gate1 whose branch does not resolve is refused`: `callTool` → refusal naming the branch.
6. `a gate1 whose repo is not a git repository is not checked`: `callTool` → stored, as the nine existing gate1 test files rely on.

Rewrite check: were the check moved into a module of its own or made async, tests 1-6 hold, since they cross only `callTool` and read the store.
