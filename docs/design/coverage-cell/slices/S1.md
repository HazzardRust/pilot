# S1 One command prints a feature's diff coverage from Node's own coverage

Feature `coverage-cell` · delivers spec 3, 4 · source: `../architecture.md` §2, §3, §5 L2, §6 A1, A6 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — rests on assumed A1 and A6, and the script starts `git` with a caller-supplied base (a process start).

## Files owned

- `scripts/diff-coverage.mjs` (new): reads raw V8 coverage and `git diff -U0`, returns and prints diff coverage; no dependency.
- `scripts/test/diff-coverage.test.mjs` (new): the pins, on a temp git repo whose coverage a `node` child writes.

## Interface

```
diffCoverage({ cwd: string, v8Dir: string, base: string }) ->
  { covered: number, total: number,
    files: { file: string, covered: number, total: number, uncovered: number[] }[],
    notMeasured: string[] }          // changed Node sources outside .js .mjs .cjs, e.g. .ts
formatDiffCoverage(result) -> string // last line: `Diff coverage: <n>% (<covered> of <total> changed lines)`,
                                     // or `Diff coverage: no changed lines to count`
CLI: node scripts/diff-coverage.mjs <v8-dir> <base>   // cwd the worktree; exit 0 printed;
                                                      // exit 2 on a base outside ^[A-Za-z0-9._/-]+$ or an unreadable dir
```

## Behaviours

1. `three of four changed lines run reads 75%` (test): `diffCoverage` → a fixture repo whose HEAD adds 4 counted lines, 3 of them run by a `node` child under `NODE_V8_COVERAGE`, gives covered 3, total 4, and `formatDiffCoverage` ends `Diff coverage: 75% (3 of 4 changed lines)`.
2. `only lines no process ran are uncovered` (test): `diffCoverage` → a never-called function's lines are the `uncovered` list exactly; blank and comment-only changed lines are in neither count; a line run in either of two coverage files counts covered.
3. `paths match across file URLs on Windows` (test): `diffCoverage` → a coverage entry `file:///C:/…` matches git's `c:/…/x.mjs` path; a changed `.ts` file is in `notMeasured`, not in `total`.
4. `a bad base is refused before git runs` (test): `diffCoverage` → `base: '--output=x'` throws and spawns no `git`; the CLI exits 2.
5. `the number prints for this repo` (run): `NODE_V8_COVERAGE=<tmp> node --test scripts/test/diff-coverage.test.mjs` then `node scripts/diff-coverage.mjs <tmp> origin/pilot` in the slice worktree prints a `Diff coverage:` line with a percentage.

Rewrite check: replacing the range walk with another line mapper keeps 75% and the same uncovered list on the fixture.
Misses: agreement with c8 on code shapes the fixture lacks (CJS wrappers, hashbangs); the fundamentalist's reading of the number reads it.

## Done

- **Expected**: given a directory of raw V8 coverage and a base, one command prints which changed lines ran and the percentage.
- **Verification**: `node --test scripts/test/diff-coverage.test.mjs`; behaviour 5's two commands; `npm test`.
- **Evidence**: tests 1-4 failing before (no module) and passing after; behaviour 5's printed line.
- **Prohibited**: no dependency added to `package.json`; no `npx`, `uvx` or network; no shell string to `git` (argv array only); no reading outside `cwd` and `v8Dir`; no file written.
- **Done when**: tests 1-4 pass, the gate is green, and behaviour 5 printed a percentage.
