## Repository facts

- The live deck on 127.0.0.1:4321 is the user's: never post to it, stop it or point a test at it. Live checks run
  on `pilot deck --scratch` (its own dir and port), stopped with `pilot deck --stop <pid>`.
- Most tests get a server from `deck/testUtils.mjs` `deckOnAPort`, which after S1 passes `secret: null` (L5). A
  test that means to prove the guard passes a string secret.

- A new deck module needs a `deck/README.md` row (the deck-readme pin).
- Every child process passes `windowsHide: true` (ADR 0155, a source-scan test).
- `docs/adr/README.md` is regenerated by `node scripts/adr-index.mjs`, never hand-merged. Take the next free ADR
  number when the slice lands.
- `scripts/vocabulary.mjs` retires a common four-letter synonym for "piece of work" (spelt in halves there); run
  `node scripts/vocabulary.mjs check <paths>` on what you write.
- Edit files with the Edit or Write tools, never heredoc, `sed -i` or Python text mode, which write CRLF on Windows.
