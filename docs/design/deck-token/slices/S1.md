## Interface

```
// hooks/lib/deck-secret.js (CommonJS)
deckDir(): string                       // PILOT_DECK_DIR or ~/.claude/pilot
secretFile(dir?: string): string        // <dir>/deck.secret
ensureSecret(dir?: string): string      // reads it, or creates it: randomBytes(32) hex, flag 'wx', mode 0o600
readSecret(dir?: string): string        // throws Error naming the file, never a value, when it is missing
bearer(dir?: string): { authorization: string }
cookieName(port: number): string        // `pilot_deck_<port>`
// deck/server-wait.mjs
isAuthorized(request: http.IncomingMessage, secret: string | null): boolean
  // null -> true; else the Bearer header or the cookieName(localPort) cookie, timingSafeEqual
// deck/server-routes.mjs
createDeckHttpServer(options?: { secret?: string | null, ... }): http.Server   // secret omitted -> ensureSecret() on every POST, so a rotated file is taken at once
POST <any> without it -> 401 (API: { error }, page: text naming `pilot deck`)
```

## Tests

1. `a write without the secret is refused`: `createDeckHttpServer` → `POST /api/tool` 401, its body without the secret; with `bearer()` 200.
2. `a refused page press names pilot deck`: `createDeckHttpServer` → `POST /reply` with own Origin and no cookie is 401 text naming `pilot deck`.
3. `the cookie for this port is taken and another port's is not`: `isAuthorized` → true for `cookieName(port)`, false for `cookieName(port + 1)`.
4. `the secret is created once, 0600, and reused`: `ensureSecret` → the same value twice; mode 0o600 on POSIX; a second process racing `wx` reads the first's.
5. `a missing secret names the file`: `readSecret` → throws with `secretFile()` in the message.
6. `the MCP client round-trips on a real daemon`: `bearer` → a spawned daemon takes `deck_post` and `pilot wait` returns its reply.
7. `a rotated file is taken without a restart`: `createDeckHttpServer` → after `deck.secret` is replaced, the old value is 401 and the new 200.
8. `a scratch deck has its own secret`: `ensureSecret` → the scratch dir's differs from the user's; the scratch tests pass unchanged.

Rewrite check: replacing the hex file with any other store for the secret keeps every result above.
