# S5 A read without the secret is refused, and every reading client sends it

Feature `deck-token` · delivers spec 8 · source: `../architecture.md` §2, §5 L4, §6 A4 · after: S3 (server-routes.mjs, the page credential)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — it widens the guard to every route but a fixed list, a trust boundary the user changed (A4).

## Files owned

- `deck/server-routes.mjs`: the guard in `route` runs on every method, with `OPEN_ROUTES` exempt.
- `deck/tickets.mjs`, `deck/landing-wait.mjs`, `deck/schedule.mjs`: each GET spreads S1's `bearer()`.
- `deck/test/deck-reads.test.mjs` (new): the pins.

## Interface

```
// deck/server-routes.mjs
OPEN_ROUTES: (request, pathname) => boolean
  // true only for GET /open, GET of a UI_ASSETS path, GET /api/health
GET <any other> without S1's isAuthorized -> 401 (API: { error } naming the file; page: S1's 401 text naming `pilot deck`)
S1's bearer(dir?)        // the three readers spread it
S3's openCookie(...)     // the page's credential on every GET, /events included
```

## Tests

1. `a read without the secret is refused`: `OPEN_ROUTES` → `GET /`, `/api/items`, `/thread/<id>` and `/events` answer 401 bare, and the body holds no secret.
2. `a read with either credential is served`: `OPEN_ROUTES` → each of those answers 200 with the Bearer header, and 200 with S3's cookie.
3. `three routes stay open by name`: `OPEN_ROUTES` → `/api/health`, `/ui/deck.css` and `/open?key=<secret>` answer bare; a new route is guarded unless listed.
4. `pilot tickets reads a guarded deck`: `bearer` → `pilot tickets` against `createDeckHttpServer({ secret })` prints the queue.
5. `pilot landing and the record reader read a guarded deck`: `bearer` → each answers as it did unguarded.

Rewrite check: replacing the exemption list with any predicate exempting exactly those three keeps all five results.

## Done

- **Expected**: a curl of the deck's page or items gets 401; the user's signed-in tab, `pilot tickets` and `pilot landing` read as before; `/api/health` still answers `pilot ps` and `pilot deck`.
- **Verification**: `node --test deck/test/deck-reads.test.mjs deck/test/landing-wait.test.mjs`; `npm test`; on a scratch deck, `curl <url>/api/items` bare and with the Bearer header, and the signed-in tab reloaded.
- **Evidence**: tests red before and green after; both curl status lines read; the tab seen loading after a reload.
- **Prohibited**: no exemption by prefix (`/api/`, `/ui`) wider than the list; no fallback that serves a read when the secret file is missing; no change to `deck/ui/js`.
- **Done when**: the five tests pass, the gate is green, and the scratch curls and the reload have been seen.
