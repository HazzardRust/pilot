## Files owned

## Interface

```
checkSlice(text: string) -> Array<{ line: number, rule: 'after-ticket' | 'after-reason' | …, message: string }>
// 'after-ticket' message: "`<blocker>` waits on another ticket's PR; a red ticket is on pilot already, and the order between tickets is the deck queue"
```

## Tests

1. `a PR wait in after is refused as after-ticket`: `checkSlice` → one `after-ticket` problem for `after: S3 (x), #445 on pilot`, and no `after-reason` for that blocker.
2. `a bare S<n> still reads after-reason`: `checkSlice` → `after-reason` for `after: S3`.
3. `a reasoned slice blocker passes`: `checkSlice` → no problem for `after: S3 (deck/store.mjs)`.

Rewrite check: replacing the regex with a parser keeps all three results.
