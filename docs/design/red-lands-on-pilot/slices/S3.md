# S3 Merge first names what this head stands on; a landing comments on its PR

Feature `red-lands-on-pilot` · delivers spec 4 · source: `../architecture.md` §2, §3 "What land.mjs changes", §5 L7, §6 A4 · after: S6 (scripts/land.mjs)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Files owned

- `scripts/land.mjs` (:99-131): `mergeFirst` keeps a PR only when its head is an ancestor of this landing's feature head, reads `isDraft`, marks drafts; after a landing, comments on the open PR whose head is `head`.
- `scripts/test/land.test.mjs`: the pins below, on its scratch bare origin with `gh` injected.

## Interface

```
land({ cwd, git, gh, test }) -> { head, sha, retried, mergeFirst: Array<{ number: number, draft: boolean }> | null, unknown?: string, commentFailed?: string }
// gh argv only: ['pr','list','--head',head,'--state','open','--json','number'], then ['pr','comment',<n>,'--body','landed on pilot at <sha>']
main(argv, inject) stdout: "landed <head> on pilot at <sha7>\nmerge first: #12 (Gate 2 open), #13\n" [+ "pr comment failed: <reason>\n"]
```

## Tests

1. `a later feature on pilot is not merge first`: `main` → A's line reads `merge first: none` with B (cut on A) landed on `pilot`.
2. `a draft the head stands on is marked Gate 2 open`: `main` → B's line reads `merge first: #11 (Gate 2 open)` when A's #11 is `isDraft: true`.
3. `a landing comments its sha on the feature PR`: `land` → the fake gh saw `pr comment <n> --body landed on pilot at <sha>`.
4. `a failing comment still lands`: `land` → `commentFailed` set; `main` exits 0 and prints `pr comment failed:`.

Rewrite check: swapping gh's JSON for the REST API keeps all four results.

## Done

- **Expected**: the user's merge-first step names only what a PR stands on, flags any still unsigned, and every landing leaves its sha on the PR.
- **Verification**: `node --test scripts/test/land.test.mjs`; `npm test`.
- **Evidence**: tests 1–4 failing before and passing after.
- **Prohibited**: a shell string to gh; a comment body from anything but the sha; failing a landing on a gh error.
- **Size**: over 200 changed lines, stop and ask `main`.
- **Done when**: the four tests pass and `npm test` is green.
