# S2 Prune keeps a worktree a live process holds

Feature `landing-keeps-worktrees` · delivers spec 2 · source: `../architecture.md` §2, §3, L2–L4 · after: S1 (`scripts/worktrees.mjs` `prune`, `scripts/land.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — path matching across platforms and the unsure-is-live rule are judgement calls.

## Files owned

- `deck/procs.mjs`: `holderOf(owned)`, which maps rows to a worktree holder.
- `scripts/worktrees.mjs`: `prune` takes `holder`; `main` (the CLI) wires it from `processTable` and `pilotProcesses`.
- `scripts/land.mjs`: `main` reads the table once and hands it to `land({ holder })` and `landSweep`.
- `scripts/test/worktrees-holder.test.mjs` (new): the pins.

## Interface

```
holderOf(owned: { pid, worktree, orphan }[]) -> (dir: string) => number | 'unsure' | null
  // a non-orphan row whose worktree is dir or under it (realpath, case-folded on win32); unsure when its owner is null
prune(repo, base, { …S1's options, holder?: (dir) => number | 'unsure' | null })
  // a held merged-clean tree is kept as state 'live <pid>' or 'live unsure'
land({ …, holder? })   // default: no holder, so tests without a table are unchanged
```

## Tests

1. `a live leash keeps its worktree`: `prune` → a merged-clean run tree with `holder` answering 4242 is kept as `live 4242`.
2. `an orphaned leash lets it go`: `holderOf` → a row with `orphan: 'leash 4242 gone'` holds nothing, and `prune` removes the tree.
3. `an unsure daemon keeps it`: `holderOf` → a row with `orphan: null, owner: null` answers `'unsure'`.
4. `a path under the worktree counts, a sibling does not`: `holderOf` → `<wt>/deck` holds `<wt>`; `<wt>-land-x` does not.

Rewrite check: replacing procs' process reading keeps all four results, given the same rows.

## Done

- **Expected**: `pilot worktrees prune --run <slug>` with a scratch deck leashed into a run worktree prints `kept live <pid> <path>`, and after the deck stops it removes the worktree.
- **Verification**: `node --test scripts/test/worktrees-holder.test.mjs scripts/test/land-clear.test.mjs`; `npm test`; a real run of `pilot deck --scratch` in a fixture worktree, then `pilot worktrees prune --run <slug> --dry-run`.
- **Evidence**: tests 1 and 3 failing before and passing after; the CLI output from the live check.
- **Prohibited**: treating an unsure row as free; a second process-table read in land; string-prefix path matching without a separator.
- **Done when**: the four tests, the gate and the live CLI check all pass.
