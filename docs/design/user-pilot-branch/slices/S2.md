# S2 Integrate and sync land on your pilot branch

Feature `user-pilot-branch` · delivers spec 1, 2, 3 · source: `../architecture.md` §2, §5 L5, L8 · after: S1 (`pilotBranch`, `landingSubjects`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — ~25 sites across the landing merge and the main-into-pilot sync, each a push target.

## Files owned

- `scripts/integrate.mjs`: every `PILOT_BRANCH` becomes `pilotBranch(git)`; `landedOnPilot`, `landingsOf` match `landingSubjects`; `baseOf` uses `isPilotBase`.
- `scripts/sync.mjs`: `TARGET`, the merge message and its lines name `pilotBranch(git)`; `main` calls `namePilotBranch` with its host.
- `scripts/worktrees.mjs`: the pilot branch passed at :300 from `pilotBranch`.
- `scripts/test/integrate-user-branch.test.mjs` (new): the pins.

## Interface

```
landingMessage(head: string, name: string): string   // `Merge ${head} into ${name}`
landedOnPilot(cwd, head, ref?): boolean               // matches any of S1's landingSubjects
sync({ cwd, git, test, keep }): { ok, line }        // moves only pilotBranch(git) on the run remote
baseOf(cwd, runs?): { ref, chained? }                // a record base `pilot` reads as the pilot branch
S1's pilotBranch, isPilotBase, landingSubjects
```

## Behaviours

1. `a slice merge names the user's branch` (test): `landingMessage` → `Merge feat/x into hazzardrust-pilot` with `pilot.branch` `hazzardrust-pilot`.
2. `a pre-move landing still counts` (test): `landedOnPilot` → a `Merge feat/x into pilot` merge on `hazzardrust-pilot`'s first-parent history reads landed.
3. `sync touches only its own branch` (test): `sync` → two clones with `a-pilot` and `b-pilot`; a sync in clone a moves `a-pilot` only, `b-pilot`'s tip unchanged.
4. `a record based on pilot reads as the branch` (test): `baseOf` → record base `pilot` answers the `hazzardrust-pilot` ref.

Rewrite check: matching landings by ancestry instead of subject keeps 2's answer.
Misses: a merge subject hand-edited by a user; QA's walkthrough of one landing reads that.
