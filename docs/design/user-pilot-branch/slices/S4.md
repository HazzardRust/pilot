Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`

## Behaviours

1. `the move retargets the user's pilot PRs` (test): `restack` → fake host with 2 own open PRs based `pilot` prints `retargeted #1 to hazzardrust-pilot`, `retargeted #2 to hazzardrust-pilot`; `host.edit` called twice with that base.
2. `another user's PRs are untouched` (test): `restack` → a PR by another author based `pilot` gets 0 `host.edit` and 0 pushes.
3. `a second restack is level` (test): `restack` → after 1, both PRs read `level`.

Rewrite check: filtering by head-branch owner instead of `--author @me` keeps 1-3.
Misses: GitHub's `--author @me` under a token for another account; QA's live retarget (L13) reads it.
