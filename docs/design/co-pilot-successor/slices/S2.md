## Interface

```
isCoPilot(input): boolean                     // agent_type === 'pilot:pilot-co-pilot'
coPilotTicketOf(repo): Promise<string|null>     // GET /api/record?repo= -> co-pilot.ticket; null on any failure
announce(input, seen, marks, repo)            // co-pilot: posts at the advisory (one claim), not again at hard
  crew-handoff for a co-pilot:
    title "Handoff: pilot-co-pilot on <ticket> paused itself at <tokens>"
    body  ticket id, reason "self-pause at the advisory", record location `GET /api/record?ticket=<id>`,
          "the main session spawns its successor with this item's id; Handoff failed: spawn a fresh co-pilot from the plan"
advice(...)                                   // co-pilot, on deck: advisory = pause now; hard = the same, overdue; no `wip:`
```

Off the deck a co-pilot gets the generic texts; the pilot's and slice agents' texts and items are unchanged.

## Tests

1. `a co-pilot at 225,000 tokens posts one crew-handoff naming its ticket`: `announce` → one post, body has the ticket id and record location.
2. `a co-pilot at 260,000 tokens posts no second item`: `announce` → the advisory's claim holds.
3. `a co-pilot is told to pause and hand back paused, never wip:`: `advice` → both texts.
4. `a co-pilot whose ticket the deck cannot name still gets its text`: `coPilotTicketOf` → null; the item says "ticket unknown".
5. `an implementer's texts and item are unchanged`: `advice` → the existing crew tests pass unedited.
