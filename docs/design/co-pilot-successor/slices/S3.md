## Interface

```
// deck/schedule.mjs
export function startable(rows: Row[], slots: number): Start[]
type Start = { slice: string, from: 'feat' | string }   // 'feat': the feat/<slug> tip; else the blocker's branch (pipeline, L12)
// rows: the record's slice rows; blockers by status.mjs's blockersOf, phases by phaseOf
// startable = planned, every blocker done; or exactly one blocker whose state is `draft` (L12)
// order: graph order (a blocker before what follows it, ties by depth below the roots, then the `S<n>` number, then the name (co-pilot, as built in #446)), never row order; at most `slots`

pilot ready --ticket <id> --slots <n> [--repo <dir>]
  // reads GET /api/record?ticket=&repo=; prints one line per Start: "S<n> from <feat|branch>"; "none" when empty
  // exit 1 with one line when the deck is down or the ticket has no record
```

7. `pilot ready prints the starts and exits 1 with no record`: `pilot ready` → lines against a scratch deck; one line and exit 1.
