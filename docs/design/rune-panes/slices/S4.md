## Interface

```
chatView(reads, query) -> { id?, messages: [...], threads: [{ id, title, href }] }
pub fn draw(v: &Value, l: &Local, cx: &mut Cx<State>) -> El   // a thread row press goes to that thread
```

## Behaviours

1. `the tab's Create threads are listed` (test): `chatView` → two `user` items on the tab's repo and one on another: `threads` holds the two, open and closed alike.
2. `they sit above the messages` (test): `draw` → both rows' y above the first message's.
3. `a row opens its thread` (test): `draw` → pressing the second row sets the query to that thread's screen.
4. `they show with no chat open` (test): `draw` → no chat id, two threads: both rows drawn.

Rewrite check: any store read that yields the same items keeps behaviours 1-4.
Misses: the list's length on a busy tab; the walkthrough.
