## Behaviours

1. `the selector reads lane · title, one per line, a bar on the chosen` (test): `draw` → two seeded lanes draw "implementing · Build the kettle" and its sibling at two y's; one 2 px bar, beside the chosen.
2. `a URL in State opens the browser` (test): `draw` → pressing `http://localhost:3260/jobs.` in a State cell leaves 1 request, `http://localhost:3260/jobs`, in `take_url_requests`.
3. `a file URL stays text` (test): `links` → `file:///C:/x` returns one `Text` part.
4. `a held ticket with no record is flagged` (test): `statusView` → `held: true` for a held lane with no record; absent for a tab with no ticket.
5. `the held ticket says so` (test): `draw` → "no slice table yet" once on the deck, once under the overview group.

Rewrite check: replacing the hand scan with a regex keeps behaviours 2 and 3.
