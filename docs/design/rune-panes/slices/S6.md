## Behaviours

1. `an agent's start reads as the HTML deck's` (test): `agentsView` → `since` 3 min before now gives `started: '3 mins ago'`, the HTML deck's words for that age.
2. `the overview groups by deck` (test): `agentsView` → two decks with one agent each: 2 groups, in tab order.
3. `each row reads type · started` (test): `draw` → a seeded row's texts start "pilot-implementer · started 3 mins ago"; its quiet age is still drawn.
4. `a section per deck` (test): `draw` → two group headings, each above its own rows.

Rewrite check: computing the words in Rust from `since` instead keeps 3 and 4.
