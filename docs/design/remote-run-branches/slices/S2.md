# S2 `pilot branches prune --slug` clears the same leftovers

Feature `remote-run-branches` · delivers spec 4, 6 · source: `../architecture.md` §2, §3 F1, §5 L7, L10, L11 · after: S1 (`scripts/branches.mjs`, `runOwns`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument, `--slug`, picks what is deleted on a shared remote: the security trigger.

## Files owned

- `scripts/branches.mjs`: `main`'s select through S1's `runOwns`; its doc comment drops `isRunBranch`.
- `scripts/test/branches.test.mjs`: the sweep's pins.

## Interface

```
pilot branches prune --slug <slug> [--dry-run]   // flags unchanged
main(argv: string[], inject?) -> 0 | 1 | 2       // select: (name, known) => runOwns(name, slug, known)
S1's runOwns, S1's deleteMerged select(branch, known)
```

## Behaviours

1. `the sweep takes the run's leftovers and no longer run's` (test): `main` → `prune --slug x` on a scratch remote with merged `fix/x-drift` and `fix/x-y-drift`, `feat/x-y` known: prints `deleted fix/x-drift`, and `fix/x-y-drift` stays on the remote.
2. `a dry run over the real origin deletes nothing` (run): `pilot branches prune --slug prune-worktrees --dry-run` in this repo: `would delete` for 5 of 5 `fix/prune-worktrees-*`, `kept slice/prune-worktrees-s9`, and `git ls-remote origin` unchanged.

Rewrite check: whatever selects, `--slug x` never deletes a branch a longer known run owns.
Misses: a `--slug` naming a run that has not landed; the merged check keeps its unmerged branches, and QA's walkthrough reads the output.

## Done

- **Expected**: the user can list and clear a landed run's leftovers with `pilot branches prune --slug <slug>`, and `--dry-run` shows them first with nothing deleted.
- **Verification**: `node --test scripts/test/branches.test.mjs`; `npm run test:quiet`; behaviour 2's command, read.
- **Evidence**: behaviour 1 red before, green after; the existing `prune needs --slug` pin green unedited; behaviour 2's output and the unchanged `ls-remote` count.
- **Prohibited**: running the sweep without `--dry-run` against this repo's origin; a new flag; editing `deleteMerged` or `runOwns` (S1's).
- **Done when**: both behaviours hold and the gate is green.
