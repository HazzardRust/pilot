# S1 A landing deletes every merged branch it owns

Feature `remote-run-branches` · delivers spec 1, 2, 3, 5 · source: `../architecture.md` §2, §3 F1-F2, F4, §5 L2-L6, L8 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — the ownership rule decides what is deleted on a shared remote, and a wrong guard loses another run's names.

## Files owned

- `scripts/run-names.mjs` (new): `knownRuns` and `runOwns`, pure.
- `scripts/branches.mjs`: `deleteMerged` builds the known set from every ref it read and calls `select(branch, known)`.
- `scripts/land.mjs`: `deleteRunBranches` selects through `runOwns`, never `feat/<slug>`; its doc comment says so.
- `scripts/test/run-names.test.mjs` (new): the rule's pins, the real-origin read in behaviour 4.
- `scripts/test/land-prune.test.mjs`: the scratch-remote landing with the new names, the longer slug and the unmerged branch.
- `docs/adr/0228-remote-run-branches.md` (new): L2-L10; amends ADR 0134.

## Interface

```
knownRuns(names: Iterable<string>) -> Set<string>   // s of feat/<s>, and of design/<s> unless s ends '-recut'
runOwns(branch: string, slug: string, known: Set<string>) -> boolean
// true for feat|design|fix|qa/<slug>, fix|slice|qa/<slug>-<any>, design/<slug>-recut,
// unless a known run longer than slug names it (k === rest, or rest starts k + '-')
deleteMerged({ git, host, select, into, wait, dryRun, fetched }) -> { deleted, kept }
// select(branch: string, known: Set<string>) -> boolean; known from every remote's list read plus local refs
```

## Behaviours

1. `a landing deletes the run's merged leftovers` (test): `deleteMerged` → in the land-prune fixture, `fix/x`, `fix/x-drift`, `slice/x-base`, `qa/x-2`, `design/x-recut` merged into `feat/x`: 5 of 5 deleted, `feat/x` on origin.
2. `the longest known slug owns a branch` (test): `runOwns` → with `x` and `x-y` known, `fix/x-y-drift` and `design/x-y-recut` false for `x` and true for `x-y`; `design/x-recut` adds no known run.
3. `an unmerged branch is kept and named` (test): `deleteMerged` → an unmerged `fix/x-late` in `kept` with `not merged into origin/feat/x`; the landing's `kept:` line names it; `ls-remote` lists it.
4. `no real branch has two owners` (run): `runOwns` for every slug of `knownRuns` over `git ls-remote --heads origin` in this repo, read-only: 0 names claimed twice.

Rewrite check: any ownership rule keeps a longer known run's branches out and deletes only names whose tips feat/<slug> holds.
Misses: a run with no feat or design ref whose merged branch a shorter slug claims; F2 bounds it to a name, and the fundamentalist reads the guard.
