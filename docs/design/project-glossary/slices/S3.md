# S3 The audit names a stale term

Feature `project-glossary` · delivers spec 4, 7 · source: `../architecture.md` §2, §5 L3, L5 · after: S1 (`scripts/glossary.mjs`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — terms read from an audited repository reach a `git grep` process (security trigger).

## Files owned

- `scripts/glossary.mjs`: `staleTerms` and the `stale` command, beside S1's parser.
- `scripts/test/glossary-stale.test.mjs` (new): the pins.
- `scripts/test/fixtures/glossary-stale/` (new): a `GLOSSARY.md` of 3 terms and source files using 2 of them, made a git repository by the test.
- `skills/audit/areas/navigability.md`: item 5 names `GLOSSARY.md`; item 6 runs `check` and `stale` and judges contradiction.
- `scripts/test/audit-navigability.test.mjs`: pins item 6's commands.

## Interface

```
staleTerms(repoDir: string, text: string): { term: string, line: number }[]
  // L3: per term, `git grep -i -F -q -- <term>` outside GLOSSARY.md, docs/design/, docs/adr/; no hit = stale
node scripts/glossary.mjs stale <repo>   // one `<line> <term>` per stale term; exit 0 none, 1 some, 2 no glossary or no git
navigability.md: ## Measure item 6, glossary terms   // runs `check` and `stale`, judges contradiction
S1's parseGlossary, lintGlossary
```

## Behaviours

1. `one unused term is one result` (test): `staleTerms` → on the fixture, exactly 1 result naming the unused term.
2. `a term in a hostile shape stays a literal` (test): `staleTerms` → a term `--output=x` or `$(echo)` is searched as text, no file written, no shell.
3. `a term used only in docs/design is stale` (test): `staleTerms` → a term found only under `docs/design/` counts as unused.
4. `the area runs the measure` (test): `navigability.md` → its Measure section names `glossary.mjs stale` and `glossary.mjs check`, and stays read-only by the existing lint.

Rewrite check: any search keeping literal matching and the three exclusions keeps 1-3.
Misses: a term the code contradicts while still using its word; the explorer's judgement row reads it.

## Done

- **Expected**: an audit of a repository whose glossary keeps a word the code dropped shows one row naming it.
- **Verification**: `node --test scripts/test/glossary-stale.test.mjs scripts/test/audit-navigability.test.mjs`; `node scripts/glossary.mjs stale .`; `npm test`.
- **Evidence**: behaviours 1-4 red before, green after; the `stale .` output on this repository read and pasted in the report.
- **Prohibited**: no `shell: true` or string-built command; no regex mode for terms; no edit to `parseGlossary`'s shape (S1's).
- **Done when**: the 4 behaviours hold and `npm test` is green.
