# S7 The fundamentalist flags a term the diff misuses or orphans

Feature `project-glossary` · delivers spec 12 · source: `../architecture.md` §2, §5 L10 · after: S1 (`parseGlossary`), S4 (`staleTerms`)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — an agent definition (security trigger) and refs reaching `git diff`.

## Files owned

- `scripts/glossary-diff.mjs` (new): `termsInDiff` and its CLI.
- `scripts/test/glossary-diff.test.mjs` (new): the pins, over a scratch git repository with a base and a head.
- `agents/pilot-fundamentalist.md`: in "The judgement pass", one terms paragraph: run the command, judge each candidate, and check the artefact's lasting terms against the glossary diff; a kept one is a finding with its fix.
- `scripts/test/fundamentalist-terms.test.mjs` (new): pins that paragraph.

## Interface

```
termsInDiff(repoDir: string, base: string, head: string): Candidate[]
type Candidate =
  | { kind: 'avoid', word: string, term: string, file: string, line: number }  // an added Markdown line outside docs/design, docs/adr
  | { kind: 'orphaned', term: string }                                          // used at base, stale at head (S4's staleTerms)
  | { kind: 'glossary', term: string, change: 'added' | 'removed' }             // entries the diff adds or drops
node scripts/glossary-diff.mjs <repo> <base> <head>   // one line per candidate; exit 0
pilot-fundamentalist.md: ## The judgement pass, terms paragraph
```

## Behaviours

1. `an Avoid word in added prose is a candidate` (test): `termsInDiff` → a head adding "the subagents" to a `.md` file gives 1 `avoid` candidate naming `Crew`.
2. `a term whose last use goes is orphaned` (test): `termsInDiff` → a head deleting the only use of a term gives 1 `orphaned` candidate.
3. `code and design docs are not scanned for Avoid words` (test): `termsInDiff` → the same words added in a `.mjs` file and under `docs/design/` give 0 `avoid` candidates.
4. `the fundamentalist runs it and judges` (test): `pilot-fundamentalist.md` → its judgement pass names `glossary-diff.mjs` and the artefact's lasting terms, and the decisions-pass tests still pass.

Rewrite check: any differ giving these candidates on these fixtures keeps 1-3.
Misses: a new concept the diff names without the artefact calling it lasting; the fundamentalist's reading, not the script.
