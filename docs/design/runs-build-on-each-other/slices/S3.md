# S3 A stack deeper than 3 is refused

Feature `runs-build-on-each-other` · delivers spec 6 · source: `../architecture.md` §2, A3 · after: S1

## Files owned

- `scripts/base.mjs`: counts the stack under the top and refuses past the limit.
- `scripts/test/base-depth.test.mjs` (new): the depth pins.

## Interface

```
MAX_STACK = 3                                   // A3
pilot base -> exit 3, "stack of 3 open PRs (#a, #b, #c): merge one or ask the user" when the top already has 3 under it
S1's openRuns, topOf: the stack is walked through standsOn
```

## Tests

1. `three stacked open PRs refuse a fourth, naming all three`.
2. `two stacked open PRs still give a base`.
3. `a merged PR in the middle shortens the stack` (its standsOn chain stops at a closed PR).
4. `a standsOn cycle stops the walk and is reported, never loops`.
