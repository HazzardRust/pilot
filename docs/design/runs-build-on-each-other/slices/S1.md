# S1 Walking skeleton: `pilot base` names the top of the stack, and a run is cut from it

Feature `runs-build-on-each-other` · delivers spec 1, 2, 5, 7, 8, 12 · source: `../architecture.md` §2, F1-F5, L2, L3, L6, L8, L10 · after: –

## Files owned

- `deck/stack.mjs` (new): open runs of a directory, `Stands on` parsing with the L10 checks, the top of the stack.
- `scripts/base.mjs` (new): `pilot base`, one line out.
- `bin/pilot.mjs`: the `base` subcommand and its usage line.
- `deck/tickets.mjs`: `queueView` adds the directory's records (slug, branch, finished, updatedAt).
- `deck/server.mjs`: `/api/tickets` serves the records beside the queue; still a read.
- `agents/pilot.md`: step 2's brief carries `pilot base`'s line; Gate 1's PR body carries its `Stands on` line; step 5's integrate restatement cut to pay (L6).
- `agents/pilot-architect.md`: "Where you work" cuts from the base the brief names (spec 8).
- `deck/test/stack.test.mjs` (new), `scripts/test/base.test.mjs` (new), `deck/test/tickets.test.mjs`: the pins.

## Interface

```
GET /api/tickets?repo=  -> { live, green, decision, records: { slug, branch, finished, updatedAt }[] }   // records of this directory only
type OpenRun = { slug: string, branch: string, pr: number, standsOn: number | null, updatedAt: string }
type Gh = (args: string[]) => string            // argv only; default spawns `gh` without a shell
standsOnOf(body: string): number | null          // first /^Stands on #(\d+)\.$/m
openRuns(records, { gh, cwd }): OpenRun[]        // feat/ branch, not abandoned, PR open, same repository, authored by the signed-in gh account (L13)
checkedPr(n: number, { gh }): { number, headRefName, state, isCrossRepository, author } // refuses a fork, a non-feat/ head or another account's PR, by name
topOf(runs: OpenRun[]): OpenRun | null           // the one no other stands on; newest updatedAt on a tie
pilot base   -> "base feat/<a> <sha> stands on #N" | "base <default> <sha>" [+ "; <reason>" when gh could not answer]
```

## Tests

1. `a directory with no records prints the default branch` (spec 7).
2. `one open run is the base, with its tip and its PR` (spec 1).
3. `the top of a stack is the run no other stands on` and `the newest wins a tie` (spec 1).
4. `an abandoned record or a merged or closed PR is not an open run`.
5. `a Stands on line naming a fork PR is refused by name`, `naming a non-feat/ head is refused` and `naming a PR another account authored is refused` (spec 5); `an open PR of another account is not an open run` (spec 1, L13).
6. `a body "Stands on #12; rm -rf" yields no PR number`, and `gh` is called with argv arrays only (spec 5).
7. `gh failing prints the default branch with the reason` (R1).
8. `/api/tickets carries this directory's records and marks nothing delivered`.
9. `pilot.md step 2 names pilot base, Gate 1 names the Stands on line; pilot-architect.md cuts from the brief's base` (spec 2, 8; text pins).
