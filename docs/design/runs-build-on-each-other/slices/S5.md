# S5 A closed base is taken out when that is clean

Feature `runs-build-on-each-other` · delivers spec 13 · source: `../architecture.md` §2, L5, L10, L12 · after: S2

## Files owned

- `scripts/integrate.mjs`: before S2's closed-base stop, try the take-out; on success carry on with the default branch as the base.
- `scripts/test/integrate-takeout.test.mjs` (new): the take-out pins, on real git repos with a bare remote and a fake `gh`.

## Interface

```
integrate(branch?: string, options & { gh?: Gh }) -> { ok, line, failing, code? }   // unchanged from S2
line: "... took out #N (closed unmerged) at <sha>; base main@<sha> ..."            // clean
      | "NOT integrated: stands on #N, closed unmerged, take-out <conflicted | red: <tests>>: ask the user"   // code 3
take-out: one commit, subject "revert(<slug>): take out #N, closed unmerged", reverting #N's own non-merge commits
          (reachable from #N's head SHA as gh reports it, not from origin/<default>), newest first
already out: that subject for #N in feat/<slug>'s history -> base is the default branch, no second revert
```

## Tests

1. `a closed base is taken out in one revert commit, tested and pushed` (spec 13): #N's files are gone, B's stay.
2. `after the take-out the default branch is the base, and the slice is integrated in the same call` (spec 13).
3. `a second integrate does not revert again` (L12: the commit is the record).
4. `a take-out that conflicts resets to the start, pushes nothing and exits 3 naming #N` (spec 4).
5. `a take-out that turns the tests red resets to the start, pushes nothing and exits 3 naming #N and the tests` (spec 4).
6. `#N's merges of the default branch are not reverted`: main's commits that reached B through #N stay.

## Done

- **Expected**: in the L9 scratch clone, with `feat/b` cut from `feat/a` and #1 marked closed unmerged, `pilot integrate` pushes one revert commit and names `base main@<sha>`; with B editing a line A added, it exits 3 and `git status` and `git log` show the branch as it was.
- **Verification**: `node --test scripts/test/integrate-takeout.test.mjs scripts/test/integrate-base.test.mjs scripts/test/integrate.test.mjs`; `npm test`; §9 step 4 run in the scratch clone.
- **Evidence**: tests red before and green after; both integrate lines and `git log --oneline -3` pasted in the PR.
- **Prohibited**: no conflict resolved by the tool; no push of a revert the tests have not judged; no `gh pr edit`; no shell string carrying a ref, SHA or PR number; no rebase or force-push; never the real repository's branches.
- **Done when**: the six tests and `npm test` are green, and the scratch-clone step has been run with its output read.
