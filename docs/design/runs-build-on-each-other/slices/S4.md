# S4 Ticket-making checks what already exists

Feature `runs-build-on-each-other` · delivers spec 10, 11 · source: `../architecture.md` §2, F4, F6, L7, A5 · after: S1

## Files owned

- `deck/tickets.mjs`: `pilot tickets --open` prints every open ticket in any state and every open run's PR with its changed files.
- `deck/server.mjs`: `/api/tickets?open=1` adds open tickets of every state; still a read.
- `skills/ticket-making/SKILL.md`: a "Check first" step before the proposal, and the Found column.
- `deck/test/tickets-open.test.mjs` (new): the listing pins.
- `scripts/test/ticket-making.test.mjs`: the skill pins.

## Interface

```
GET /api/tickets?repo=&open=1 -> { ..., open: { id, title, state, body }[] }   // green, yellow, red; never closed
pilot tickets --open   // "## <id> — <title> (<state>)" + body per open ticket; then "## #N feat/<a>" + changed files
                     // (git diff --name-only origin/<default>...origin/feat/<a>, argv only) per S1 openRuns entry
Proposal columns: | # | Ticket | Holds | Why together | Found | Estimate | Position |
Found: "merge into <ticket>" | "drop: in #N" | "drop: in <ticket>" | "nothing found"
S1's openRuns: the unmerged PRs of this directory
```

## Tests

1. `--open lists green, yellow and red tickets of this directory and no closed or foreign ticket`.
2. `--open lists each open run's PR with the files it changes`.
3. `plain pilot tickets prints what it printed before` (merge-first pins stay).
4. `the skill runs pilot tickets --open before the proposal` (text pin).
5. `the proposal table carries Found with its three values` (text pin).
6. `the skill does not restate the same-surface merge` (merge-first L6; existing pin kept).

## Done

- **Evidence**: tests red before and green after; the `--open` output pasted in the PR.
- **Prohibited**: no merge rule copied from "Merge first"; the route writes nothing; the skill stays under its line pin; no change to `deck/stack.mjs`.
- **Done when**: the six tests and `npm test` are green, and `pilot tickets --open` has been run on the scratch deck with its output read.
