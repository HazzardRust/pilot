# S2 `pilot integrate` takes the base

Feature `runs-build-on-each-other` · delivers spec 3, 4, 9, 12 · source: `../architecture.md` §2, F3, F7, L4, L5, L6 · after: S1

## Files owned

- `scripts/integrate.mjs`: take the base before the slice; no-branch form takes the base alone; exit 3 on a closed base.
- `scripts/test/integrate.test.mjs`: existing pins kept green, the usage line updated.
- `scripts/test/integrate-base.test.mjs` (new): the base-taking pins, on real git repos with a bare remote and a fake `gh`.
- `agents/pilot.md`: step 5 says integrate takes the base; step 7 runs `pilot integrate` alone before the tip goes to QA, and the diff is against the base.
- `agents/pilot-fundamentalist.md`: line 14 reads the base the brief names.

## Interface

```
integrate(branch?: string, options & { gh?: Gh }) -> { ok, line, failing, code? }   // code 3: base closed unmerged
pilot integrate [<slice-branch>] [--test "<cmd>"] [--no-push] [--trailer "<line>"]...
line: "integrated <slice> at <tip> (base <ref>@<sha>): <counts>; pushed" | "took base <ref>@<sha> at <tip>: ..." 
      | "NOT integrated: stands on #N, closed unmerged: ask the user" | "... base not read: <why>"
S1's standsOnOf, checkedPr, Gh: how the base is found from this branch's own PR body
```

## Tests

1. `an open base's new tip is merged before the slice, in its own merge commit` (spec 3).
2. `once the base PR is merged, the default branch is taken instead` (spec 3).
3. `an unstacked run takes the default branch` (L4).
4. `no branch takes the base alone, tests, and pushes`.
5. `a base closed unmerged merges nothing and exits 3 naming it` (spec 4). S5 puts the clean take-out (spec 13, L12) in front of this stop; build the stop so that a step can run before it.
6. `a conflict taking the base aborts, resets to the start and names the base` (spec 4).
7. `red tests reset both merges; nothing is pushed` (L5).
8. `gh unavailable: the slice is integrated and the line says base not read` (R1).
9. `pilot.md step 7 runs integrate alone before QA's tip and diffs against the base; the fundamentalist reads the base` (spec 9; text pins).

- **Verification**: `node --test scripts/test/integrate.test.mjs scripts/test/integrate-base.test.mjs`; `npm test` (the pin included); the scratch-clone sequence of §9 steps 3-4 with `--no-push` off against the bare remote.
- **Evidence**: tests red before and green after; the integrate lines and the `git diff --name-only` output pasted in the PR; the measure-prompt figure.
