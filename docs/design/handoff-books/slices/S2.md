## Interface

```
advice(input, seen, marks, threshold, onDeck) -> { systemMessage, additionalContext }
  pilot, hard:    step 1's deck_status carries `friction`: every crew row not yet sent and your drains
  crew, hard:     step 2's handoff carries your friction row
  co-pilot:       one deck_status with your unsent `friction` rows, then hand back `paused`
nextRecord(previous, given) -> record        // deck/runs.mjs, unchanged
commitRecords(dir, trailers) -> boolean      // scripts/integrate.mjs, unchanged
```

## Tests

1. `the pilot's hard text asks for friction in step 1`: `advice` → `additionalContext` names `friction` before `pilot handoff`.
2. `the crew hard text asks for the friction row in the handoff`: `advice` → step 2 names `friction`.
3. `the co-pilot text asks for its rows before paused`: `advice` → names `deck_status` and `friction` before `paused`.
4. `rows written before a hand-off survive it`: `commitRecords` → `run.json` at HEAD holds n rows; `nextRecord` with 1 more → n+1.

Rewrite check: any wording of the three texts that names the rows in that step keeps tests 1-3; test 4 holds for any record store that appends.
