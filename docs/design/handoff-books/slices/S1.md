## Interface

```
export const OFFER_EVERY_HANDOFFS = 20;
export function countHandoff(repo: string, id: string): number   // count since the last offer or report; an id once
export function auditDue(repo: string): 'first' | 'every' | null  // 'every' at 20 counted hand-offs
export function recordOffer(repo: string, runKey: string): Record // re-arms handoffs to []
type Record = { offers: { run: string, at: string }[], handoffs: string[] }
pilot audit due      -> stdout `not due <n>` exit 1 | `due first` | `due every <n>` exit 0
pilot audit count    -> usage, exit 2
lane run(input)      -> result as today; one countHandoff per claimed hand-off id
```

## Tests

1. `twenty hand-offs make the audit due, nineteen do not`: `auditDue` → null at 19, 'every' at 20.
2. `the same hand-off counted twice counts once`: `countHandoff` → 1 then 1.
3. `the lane counts a claimed hand-off and pilot audit due reads it`: `lane run(input)` → `countHandoff` count 1; `pilot audit due` in that cwd prints `not due 1`.
4. `an offer re-arms the count`: `recordOffer` → `handoffs` is [].
5. `an old record of counted runs is read and not due`: `auditDue` → null for `{offers:[x], counted:[10 runs]}`.
6. `audit count is gone`: `pilot audit count` → exit 2 with the usage.

Rewrite check: storing the count anywhere else in the store keeps all six results.
