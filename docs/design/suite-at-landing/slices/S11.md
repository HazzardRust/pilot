## Files owned

- `scripts/select-tests.mjs`: `TEST_GLOB` skips `test/lib/`.

## Interface

```
TEST_GLOB  // '**/{test,test/*,test/!(lib)/**/*,test-*,*[._-]test}.{js,mjs,cjs,ts,mts,cts}'
           // matches no path under a test/lib/ directory; the helpers stay in test/
```

## Tests
