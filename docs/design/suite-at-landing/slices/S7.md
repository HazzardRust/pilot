# S7 The landing runs the full suite once and says so on the PR

Feature `suite-at-landing` · delivers spec 3, 7 · source: `../architecture.md` §2, L8 · after: S6 (`mergeIntoPilot`'s `counts`)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — one comment string and two pins; the full run needs no change in land (L8).

## Files owned

- `scripts/land.mjs`: `comment` carries the feature merge's `counts`.
- `scripts/test/land-suite.test.mjs` (new): the pins below over a land fixture (`scripts/test/lib/land-repos.mjs`).

## Interface

```
comment({ gh, head, sha, counts: string | null })
  // body: `landed on pilot at <sha>; full suite <p> pass, <f> fail`; counts null: `landed on pilot at <sha>`
land({ cwd, git, gh, test, ... })   // unchanged signature; the feature merge passes no since
```

## Tests

1. `the land comment names the full run`: `comment` → `gh` receives `landed on pilot at <sha>; full suite 12 pass, 0 fail`.
2. `the feature merge is the full run`: `land` → with a `test:changed` script present, the feature merge runs `npm test` with no `--since`, 1 time.
3. `no counts, the old comment`: `comment` → counts null gives `landed on pilot at <sha>`.

Rewrite check: building the body elsewhere keeps all three results.

## Done

- **Expected**: the feature PR shows `landed on pilot at <sha>; full suite <p> pass, <f> fail`.
- **Verification**: `node --test scripts/test/land-suite.test.mjs scripts/test/land*.test.mjs` in the background; `npm test`.
- **Evidence**: tests 1 and 2 red before, green after.
- **Prohibited**: a second suite inside land; parsing counts out of `merge.line`.
- **Done when**: the three tests and `npm test` are green.
