# S5 `testCommand` picks the repository's selected or full command

Feature `suite-at-landing` · delivers spec 5 · source: `../architecture.md` §2, §3 Seams, L9, L10, A5 · after: S1 (`scopeOf`, the `test:changed` contract)
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — the fold changes how a shell command is composed (the security trigger, ADR 0110).

## Files owned

- `scripts/integrate.mjs`: `testCommand` replaces `repoTestCommand`; `runTests` takes `slot` and answers `scope`.
- `scripts/sync.mjs`: its `repoTestCommand(dir)` becomes `testCommand(dir)?.command`; no behaviour change.
- `scripts/test/test-command.test.mjs`: the ADR 0110 pins moved onto `testCommand`, and the pins below.

## Interface

```
testCommand(cwd: string, { since?: string } = {})
  -> { command: string, selected: boolean } | undefined
  // since a 40/64-hex sha and package.json has scripts["test:changed"]:
  //   { command: `npm run test:changed -- --since=<sha>`, selected: true }
  // otherwise npm test | git config pilot.test, selected false; neither: undefined
  // since given and not a full sha: throws (callers pass rev-parse output only)
runTests(cwd, test, { label, home, slots, slot = true })
  -> { status, counts, failing, log, scope: string | null }
  // slot false: no takeSlot, PILOT_GATE_SLOT not set; scope = S1's scopeOf(output)
```

## Tests

1. `a test:changed script selects`: `testCommand` → a package.json with both scripts and a sha gives the `--since=<sha>` command, selected true.
2. `a selecting run takes no slot and passes none`: `runTests` → `slot: false` with a command printing `PILOT_GATE_SLOT` shows it unset and the slot dir empty.
3. `npm test alone stays full`: `testCommand` → a package.json with only `test` gives `npm test`, selected false, sha or not.
4. `git config pilot.test stays full`: `testCommand` → no package.json and `pilot.test` set gives that command, selected false.
5. `a ref that is not a sha is refused`: `testCommand` → `since: 'main; rm -rf x'` throws.
6. `the scope reaches the caller`: `runTests` → a command printing `selected 2 of 9 test files since abc1234` answers that as `scope`.

Rewrite check: reading package.json another way keeps all six results.

## Done

- **Expected**: a repository with a `test:changed` script gets its selection; any other runs its full suite as today.
- **Verification**: `node --test scripts/test/test-command.test.mjs scripts/test/red-line.test.mjs scripts/test/gate-slots.test.mjs`; `npm test`.
- **Evidence**: tests 1, 2 and 5 red before, green after.
- **Prohibited**: interpolating anything but a validated sha; keeping `repoTestCommand` as a pass-through.
- **Done when**: the six tests and `npm test` are green and no caller of `repoTestCommand` is left.
