# S2 The selection follows import chains, prose pins and whole-tree tests

Feature `suite-at-landing` · delivers spec 1 · source: `../architecture.md` §2, §3, A1, A2 · after: S1 (`select-tests.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — the mapping rule (A1) is assumed and its recall is the feature's risk.

## Files owned

- `scripts/select-tests.mjs`: transitive importers (static and literal `import()`), basename mentions, `TREE_TESTS`.
- `scripts/test/select-tests.test.mjs`: the pins below, and the tree-test census over the real repository.

## Interface

```
selectTests(...)   // S1's; now also: tests reaching a changed module through any chain of
                   // relative imports; tests whose source names a changed file's basename;
                   // every TREE_TESTS entry that exists; deleted test files never listed
TREE_TESTS: readonly string[]   // repo-relative tests that read every tracked file of a kind
treeWalkers(root: string) -> string[]   // test files whose source runs ls-files or readdirSync of the root
```

## Tests

1. `an import chain selects the far test`: `selectTests` → `t.test.mjs` imports `a.mjs` imports `b.mjs`; changing `b.mjs` selects `t.test.mjs`.
2. `a literal dynamic import counts`: `selectTests` → `await import('../c.mjs')` in a test selects it when `c.mjs` changes.
3. `a prose pin is selected by name`: `selectTests` → a test reading `agents/x.md` through `path.join` is selected when `agents/x.md` changes.
4. `whole-tree tests ride every selection`: `selectTests` → a docs-only diff answers exactly the fixture's `TREE_TESTS`.
5. `a deleted test file is not listed`: `selectTests` → a diff deleting `old.test.mjs` answers no path to it.
6. `every tree walker is listed`: `treeWalkers` → over this repository, every file it answers is in `TREE_TESTS`.

Rewrite check: a graph built by a parser instead of the regex keeps results 1 to 5; 6 holds for any list kept current.

## Done

- **Expected**: changing `deck/store.mjs` selects the server and render tests that reach it, and every `agents/*.md` pin is selected when its file changes.
- **Verification**: `node --test scripts/test/select-tests.test.mjs`; `npm test`; `npm run test:changed -- --since=<a commit before one touching agents/pilot.md>`, its output read.
- **Evidence**: tests 1 and 6 red before, green after; the live selection count for an `agents/pilot.md` change.
- **Prohibited**: hard-coding this repository's paths outside `TREE_TESTS`; weakening test 6 to a count.
- **Done when**: the six tests and `npm test` are green.

## Seam note (co-pilot, at integration)

Basename mentions are matched against every reached file (the changed files plus everything importing them, directly or not), not the changed files alone, so a test that spawns a script by path is selected when a module that script imports changes. Within A1 (its verdict: spec 1 says "directly or through other modules"; S10 measures the cost); if S10's replay puts the median over 60%, narrowing mentions back to the changed files is the first lever.
