# S3 The selection falls back to full and says why

Feature `suite-at-landing` · delivers spec 2 · source: `../architecture.md` §2, L3, A6 · after: S2 (`select-tests.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: sonnet — six fixed triggers, each with its reason named here; nothing is left to choose.

## Files owned

- `scripts/select-tests.mjs`: `FULL_TRIGGERS`, the unreached-source rule, the argv bound.
- `scripts/test/select-fallback.test.mjs` (new): one pin per trigger.

## Interface

```
FULL_TRIGGERS: readonly string[]
  // package.json, package-lock.json, scripts/gate.mjs, scripts/gate-slots.mjs,
  // scripts/count-spawns.mjs, scripts/select-tests.mjs
ARGV_LIMIT = 24000   // joined absolute selected paths, characters
selectTests(...)   // S1's; files null with reason:
  // `<path> changed` for a trigger; `<path> reaches no test` for an unreached .mjs/.js/.cjs;
  // `selection is <n> characters of argv, over 24000`
```

## Tests

1. `package.json runs full`: `selectTests` → reason `package.json changed`.
2. `the lockfile runs full`: `selectTests` → reason `package-lock.json changed`.
3. `the gate runs full`: `selectTests` → each of the four script triggers in `FULL_TRIGGERS` gives `<path> changed`.
4. `an unreached module runs full by name`: `selectTests` → a new `lib/lonely.mjs` no test reaches gives `lib/lonely.mjs reaches no test`.
5. `unreached prose does not run full`: `selectTests` → a new `docs/x.md` answers `TREE_TESTS` only.
6. `a selection past the argv bound runs full`: `selectTests` → with 400 long paths selected, the reason names the character count over `ARGV_LIMIT`.

Rewrite check: any rule order keeps each reason; a diff with two triggers may name either.

## Done

- **Expected**: a diff that touches package.json prints `full suite: package.json changed` and runs everything.
- **Verification**: `node --test scripts/test/select-fallback.test.mjs`; `npm test`; `npm run test:changed -- --since=HEAD` with package.json touched locally (reverted after), its output read.
- **Evidence**: each of the six red before, green after; the live scope line.
- **Prohibited**: a silent fallback; reading a git error as an empty diff.
- **Done when**: the six tests and `npm test` are green.
