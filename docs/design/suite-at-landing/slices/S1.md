# S1 `npm run test:changed -- --since=<ref>` runs the changed tests and their importers

Feature `suite-at-landing` · delivers spec 1 · source: `../architecture.md` §2, §3, L2, L5-L7, L10 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a CLI argument reaches git (the security trigger), and this seam carries every later slice.

## Files owned

- `scripts/select-tests.mjs` (new): `selectTests` over the diff, the changed test files and their direct importers; `scopeLine`, `scopeOf`.
- `scripts/gate.mjs`: `--since=<ref>` takes the selection; the flag never reaches `node`; an empty selection runs nothing.
- `package.json`: `"test:changed": "node scripts/gate.mjs"`, the contract that the script takes `--since=<sha>`.
- `scripts/test/select-tests.test.mjs` (new): the selector pins over a git fixture (`scripts/test/lib/git-fixture.mjs`).
- `scripts/test/gate-select.test.mjs` (new): the gate's `--since` pins, `spawn` and `select` injected.

## Interface

```
selectTests({ cwd: string, since: string, git?: (args: string[]) => string })
  -> { files: string[] | null, total: number, since: string, reason?: string }
  // files: absolute test paths; null = full run, reason says why; since: the merge-base sha
  // diff = git diff --name-only <merge-base(since, HEAD)> plus ls-files -o --exclude-standard
  // a ref git rev-parse --verify cannot resolve: files null, reason `cannot resolve <ref>`
scopeLine(selection) -> string   // `selected <n> of <m> test files since <sha7>` | `full suite: <reason>`
scopeOf(output: string) -> string | null   // the last scope line in a gate's output
runGate(args: string[], { select?: typeof selectTests, ... }) -> number
  // args with --since=<ref>: prints scopeLine first; files [] -> exit 0, no node --test
```

## Tests

1. `a changed test file is selected alone`: `selectTests` → a fixture where only `test/a.test.mjs` changed answers that one file of 3.
2. `a changed module selects its direct importers`: `selectTests` → changing `lib/b.mjs` answers the two tests importing it, not the third.
3. `an empty selection starts no node`: `runGate` → `--since` with a selection of `[]` prints `selected 0 of 3` and `spawn` is never called.
4. `the since flag never reaches node`: `runGate` → the spawned argv has the selected files and no `--since`.
5. `an unresolvable ref runs full and says so`: `selectTests` → `--since=nope` gives `files: null`, reason `cannot resolve nope`.
6. `the scope line round-trips`: `scopeOf` → reads back what `scopeLine` wrote, from output with test noise around it.

Rewrite check: replacing the diff or the import scan with another implementation keeps all six results.
