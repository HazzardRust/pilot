# S6 Integrate and sync run the selection

Feature `suite-at-landing` · delivers spec 3 · source: `../architecture.md` §2, §3, L4, L6, L8 · after: S5 (`testCommand`, `runTests`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — five call sites, each with its own `since`, and the land path must stay full.

## Files owned

- `scripts/integrate.mjs`: slice and base, `--default` and its resume pass `since` = the tip before the merge; the line carries the scope.
- `scripts/sync.mjs`: `mergeIntoPilot` takes `since`; `sync` passes pilot's tip; it answers `counts`.
- `scripts/test/integrate-select.test.mjs` (new): over git fixtures with a `test:changed` script that echoes its argv.

## Interface

```
integrate(branch, options) -> { ok, line, failing }
  // line: `integrated <slice> <sha7> (base <ref>): <counts>; <scope>; pushed`
mergeIntoPilot({ cwd, git, source, message, test, label, keep, reuse, side, push, since? })
  -> { sha, merged, line, counts: string | null }
  // since given: testCommand(dir, { since }); absent: the full command (land's feature merge)
sync({ cwd, git, test, keep }) -> { sha, merged, line }   // passes since = pilot's tip
```

## Tests

1. `a slice merge runs the selection since the tip before it`: `integrate` → the echoed argv has `--since=<start sha>` and the line holds the scope.
2. `taking the default runs the selection`: `integrate` → `--default` echoes `--since=<start sha>`.
3. `sync selects since pilot's tip`: `sync` → main moved; the echoed argv has `--since=<pilot tip>`.
4. `a merge into pilot without since runs full`: `mergeIntoPilot` → no `since`, the command is `npm test` and `counts` is set.
5. `an injected test command is run as given`: `integrate` → `test: 'node -e ...'` runs that, in a slot.

Rewrite check: computing `since` another way keeps 1 to 3 as long as it names the pre-merge tip.
