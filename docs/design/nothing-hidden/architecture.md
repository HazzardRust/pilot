# nothing-hidden: nothing waiting on you is hidden from the deck

Ticket `itm_31849c6b5525` · base `feat/ci-gate` (203bcfb6) · merge thread `itm_5884fcab7255` (merged none) · ADR 0204

## 1. Problem

The home page lists only the threads of each stage's ticket in hand. A thread of any other open red or green
ticket is "behind" and is dropped from the home queue, its counts and its thread arrows. A landing ticket is never
in hand (ADR 0154 L1), so its gate2 is always behind. On 2026-11-19/20 this hid gate2 `itm_c6ad0caef772` for 7
hours, plus question `itm_1309ffdc6081` and walkthrough `itm_bf15a1968bf3` of a parked green ticket. The user: "I
can not see this gate 2. it is not on my deck … make sure that tickets like that show up on the deck instead of
hiding away". Everything waiting on the user is drawn and counted on home, always.

## 4. Ubiquitous language

- **Queued**: open and not a chat (`isQueued`); everything waiting on the user or the pilot. Drawn always.
- **Behind**: a queued thread whose ticket is open, not yellow, not paused, and not in hand on its stage. Folded,
  unless it is an owed press.
- **Owed press**: a gate1, gate2 or signoff, a press the user owes; never folded.
- **Fold**: the one counted `<details>` line under home's cards holding every behind thread that is not an owed press.
- **Shown queue**: the cards home draws: in-hand, unticketed and every owed press.
- **Standing**: where a thread's ticket stands, `standingOf`'s word.
- **In hand**: a stage's live ticket, else its next (`inHandOf`).
