# S3 A slice integrates as one subject with its verdicts

Feature `pilot-develop-line` · delivers spec 3 · source: `../architecture.md` §2, A3, A8 · after: –
Reviewers: `pilot:typescript-reviewer`
Model: opus — deletes the slice-PR lookup across `integrate.mjs` and its tests; the subject source moves to the run record.

## Files owned

- `scripts/integrate.mjs`: the slice merge's subject is `feat(<slug>): S<n> <title>` from the run record row whose `branch` is the slice; `prOf`, `mergeMessage`'s `(#n)`, `titleProblem` and the `findPr` option go; `trailers` stay.
- `scripts/test/integrate-slice-commit.test.mjs` (new): the pins below.
- `scripts/test/integrate.test.mjs`: PR-title and `(#n)` cases removed or rewritten to the record subject.

## Interface

```
integrate(branch, { cwd, test, push, trailers, gh, install, wait }) -> { ok, line, failing, code? }
  // the merge commit: subject `feat(<slug>): S<n> <title lower-case first>`, body the trailers, e.g. `Reviewed-by: pilot:typescript-reviewer: approve`
  // the row: docs/design/<slug>/run.json slices[] with branch === <slice>; none: `NOT integrated <slice>: no run record row names it; nothing merged or pushed`
sliceSubject(slug, row) -> string   // `feat(<slug>): S3 a slice integrates as one subject`
```

## Tests

1. `the slice merge carries the record's subject`: `integrate` → `git log --first-parent -1 --format=%s` is `feat(demo): S1 one thing`.
2. `every trailer rides the slice commit`: `integrate` → two `--trailer Reviewed-by:` values appear in `%b`.
3. `a slice no row names is refused`: `integrate` → line starts `NOT integrated`, HEAD unmoved, 0 pushes.
4. `no PR is read`: `integrate` → the fake gh records 0 `pr list` calls.
5. `the subject lower-cases the title's first letter`: `sliceSubject` → `S2 The x` gives `S2 the x`.

Rewrite check: any source of the title keeps one first-parent subject per slice with its trailers.

## Done

- **Expected**: `git log --first-parent feat/<slug>` reads one `feat(<slug>): S<n> …` per slice, each with its reviewers.
- **Verification**: `node --test scripts/test/integrate*.test.mjs`; `npm test`.
- **Evidence**: the test output and one `git log --first-parent --format='%s%n%b'` from the test repo pasted in the report.
- **Prohibited**: no squash; no fallback to a PR title; no change to the base merge (spec 5).
- **Done when**: the five tests pass, `integrate-base.test.mjs` passes unchanged, `npm test` is green.

## Seam change (co-pilot, 2026-10-21)

The subject refusal applies only when `docs/design/<slug>/run.json` exists and has no `slices[]` row whose `branch` is the slice; with no run.json the subject stays `Merge <slice>`, so unowned integrate fixtures pass unchanged. *Assumed*, default taken.

## Seam change 2 (co-pilot, 2026-10-21)

`pilot integrate` refuses, nothing merged, a `--trailer` value with a CR or LF or not matching `^[A-Za-z][A-Za-z-]*: \S.*$` (S4 security review MEDIUM: a forged line reaching a `Reviewed-by:` trailer). Built in S3's fix round.
