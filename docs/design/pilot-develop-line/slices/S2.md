## Interface

```
comment({ gh, head, sha, counts, already = false, wait = 30_000, sleep }) -> void
  // polls `gh pr view <n> --json state` until MERGED or wait elapses; then `gh pr comment <n> --body "landed on pilot at <sha>…"`
  // never calls `gh pr close`; still OPEN after wait: comments anyway, and land prints `feature PR #<n> still reads open`
```

## Tests

1. `an open PR that turns merged is commented, not closed`: `comment` → fake reads OPEN, OPEN, MERGED: 0 `pr close`, 1 `pr comment`.
2. `a PR still open after the wait is commented and named`: `comment` → land output has `feature PR #7 still reads open`, 0 `pr close`.
3. `already landed comments on nothing`: `comment` → `already: true`, 0 gh writes.

Rewrite check: any wait strategy keeps 0 `pr close` calls and 1 comment per landed PR.
