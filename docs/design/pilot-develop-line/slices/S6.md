# S6 integrate takes the chained base until N lands

Feature `pilot-develop-line` · delivers spec 4a, 5 · source: `../architecture.md` §2, L6 · after: S3 (`integrate.mjs`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — a record field across the deck tool schema and the integration base, with the prompt pin.

## Files owned

- `deck/runs.mjs`: `RECORD_ORDER` gains `base` after `branch`; a cell `feat/<slug>` or `pilot`.
- `deck/tools.mjs`: `deck_status` takes `base` (string).
- `scripts/integrate.mjs`: `baseOf` reads the record's `base`; `feat/<N>` until `landedOnPilot(cwd, 'feat/<N>', pilot)`, then pilot.
- `scripts/test/integrate-chain.test.mjs` (new): the pins below.
- `scripts/test/measure-prompt.test.mjs`: the pin moves by the measured cost of `base`.

## Interface

```
baseOf(cwd, runs) -> { ref: string, chained?: string }
  // ref: `origin/feat/<N>` while the record's base is feat/<N> and N has not landed; chained: 'feat/<N>'
  // else { ref: '<runs>/pilot' } as now
deck_status({ slug, base?: string, … })   // base: 'feat/<slug>' | 'pilot'
```

## Tests

1. `a chained run merges N's tip`: `baseOf` → record base `feat/n`, N unlanded: ref `origin/feat/n`, chained `feat/n`.
2. `once N lands the base is pilot`: `baseOf` → a `Merge feat/n into pilot` on pilot: ref `origin/pilot`, no chained.
3. `a record without base is pilot`: `baseOf` → ref `origin/pilot`.
4. `deck_status keeps base`: `deck_status` → the record and `run.json` mirror carry `base: feat/n`.

Rewrite check: any source of the record keeps the base switching exactly at N's landing merge.

## Done

- **Expected**: a chained run's slices take N's fix rounds while N waits, and pilot once N lands.
- **Verification**: `node --test scripts/test/integrate-chain.test.mjs scripts/test/integrate-base.test.mjs scripts/test/measure-prompt.test.mjs`; `npm test`.
- **Evidence**: test output; `integrate-base.test.mjs` unchanged and green.
- **Prohibited**: no base read from ancestry; no change to `landedOnPilot`'s rule.
- **Done when**: the four tests pass, the prompt pin passes and `npm test` is green.
