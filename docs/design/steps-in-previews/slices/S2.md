## Files owned

- `deck/view/thread.mjs`: `standingLine` exported as `ticketLineOf`; `threadView` gains `steps` for a steps thread.
- `deck/view/queue.mjs`: `cardOf` gains `ticket`, read from `ticketLineOf`.
- `deck/rune/src/regions/queue.rs`: `Card.ticket`, drawn after the kind and time on the card's kind line.
- `deck/rune/src/regions/thread.rs`: `Thread.steps`, drawn as a numbered list under the body, with Done while open.
- `deck/test/view-steps.test.mjs` (new): the view pins.
- `deck/rune/tests/deck/support/seed-steps.mjs` (new): seeds a green ticket and its steps thread on a scratch store with `postSteps`.
- `deck/rune/tests/deck/queue.rs`: the card's ticket line and count.
- `deck/rune/tests/deck/thread.rs`: the steps, Done, and the closed ticket.

## Interface

```
ticketLineOf(item, items, lanes) -> string | undefined   // '<ticket title> <standing>', was standingLine
cardOf(item, { items, lanes, tab, back, all }) -> Card & { ticket?: string }
threadView(reads, { id }) -> Thread & { steps?: { texts: string[], open: boolean } }   // steps threads only
Card { ..., ticket: Option<String> }        // queue.rs, serde default
Thread { ..., steps: Option<Steps> }        // thread.rs; Steps { texts: Vec<String>, open: bool }
Done press -> act::send(&mut s.pending, "done", Action::Close { id })   // no confirm
node seed-steps.mjs <dir> <repo> <n> -> prints the steps thread's id
```

## Behaviours

1. `a card names its ticket` (test): `cardOf` → a question on ticket T reads `ticket` with T's title; a thread on no ticket has none.
2. `the steps view carries its steps` (test): `threadView` → a 3-step thread's `steps.texts` has 3 entries and `open` true; closed, `open` false; a question has no `steps`.
3. `the Rune card draws the ticket and the count` (test): `Card` → from a scratch deck's view, the steps card's texts hold `human steps · 3 steps` and the ticket's title.
4. `Done in Rune closes the thread and its ticket` (test): `Thread` → 3 numbered rows and one Done; one press posts `/close`; the scratch deck's item reads closed and its ticket `closed`.
5. `the window shows it` (look): `pilot-deck --open "screen=thread&id=<id>" --theme dark --snap <png>` and `--theme light` on the scratch deck; both snaps show the steps and Done.

Rewrite check: drawing Done from the reply box instead keeps 4.
