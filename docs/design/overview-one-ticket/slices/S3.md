# S3 Ticket groups fold, start folded and show their counts

Feature `overview-one-ticket` · delivers spec 12–14 · source: `../architecture.md` §2, L9, A2 · after: S2

## Files owned

- `deck/ui/render.mjs`: `renderTicketQueue` becomes a shut `<details class="ticket-queue" data-queue data-repo>` whose `<summary>` is the heading and count; `TICKETS_OPEN` no longer opens on red (A2).
- `deck/ui/deck.css`: the summary styled as today's `h3`, keeping the state colour.
- `deck/ui/js/live.mjs`: re-applies the remembered open groups to every fetched page, as for days.
- `deck/ui/js/bookmarks.mjs`: remembers open groups in `localStorage`; `showFirstRed` goes (A2).
- `deck/ui/js/page.mjs`: drops the `showFirstRed` call.
- `deck/test/ticket-folds.test.mjs` (new): the pins.
- `deck/test/resize.test.mjs`: the `showFirstRed` case goes with it.

## Interface

```
<details class="ticket-queue" data-queue="green|yellow|red"><summary>Green <span class="count">20</span></summary>…</details>
localStorage 'pilot.ticket-folds': { [repoKey]: Array<'green'|'yellow'|'red'> }   // the opened groups
```

## Tests

1. `each group is a shut details with its count in the summary`: spec 12–14 on the rendered HTML.
2. `an opened group is remembered and re-opened on load`: spec 13, with a fake `localStorage`.
3. `a live swap keeps the opened groups open`: the `live.mjs` refold.
4. `the Tickets bookmark does not open itself on a red ticket`: A2.

## Done

- **Expected**: Tickets shows three coloured headings with counts and no rows; a press opens one, and it stays open across a reload.
- **Verification**: `node --test deck/test/ticket-folds.test.mjs deck/test/resize.test.mjs`; `npm test`.
- **Evidence**: tests red before, green after; on the scratch deck with 21 green tickets, the fold pressed, the page reloaded, and the open group seen still open.
- **Prohibited**: no server-stored fold state; no `sessionStorage`; no script-only fold (the `<details>` works without JS); `renderPreviews` and the move arrows keep working inside a fold.
- **Merge-first**: no overlap.
- **Done when**: `npm test` is green and the fold, count and reload have been seen in a browser.
