# S3 A human step sent with deck_status is kept on the run record

Feature `human-steps` · delivers spec 7 · source: `../architecture.md` §2, §3, §5 L5, §6 A1 · after: –
Reviewers: `pilot:typescript-reviewer`, `pilot:security-reviewer`
Model: opus — a new tool argument at an API boundary that must refuse a credential; A1 is assumed.

## Files owned

- `deck/tools.mjs`: `deck_status` schema gains `step`.
- `deck/server-tools.mjs`: `deck_status` passes `step` to `setSlices`.
- `deck/store-runs.mjs`: `setSlices` appends a step to `record.humanSteps`.
- `deck/test/human-step-record.test.mjs` (new): the pins.

## Interface

```
deck_status { ..., step?: string }   // one human step, one line, 1-300 chars
record.humanSteps: { text: string }[] // at most 20, in arrival order
setSlices(runId, slices, feature, given: { ..., step?: string })
  // refused: empty, >300 chars, multi-line, a credential (refuseCredentials), a 21st step
```

## Behaviours

1. `a sent step is kept in order` (test): `setSlices` → given `step` twice, `record.humanSteps` = the two `{ text }` in order.
2. `a credential value is refused` (test): `setSlices` → given `step: "Set KEY=ghp_…"`, `DeckRefusal`; record unchanged.
3. `the schema bounds hold` (test): `setSlices` → `DeckRefusal` for an empty, a 301-char, a two-line and a 21st step.
4. `the tool takes it` (run): `deck_status` with `step` on a scratch deck → `D<n>: … saved`, and the record file shows it.

Rewrite check: any store of the record keeping order and the bounds keeps 1-3.
Misses: whether the crew sends steps at all; S4's prose and QA's run read that.

## Done

- **Expected**: the pilot can record a human step the moment the crew reports one, and no secret value is stored.
- **Verification**: `node --test deck/test/human-step-record.test.mjs`; `npm test`; one `deck_status` call on a scratch deck.
- **Evidence**: behaviours 1-3 red before, green after; the scratch call's answer line.
- **Prohibited**: no step stored before the credential check; no second store of steps outside the record; no edit to `deck_post`'s concluding line (yellow-never-idle's, landed).
- **Done when**: the four behaviours hold and `npm test` is green.
