## Interface

```
KIND_STEPS = 'steps'
postSteps({ ticket: string, repo: string, title: string, steps: { text: string }[] }): Item
  // refused: ticket not open green; 0 or >20 steps; a text empty, >300 chars, multi-line, or carrying a credential
closeTicket(ticket, by: string, at: string): void  // state closed, resolution `closed by <by>`, resolvedAt; clears live, concludedBy
closeItem(id): Item      // on a steps thread: resolution CLOSED_BY_USER, closeTicket on its ticket in the same write, no reply seq
resolveItem(id, resolution, author): Item   // on a steps thread: DeckRefusal for every author
isReportOwed(ticket, items): boolean        // false once a report names the ticket
postItem(fields): Item   // a report clears live, concludedBy; closeTicket only when no open steps thread names it; kind steps refused
yellow-never-idle's concludedBy: the ticket field a green ticket's gate2 exemption reads (store-items.mjs:216)
```

## Behaviours

1. `a report leaves its ticket green while a steps thread is open` (test): `postSteps` → a report posted after it leaves `stateOf(ticket)` = `green`, `concludedBy` and `live` unset, and a gate2 on it refused.
2. `a report on a ticket with no steps thread closes it as today` (test): `postItem` → a report on a ticket no steps thread names leaves `stateOf(ticket)` = `closed`.
3. `Done closes thread and ticket and hands nothing to a waiter` (test): `closeItem` → thread and ticket closed, the ticket's fields equal to a report's close (`closeTicket`); `repliesSince(seqBefore)` returns 0 replies.
4. `no agent closes or posts a steps thread` (test): `resolveItem` → `DeckRefusal` for `pilot`, `lander`, `qa`; `deck_post` kind `steps` refused.
5. `the ticket holds no lane and is owed nothing` (test): `isReportOwed` → false after the report; `nextTicketOf(items, repo, 'green')` → the next green ticket.
6. `the Stop gate does not hold for it` (test): `KIND_STEPS` → standing in `deck/items.mjs` and `hooks/lib/deck.js` alike, `isStanding` true in both; `join.test.js` pins the lists equal.
7. `the user sees the steps and presses Done` (look): a scratch deck page shows the ticket labelled `human steps`, the numbered steps and `Done`; one press closes both.

Rewrite check: any store keeping the ticket open until the thread's close keeps 1-3; any kind list keeps 4-6.
Misses: whether the label reads as a reminder; QA's walkthrough and the user read it.
