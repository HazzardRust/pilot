# S2 The lander's report posts the steps thread and loses its human steps

Feature `human-steps` · delivers spec 1, 2, 8 · source: `../architecture.md` §2, §3, §5 L2, L5, §6 A5 · after: S1 (`postSteps`), S3 (`record.humanSteps`)
Reviewers: `pilot:typescript-reviewer`
Model: opus — A5 is assumed, and four existing report tests move their human-step pins to a new seam.

## Files owned

- `deck/closing-report.mjs`: `stepsOf`; `closingReportOf` drops `mainStep` and `PRUNE_STEP` from the body; `postFilled` posts the steps thread before the report and refuses a second report.
- `deck/test/closing-report.test.mjs`: human-step pins moved to `stepsOf`; the body has none.
- `deck/test/closing-main-pr.test.mjs`: main-PR pins read `stepsOf`.
- `deck/test/host-none-report.test.mjs`: by-hand pins read `stepsOf`.
- `deck/test/report-post-body.test.mjs`: the filled report beside its steps thread.
- `deck/test/human-steps-fill.test.mjs` (new): the pins.

## Interface

```
stepsOf(record, gate, left: string[] | Error): { text: string }[]
  // [main-PR step, ...record.humanSteps, 'Remove <path> when you are done with it.' per left, prune step]
postFilled(fields): Item   // bodiless lander report: S1's postSteps first (unless one names the ticket), then the report
S1's postSteps, S3's record.humanSteps
```

## Behaviours

1. `a landing posts one steps thread in order` (test): `postFilled` → on a landed gate2, a record with one step and one worktree left, one steps thread: main-PR, the step, `Remove <path>…`, prune.
2. `the report carries no human step` (test): `postFilled` → the report's body matches no `/Human step/`; `Worktrees left:` still listed.
3. `a retry after a lost report posts only the report` (test): `postFilled` → with a steps thread already open on the ticket, one report and still one steps thread.
4. `a second report is refused` (test): `postFilled` → called twice, the second throws `DeckRefusal` naming the first report's id.
5. `every main-line shape still yields its step` (test): `stepsOf` → the five `mainStep` wordings of today, one per land line.

Rewrite check: any builder giving these steps in this order keeps 1, 5; any fill keeps 3, 4.
Misses: how the thread reads to a user who skims; QA's walkthrough reads it.
